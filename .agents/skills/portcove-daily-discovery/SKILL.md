Read [the daily investigation contract](../../../docs/DAILY-PORT-DISCOVERY.md).
Apply its current #1422 owner amendment and the
[upstream-first ownership boundary](../../../docs/CATALOG.md#integration-ownership)
when investigating routes: a useful limited integration, upstream dependency or
product deferral can replace disproportionate downstream engineering. Discovery
does not authorize implementation or reversal of deferrals.
Use the existing portcove-roadmap skill for canonical intake and readback.
Run the maintained `node scripts/daily-discovery.mts plan`, then `run` in the
clean, detached dedicated metadata checkout. Start `run` with `exec_command`
using `tty:true`, `login:false` and the installed Vite+ Node environment. Retain
its `session_id`; send protocol operations with `write_stdin` to that same
process. A piped/noninteractive `run` is refused before Git or API work.
Keep that foreground session open
through collection, research, separate review, delivery and explicit `finish`.
Use the structured protocol and completion criteria in the contract; `status`
reads the latest receipt. Recover retained candidate identities before new intake.
Ordinary delivery uses scoped affected-issue checks. An unchanged finish retains
the complete inventory guards and records doctor `not_run`, scope `none`; neither
receipt proves a historical full-doctor acceptance requirement. Full doctor is
for substantial Roadmap changes or release readiness, without a periodic audit.
Use GPT-6.1-Sol Medium for scheduled collection and research, with a separate
GPT-6.1-Sol High non-writing review of proposed writes. Ordinary and cold budgets
are selected by the runner. Retain an explicit continuation when work does not fit.
The one permitted count-drift recollection spends the existing delivery reserve
for one complete replacement inventory; it does not start a new delivery budget.
This workflow researches metadata and applies authorized neutral intake or
material factual updates. It does not implement, install, admit, qualify or
publish ports, change release commitments, reverse deferrals or assign work.
