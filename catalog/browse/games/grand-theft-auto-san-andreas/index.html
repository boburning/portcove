Setup

  1. Prepare your installed PC game

    Keep your installed PC Grand Theft Auto: San Andreas data outside the San Andreas Unity player folder. In San Andreas Unity, use Change path to GTA to select your installed game folder. The project focuses on free exploration and multiplayer. Expect its own menus and modes.

  2. Start an existing Windows or Linux copy

    Keep the executable, Unity libraries and SanAndreasUnity_Data together in a writable folder. On Linux, the v4.0 ZIP may need owner read permission on files, owner access on directories and execute permission on SanAndreasUnity.x86_64. In Portcove, select SanAndreasUnity.exe on Windows x64 or SanAndreasUnity.x86_64 on Linux x64. Choose that folder as the working directory, review the registration and select Play.

Setup notes
Keep your desktop settings
Preserve config.user.json from the directory you start the player in. Also preserve the active Unity user profile and any local Data folder, plugins or mods you use.
Android preview and Mac source
The Android v4.0 APK is an ARMv7 debug build and requires a device that can run 32-bit apps. It needs your installed PC game data and keeps its settings in the app’s user data. For Intel Mac and Apple Silicon, refer to the upstream Unity source build instructions. Compatibility for each Mac architecture still needs to be verified.

Limitations and evidence

  • Keep your original game, working folder and actual user profile before updating or replacing the player. You and upstream own the separate copy.
  • The upstream menu and app icons use Grand Theft Auto: San Andreas cover art. You need your own installed PC game for its game data.
