Setup

  1. Get the matching arcade files

    Use your own Cyberbots: Fullmetal Madness (Europe 950424) arcade ROM set (`cybots`).

  2. Set up the game in the collection

    Extract the complete package for your system. Open CPS-2 Recomp and select the ROM folder on its Games page. Pick the game and press Play.

  3. Start the prepared game again

    Choose Play in CPS-2 Recomp. On desktop, a frontend can call the collection launcher with two arguments, `--play` and `cybots`. Open the launcher without arguments to change the ROM folder or settings.

Setup notes
Linux ARM64 and Android
For Linux ARM64, use CPS2Recomp-linux-arm64.tar.gz and run cps2recomp-launcher. On an ARM64 device running Android 9 or later, install CPS2Recomp-android.apk and use Games → Add ROM sets. Get both packages and their checksums from the upstream release page.
Find saves and update the collection
Use Your files → Show in the launcher to find the actual launcher and game folders. With portable.txt beside the launcher or Mac app, the collection uses user/ there. Keep your settings, saves and the working package before replacing it. The shared launcher offers updates. Leave its files together and manage them outside Portcove.
