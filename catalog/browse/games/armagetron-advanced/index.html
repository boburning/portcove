Setup

  1. Choose the game client for your computer

    On Windows, run the official 32-bit client installer. The stable Launchpad release also offers a 32-bit client ZIP. Extract it completely and run armagetronad.exe from that folder. On Linux, choose the x64 or x86 AppImage, make it executable, and start it. If FUSE is unavailable, try starting it with --appimage-extract-and-run. You can also install the Flathub edition through your app manager. On Intel Mac, follow the publisher’s current macOS requirements, mount the official disk image and copy the complete Armagetron Advanced.app into Applications. The download page has a separate section for dedicated servers.

  2. Set up your rider and try a local game

    On first launch, choose a language, set your name, color and controls, and select Accept. Follow the welcome screen to enter the first local match against a computer rider.

  3. Keep your profile before switching packages

    Close the game and copy the folder containing your profile, including var/user.cfg and any custom maps or resources. Check %APPDATA%/Armagetron on Windows, ~/.armagetronad for the Linux AppImage, or ~/Library/Application Support/Armagetron Advanced on Mac. If your build uses a different location, keep that profile folder instead. To restore settings for the same release, close the client and copy your backup into the profile location it uses. Keep the backup until you verify the settings.

Setup notes
Check Apple Silicon and Android availability
The publisher lists its Intel Mac client for use on Apple Silicon through Rosetta. Use the complete Intel app as supplied. The stable download page does not offer an Android client.
