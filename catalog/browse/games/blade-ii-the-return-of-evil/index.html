Setup

  1. Check your original game files

    Provide your own XCI and prod.keys, or extracted ExeFS and RomFS. The project’s example uses title 01009cc00e224000 with update v131072. Other accepted versions are unconfirmed.

  2. Follow the project’s setup

    Follow the Mac source guide to prepare the game modules and shaders locally, then use mac_app_blade.sh to create an app or disk image. The project has no published player package.
