Setup

  1. Keep your installed PC game

    Keep your own complete PC installation of Mercenaries 2: World in Flames, with its data\vz.wad file. The beta finds an EA app, Origin or EA Games installation and reads it in place. If it cannot, add an install line with the quoted path to that folder to m2-alpha.toml beside m2-beta.exe, or pass --install and that path.

  2. Keep beta settings and progress

    Keep m2-alpha.toml and the m2-alpha save, autosave and catalogue files. The beta checks its working directory and then the executable folder for settings. Saves go beside the settings file it finds, or beside the executable. Preserve that location and your original game before replacing the beta.

Limitations and evidence

  • The project publishes no licence, and the program bundles third-party libraries without their licence notices. Portcove downloads it only from the project’s own releases. You need your own installed PC game.
  • A plain launch can join a Mercenaries 2 invitation on your clipboard. For solo play, remove any old game invite from the clipboard before opening the beta.
  • The initial town and gameplay systems are part of the upstream beta. The publisher describes the rebuild as still in development.
  • The beta needs the Microsoft Visual C++ 2015-2022 x86 runtime and a Windows PC that runs 32-bit apps.
  • Movies play only when FFmpeg is installed on your PATH or named by the M2_FFMPEG environment variable.
