The release bundles modified Spelunky game data. Portcove needs an exact record of the applicable game-data permission and notices before offering Download. The setup guide covers a copy you already have permission to use.

A release may contain research reports rather than a playable package.

Setup

  1. Start the Windows or Linux package

    For a copy you already have permission to use, on Windows x64 extract the complete x86_64 ZIP and open SpelunkyClassicHD.exe from its folder. On Linux x86-64, allow the AppImage to run as a program and open it on a system with FUSE support.

  2. Keep your settings and scores

    Close the game before backing up the SpelunkyClassicHD profile under %LOCALAPPDATA% on Windows, or under $XDG_CONFIG_HOME or ~/.config on Linux. Keep settings.json and spelunky.ini. If you use the publisher’s portable mode on Windows, back up the profile files from the extracted game folder.

Setup notes
Set up Windows N media components
Both Windows builds need Media Foundation. On Windows N, install Microsoft’s Media Feature Pack in Optional features and restart before opening the game.
Use a sibling package from the same release
The publisher offers a Windows 11 on Arm ZIP and a native Linux ARM64 ZIP. On Linux ARM64, extract the complete ZIP, keep assets beside SpelunkyClassicHD, and run it from that folder on a system with glibc 2.34 or later, libstdc++ with GLIBCXX_3.4.30, OpenSSL 3, OpenSSL-backed libcurl.so.4, X11, and OpenGL.
Find the Android build
The same release includes an Android APK for ARM64, ARMv7 and x86-64. Follow the publisher’s Android setup and keep its data separate from desktop copies. This release has no Mac package.

Limitations and evidence

  • The release includes modified original game data. Portcove Download is held while its exact permission and notice record is unresolved.
  • Before changing Windows portable mode or replacing an extracted copy, back up the files from the mode you already use.
