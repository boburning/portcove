Setup

  1. Complete the exact owned-ROM setup upstream

    Use a complete copy and components you are independently permitted to use. Supply your own Japanese Doraemon3 N3DJ revision0,16MiB big-endian .z64 ROM. The selected README identifies SHA-256 410f99bdd58795639da272c9be9d1ab8c35b61f24f7c1fb92f7e83e1069a2602. The actual native loader checks file size0x1000000 and XXH3-64 F3BFFF0C58827510; that is a compatibility check, not a demonstrated SHA-256/entitlement check of supplied data. The ROM is not included. Convert other representations and complete any upstream generation/build outside Portcove; no ROM, BIOS, compiler or helper is acquired or run by this registration.

  2. Select the documented direct Windows player

    Keep the entire creating writable Windows folder with matching DLLs, assets and notices. Place the supported .z64 beside Dora64-3.exe, choose that native executable and its containing directory, and use no arguments. Windows wmain rejects extra arguments and discovers the matching adjacent ROM; do not use the private ROM/run-directory diagnostic interface, research probes, Android package or Linux setup script. Review and consent to the exact executable/CWD/arguments, then request Play separately.

  3. Close the game before changing files

    The native entry calls the pinned runtime in-process and waits for its game/event/saving threads before returning. The documented reset restarts the game in the same window; it is not a new Core orchestration path. Upstream/user owns preparation, replacement and recovery. Close the actual player normally, keep a separate working runtime/data backup, perform upstream maintenance, then review/relink changed selected bytes. Removing registration preserves external files; Portcove offers no external update, backup, rollback, migration, deletion or cross-version save guarantee.

  4. Check platform and content requirements

    This guide concerns Windows10/11 x64 and the selected direct entry only. Linux glibc2.43 and the Android README APK versus published ZIP discrepancy remain separate. GPL3-or-later project and runtime/component terms do not grant ROM or original/extracted assets; localized wordmarks/artwork retain their own provenance and permissions. Use only actual material you are permitted to use. Upstream gameplay/autosave/translation claims are not Portcove observations.

Preserve local saves and every settings file
