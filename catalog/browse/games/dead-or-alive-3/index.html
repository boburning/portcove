Setup

  1. Complete the USA title’s supported preparation upstream

    Use only an already completed DOA3 native copy and components you are permitted to use, with your own unmodified Dead or Alive 3 USA (En,Ja) Xbox disc. The inspected USA importer accepts XISO at game-partition offset zero, .xiso.iso, or the original full .iso with a supported game-partition offset. It requires title 0x54430001 and default.xbe of 3,928,064 bytes with upstream FNV-1a64 value A2F3BDCB2A5B02D4; this is not a cryptographic full-disc certificate. Other regional builds are distinct; do not use the Japan player or inherit USA save compatibility.

  2. Attach the completed supported Windows native entry

    Finish upstream extraction into assets/ before attachment. Select the USA copy’s DOA3.exe, its containing directory as working directory and no arguments. The inspected main ignores arguments, anchors its working directory to the executable, loads assets/default.xbe and calls the translated game entry in the same process. Keep the complete matching runtime and companions together; do not select a build tool or another Xbox game’s entry.

  3. Retain one runtime replacement owner

    Review and consent to the exact selected executable, working directory and empty argument list, then choose Play separately. You and upstream own preparation, Check for Updates, runtime replacement and recovery. Complete update/restart operations outside the attached session, close all players and companions, preserve the old working copy separately from the updater’s disposable .old file, then review and relink changed selected bytes. Removing registration preserves every external file. Portcove supplies no external update, backup, rollback, conversion, migration or deletion.

  4. Use permitted content and check feature limits

    Preserve the project MIT and separate component notices. Their grants cover their own code, not Tecmo or Koei Tecmo original-game content; your original-disc and other component permissions remain separate. This guide offers local completed-copy launch. Online matches, router/firewall changes, account setup and cross-version save behavior are outside its evidence. Upstream claims of complete gameplay are not Portcove observations.

Setup notes
Preserve original, package and profile data separately
Keep original disc images and the complete assets/ folder beside the executable, together with doa3_settings.ini, doa3_input.ini, doa3_log.txt when enabled, mods, caches, unknown files and every custom root. The USA save root defaults to %LOCALAPPDATA%/DeadOrAlive3, with TitleData/, UserData/ and Cache/; if the platform path is unavailable the inspected runtime falls back to SaveData/ in the current directory. Preserve all actual roots, backups and creating runtimes; the Japan build uses a separate DeadOrAlive3_JPN root, and no save conversion or compatibility is certified.
