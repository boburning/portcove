Setup

  1. Finish upstream setup in a permitted copy

    Use your existing permitted Windows copy with its own upstream instructions. The installed edition uses the upstream installer; the portable ZIP has no installer and includes DantesInfernoLauncher.exe, the native player and an original-disc importer. Choose DantesInfernoLauncher.exe with its folder as the working directory when registering it. Save launch details first, then choose Play separately.

  2. Import your own original through the launcher

    In the portable launcher, choose Play and deliberately accept its ISO import prompt, then select your own supported Xbox 360 Dante’s Inferno ISO. The launcher runs its bundled extract-xiso into the selected game-data directory. Portcove never invokes that tool during discovery. Keep the ISO and game data recoverable. The package’s bundled title-update patch and imported originals share game; do not overwrite a new package’s patch by copying an old whole game folder without upstream guidance.

Setup notes
Keep upstream updates and your data together
The installed edition can offer and launch its own update installer. The portable launcher opens the upstream release page and asks for a manual portable update; it does not silently self-replace. Close the game, keep the old copy, and back up userdata, dantes_inferno.toml, dlc and your imported original data before following the matching upstream route. With portable.txt present, normal saves/cache use userdata. Without portable mode, including normal installed copies, the default live profile is Documents/dantes_inferno; if Documents is blocked, the player can fall back to the dantes_inferno folder under LocalAppData. Back up the actual live profile, plus any custom game-data/profile locations. Portcove leaves the external files untouched and supplies no managed Update, Backup or Rollback.
