Setup

  1. Use the exact original files

    Use your own Final Fantasy IX (USA, Canada) (Rev 1) four-disc set (SLUS-01251, SLUS-01295, SLUS-01296, SLUS-01297), each disc with its single data track, and your own retail SCPH-1001 BIOS. Portcove checks the files and builds the player.

Limitations and evidence

  • Portcove checks each disc's data track and track count. Keep every disc intact.
  • Native build, disc switching, gameplay and save compatibility remain unobserved.
