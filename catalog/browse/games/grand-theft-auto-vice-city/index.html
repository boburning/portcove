Setup

  1. Use your existing player for this game

    Use an existing reVC copy you are permitted to use with your own original PC Grand Theft Auto: Vice City assets. Select reVC.exe on Windows or the native reVC executable on Linux and use that game’s root folder as its working directory. Keep its renderer/audio dependencies and data together. The other game’s executable, console originals and Definitive Edition are not substitutes.

  2. Keep saves and settings with the working copy

    This game-specific reVC_1.0 README places user files (saves and settings) in the game root and uses reVC.ini. Back up the complete working game folder and any custom user-file location before an upstream update or modification. Do not assume compatibility with original-game or other fork saves. Portcove preserves external ownership and supplies no managed update, backup or rollback.

  3. Preserve the archived implementation identity

    Grand Theft Auto III and Vice City share an archived source repository but use separate players and game data. These instructions cover an existing copy you are permitted to use. Portcove does not supply a new binary, establish a code-licence grant or build and repair this archived engine.
