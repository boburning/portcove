Setup

  1. Check the required game files

    Use your own base 01.00 decrypted CUSA01073 directory with eboot.bin, sce_module and sce_sys; no update merged. Extract owned PKG using a recent extractor. Game files remain required at runtime.

  2. Follow upstream setup

    Use the README’s recommended Ratchet-Clank-port-x86_64.AppImage and its adjacent sha256 file. Select your game folder in the launcher; the first start prepares an image and shader caches. Alternatively, build with build.sh and the optional GTK4 launcher. Preserve ~/.local/share/ratchet-port for saves and cache. Only one copy can run at once because they share /tmp/.racS.

Limitations and evidence
