Setup

  1. Use the matching original game

    Use your own Quake III Arena baseq3/pak0.pk3 and the matching official patch PK3s (pak1 through pak8). Team Arena additionally requires your own missionpack/pak0.pk3 and matching missionpack patch files; Arena alone is not the expansion. Preserve the original installation; prepare a separate working data copy.

  2. Prepare upstream and select the player

    Use the official ioquake3.org Get It page and player guide to obtain the complete Windows player folder, then prepare baseq3 and missionpack as documented. The official guide names ioquake3.x86_64.exe. On Windows, register that player with its working ioquake3 folder. Select the expansion with three separate argument lines: +set, fs_game, missionpack. There are no GitHub releases in the inspected inventory; the official website provides the download. The package bytes and CPU header were not verified by this research because the download transport returned HTTP 403.

  3. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Select the game executable and its working folder, and put each launch argument on a separate line. Choose Play separately when you are ready. You manage this game’s files, originals, saves and settings. Removing its registration leaves those external files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Close the game and keep a working copy and every data and profile folder before changing versions.

  4. Choose the official ioquake3 build

    Use the Linux or macOS artifact from a successful push build on the official ioquake/ioq3 main branch. On Linux x86-64 keep the unpacked player and its companion files together. Select ioquake3 and its containing folder. On macOS 11 or later keep the complete Intel or Apple Silicon ioquake3.app and select Contents/MacOS/ioquake3 and its containing folder. Enter +set, fs_game, and missionpack on separate argument lines. To keep a private player profile, add +set, fs_homepath, and the absolute profile path on separate lines. Keep the actual profile, game data, mods and settings under external ownership.

  5. Set up the correct game data

    Place your original Quake III Arena baseq3 PK3s and Team Arena missionpack PK3s in the corresponding baseq3 or missionpack directories in the ioquake3 data root. Start Team Arena with +set fs_game missionpack.

Setup notes
Keep your existing game data
Windows normally uses %APPDATA%/Quake3 for user configuration, demos, videos, screenshots and downloaded PK3s. Explicit fs_homepath settings redirect storage. Preserve the actual profile, game/mod data and working runtime before upstream updates; no server-download trust or cross-version save compatibility is inferred.
Back up the external Quake3 profile
On Linux preserve the Quake3 directories under ~/.config, ~/.local/share and ~/.local/state or their XDG overrides. On Mac preserve ~/Library/Application Support/Quake3. Keep any explicit fs_homepath and the creating engine, saves, settings and original data before replacement.
