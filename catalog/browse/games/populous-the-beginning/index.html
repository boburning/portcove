Setup

  1. Choose the Apple Silicon app

    The standard Populous TB.app uses the original software renderer. Populous TB (Direct3D).app uses your D3DPopTB.exe, and Populous UW.app needs popTBUW.exe for Undiscovered Worlds. The ZIP requires macOS 14 or later and Apple’s Command Line Tools for first launch.

  2. Prepare a writable working copy

    Make a separate writable copy of your installed GOG game, including QMixer.dll, WEANETR.dll, and the data, levels, sound, and fmv folders. Choose that folder in the app. Compare the executable and libraries to the tested hashes in upstream’s guide. For Direct3D, see the D3DPopTB.exe hash in the tagged runtime source. The app builds locally from your copy and can also unpack the owned GOG offline installer with its companion files.

  3. Back up the actual save directory

    Keep save from the chosen working folder and retain your original files. The apps share ~/Library/Application Support/OpenPopTB for the remembered directory and generated code. Before selecting an installer again or changing variants, back up the active save folder and any app-extracted Game folder. Use the upstream release when replacing the app.

Setup notes
Check the Direct3D original
The D3DPopTB.exe hash is listed at https://github.com/iagodemacedo/OpenPopTB-MacOS/blob/e888d11ddb4810758c33d55bd6e0a7144e804409/runtime/prepare.c#L350.

Limitations and evidence

  • Installer extraction can replace the shared Game folder. Keep separate working folders for variants when you want separate saves.
  • The exact downloadable package is Apple Silicon only. Multiplayer is still in development.
