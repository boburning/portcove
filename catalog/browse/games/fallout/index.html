Setup

  1. Use the actual Community Edition player

    Keep a complete already permitted Fallout Community Edition 1.1.0 Windows x64 copy and its supported original Fallout installation. Upstream documents fallout-ce.exe as the drop-in player in that game folder. Select it directly, not the original DOS/Windows executable, installer or another mod engine. Native Windows entry runs the game in the selected process; it uses the shared GNW95MUTEX and can decline to start when another such instance exists.

  2. Prepare original data with upstream tools

    Finish the upstream setup using your own complete supported original game installation, with original master.dat/critter.dat, patch/data/music and all other necessary files. Keep the whole working game and data rather than reconstruct a guessed minimal folder. Start/quit upstream normally before registration. Portcove does not import or authenticate those originals or private outputs.

  3. Preserve the established working directory and config

    Select the actual game folder as working directory and preserve supported existing literal arguments. Windows entry does not change directory for you. fallout.cfg is located using the executable path; actual master/critter DAT, patch and music locations can be relative or custom absolute paths. Keep the exact established paths rather than rewriting a host root or forcing a new portable profile. Review consent and choose Play separately.

  4. Keep the separate license and asset boundaries

    The selected engine uses Sustainable Use License 1.0, not GPL/MIT. Its personal/noncommercial/internal-business scope, free noncommercial distribution conditions and notices remain applicable. This guide adds no general commercial, original-asset, mod, repackaging or redistribution grant; attach only a copy you are already permitted to use.

  5. Update the game and remove its registration

    Close every running copy before changing external files. You manage setup, game replacement, profile changes, data migration and recovery. Keep the working game version and every data folder, update it with the project’s tools, then review and select the changed executable before choosing Play. Portcove monitors only the process you selected and agreed to launch. It does not prevent other copies from running, restrict file access or take over unrelated helpers or replacement processes. Removing the registration leaves external files in place. This route does not offer Portcove downloads, setup, updates, backups, rollback, data migration or deletion.

Setup notes
Keep all actual save and data roots
Preserve the complete external runtime/original data, fallout.cfg, actual master_patches/data root including SAVEGAME and slot contents, music, mods, screenshots/logs and unknown files. Retain every configured external root and old creating copy; another executable directory alone does not prove save or instance isolation. No arbitrary Fallout mod or cross-version save compatibility is established.
Use the upstream Linux or Mac player
The Linux x86-64 tarball contains fallout-ce and needs SDL2. The Mac disk image contains an app for Intel and Apple silicon. Use the tagged project instructions to put the player with your original Fallout data. The featured Portcove registration instructions above are for the prepared Windows player.
Use the Android release from the project
The upstream APK includes ARM64, ARMv7, x86 and x86-64 builds. On first launch, choose a folder with your original master.dat, critter.dat and the data folder. Open the same app again to use the imported data. Its release profile is under Android/data/com.alexbatalov.falloutce/files on typical Android devices. Debug builds use a separate profile. Keep the actual profile when updating.
