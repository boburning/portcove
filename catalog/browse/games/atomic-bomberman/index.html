Setup

  1. Start the Atomic Bomberman player

    Use atomic.exe from the v1.0 modern Windows x64 ZIP or atomic from the modern Linux x86-64 tar.gz. Choose the player package. The dedicated server is a separate program. The player can generate free assets without original files.

  2. Check Linux graphics and libraries

    Use an OpenGL 3.3 driver, glibc 2.38 or later, and libstdc++ with GLIBCXX_3.4.31. SDL3 is built into this Linux package.

Setup notes
Use original assets if desired
Follow upstream to import from your own copy of Atomic Bomberman. Preserve the original files and the SDL profile, normally ~/.local/share/atomic-bomberman-modern/atomic on Linux or %APPDATA%/atomic-bomberman-modern/atomic on Windows. Free assets can fall back to the player working directory when the profile is unavailable.

Limitations and evidence

  • Keep the whole effective SDL profile, imported assets and custom files before updating. A second copy normally shares the same user profile.
