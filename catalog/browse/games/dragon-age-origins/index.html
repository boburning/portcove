Setup

  1. Check the required game files

    Use your own Xbox 360 Dragon Age: Origins disc with title ID 454108C0, media ID 186A1115 and English/Italian/Spanish content, or matching Ultimate Edition disc 1. Supply your own TU6/TU7 and DLC separately if using them.

  2. Follow upstream setup

    Follow upstream setup with your own ISO. DAORecomp.exe downloads tools, translates the game and builds it locally; upstream estimates 30–60 minutes. The source setup uses install.py. Portcove does not install or build this project automatically.

Limitations and evidence

  • Upstream describes renderer, input and DLC features, with experimental upscaling and frame-rate options. Full-game and hardware compatibility have not been confirmed by Portcove. Linux setup requires Wine or Proton, and upstream calls Linux support untested; it does not produce a native Linux game.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
