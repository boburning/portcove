Setup

  1. Choose the package for your system

    Keep the complete Windows ZIP contents together. On Linux, make the extracted file executable and use glibc 2.38 or newer with SDL3 and zlib. On macOS 11 or later, extract the app. See the publisher’s packaged guide for the first open of the unsigned app.

  2. Provide your own game files once

    Start the program and choose your decrypted 88888 folder or a ZIP of that folder. The program checks the files before copying them into your user data folder.

  3. Play again and change settings

    Start the same game under the same user profile. On Windows and macOS, use the game’s settings window. The Linux package has no settings window or background music.

Setup notes
Find saves and settings on Windows
Keep the game’s data under %APPDATA%\iPod Mini Golf.
Find saves and settings on Linux
Keep the game’s data under $XDG_DATA_HOME/ipod-mini-golf, or ~/.local/share/ipod-mini-golf.
Find saves and settings on macOS
Keep the game’s data under ~/Library/Application Support/iPod Mini Golf.
Update the program
Get new versions from the upstream release page. Preserve your user data folder before replacing the program files.
Set up Mini Golf on Android
Download minigolf-1.0.1-android.zip from the upstream release. Install minigolf.apk on an ARM64 device with a gamepad and place your 88888 folder in /sdcard/Android/data/org.ipodrecomp.minigolf/files/88888 before opening the game. Saves and settings live in the app’s files folder. Back it up before removing an installed APK.
