Setup

  1. Download and unpack the setup kit

    Extract the complete official ZIP for your system into a separate writable folder. On Linux, follow the kit’s requirements for CMake, Ninja, Python 3 and a C/C++ compiler. Use Linux tools for the Linux build.

  2. Supply the matching original files

    Follow the upstream guide for the version you downloaded. Use your own original in its supported image representation, keeping a CUE and every referenced track together when required, and supply your own BIOS whenever that guide requires it. For Europe SLES-02529, keep its matching SBI beside the CUE with exactly the same basename; upstream setup checks and retains it. Use the documented SCPH-5502 or SCPH-5552 Europe BIOS and preserve the referenced disc tracks.

  3. Build the game and add it to Portcove

    Open the project’s launcher and follow its build instructions. Keep the completed game with its required program and compiler files. In Portcove, select the completed program or supported launcher and its start folder. Save the details, then choose Play.

Setup notes
Updates and backups
Keep a working copy and its data before changing versions. Use the project’s tools for updates and back up your original files, saves and settings yourself.

Setup

  1. Check the required game files

    Use your own Resident Evil 3 USA SLUS00923 CUE/BIN with raw 2352-byte sectors. A 2048-byte-sector ISO is rejected because it lacks the required audio and video. This guide does not include the exact accepted hashes; check this game’s project requirements before setup.

  2. Follow upstream setup

    For a source build, follow the project’s build.ps1 -Regen -DiscPath instructions with your own disc, then its launcher build.ps1 instructions. The ZIP launcher also documents InstallGame with your own CUE. Version v1.7 generates its cache from the disc and documents fallback and background toolchain use. This guide does not establish an accepted package.

Limitations and evidence

  • This is experimental RE3 work. Earlier claims of fully static translation and 60 FPS were corrected. An older cache used interpretation for a measured 0.03–0.15% over four sessions totalling 20 minutes. That historical result does not establish no fallback or full-game compatibility.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
