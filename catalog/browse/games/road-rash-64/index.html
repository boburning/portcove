Setup

  1. Use the complete Windows package

    The managed Windows route keeps RoadRash64Recompiled.exe with its official assets, libraries and importer tools, and prepares your matching USA v1.0 original through Core.

  2. Run a permitted experimental Linux copy

    For a permitted v1.5.0 experimental Linux x64 copy, extract the complete ZIP to a writable folder and make the AppImage executable. Use an AVX-capable CPU, a Vulkan driver, glibc 2.35 or later and libstdc++ with GLIBCXX_3.4.30. Open the AppImage, choose Select Game ROM with your own Road Rash 64 USA v1.0 original, then Start Game.

  3. Keep optional setup with the game

    Optional texture, character and Mario Kart 64 course imports remain deliberate upstream features. Follow the included guide and supply an extra original only if you choose that feature. Portcove does not discover and run the DirectStart or importer helpers automatically.

  4. Register a separately prepared Road Rash player

    For a separately prepared or customized upstream copy, select the completed player in its own stable folder, save launch details, then choose Play separately.

Setup notes
Preserve optional Road Rash imports before replacement
Close the game and importer before replacing a runtime. Preserve the complete local race-packs folder, including import jobs and previous-pack backups; custom external course-pack folders require a separate backup.
Back up the Linux profile and adjacent files
Close the game and importer. Keep ~/.config/RoadRash64Recompiled or the profile you selected through APP_FOLDER_PATH, plus music and race-packs beside the writable AppImage. For an already working normal AppImage launch, select the AppImage and its containing folder when adding it to Portcove. If FUSE is unavailable, upstream provides APPIMAGE_EXTRACT_AND_RUN=1 for manual launch.
Keep your current copy while changing routes
A historical managed v1.4.3 copy retains its accepted definition and data locations. Keep it usable while a supported transition is unavailable.
Keep external Road Rash replacement and data ownership
Upstream or you provide that external copy’s runtime updates; Portcove registration removal leaves every external file untouched and does not grant managed Backup or Rollback.
