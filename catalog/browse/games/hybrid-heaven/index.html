Setup

  1. Supply your original on first Play

    Choose Play. First launch asks once for your own ordinary USA Hybrid Heaven cartridge dump (upstream SHA-1 16dbc21620b52deab5c5abf8a309ac60adfbee85). The game checks it and copies it into its own profile, then offers Start Game. No decompression or converter is needed. Keep your original separately.

  2. Keep the complete package

    For a copy you manage yourself, keep the complete upstream package in a folder you control and start HybridHeavenRecompiled.exe on Windows or HybridHeavenRecompiled on Linux from that folder, with assets beside it. To add that copy to Portcove, select the player and its folder; removing it from Portcove leaves every file in place. Android APK installation remains an upstream device setup route.

Setup notes
Keep the game profile when updating
Close the game and back up its profile before changing versions: normally %LOCALAPPDATA%\HybridHeavenRecompiled on Windows or ~/.config/HybridHeavenRecompiled on Linux. A copy with portable.txt uses its own folder instead, and a Linux copy started with APP_FOLDER_PATH uses the folder that variable names. The profile holds the copied original, settings, saves and mods. The game can import a compatible save through Settings → Saves before starting; its existing save is kept as hybridheaven.us.bin.pre-import.bak. Controller Pak .mpk files are not accepted by that importer. Check progress in the new copy before retiring the old one.

Limitations and evidence

  • The package includes Chiaro fonts by Fontworks that the project license does not cover, and fan-made launcher background and icon artwork credited in the project README. Portcove downloads the package only from the project’s own releases. You need your own original game files.
  • Portcove has not observed native setup, gameplay or saves. On Linux the player needs a Vulkan driver, SDL2 and GTK 3.
