Setup

  1. Prepare your DOS game files

    Use a complete installation of the original SEAL Team. Keep st.exe, the LIB and FNT files, and the sound drivers together. The port reads data from st.exe and the companion files. Keep your original installation as a separate copy.

  2. Set up Windows or Linux

    Extract the matching archive into a writable folder. Copy the DOS installation files into the Game folder next to the native player. Select sealteam.exe on Windows or sealteam on Linux and use its containing folder as the start folder. The 0.6.1 Linux x86-64 player requires glibc 2.35 or later.

  3. Set up an Intel or Apple Silicon Mac

    The universal ZIP requires macOS 11 or later. Extract it, move SealTeam.app to Applications and open it once to create and reveal ~/Library/Application Support/SealTeam/Game. Copy the DOS files into that Game folder and reopen SealTeam.app.

Setup notes
Keep your settings and game files
On Windows and Linux, preserve the Game folder and sealteam.cfg next to the native player. On Mac, preserve ~/Library/Application Support/SealTeam, including any Game folder there. If you selected a different original-data folder with --data, keep that folder separately. Keep a working copy before replacing the runtime.

Limitations and evidence

  • The publisher's packages contain the source port only. Campaign, practice and demo modes all use files from your DOS installation.
  • The macOS package is ad-hoc signed and lacks Apple notarization. Follow the publisher's Mac setup instructions if macOS asks you to review the app.
