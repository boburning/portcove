Setup

Use an existing copy you are permitted to use and select its exported game executable, with that game folder as the working directory. Keep its companion data files together. Current releases are RAR archives; Portcove does not extract RAR. Older ZIP releases do not resolve the separate bundled-artwork question.

  2. Use your own recognized Super Mario World ROM

    Place your own baserom.sfc in the SuperMarioWorldRemastered user-data folder shown by the game’s ROM screen. Its checker accepts specific USA, Japanese and European SNES hashes, including some headered variants; an additional accepted hash has no independently established edition here. This gate checks the ROM but does not extract or establish permission for the already bundled sprites/music. Use upstream’s exact recognized edition; no Core original-file receipt is claimed.

Setup notes
Preserve the shared profile before switching forks

Back up that actual Godot profile with both games closed before switching, and keep each working runtime; save compatibility between forks is unqualified. The game normally uses %APPDATA%/SuperMarioWorldRemastered on Windows and $XDG_DATA_HOME/SuperMarioWorldRemastered or ~/.local/share/SuperMarioWorldRemastered on Linux.   2. Keep artwork and original-file permissions separate

  3. Use the exact upstream ROM gate

    Place your own recognized SNES ROM at baserom.sfc in the SuperMarioWorldRemastered user-data folder shown by the ROM screen. The gate checks the file hash; it does not extract or license the already bundled artwork/music.

Startup creates settings when missing and verifies/rewrites existing settings; save creation/replacement and the in-game delete action can overwrite or remove a campaign slot. Keep recovery copies outside the active profile.

  5. Keep parent and fork data recoverable

    The independently checked parent configuration and the existing Remastered Plus record select the same SuperMarioWorldRemastered custom user directory. The exact packaged filename and release-ZIP layout have not been established here; do not select a Godot editor, console/helper wrapper or installer.   7. Keep updates and external data upstream

    Close the game completely before replacing, relinking or removing an external copy. Upstream and the user own the runtime, companion files, custom packs and all player data.
