Setup

  1. Build your game once

    Extract the package. Put your own supported GTI Club 2 JAB (Corso Italiano) or EAA (Driving Party) game files and the kviper board files in roms (941b01.u25 and the ds2430.u3 EEPROM). Include the matching CHD and NVRAM files listed by the project. Run viper-setup.exe on Windows or viper-setup from the package folder on Linux or Mac. Setup builds a player from the files it recognizes.

  2. Open the generated player

    After setup succeeds, open the player for your original. gticlub2 for JAB or gticlub2ea for EAA. On Windows the player has an .exe extension. Open the same player on later launches. Use Options for settings. The --classic option starts the arcade mode.

Setup notes
Keep saves when replacing the package
Keep the NVRAM saves and settings beside the generated player, including its separate enhanced and classic saves. Back up that folder before replacing the release, then run the upstream setup again for the new version. Portcove does not replace the generated runtime or back up its data.
Use the upstream command line
For the default release variant, run viper-setup --prepare --roms with your original-files folder followed by gticlub2. Watch the progress lines and wait for success. Then viper-setup --play gticlub2 starts the generated player and returns its exit status. Exit code 66 means the upstream setup has no built game for that variant.

Limitations and evidence

  • The release package contains a builder. You supply the original game files and board BIOS.
