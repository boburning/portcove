The publisher packages include game data from several original releases. Use the setup guide for a copy you already have. Portcove can offer downloads after the bundled game data is cleared for these packages.

A release may contain research reports rather than a playable package.

Setup

  1. Open the Windows or Linux player

    Extract the archive to a writable folder. Keep gamedata next to the player. On Windows 10 or later, open Kens-Labyrinth.exe from the extracted folder. The publisher offers separate ARM64 and 32-bit Windows builds. On Linux, install the SDL2, SDL2_image and GLU libraries listed in the upstream guide, then run ./ken from the extracted folder. The publisher also offers Linux ARM64 and other architectures.

  2. Set up the universal Mac app

    On macOS 12.4 or later, copy Kens-Labyrinth.app from the disk image to an Applications folder you can write to, then open the copied app. The same app runs on Intel and Apple Silicon and already contains the game data and libraries.

  3. Choose a game and keep its progress

    Choose Ken’s Labyrinth 2.1 for the full Epic release. Walken is the separate 1992 prerelease and uses its own save slots. Before replacing a copy, keep settings.ini. On Linux, also preserve ~/.config/ken/settings.ini if you use it. Keep the save slots and high scores from each game’s own gamedata subfolder. The Mac copy keeps these files under Contents/Resources/kenfiles inside the app.

Limitations and evidence

  • The Linux system package can place gamedata in a system-owned directory. Use the writable portable copy for saving game progress.
