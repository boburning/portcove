The Windows and Android packages embed an initialized data block extracted from the original game, including font data. The Android package also includes an icon derived from an original sprite. Portcove Download requires permission covering these materials or replacement packages without them.

A release may contain research reports rather than a playable package.

Setup

  1. Prepare a working copy of your original data

    Copy the SQZ and TRK files from your own Prehistorik 2 DOS installation into a writable folder. Check that the folder contains SPRITES.SQZ. You can leave the old DOS executable in the original installation.

  2. Start the Windows x64 engine

    If you already have permission to use the Windows package, extract it to a separate folder and keep pre2native.exe with its _internal folder. Run pre2native.exe --game-root followed by the quoted path to your writable data copy. The packaged engine includes its Python runtime.

Setup notes
Keep your desktop settings and progress
Close the game and copy pre2native_settings.json and pre2native_progress.json from the folder you passed to --game-root before replacing that folder. Keep the runtime, your original files, and the writable data copy separate.
Run from source on Linux or Mac
This release provides no Linux or Mac desktop package. If you have permission to use the source, the publisher’s guide uses Python 3.11 or later with NumPy and pygame. Pass your writable data copy to scripts/play_native.py with --game-root.
Android ARM64 availability
If you already have permission to use the Android ARM64 package, use its folder picker to import your own SQZ and TRK files. The app stores settings and level progress with its imported copy. Verify a separate copy of pre2native_settings.json and pre2native_progress.json before clearing app data or uninstalling.

Limitations and evidence

  • Keep your original game files separate from the writable working copy.
