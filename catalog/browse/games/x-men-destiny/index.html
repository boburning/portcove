Setup

  1. Prepare your own supported original upstream

    Use your own legally obtained Xbox 360 X-Men: Destiny original. Complete upstream’s supported installation/preparation outside Portcove and retain game/default.xex plus all original textures, audio, modules and other files in their relative layout. The published installer extracts the user-selected ISO; Portcove neither runs it nor an extraction helper. No additional title-update requirement was established by this inspected source.

  2. Add the completed Windows game player

    Select the already-installed native xmd.exe, not xmd_installer.exe or xmd_launcher.exe. Use the actual installed directory as working directory and preserve the supported literal arguments established by the launcher: --gpu_plugin xenos, --game_data_root <actual installed game directory> and --user_data_root <actual user_data directory>, plus existing log/debug choices if needed. Enter each path as one literal argument. The inspected launcher spawns xmd.exe and exits, so it is not a substitute lifetime root.

  3. Review launch details, then choose Play

    Review the selected game executable, working folder and launch arguments, then agree to use them. Choose Play separately when you are ready. Adding this copy does not prepare, update or replace its external files. Removing its registration leaves all external files in place. Before changing versions, close the game and its companion programs and keep the working copy and all data. Review and select the changed executable before playing again.

Setup notes
Keep upstream maintenance outside the attached session
Upstream launcher/installer retain installation and updater ownership; Portcove attaches only an independently permitted completed native output. Close actual native player and companions before upstream replacement, retain old runtime/data and review/relink changed selected bytes.
Keep your working game and every data folder it uses
Keep the full creating installed directory, game/, user_data/, xmd.toml, effective logs, saves, profiles, mods, caches, backups and every custom root. Source installer uninstall explicitly deletes user_data; this guide offers no uninstall or deletion. Retain the installed copy and data before upstream maintenance and do not invoke that destructive uninstall as registration removal.

Limitations and evidence

  • Use only a copy and components you are permitted to use. Before changing versions, keep a copy of the complete working game, original files and every profile, save, cache, mod, backup, temporary file and custom data location. Another executable may use the same data. Portcove does not offer updates, backups, rollback, data migration or deletion for these external files.
