Setup

  1. Use your own USA raw disc

    For an existing official beta7.1 Windows copy, choose ctr_native.exe inside its extracted wrapper, with that executable’s folder as the working directory. Place your own NTSC-U raw MODE2/2352 disc BIN at assets/ctr-u.bin beside it; the data track must start at byte 0. A cooked 2048 ISO, another edition or a CUE file is not this route. No compiler, BIOS or extraction helper is needed for the official player archive. Windows runs its x86 player through x64 compatibility; upstream also offers a separate 32-bit Linux package with its own dependency requirements.

Setup notes
Prefer in-game memory-card saves
Normal saves and ghosts live under memcards. F12 captures SCREENSHOT.BMP and the VRAM debug capture uses VRAM.TGA. Internal F5 quickstates under debug/states hold runtime memory and are tied to their creating build; replay reports under debug/reports can include independent recorded memory-card progress. Keep the old runtime with those files for matching-build use; do not insert them into another version.
Keep external ownership or preserve debug output before retrying
You or upstream update an external copy. Keep its complete working folder and back up memcards and captures before extracting a new player separately. Keep debug output with the originating runtime for matching-build use; no cross-version state compatibility is promised. External registration preserves every file and supplies no managed Backup or Rollback.

Crash Team Racing (CTR Recompiled)

An experimental Crash Team Racing port with critical post-race and ChangeLevel failures reported by the project. Windows, Linux and macOS setup packages use Generate & Build; exact host CPU architectures are unconfirmed. Use your own USA PlayStation SCUS-94426 CUE/BIN. The current game.toml requires data track 1 to be 605,698,800 bytes with SHA-1 1bb785082def3fe25f6b46be06d4eaf33c5bc772 and boot executable SCUS_944.26. Setup uses OpenBIOS unless you supply your own local SCPH BIOS. Original images and proprietary BIOS are not distributed. Portcove has not confirmed setup or gameplay.

Setup

  1. Finish setup in the upstream Android app

    Install this fork’s Android APK and open its Missing Assets screen. Follow its storage-permission handoff, choose Select File, and select your own Crash Team Racing NTSC-U raw BIN or supported BIGFILE.BIG. The app copies the chosen data to its own assets storage; restart the app after the copy. Do not use another region or the parent’s desktop executable as an Android package. The source targets a 32-bit Android memory model and requires OpenGL ES 3.0.

  2. Keep your data when changing versions

    Keep your original disc data and preserve the app’s saves/data before Android app replacement or removal. The Android guide describes /data/data/com.ctrnative/files/assets for picker copies and a different external assets path for manual PC/root setup; use the picker instead of guessing between them. Release Build4 adds touch controls when no controller is detected. Full-game and device coverage remain unqualified; Portcove owns neither APK updates nor its profile backup.
