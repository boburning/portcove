Setup

  1. Check the required game files

    Use your own Pokémon Colosseum GC6E01 disc image. The supplied build normally uses ISO. Its picker also lists WBFS and RVZ, but this guide has not confirmed those formats. Setup uses extracted files and 168 REL overlays; the generated module is not included.

  2. Follow upstream setup

    Extract the project’s complete colosseum-launcher-2.zip, including its launcher, runner, app-local MSVC libraries and two offline component archives with pinned hashes. On first run it extracts your own disc, generates C code and compiles a local DLL cached by DOL hash. That first-run setup needs no network connection.
