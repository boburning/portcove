Setup

  1. Download the Windows port

    Choose a release with a Windows player download. Extract the complete package and keep syphon_filter.exe with its DLLs, locales, assets and notices. A release with no attached player download cannot be used for this step. Check the project’s downloads before choosing a version.

  2. Keep your original disc files together

    Use your own Syphon Filter USA v1.1 (SCUS-94240) BIN/CUE files. Keep the CUE beside every BIN file it references. The download does not include the original game. This setup does not require a separate BIOS import or compilation step.

  3. Add the program to Portcove

    Choose syphon_filter.exe. For the documented normal launcher, use its package folder as the start folder and leave launch options empty. Check the selected program and launch options, then add it to Portcove. This does not start the game. A CMD wrapper or separate setup process is not needed.

  4. Choose Play

    Use the game’s BROWSE/DEPLOY file picker to choose your CUE file. The game checks the supported game executable itself.

Setup notes
Updates and file ownership
Portcove can launch this copy, but it won’t update, back up, restore, switch to an older version, convert, move, or delete its files. Removing it from Portcove leaves those files in place. After replacing the program, review and update its saved launch details.
Where the inspected version keeps saves and settings
For public-test.16, launcher.ini normally lives under %LOCALAPPDATA%/SyphonFilterPC; it can fall back to the executable folder or start folder. Campaign saves use SyphonFilterPC/Saves/<sanitized serial>.sav under the effective user-data folder, with backups and temporary files. That folder can fall back through APPDATA and the system temporary directory.
About the inspected download
The inspected v0.1.0-public-test.16 Windows x64 ZIP contains the player. At the recorded inspection, the later listed 0.2.0 beta and test releases had no attached player packages. This is a historical observation, not a check of today’s latest release or a recommendation to use an older test.

Limitations and evidence

  • Use only a copy and components you are permitted to use. Back up the complete working installation, original files, saves, settings, mods, generated files, caches and any custom folders before maintenance. Another program can share the same saved data.
  • Close the game and its companion programs first. Keep the working program, original disc files, saves, settings, mods and custom data before replacing or moving this copy. Different program folders can share saves.
  • For the inspected public-test.16 version, the game can move a legacy SyphonFilterPC.sav beside the CUE into its newer save location. Preserve the whole profile and all legacy save locations. Other versions may use different locations or incompatible saves.
  • Portcove will not back up or update this external installation. Back up its saves, settings and custom folders separately.
