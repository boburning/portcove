Setup

  1. Open the start menu

    Extract the ZIP and open openrts_game.exe from the extracted folder. Install the x64 Microsoft Visual C++ Redistributable if needed. The project requires a graphics driver with Vulkan or DirectX 12.

  2. Choose your RTrainSim folder

    In the start menu, set the folder of your own RTrainSim installation with routes and rolling stock. The menu remembers the folder. Return to openrts_game.exe to choose a route or save, or open Settings to change the folder.

Setup notes
Keep saves and settings
The default profile is %LOCALAPPDATA%/openRTS. If you use the project’s portable.txt marker, the profile stays beside the program. Open the profile from the project’s Settings and back it up separately. It holds viewer_state.ini, saves grouped by route and RTS_TAPES. The project’s start menu handles updates and lets you turn off checks at startup.
