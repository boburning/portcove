Setup

  1. Locate your original game folder

    Keep your installed copy of Lords of the Realm II. The engine looks for L2_maps.dat and either Lords2.exe or L2.eng to recognize the folder, and then reads the required game assets. The publisher tests with GOG’s edition.

  2. Start the player for your computer

    On Windows x64, run l2-game.exe from the extracted ZIP. It can find your installed copy or open its folder picker. It needs the Microsoft Visual C++ x64 runtime. On Linux x64, extract the tar.gz and run l2-game with the absolute path to your original game folder as one argument. Linux needs glibc 2.34 or later and libasound.so.2. The preview does not provide a Linux folder picker.

  3. Keep your save and preference files

    Back up the active saves folder with the game closed. It defaults to %APPDATA%/open-lords2/saves on Windows or $XDG_DATA_HOME/open-lords2/saves on Linux, usually ~/.local/share/open-lords2/saves. An explicit LORDS2_SAVES directory takes precedence. Keep prefs.ini and your saves together when replacing an extracted engine copy.

Limitations and evidence

  • This is the upstream preview. If you use its multiplayer option, both players need the same engine build and their own original game files.
