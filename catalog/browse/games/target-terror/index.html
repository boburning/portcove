Setup

  1. Prepare your Wii disc image

    Copy your own NTSC-U TARGET: Terror Wii disc image (RGDEA4, .iso or .ciso) into the folder beside targetterror.exe, and keep your original separately. On first start the game builds its game folder from the image, which takes a few minutes; after that the copied image is no longer needed.

  2. Allow space for the upstream import

    Run targetterror.exe and leave the console window open while first-run extraction populates game. Leave enough free space for the image plus up to about 4.4 GB of extracted files. If the first start is interrupted or used the wrong image, delete the game folder before starting again with the right image in place.

  3. Preserve the creating profile

    Keep the generated game folder, targetterror.ini and nand, including high scores, with the creating runtime.

Limitations and evidence

  • The package includes recompiled game code, icon art and bundled fonts that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • Keep the upstream folder outside the Portcove library. Close the game and its helpers before backing up or replacing the creating runtime and its data.
