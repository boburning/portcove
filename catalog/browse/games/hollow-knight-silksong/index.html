Setup

  1. Finish setup in the upstream Android app

    Install this fork’s Android APK. Supply your own Silksong Linux game files by choosing the complete folder containing Hollow Knight Silksong.x86_64, UnityPlayer.so and Hollow Knight Silksong_Data; the Windows and macOS depots are not compatible. You can copy that folder from your own PC without signing in. The app also offers optional Steam sign-in on the device. Portcove does not request or handle your account credentials. Start the app’s build and then Play; this can take substantial time on the device.

  2. Keep your data when changing versions

    Leave the selected Linux game folder on the device: the app reads it every Play and during rebuilds instead of copying the whole game into app storage. Moving or deleting it stops the game. Keep a separate save backup before updates or Steam Cloud synchronization; cloud pull/push is an optional app feature, not a Portcove data-restore guarantee. The APK is an upstream build system that downloads its toolchain and builds from your inputs, outside the native-portable replacement contract.
