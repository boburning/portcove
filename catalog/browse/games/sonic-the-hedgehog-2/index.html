Setup

  1. Supply this game’s original assets

    Before first Play, copy the supported Data.rsdk assets from your own official Sonic the Hedgehog 2 (2013) release beside RSDKv4.exe on Windows or RSDKv4 on Linux. Follow upstream’s linked mobile/Origins extraction instructions for that game. Use this game’s assets; Sonic 1 and Sonic 2 each keep their own installation and saves. No separate compiler or installer is needed for the published x64 player.

  2. Prepare the Linux x64 player

    Install the official Linux x64 player through Portcove. Before Play, put your matching original Data.rsdk beside RSDKv4 in this game’s installation folder. The inspected player requires glibc 2.38, libstdc++ with GLIBCXX_3.4.32, SDL2, OpenGL, GLEW 2.2 and Vorbis.

  3. Use Android only where legacy shared storage works

    The upstream v4-android.zip contains an ARM debug APK that reads Data.rsdk from the shared RSDK/v4 folder on compatible Android devices. Both Sonic games use the same app and folder. Use the Data.rsdk from your own Sonic the Hedgehog 2 (2013) copy. Back up the entire active v4 folder, including settings, saves and mods, before switching titles. Use the app directly on Android.

Limitations and evidence

  • For an installation managed by Portcove, compatible updates preserve the declared originals, saves, settings and mods in that game’s folder. If you register a separately prepared player, you manage its updates and backups. Back up any custom redirected save location separately.
  • The Android APK relies on legacy storage permission. If Android prevents access to the shared RSDK/v4 folder, this package has no verified alternate import path. Keep each game’s data and saves separately and use upstream’s noncommercial-use and attribution terms.
