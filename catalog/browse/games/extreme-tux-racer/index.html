Setup

  1. Install the desktop game

    On Windows x64, open the stable release folder and run ExtremeTuxRacer.msi. Then use the Extreme Tux Racer Start menu shortcut. On Debian or Ubuntu, install extremetuxracer from your distribution and open Extreme Tux Racer. On Linux x86-64 or ARM64, you can also install the community package net.sourceforge.ExtremeTuxRacer from Flathub. Use the same package source for updates.

  2. Start your first race

    Choose an existing player or select Register a new player. Choose your character and select Enter. Select Practice, choose Bunny Hill, then select Race!

  3. Keep your players and high scores

    Close the game before copying your profile. On Windows, copy the config folder in the game’s installation folder. On Linux, copy the etr folder under your configuration directory, usually ~/.config/etr. If the game uses an existing ~/.etr folder, copy that folder instead. For Flatpak, copy ~/.var/app/net.sourceforge.ExtremeTuxRacer/.etr. Restore using the same package and keep the backup until you can see your players and scores.

Setup notes
Check Mac and Android availability
The current desktop release has no Intel or Apple Silicon Mac package. The separate drodin/extremetuxracer project offers its older Android APK under release 0.8.107 on GitHub. It uses a separate profile, and device compatibility has not been verified.
