Setup

  1. Check the required game files

    Use your own Japan BLJS10220 disc, ELF and assets. Check docs/BUILD for the exact required EBOOT hash before setup.

  2. Follow upstream setup

    The v0.4.1 AppImage contains tools, public source code and optimization profiles, rather than a compiled game. Follow it to import your own Japan BLJS10220 ISO with the pinned official RPCS3 import helper, translate EBOOT and compile locally using the bundled toolchain. Your original data remains required. The first start needs the helper download unless already present, about 8 GB RAM and 8 GB free space. The estimated compile time is 15–60 minutes; the project measured 12–14 minutes on a Ryzen 5 4600H. It reuses the build until the AppImage version or CPU changes. A manual source/CMake build is a separate documented route. Portcove has not inspected a new release file or observed a build for this guide.

Setup notes
Project testing notes
In its October 25 report, the project describes the intro, title, menus, opening cutscene and manual completion of STG02, returning to mission selection. The rest of the game remains unplayed. That play test used Fedora on a Ryzen 5 4600H and GTX 1650; Arch container builds and Ubuntu 22.04 import-helper checks are separate results. Scripted STG02 v0.4.x AppImage tests averaged 47.9 guest FPS on that hardware; earlier crowded manual fights ran slower with audio breakup. An occasional untextured polygon remains. Sessions longer than about 30 minutes, clean exit on every path, ATRAC audio and a full playthrough are unconfirmed. CPU, GPU and distribution check tables do not establish equivalent gameplay; SteamOS is unconfirmed. Portcove has not confirmed setup or gameplay.

Limitations and evidence
