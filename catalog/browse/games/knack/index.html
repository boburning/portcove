Setup

  1. Check the required game files

    Use your own decrypted CUSA00068 base game and 01.10 update. Merge them using upstream’s instructions or select separate game and update folders. PKG extraction scripts require your own dumped base and update packages.

  2. Follow upstream setup

    Follow the README for v0.1.0 knack-windows.zip with Knack.exe or knack-x86_64.AppImage. Select the game and optional separate update folder, then Play. First launch prepares shaders. Windows source builds use MSYS2 CLANG64 and Python; Linux has separate packaging scripts.
