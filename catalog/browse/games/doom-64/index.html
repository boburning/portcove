Setup

  1. Keep a permitted working copy

    Use an existing permitted Windows installation with DOOM64EX+ENHANCED.exe and its accompanying Enhanced WAD and libraries. Keep your current working copy recoverable.

  2. Provide the PC remaster assets before Play

    The engine searches supported GOG and Steam DOOM 64 remaster installations. It requires DOOM64.WAD, Doom64.kpf and normally DOOMSND.DLS; legacy ROM-derived WADs do not substitute. Missing files cause an error rather than an original-file picker.

  3. Preserve both current and older profiles

    Choose that player and its folder, then Play explicitly. Current Windows saves, config.cfg and screenshots normally use AppData/Roaming/doom64ex-plus. Older copies may keep them beside the executable, and the game can move those files on startup. Back up both locations before changing versions. Upstream updates and any shared profile remain outside Portcove management.

  4. Register your prepared player

    Complete the upstream setup in your permitted working copy first. Select the actual DOOM64EX+ENHANCED.exe and its containing folder as the working directory; keep all companions. Normally leave arguments empty. Enter separate literal arguments only when deliberately following documented options. Confirm the selected player, folder and arguments; registration does not start a game. Choose Play separately when ready.

Setup notes
Keep your runtime and data recoverable
You and upstream own runtime replacement, originals, saves, settings and profiles. Close all actual players and preserve the working copy and every actual data location before upstream changes. Removing the registration leaves all external files untouched. Managed Install, Update, Backup, Rollback, migration, original authentication and external deletion are unavailable for this route.

Limitations and evidence

  • Use your permitted upstream copy under its applicable conditions. Keep both the older working folder and current user profile backed up before first Play.
