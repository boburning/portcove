Setup

  1. Keep your original PC game recoverable

    Use your permitted original PC installation and an executable edition listed by upstream. Preserve the working game folder, saves, settings and any existing renderer wrapper before changing it. The download is an enhancement, not a standalone game.

  2. Place the enhancement beside the player

    Copy the archive’s BIN/ddraw.dll and BIN/remaster.ini into the game’s BIN folder beside bugs.exe. Review any existing file before replacing it. Do not register the DLL or the BugsBunny.exe launcher.

  3. Set the required launch details

    Select BIN/bugs.exe, set the working directory to BIN, and add five separate launch arguments: /opengl, /win, /b0, /x800, /y600. Then choose Play explicitly. Keep saves, settings and remaster.log in BIN backed up; updates remain with you and upstream.

Limitations and evidence

  • The enhancement checks specific original bugs.exe editions. Modified or other editions are outside this claim; use upstream’s exact requirements. Linux Proton observations do not establish a native Linux player or Portcove-managed compatibility layer.
