Setup

  1. Use the upstream setup for your own Dungeon Keeper

    The upstream Windows web installer is the simplest setup route. Follow the linked instructions, choose a separate KeeperFX folder and supply your own supported Dungeon Keeper CD, GOG, EA or Steam files. If you downloaded the complete .7z package here, extract it with your archive tool and open keeperfx-launcher.exe yourself; it prompts for the original files. The archive is not an installer, and patches/alphas alone are not a complete game.

  2. Select original CD data

    Select the CD’s keeper folder when upstream asks for original CD data; other editions have their own folder rules in the linked guide.

  3. Choose the upstream launcher

    On Windows 10 or newer, choose keeperfx-launcher.exe from the prepared KeeperFX folder, with that folder as its working directory. It provides setup, settings and upstream updates. Save launch details in Portcove, then choose Play separately. Upstream also documents keeperfx-launcher-legacy.exe or the direct keeperfx.exe route for older environments; those are deliberate alternatives, not another required setup question.

Setup notes
Preserve the external copy when updating
Let the upstream launcher provide updates, and keep a separate copy of your working folder before replacing files. Preserve save (including settings.toml), keeperfx.cfg, original data, screenshots and any custom maps, campaigns or mods. Portcove does not own these files or provide managed Update, Backup or Rollback for them.

Limitations and evidence

  • Let the upstream launcher provide updates, and keep a separate copy of your working folder before replacing files. Preserve save (including settings.toml), keeperfx.cfg, original data, screenshots and any custom maps, campaigns or mods.

Setup

  1. Start the Linux AppImage

    On a current Linux x86-64 system such as Ubuntu 24.04 or newer, download KeeperFX-Tux-Edition-x86_64.AppImage from the publisher and make it executable. Run it directly or use --appimage-extract-and-run if FUSE is unavailable.

  2. Copy your owned Dungeon Keeper files

    At the launcher’s Copy Dungeon Keeper Files prompt, select your original CD or a prepared GOG, Steam, or EA installation. Keep the original files in place. For music, use tracks from your own copy as described in the upstream guide.

  3. Keep one Linux game folder

    The AppImage uses ~/.local/share/keeperfx-alpha by default. To use a separate folder, set KFX_ALPHA_PREFIX to its absolute path on each launch. Keep this folder separate from the Windows KeeperFX installation. A different AppImage version can update the same folder on its first launch. Before opening a replacement AppImage, close the game and launcher and back up the complete Linux folder, which holds saves, settings, screenshots, mods, and Workshop maps.

Setup notes
Check save compatibility and use owned original data
See https://github.com/ForkedInTime/keeperfx-tux-edition/blob/v1.4.0.6103/docs/faq.md for edition-specific setup and save compatibility.

Limitations and evidence

  • Keep the build that wrote your saves before changing channels or versions. Older saves can depend on their original build, and some later scripted levels have an additional compatibility boundary. The publisher’s FAQ lists the affected versions.
