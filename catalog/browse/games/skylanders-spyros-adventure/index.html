Setup

  1. Check the required game files

    Use your own Xbox 360 ISO or extracted folder with the region-free 10-language executable for title 415608AB. The accepted default.xex fingerprint is e195f5130c1e23fb4654baf7c383ef97d02c89aeb7d4389705ae31235646ef7b.

  2. Follow upstream setup

    Use the release installer and import your own ISO. Games run as standalone native programs. The CoreOfLight hub and a real USB portal are optional; a virtual portal is supported. The Windows x64 player uses D3D12. Building from source requires VS2022 Clang, CMake, Ninja, just and Python.
