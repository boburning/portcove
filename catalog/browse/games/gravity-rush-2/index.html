Setup

  1. Check the required game files

    Own decrypted PS4 Gravity Rush 2 dump CUSA00547/CUSA03694/CUSA04934/CUSA04943, containing eboot.bin and sce_sys/param.sfo. Bundled executable/FPS patches target update01.11; other versions run without those patches, not with verified gameplay compatibility. Optional audio module libSceNgs2.sprx comes from the owner console. Do not accept Remastered CUSA01113/CUSA01130 as this game.

  2. Follow upstream setup

    The project documents Windows packaging and a launcher that prepares your own decrypted game files. The retained evidence does not confirm a completed native build or working game package. One recorded macOS build stopped because Vulkan headers and libraries were missing; that result does not establish whether builds on other systems work.
