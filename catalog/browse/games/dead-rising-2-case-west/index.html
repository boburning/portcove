Setup

  1. Use a completed copy you already have

    Continue with a complete player you already have. Portcove downloads are paused because the package includes shader pre-warm data recorded from the game and recipes for patching the game’s own shaders. The package also includes compiled-in libxlive, whose licence it defers to XenonLive; offline use does not remove it.

  2. Complete Case West preparation through its own player

    Keep the complete CaseWestRecomp folder, matching DLLs, assets, tools, defaults and shader resources. Use your own Dead Rising 2 Case West XBLA package, title 58410B00. The native player’s own first-run picker/import and GPU shader preparation run in-process; no separate CPU recompilation is required by this guide. This is not Case Zero and its input/profile is not interchangeable. Complete upstream preparation outside Portcove; no original or helper is acquired or executed here.

  3. Select the direct offline player

    Select the completed cw_runtime.exe, its CaseWestRecomp directory as working directory and no arguments for the normal native launcher. The direct player has an offline default profile and requires no account. XenonLiveLauncher and online sign-in are optional separate upstream features, not a prerequisite for this offline attachment. Keep existing explicit path choices; do not point CW_ROOT at a data-only subfolder because it selects the whole resource root.

  4. Review launch details, then choose Play

    Select the completed game executable, its working folder and supported launch arguments. Review those details and agree to use them, then choose Play separately. You manage setup, game replacement and recovery using the project’s tools. Removing its registration leaves external files in place. Before changing versions, close the game and its companion programs and keep the working copy and all data. Review and select the changed executable before playing again.

Setup notes
Keep the complete working root and external profiles
Preserve the entire creating runtime/resource root, including assets/package, assets/game, assets/save, assets/shader_spv, config, tools, defaults, recipes, logs, key maps and all custom locations. The inspected Windows source also resolves the redirected Saved Games known folder under Dead Rising 2 Case West, falling back through USERPROFILE/Saved Games and finally the executable directory. Keep offline and per-gamertag profiles, all saves, original packages, backups and temporary files. These are separate unowned roots; this guide does not claim a complete managed backup or cross-profile migration.

Limitations and evidence

  • Use only a copy and components you are permitted to use. Before changing versions, keep a copy of the complete working game, original files and every profile, save, cache, mod, backup, temporary file and custom data location. Another executable may use the same data. Portcove does not offer updates, backups, rollback, data migration or deletion for these external files.
