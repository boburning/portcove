Setup

  1. Choose your original game data

    Select your complete X-Wing vs. TIE Fighter installation root containing BalanceOfPower. The base game by itself is insufficient.

  2. Start the Linux player

    On Linux x86-64, install the official portable engine in Portcove, then choose Play and select your original game data in the upstream picker. Use glibc 2.35 or later, libstdc++ with GLIBCXX_3.4.22, libcurl.so.4 with CURL_OPENSSL_4, and a Vulkan driver. If you prefer an external copy, keep the resources, shaders and lib folder beside OpenXvT.

Setup notes
Open the Apple silicon Mac app
Mount the upstream v0.0.5 macos-arm64-release.dmg and copy OpenXvT.app out of it. Use Apple silicon, macOS 13 or later and Metal. Keep the app bundle intact and maintain this copy outside Portcove.
Keep your settings and pilots
The normal SDL profile is TotallyOpen/OpenXvT under the Linux data home or Mac Application Support. Keep the whole profile with the player closed.

Limitations and evidence

  • Back up the entire effective profile, all original game folders, and the working player before updating. If the profile cannot be opened, check the working directory for pilots, settings and other files.
