Setup

  1. Complete the exact owned-original setup upstream

    Use an independently permitted complete Freedom Unbound Windows package and your own Monster Hunter Freedom Unite USA ULUS10391 PSP ISO. The selected production profile checks disc identity and selects the plain on-disc BOOT.BIN, whose known SHA-256 is 3070954e2dc88fd0b0836c0c1dc526531aca4a213b0f18806e324963efb514f4. The profile also records encrypted EBOOT.BIN SHA-256 3354adb3ee40821f230c4055b9bf7cc5d4c864e42abb74ce8ac022933f9697a7 as reference metadata; this route does not demonstrate a separate EBOOT read or hash check. No separate PSP decryption key is needed for the documented BOOT path. Complete first-run setup upstream; do not substitute another region, test-data profile or another Monster Hunter title.

  2. Attach the supported waiting native launcher

    Select FreedomUnbound.exe with its complete creating package directory as working directory and no arguments for normal play. Keep Start-Freedom-Unbound.ps1, FreedomUniteNative.exe, overlay/runtime DLLs, fonts and resources together. The native launcher starts the supplied script through Windows PowerShell and waits; that script starts the native game, waits for its exit and records session logs. The script uses Add-Type for foreground activation. Do not attach the PowerShell executable, CMD fallback, save editor or private runtime directly, or invent a wrapper to bypass the supported environment.

  3. Retain the launcher’s actual argument and environment boundary

    For an established custom data or log root, retain its supported literal -DataDirectory or -LogDirectory option and value. The script clears MHFU_/PSPRECOMP_ variables only in its own child environment and sets the supported home-screen/no-interpreter choices; an ambient MHFU_DATA_DIR is not a substitute for the supported launcher argument. Portcove adds no environment, compiler or shell orchestration. The full upstream chain is part of the independently permitted complete copy and remains user/upstream owned.

  4. Review Play and preserve every effective data root

    Review and consent to the exact selected executable, working directory and literal arguments, then request Play separately.
