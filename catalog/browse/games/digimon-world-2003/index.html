Setup

  1. Check the required game files

    Use your own Europe SLES03936 disc as a single-track MODE2/2352 BIN/CUE image: 692146560 bytes, SHA-1 457cb233349ba841e03b33d8060f8fbcadd45cb3. A 2048-byte-sector ISO is rejected.

  2. Follow upstream setup

    Follow the README for dw2003-<version>-x86_64.AppImage and SHA256SUMS. The launcher selects and checks your disc, then reads it while the game runs. A native source build is also available.
