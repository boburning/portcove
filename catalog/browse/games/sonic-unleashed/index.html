Setup

  1. Prepare your own international Xbox 360 game upstream

    Use your legally obtained US or EU Sonic Unleashed Xbox 360 base game plus its matching-region required Title Update. The Japanese, PS3 and Wii editions are not this contract; DLC is optional. Use upstream’s normal in-process installer: Add Files accepts dumped Xbox 360 containers/images; Add Folder accepts the exact requested raw content directory and does not recursively search for it. Modified inputs are rejected upstream. Core does not acquire or authenticate these originals, apply title updates or build the port.

  2. Select the established Unleashed player

    Use the completed UnleashedRecomp.exe with its installation directory as the established working directory. The selected source defaults game content to the current working directory, so an arbitrary working directory is not equivalent. Preserve the existing package and completed installer outputs. The reviewed v1.0.3 Windows asset has no published GitHub digest: this guide does not authenticate or enroll a fresh managed download.

  3. Add the completed native player, then choose Play

    Finish setup with the project’s tools, then select the Windows game executable, working folder and supported launch arguments in Portcove. Review and agree to those details, then choose Play separately. Keep the complete package together and close the game and companion programs before changing files. You manage this external copy; Portcove does not replace it or back up, convert, migrate or delete its data. Removing its registration leaves those files in place. Source review and automated registration checks do not confirm an installed game session, successful forced exit, gameplay or save compatibility.

  4. Retain upstream ownership and every effective profile

    Upstream remains the single engine/data-preparation owner. Preserve the complete creating installation, original base/update/DLC inputs, mods and all effective profiles before deliberate compatible changes. Default Windows settings are in the Roaming AppData UnleashedRecomp directory, with config.toml and save/SYS-DATA; a portable.txt beside the player switches the profile to its executable directory. Hedge Mod Manager can redirect saves, including mlsave or another configured path. Preserve both old/new roots before changing portable mode. A failed Windows known-folder lookup can leave relative profile paths, so preserve the actual effective location. Upstream’s version-replacement guidance is not a Portcove promise of cross-version save or mod compatibility; relink and review any changed selected executable.

Setup notes
Install the Linux Flatpak through your system
The Linux x86-64 ZIP contains io.github.hedge_dev.unleashedrecomp.flatpak. Extract and install that bundle with your system’s Flatpak tools. Open it once to supply your original files, then reopen the installed application. The Windows executable registration above is a separate route.
Keep your Flatpak data when updating
The game installs its original-file data under ~/.var/app/io.github.hedge_dev.unleashedrecomp/data. Back up that folder and the active save profile. The game normally uses ~/.config/UnleashedRecomp for settings and saves. Keep any different save path chosen by your mod manager. Update with the project’s new Flatpak bundle and keep application data when replacing the old version.

Limitations and evidence

  • Before changing versions, keep a copy of the working game and all original files, profiles, mods, generated caches and custom data locations. Another executable may use the same saved data.
