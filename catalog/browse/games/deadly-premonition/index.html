Setup

  1. Prepare and confirm the regional player upstream

    Start from an already-permitted, fully prepared working Windows copy corresponding to the upstream v2.0.14 route, using your own supported PAL or USA Xbox 360 disc. The selected source describes release-bundled disc-derived shader storage; establish applicable permission for the selected package/component or an asset-clean or owned-input route before fresh acquisition. Sharing consent alone does not resolve that condition. Finish upstream import and one normal working launch before adding it. An incomplete first-run installer can start another process and exit. The importer and launcher use default.xex size to choose a region; that is not complete original-file authentication. Keep your originals and failed preparation work recoverable rather than mixing regional files or treating a same-size retry as verification.

  2. Keep shader sharing off

    In the upstream launcher explicitly choose No at the sharing prompt (Yes is preselected), and keep Advanced → Share Shader Cache off (launcher.ini: launcher_share_shader_cache=off). That prompt offers to send disc-derived shader microcode and pipeline descriptions; adding a Portcove registration grants no permission to upload them. Portcove does not accept this prompt or configure sharing. Leave optional native-renderer testing, external reporting and upstream online features to your own separate choices.

  3. Add the actual prepared game executable

    Select the already-working deadlyprem.exe for PAL or deadlyprem_usa.exe for USA, using the installation as the normal working directory; preserve a different established working directory and its literal paths if your actual prepared launch requires it. Do not select PlayDeadlyPremonition.exe: its PLAY button starts the game, closes the child handle and exits. The prepared native entry defaults to assets beside the executable; retain actual supported --game_data_root, --user_data_root and --cache_root flags with their creating absolute paths as separate arguments if your copy uses them. Saving launch details and Play are separate actions. This route does not run or supervise the upstream importer or updater.
