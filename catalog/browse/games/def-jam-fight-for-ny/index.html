Setup

  1. Complete upstream setup with your own USA Xbox copy

    Use the upstream Windows x64 setup and components you are independently permitted to use. It compiles locally from your own USA/NTSC-U Xbox title 45410049 (EA-073) ISO/XISO or extracted tree. The required default.xbe is 3,284,992 bytes with SHA-256 31cc0d11f7c656b1a6f337fdf7d9bbaac9df11c324a2fb881f7eb639d4be00c2; the complete required XML and assets/audio/fonts/motion/movies/screens files are also needed. PS2/GameCube copies do not fit. Keep originals unchanged. The published setup is preparation, not the player; its provider digest is expected metadata, not our inspection of installer bytes.

  2. Choose separate install and data destinations

    Finish upstream installation outside Portcove, including its original verification, extraction and local compilation. Install, data and original dump paths must be separate and non-nested, writable and within upstream path limits. Review any requested Microsoft compiler installation and consent yourself. Preserve the exact chosen install/data paths, installed.ini and complete successful version tree. Optional HD textures are generated locally from your dump; no separate texture-pack permission is inferred.

  3. Register the stable installed launcher

    Select <install>/DefJamLauncher.exe, use that actual install root as working directory, and leave arguments empty. This documented native launcher reads installed.ini, supplies the chosen DEFJAM_DATA, DEFJAM_INSTALL_DIR and log root, and starts the recorded compiled player with its recorded source directory as child working directory. It holds play.lock and waits for that child to exit. Do not select the setup wizard, setup scripts or an internal versioned defjam_recomp.exe. Saving launch details and Play are separate actions. An interrupted setup transaction requires upstream setup recovery.

  4. Keep replacement and cleanup with upstream setup

    Close the game before upstream install/repair/update/rebuild/uninstall. Setup owns its activation journal, versioned builds and stable launcher; successful older builds may be retained, failed/cancelled attempts remove their own candidate, and upstream uninstall removes recognized application versions/launcher/receipts while retaining player data and originals. Preserve independent backups outside those application/version paths before maintenance. Review the selected release’s actual offered operations; documented future updater protocol is not proof of a published compatible pair. After replacement review/relink changed launcher bytes. Removing Portcove registration preserves external files; Portcove does not own update, rollback, backup, migration or deletion.

Setup notes
Back up every active data and recovery root before startup or maintenance
Preserve the complete chosen data folder: settings.ini, save/ (including UserData, TitleData, cache and partition images), extracted originals, mods, texture/HD caches and artwork. Also retain setup logs under %LOCALAPPDATA%/DefJamSetup/logs, install logs, and the active version source/logs; custom RECOMP_SETTINGS or RECOMP_SAVE_DIR paths remain separate roots when present. The pinned runtime copies missing disc UDATA metadata without overwriting it; its legacy save-name compatibility lookup does not rename or rewrite saves. Preserve any older game-side UserData/TitleData and unconfigured %LOCALAPPDATA%/xboxrecomp saves separately; no automatic migration or save compatibility is promised.

Setup

  1. Build from your own Xbox game

    Open the Windows setup and choose your own USA Xbox disc image or matching extracted dump. The installer checks the original against the project's manifest, then builds the player in a writable NTFS or ReFS folder. Allow 16 GB of build space plus the game copy and 1 GB, with another 15 GB for optional HD textures. Setup may install the Microsoft C++ Build Tools if they are missing.

  2. Play again from the project launcher

    After setup succeeds, use the installed FFNY Online launcher to play again. Open its settings before Play or use F1 in the game. The Play action at the end of setup runs the installed launcher with --launch.

Setup notes
Keep the installation's data folder
The setup stores settings and saves in data beside app. Preserve data before updating or repairing the installation. Choose Update in the installed upstream launcher. Its setup updates the existing installation in place and keeps its data. Portcove does not replace this player or back up that folder.

Limitations and evidence

  • Check the setup guide's storage and folder requirements. The Windows package is an installer that builds the game locally.
