Hyrule Warriors: Definitive Edition / Hyrule Warriors: Definitive Edition Recomp (sonsegajp)

A Windows port of Hyrule Warriors: Definitive Edition that reads your own Switch base game. The project reports menus, battles, movies and saving in test releases. Check the title ID before setup because the separate musoh 1.0.1 profile accepts a different input.

Setup

  1. Check your original game files

    Provide your own base NSP for title 0100AE00096EA000 and prod.keys. The player reads ExeFS and RomFS from the package. The exact region, revision and hashes have not been confirmed.

  2. Follow the project’s setup

    Follow the project’s Windows 10 or 11 x64 instructions on a machine with AVX2 and Vulkan 1.2. For movies, enable Media Foundation and install the feature pack on Windows N editions.
