Setup

  1. Import your original SimCity 2000 files

    On first Play, choose SIMCITY.EXE from your SimCity 2000 Special Edition for Windows 95 (1996), with its companion files beside it. Upstream can also import from a mounted game disc.

  2. Keep your existing copy available

    For an existing upstream installation, select OpenSC2K.exe and its folder. Portable copies use the data folder beside the player; standard Windows copies use the OpenSC2K Godot user profile. Keep the profile used by that copy when updating it.

  3. Install the Linux x64 player

    Install the official x64 archive through Portcove. On first Play, use the same original SimCity 2000 import. Portcove prepares the portable data folder beside OpenSC2K.x86_64. Keep existing standard Linux profiles with their existing copies. For an external x64 or ARM64 copy, extract the complete archive and keep the PCK, shared libraries and bundled SoundFont beside the player.

  4. Copy the upstream Mac app to Applications

    Open the universal Mac DMG and drag OpenSC2K.app to Applications. Keep the app intact and preserve its OpenSC2K Godot profile when updating it.

  5. Choose the Windows on Arm package

    On Windows on Arm, extract the ARM64 portable ZIP into its own writable folder. Run its OpenSC2K.exe and keep its PCK, DLLs and data folder together.

Setup notes
Check the inspected desktop packages
The inspected v0.3.0 Linux x64 and ARM64 archives include runtime modules that need glibc 2.35 and a bundled MIDI library that needs glibc 2.38. Use glibc 2.38 or later for the complete bundled package. The universal Mac app requires macOS 11 on Intel or macOS 13 on Apple Silicon. Linux standard copies use the Godot profile by default. The Mac app always uses that profile. You and upstream maintain external Linux, Mac and Windows on Arm copies.

Limitations and evidence

  • Extended .sc2x cities cannot be opened by the original game. Keep backup copies of your cities.
  • Save cities normally before backing up. Recent autosaves live in OpenSC2K Autosaves under the system temporary directory and upstream prunes older autosaves. Preserve the profile and any custom save or export locations used by your copy.
