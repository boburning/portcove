Setup

  1. Check the required game files

    Use your own European ULES00600 v1.01 ISO; installed assets and generated C/jitcache kept locally. ISO is needed at installation, not after import.

  2. Follow upstream setup

    Select plain TagForceRecomp-<version>-win64.zip, which README identifies as runtime/translator/TinyCC/FFmpeg without mods or textures. Install and Play imports own EUISO and locally translates/compiles into gen/jitcache; later Play no ISO is needed. Mods/EnhancedTextures/Fullsplitpacks are separate optional downloads, not default selected payload.
