Setup

  1. Choose your original USA ROM

    Use your own uncompressed 1,048,576-byte USA Zombies Ate My Neighbors ROM. Keep it outside the player folder. Select it in the launcher, then choose Play.

  2. Start the managed Windows player

    Open the installed zamn_launcher.exe and select your original ROM in the game settings. Keep zamn.exe and SDL2 beside the launcher.

  3. Start the managed Linux player

    Open the installed zamn_launcher and select your original ROM in the launcher; you can type the ROM path or drop the file onto it. Keep the launcher, zamn and the bundled SDL2 library together.

Setup notes
Check the inspected Linux build
The 20261028 Linux launcher and bundled library need glibc 2.38 or later. The launcher needs an available system font in a supported location, such as DejaVu Sans. The expected USA ROM has SHA-256 b27e2e957fa760f4f483e2af30e03062034a6c0066984f2e284cc2cb430b2059.
Keep the default player data
Preserve zamn.ini, zamn.quicksave, zamn.hiscore and any matching .tmp files in your working copy. Preserve custom config, high-score and output locations separately.

Limitations and evidence

  • The upstream Linux build is experimental and player-managed. Close both the launcher and the game before replacing the runtime or backing up its files. Keep the creating version with its configuration, quicksave and high scores.
