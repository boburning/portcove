Setup

  1. Check the required game files

    Use your own Xbox 360 ISO or extracted folder containing default.xex and databigs. Only the port’s specific original disc revision is accepted. Its region, media ID and hash are not specified in the README or BUILDING; check upstream before setup.

  2. Follow upstream setup

    Use the FNCReborn-Setup release to download a portable toolchain and recompile locally. The developer setup.bat route uses Visual Studio 2022. Windows x64, Direct3D 12, 16 GB RAM and 25 GB disk space are required; choose the CPU v2/v3 build for your machine.

Limitations and evidence

  • Upstream reports menus, Fight Now, Legacy, Champion and Create Fighter support. Only one disc version is supported, and bugs remain.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
