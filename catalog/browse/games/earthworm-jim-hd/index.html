Setup

  1. Prepare the exact owned XBLA original

    Use the official v0.9.6 Windows x64 package and your own Earthworm Jim HD original: Xbox Live Arcade title 584109E2/content type 000D0000, default.xex 1.0.0.11 (2010-04-27), size 26726400 bytes and SHA1 62d9d28a3bce42843607c26ab4b200e91cb31203; the LIVE package is 455823360 bytes, but its owner-dependent header means a package checksum is not the executable revision. Finish Install from package and settings in the supported integrated launcher before attachment. A different title update or original edition is not interchangeable.

  2. Keep the complete prepared player

    Retain earthworm_jim_hd.exe, its graphics/runtime DLLs, game/ extracted from your own original, earthworm_jim_hd.toml, logs and all notices as one unit. The selected Windows route uses Direct3D 12; Linux/AppImage or other game/framework observations do not qualify this host. The release is a native player, while developer source builds/toolchains are separate. Images used by the launcher come from the owner’s original or first-play capture, not permission to redistribute original game assets.

  3. Attach the normal in-process player

    Select earthworm_jim_hd.exe, use the complete player directory as working directory and leave arguments empty after upstream preparation. Review the selected program, working folder and arguments and choose Play when ready, then use the ordinary integrated Play if shown. The selected EarthwormJimHdApp resumes its own native runtime in the same application rather than using a detached launcher as normal Play. Finish any graphics changes that explicitly require restart, first-use preparation or updater relaunch upstream before attachment; those successor paths are not newly qualified by this guide. Quit the actual game normally.

  4. Preserve the actual save and configuration roots

    Keep the whole prepared directory, game/, earthworm_jim_hd.toml, logs, original XBLA package and recovery. Use the integrated About page’s Open save folder to identify and preserve the actual existing user root, including saves/profile, achievements, art and shader caches; keep explicit existing game/user/cache/config overrides and historical copies. The selected title source passes the resolved SDK user root to this page; this guide does not guess its default from another ReXGlue build or create a replacement empty root. No migration, save conversion, real-save restore or deletion is performed.

  5. Keep upstream maintenance and acceptance limits

    Upstream owns original checking/extraction, settings and runtime updates. Retain project, ReXGlue, launcher, library, shader and font notices; these do not license the original game or independent modifications. Close the game before upstream replacement, preserve populated user data and recovery, and review/relink changed bytes. Upstream performance, achievement, campaign, controller and multiplayer reports are not native observations here. No Supported, installed/native or managed install/update/rollback/backup/deletion acceptance is asserted.

  6. Play on Linux

    Put the EarthwormJimHD Linux x86-64 AppImage in a writable folder, make it executable and open it on a Vulkan-capable system. Use Install from package on the Play page and choose the same owned XBLA revision. The launcher prepares a game folder beside the AppImage.

Setup notes
Keep the Linux files and update through the project
The installed game and earthworm_jim_hd.toml stay beside the AppImage. Use About > Open save folder to find the actual save path. Choose the upstream update mode in About. Turn off the launcher on the Play page for direct starts after setup. Hold Shift at startup to reopen it.

Limitations and evidence

  • Select the prepared earthworm_jim_hd.exe, retain game/ and the actual user root shown upstream. Complete setup, required restarts and updates separately; do not infer another game’s save location or qualification.
