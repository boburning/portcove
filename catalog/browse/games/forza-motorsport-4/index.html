Setup

  1. Prepare the exact independently owned inputs

    Use a complete player/components you are independently permitted to use and your own Europe GOTY Disc 1, title 4D530910/media 42C67824. Required originals are default.xex (15,187,968 bytes; SHA256 B34DFB88978819CCCDA6DAFD755E7139970A58FBF6707DFBCBA06846857F52BD), XMediaFacade_default.xex (2,662,400; 2E82A8D08A59E79F4D68E68B744C2872855BFDD583EB39AD0A9C54E5B3FA1492), SpeechFacade_default.xex (2,138,112; 49D506A2F8556836943D8BAB3A50B6CD3877524500509EF462FB6E9802F2F4BF), and the complete matching Media tree. These are individual XEX hashes, not whole-disc hashes. Finish upstream preparation first; no originals, compiler, helper or game are executed here.

  2. Keep the actual native player package

    Use the complete official v0.1.0-alpha.2 Windows player ZIP with fm4.exe, matching SpeechFacade and XMediaFacade native DLLs, runtime libraries and notices. This package is ready to run after original-file preparation; the older source-kit instructions do not require you to install a compiler or SDK for it. Its published SDK revision is f16992c92e610c2d71773994436b442d9946f4e1. Use Windows 11 x64 with AVX2 and Direct3D 12; keep all files together.

  3. Attach the native player with its real roots

    Select fm4.exe and the full package directory as working directory. Match the published Launch FM4.bat native command using --game_data_root="absolute existing game folder" --user_data_root="absolute existing user folder" --cache_root="absolute existing user/cache folder", substituting the actual prepared absolute paths and retaining upstream long-path spelling when necessary. The batch file checks all three XEXs before synchronously running this native player. Review and consent to the selected launch details, then choose Play separately; do not select a compiler, helper, source kit or diagnostic probe.

  4. Preserve originals, profiles and writable game data

    Keep game/Media and XEXs, user/ profiles/saves/cache, fm4.toml, logs, actual external roots and independent recovery copies. Packaged allow_game_relative_writes=true means the prepared game tree is not promised read-only. Optional independently owned Disc 2 marketplace content uses disc2-content/ and upstream startup installation into user data; this guide imports nothing. Never replace the only original or live profile with a fresh package.

  5. Retain limits and upstream maintenance

    Keep GPLv3 project and ReXGlue, Xenia, FFmpeg, runtime and other component notices; they do not license original game assets. The selected baseline uses D3D12 ROV, full readback and synchronous host copies; upstream reports heavy scenes near 30 FPS and fresh-profile blank car thumbnails. Binary/package inspection does not prove a race, save round trip or stable 60 FPS. Quit normally before upstream replacement, retain recovery and review/relink changed bytes. Portcove does not install, update, roll back, back up or delete this external copy, and has not tested native gameplay or physical controls.
