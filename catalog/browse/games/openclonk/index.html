Setup

  1. Install OpenClonk

    On Windows x64, use the Windows 64-bit installer. On Linux, use your distribution’s openclonk package or the community OpenClonk Flatpak for x86-64. Debian also packages OpenClonk for ARM64. The publisher’s Linux archives were built with Ubuntu 16.04, so try your distribution’s package first on a newer system.

  2. Choose a player and scenario

    Create a player, or select an existing one under Player Selection and choose Activate. Open Start Game, open Tutorials, and start Wandering Wipf to learn the controls. The packages include the game data.

Setup notes
Find your player data
On Windows, look under %APPDATA%\OpenClonk. Windows stores default settings in HKEY_CURRENT_USER\Software\OpenClonk Project\OpenClonk. Keep that key if you want to transfer these settings. On Linux, keep ~/.clonk/openclonk, including its config file. The Flatpak profile is ~/.var/app/org.openclonk.OpenClonk/.clonk/openclonk.

Limitations and evidence

  • Close OpenClonk before copying players, scenarios, or saves. Keep any custom user data directory or separate configuration file you selected.
