Setup

  1. Open a Windows or Linux copy

    Extract the complete Windows x86-64 or Linux x86-64 ZIP into a writable folder. Open OpenSupaplex.exe on Windows or run OpenSupaplex from the extracted folder on Linux. Keep the packaged level files and audio beside the program. The Linux build needs glibc 2.34 or newer, SDL2 and SDL2_mixer.

  2. Open a Mac copy

    Open the complete OpenSupaplex.app from the publisher’s macOS ZIP. The inspected build and its bundled frameworks require macOS 10.13 or later on Intel and macOS 11 or later on Apple Silicon.

  3. Keep your progress before replacing the game

    Back up the working folder on Windows and in the publisher’s Linux ZIP. On Mac, back up ~/Library/Application Support/OpenSupaplex. Keep PLAYER.LST, HALLFAME.LST, SUPAPLEX.CFG, ADVANCED.CFG, any SAVEGAME files and any added levels.

Setup notes
Play the original levels in a separate Linux folder
If you have permission to use both the Linux player and the original Supaplex SpeedFix 6.3 files, keep the original archive and place a working copy of its data files beside the OpenSupaplex executable in a separate writable folder. Run OpenSupaplex from that folder. The old DOS executable is unnecessary. The separate original data does not include the newer player's packaged music.
Save and resume an original level
For a single snapshot in the working folder, start OpenSupaplex with --force-savegame-sav. Press Ctrl+W during the level to write SAVEGAME.SAV. Close the game before copying that file. To resume in a fresh folder with the same original data, copy the snapshot there and start with --load-savegame.
