Setup

  1. Supply your Diablo disc and BIOS

    Portcove checks your own single-track Diablo (Europe) CHD and retail SCPH-5552 BIOS, then builds the game on this computer.

Limitations and evidence

  • On Windows, a long library path can stop Diablo v0.1.6 from starting. Before building this version, use Change library location in Library and storage to review a shorter folder if needed.
  • Save states may stop working after an update. Make a normal in-game save before updating.
