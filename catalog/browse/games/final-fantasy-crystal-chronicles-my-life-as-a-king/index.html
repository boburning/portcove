Setup

  1. Prepare the WiiWare originals

    Copy your own NTSC-U My Life as a King base WAD (WFCE) beside mylifeking.exe, plus the matching optional add-on content WAD if you have it, and keep your originals separately. On first start the game builds its game folder from them in a few seconds; after that the copied WADs are no longer needed.

  2. Let the game import the WADs

    Run mylifeking.exe. The first start populates game and, with the add-on WAD, game/dlc. To add the add-on content later, delete the game folder and start again with both WADs in place; saves in nand stay. If the first start failed or used the wrong WAD, delete the game folder and start again with the right WAD in place.

  3. Keep saves and settings

    Keep nand, mylifeking.ini and the generated game folder with the program.

Limitations and evidence

  • The package includes recompiled game code and bundled fonts that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • Keep the upstream folder outside the Portcove library. Close the game before backing up or replacing the creating runtime and its data.
