Setup

  1. Prepare the exact disc upstream

    Use a complete rac-rs copy/components you are independently permitted to use, with your own PS2 Ratchet & Clank PAL/Europe v1.00 SCES-50916 ISO (4,213,997,568 bytes, SHA1 B0DFBD8EAC0D84F173B6FC25D8A02A5FF22C652F) or USA v1.00 SCUS-97199 (4,214,095,872 bytes, SHA1 AEE9275384F739C9B24CD5DE6F7E200292DB7B01). Japan, Platinum and Greatest Hits are not accepted by those fingerprints. Finish Setup.cmd disc validation, local translation/build and settings upstream. Keep the original ISO at its configured location. No original, toolchain, helper, compiler or game is obtained or executed here.

  2. Keep the full prepared installation

    The inspected official 0.4.3 ZIP is a source/setup kit, not a prebuilt game executable. Its producer builds build/release/rac-rs.exe locally from the player’s disc and creates generated/play.cfg. Keep the complete resulting installation, generated/ and oracle/ support data, matching libraries and toolchain/recovery, not merely the generated EXE. Source setup and a finished existing native installation are distinct states; this guide applies only after that preparation succeeds.

  3. Add the generated game player

    Select the existing build/release/rac-rs.exe from that prepared installation, use its full installation root as working directory and leave arguments empty. Review the intent and request Play separately. The native no-argument entry finds generated/play.cfg up the executable’s parent chain, reads its original ISO setting, derives required support/player paths and starts the normal retail-cold game in process. It does not require invented launcher environment. Do not attach Setup.cmd, Play.cmd, a compiler or the developer oracle. Complete an update prompt or rebuild outside the attached attempt first.

  4. Preserve player files and generated configuration

    Keep the complete player/ folder, especially card.bin and card.start1.bin/card.start2.bin safety copies, settings, mod data, logs and crash logs, plus generated/play.cfg, all configured original/source paths and any established external player root. PAL/USA compatibility and modified rosters/scripts are not established by a shared title. Script mods use the separate OmniLoader/Luau contract; keep active mods and texture packs independently. This guide performs no import, conversion, restore, backup or deletion.

  5. Check permissions and manage updates yourself

    Retain GPL-3.0-or-later and NOTICE.md, the separately scoped OpenRAC mod SDK, OmniLoader/Luau, renderer and component notices; they do not license the original game, third-party scripts or texture packs. Upstream setup/launcher owns downloads, updates and rebuilding, with its own recovery behavior. Quit normally, preserve independent recovery and review/relink changed generated executable bytes after replacement. Upstream full-game reports are not native/installed, campaign, hardware, mod-corpus, real-save or Supported acceptance here. Removing registration preserves external files; managed lifecycle operations remain unavailable.

Limitations and evidence

  • This release is a setup/source kit. Attach only the already generated native game with its complete installation and play.cfg; upstream retains compilation/update ownership.

Setup

  1. Prepare your own disc before Play

    Before Play, prepare game-data beside the new player from your own Ratchet & Clank (2002) NTSC-U SCUS-97199 version 1.00 disc. Use a 2048-byte-sector .iso; BIN, CHD and another region are not accepted by this extractor. Open the installed runtime folder and deliberately run its bundled rerac-extract.exe on Windows, or ./rerac-extract on Linux/macOS: identify --iso "<your ISO>", then extract --iso "<your ISO>" --out game-data, then verify --out game-data. Wait for successful completion and verification; allow about 4.5 GB for extracted disc data plus prepared caches. Keep the complete runtime folder and its assets/shaders together. After successful extraction and verification, return to Portcove to continue. A separately registered copy keeps its explicit Play action. Portcove never runs this extractor during discovery. The upstream runtime refuses missing, incomplete or incompatible extraction; wait for successful extraction and verification before Play.

  2. Use the guided launcher when you prefer

    For guided ISO selection, progress, verification, re-extraction and version management, use the official ReRAC Launcher linked by Open setup guide. Its published Windows MSI, Linux AppImage and macOS disk images are separate from these game ZIPs. Follow its Version Management and Install via ISO flow, then register your prepared player with its real data directory, or register the launcher deliberately if you want its own interface. That copy’s runtime updates belong to the launcher. The project’s older README statement that nothing has been released does not describe the currently published launcher packages. Mod management is planned, not a delivered feature.

Setup notes
Keep a separate backup of your memory card
Normal memory-card saves, settings and the crash log are outside the runtime: %APPDATA%/rerac on Windows, $XDG_CONFIG_HOME/rerac or ~/.config/rerac on Linux, and ~/Library/Application Support/rerac on macOS. Back up the profile you actually use separately. A custom RC_SAVE_DIR or RC_SETTINGS_FILE changes it. The launcher’s movable data/version/log folder can be different from the engine’s save/settings folder; preserve both when using it. Older versions may not read newer saves. Keep your original ISO and current working copy before re-extraction or changing versions.
