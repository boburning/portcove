Setup

  1. Keep your original GameCube disc image

    Use an unmodified image of your own Animal Crossing USA Rev 0 disc, game ID GAFE01. Nookery lists ISO, RVZ, CISO and GCM. Select the image in Nookery and follow its verification prompts.

  2. Open the Windows package

    Choose the official ZIP for Windows x64 or Windows ARM64. Extract the complete archive into a new writable folder and open Nookery.exe. Keep the package and its companions together.

  3. Open the Linux package

    Choose the official Linux AppImage for x86-64 or ARM64. Mark it executable and open it. The inspected builds require glibc 2.39 or later. The usual data location is ~/.local/share/Nookery.

  4. Open the macOS app

    Choose the official ZIP for Intel or Apple Silicon, then open the complete Nookery.app. The inspected apps require macOS 12 or later. Keep your data in the app’s current data folder, normally ~/Library/Application Support/Nookery.

  5. Install the Android package

    On an ARM64 Android device, install the official APK using the system installer. Choose your disc image in Nookery. Open the Nookery documents provider for saves and other data. If it is missing from your file manager, try a file manager that supports system documents providers.

Setup notes
Find your town and settings
On Windows the default data folder is beside Nookery.exe. On desktop, Settings > Data shows the active folder. The main town is under save/card_a; towns to visit go under save/card_b. Keep config.json, input.json, texture_pack and nes_roms in the active profile with your saves.
Bring a copy of a town to Nookery
Use a backup of your own .gci save in the active save/card_a folder. Leave the old playtest folder and settings in place until you have checked the imported town.

Limitations and evidence

  • The Nookery packages in this guide are installed and updated through upstream. The existing Portcove-managed Windows playtest uses AnimalCrossing.exe and its own retained setup and data contract.
  • Keep a separate backup before moving from a playtest or updating. Keep the original disc image, the old player and its data until you verify the town in Nookery.
  • Follow your operating system’s security prompts. For Android updates, back up data before installing a compatible update over the existing app.
