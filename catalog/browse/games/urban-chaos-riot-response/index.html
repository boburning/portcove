Setup

  1. Keep a complete prepared Burner Edition copy

    Use your independently permitted prepared Windows Burner Edition 0.08 copy. Finish upstream’s supported original-Xbox ISO/XISO import through Burner Edition Setup.exe outside Portcove. Keep the complete release folder, including tools, its bundled Python, runtime files, notices and your GameData. The selected Play launcher depends on those companions; copying only its executable is incomplete. Optional Spanish voices require your own separately supported European PS2 original and upstream’s import; they are not supplied by registration.

  2. Select the waiting native Play launcher

    Select Play Burner Edition.exe in the release folder, use that same folder as working directory and leave arguments empty. The inspected native launcher waits for its bundled worker, which prepares the upstream runtime and waits for the game. Do not substitute the internal trial runtime or Python executable: the supported worker supplies required asset paths and settings. Portcove supervises the selected launcher process; its registration does not authenticate every companion or take ownership of the worker’s file changes.

  3. Keep the actual ownership and test limits

    Review registration before the separate Play step. Upstream owns language preparation and runtime replacement within GameData. Removing the registration preserves external files. Portcove does not offer managed installation, original import, updates, backup, rollback, save migration or deletion for this copy. Experimental co-op, aiming offsets, HD HUD issues and broader campaign limits remain upstream limitations; Linux packages use this Windows runtime through Proton and are not native Linux acceptance.
