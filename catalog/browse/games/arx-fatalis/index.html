Setup

  1. Keep the complete native Arx player

    Use an already permitted complete Arx Libertatis1.2.1 Windows installation or ZIP, including compatible libraries/resources. Select arx.exe directly, not arxtool, arxsavetool, arxunpak, a crash reporter or installer. Normal GUI entry runs the game in that process; a diagnostic/crash helper is a separate upstream process and is not adopted by Core.

  2. Finish upstream data preparation first

    Use your own permitted supported full Arx Fatalis data or separately permitted demo with the upstream preparation path for that edition/language. The reviewed installer script distinguishes CD/ISO preparation needing1.21 patch data, already installed/GOG alternatives, Japanese and demo branches; do not mix their data sets or assume one minimal PAK list. Finish the upstream setup and normal start/quit before registration. Core invokes no extraction/patch/helper and grants no original/demo asset rights.

  3. Preserve the established directory choices

    Use the actual prepared working directory and existing supported literal data/user/config arguments. Actual Windows Saved Games/Arx Libertatis (older Documents/My Games fallback), registry UserDir/DataDir, config dir, executable/data search and custom/environment roots can differ. Keep established --data-dir/--user-dir/--config-dir values where used. The documented --no-data-dir --user-dir=. --config-dir=. portable combination is an existing upstream option, not a command to move your profile or force a new one. Review intent/consent and choose Play separately.

  4. Update the game and remove its registration

    Close every running copy before changing external files. You manage setup, game replacement, profile changes, data migration and recovery. Keep the working game version and every data folder, update it with the project’s tools, then review and select the changed executable before choosing Play. Portcove monitors only the process you selected and agreed to launch. It does not prevent other copies from running, restrict file access or take over unrelated helpers or replacement processes. Removing the registration leaves external files in place. This route does not offer Portcove downloads, setup, updates, backups, rollback, data migration or deletion.
