Setup

  1. Install the Windows build in a separate folder

    Run the publisher's mm-0.8.5-installer.exe and choose a dedicated MegaMod folder. The installer and UrQuanMasters.exe are 32-bit and need Windows support for 32-bit applications. Keep any existing Ur-Quan Masters installation in its own folder. The installer supplies the base data and offers optional content. Open UrQuanMasters.exe or the MegaMod shortcut after setup.

  2. Choose the Linux package for your system

    On x86-64 Linux, the publisher's .deb requires glibc 2.43 or later. Install it with your distro's package manager, then use the UrQuanMasters launcher. The upstream-linked Flathub package net.sourceforge.uqm_mods.UQM-MegaMod is available for x86-64 and ARM64 and includes additional graphics and audio packs.

  3. Keep your MegaMod profile

    Close the game before backing up the whole MegaMod profile. The Windows installer normally uses %APPDATA%/UQM-MegaMod. The Linux .deb launcher uses ~/.uqm-megamod. Flatpak keeps that directory under ~/.var/app/net.sourceforge.uqm_mods.UQM-MegaMod. Preserve saves, teams, screenshots and settings. Back up any content or add-ons you added to the game folder or to a custom add-on directory separately.

Setup notes
Recover a clipped Linux window
If the Linux .deb shows a clipped window on X11, open it in a session with a window manager and try UrQuanMasters --renderer=software.
Write a named save from the Game menu
In MegaMod 0.8.5, choose Game, then Save Game to write a named slot. Reopen the slot through Load Game. F3 quicksave can report a failure after writing its file.
Check release availability
This MegaMod release offers Windows and Linux packages. The tag includes Mac source build material, with no publisher Intel or Apple Silicon Mac binary and no Android APK in this release.

Limitations and evidence

  • The inspected Windows and Linux packages include the MegaMod base data. Use MegaMod's own content releases for add-ons. Optional packs and controller mappings vary by package.

Setup

  1. Install the Windows release

    Download uqm-0.8-win32.exe from the publisher and run the installer. Keep the base game content selected and use the installed shortcut to play. The installer and player are 32-bit and require Windows support for 32-bit applications.

  2. Install from your Linux distribution

    On Debian or Ubuntu, install uqm with your package manager and let it install the required uqm-content package. Start The Ur-Quan Masters from the app menu or run uqm. Ubuntu 26.04 publishes x86-64 and ARM64 packages. Other distribution packages are linked on the project's download page.

  3. Install the Intel Mac app

    Open uqm-0.8-macos.dmg and copy The Ur-Quan Masters.app to Applications. The Intel app includes the base game content. The publisher documents where to add the optional voice and 3DO music packages inside the app bundle.

  4. Back up your profile

    Close the game and copy %APPDATA%/uqm on Windows or ~/.uqm on Linux and macOS. Keep the save and teams subdirectories and the settings files. Copy any add-ons you placed in the installation separately before replacing the package.

Setup notes
Check platform availability
The 0.8.0 Mac download contains an Intel executable. The publisher offers no native Apple Silicon app or Android APK in this release. The project links separately maintained ports.

Limitations and evidence

  • Keep the stock profile separate from MegaMod profiles and use the matching base data and add-ons.
