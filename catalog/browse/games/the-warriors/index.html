Setup

  1. Prepare your own PS2 copy with upstream Coney

    Coney is an incomplete source-built reimplementation, not a complete game or a ready-made Windows release. Follow upstream building instructions first; the documented Windows route uses the x64 Visual Studio 2022 C++/ATL tools, CMake 3.28+, Ninja and an OpenGL 3.3-capable driver. Supply your own The Warriors PS2 disc or ISO. The upstream installer currently recognizes NTSC-U SLUS-21215; Xbox assets and other revisions have separate unfinished scope. Portcove does not download a disc, build the program or run its installer.

  2. Choose the completed native player and its existing context

    For an already completed upstream installation, select its coney.exe, use the complete installation folder as working directory and leave arguments empty. Its finished index/install.json identifies the adjacent game/ps2 installation. Keep that index and all installed files. For an already working source build, the documented output is build/dev/src/platform/coney.exe; preserve the repository/workspace working directory used by your working upstream command and supply --disc followed by the absolute path to your own existing ISO or complete WARRIORS.DIR/WARRIORS.WAD folder. Enter those two arguments on separate lines using your real path.

  3. Keep installation and direct-disc routes distinct

    A finished upstream --data installation is an alternative to --disc; do not combine them or use --install as the Play command. Finish any upstream import or repair before adding the reference. Retain its game/ps2 data, overrides and index/install.json together, and keep an original disc image elsewhere unchanged. Review the selected executable, working directory and arguments, then choose Play separately when ready. Do not select the studio, research tools, a compiler or a headless diagnostic as this game.
