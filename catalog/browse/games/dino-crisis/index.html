Setup

  1. Check the required game files

    Use your own Dino Crisis PlayStation Track 1 BIN/CUE: USA SLUS00922 v1.0/v1.1, supported PAL SLES02207–02211 with its matching SBI, Japanese SLPS02180 or the named Russian USA translation. Another Resident Evil port’s files do not establish a match.

  2. Follow upstream setup

    Follow DinoCrisisME_Setup.exe or its unpacked setup tools with your own supported disc. It generates C code and compiles the native game and mod locally using bundled compiler, Python and PSXRecomp tools. This guide does not identify a precompiled game download.
