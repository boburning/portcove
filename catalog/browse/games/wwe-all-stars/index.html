WWE All Stars (WWE All Stars Recomp)

A WWE All Stars Windows x64 Vulkan port with project-reported matches, controls and shader preparation. The ZIP includes the player and initial setup launcher: import and check your own USA/Europe Xbox 360 ISO and supported TU2, prepare shaders/pipelines, then use game/wweallstars.exe. Release notifications check for new versions but do not download them. Source development separately uses VS2026/ReXGlue; framework portability does not establish other players. Complete-game, multiplayer, exact accepted input hashes and BIOS/firmware requirements are unconfirmed. Portcove has not confirmed setup or gameplay.

Setup

  1. Complete upstream setup before registration

    Use your independently permitted WWE All Stars Windows copy. The reviewed v1.7.0 route uses WWEAllStarsLauncher.exe to prepare your own USA/Europe Xbox 360 disc image and its mandatory Title Update 2 from your console; owned DLC is optional. Finish import, upstream verification and shader preparation outside Portcove. Keep the complete package and notices. Registration neither supplies the disc/update nor runs the source-development build route.

  2. Select the supported direct player

    After successful upstream setup, select game/wweallstars.exe and use its game folder as working directory. Leave arguments empty. Upstream explicitly supports direct startup: this player finds the prepared folders relative to its own location and reads the launcher’s settings. Before setup it asks you to use the upstream launcher. Portcove does not rerun setup, reconstruct Title Update 2 or authenticate your original files.

  3. Review registration and leave replacement upstream

    Review the selected native executable, working folder and literal arguments before the separate Play step. Only that process is supervised. Use upstream for settings, repair, DLC and runtime replacement outside Portcove Play, then review and relink changed player bytes. Removing the registration preserves every external file. Managed installation, import, updates, backup, rollback, save migration and deletion are not offered for this copy.

Setup notes
Preserve the portable root and custom paths
Keep the complete parent release folder containing game, gamedata, updatedata, userdata, cache, logs, mods and licenses. Keep userdata/launcher-state.json and all saves/settings together, along with any selected external game-data, update-data or user-data folders. The direct player derives the normal portable root from its executable’s parent and writes session logs in the root logs folder. Preserve crash reports and shader caches too. Do not copy only game/wweallstars.exe or assume another ReXGlue title uses these same paths.
