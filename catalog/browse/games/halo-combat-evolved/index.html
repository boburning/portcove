Setup

  1. Choose your original Xbox disc image on first Play

    On first Play, select your own Halo: Combat Evolved Xbox .iso or .xiso; every edition works. OpenCE extracts its maps into the maps folder beside the player. Keep the disc image outside the game folder, because the game offers any image it finds there. Halo PC or Custom Edition maps do not replace these Xbox maps.

  2. Run a Windows copy you manage yourself

    Extract halo-windows-release.zip into its own folder and start halo.exe with no arguments. Use the release package for playing. Debug builds stop at failed assertions, and symbol archives contain debug information. OpenCE asks before installing its own updates and can replace its program files when you accept.

  3. Run the external Linux player

    Extract halo-linux-release.zip and keep libSDL3.so.0 beside halo. Make halo executable if needed with chmod u+x halo and run ./halo from that folder. Use a Linux host that can run 32-bit x86 programs. It needs 32-bit glibc 2.29 or newer, OpenGL and display libraries, and PipeWire or PulseAudio client libraries. Choose your own Xbox ISO or XISO on first launch. The file picker needs a desktop portal or zenity. If neither is available, start with a copy of the image beside halo. OpenCE handles updates for this external copy.

Setup notes
Keep all actual data locations
Beside the program OpenCE keeps config.toml, the extracted maps, custom_maps, mods, load_order.toml, screenshots, crash reports and debug logs. The default profile, save and shader cache location is AppData/Roaming/halo on Windows and $XDG_DATA_HOME/halo-linux on Linux, usually ~/.local/share/halo-linux. If paths.saves or HALO_SAVE_ROOT overrides it, copy the configured location before an update.
Use the publisher’s Android release
On a 64-bit ARM device with Android 9 or newer, extract app-release.apk from halo-android-release.zip and install it with Android’s package installer. Start OpenCE and choose your own Halo Xbox ISO or XISO with the system picker. Allow about 2 GB for the extracted maps. The app handles its own updates. Before uninstalling, copy your maps and the save/u profiles from Android/data/com.halo.decomp/files. That app folder also contains config.toml and mods.

Limitations and evidence

  • OpenCE is a port of a Halo: Combat Evolved decompilation; the project’s AGPL licence does not cover the original game code. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • Optional Halo Custom Edition maps and their matching resources belong in custom_maps. OpenSauce maps are incompatible.
  • Clicking a Halo or Discord invite starts OpenCE directly, outside Portcove, using the version that last registered the link. Close any game started that way before updating or rolling back in Portcove, and start OpenCE from Portcove once after an update before using an invite.
