Setup

  1. Prepare the exact USA revision

    Use a complete player and components you are independently permitted to use, with your own Wayne Gretzky’s 3D Hockey USA V1.0 ROM. The selected source identifies big-endian ROM SHA1 400aa84811f1f2f6c62c756b43b54d534d5a5ec8 and validates normalized bytes with XXH3-64 B615F7ACDFB899B4. Supported .z64/.v64/.n64 byte orders are normalized before that runtime check; their raw file digests are not interchangeable. This is source matching, not ownership or package authentication. Finish upstream ROM selection before attachment and keep the independent original.

  2. Keep the matching native Windows package

    The inspected official 0.8.1 Windows ZIP contains wg3d-recomp-v0.8.1/wg3d.exe as an AMD64 player with matching renderer/runtime libraries and notices. Keep the complete folder. The linked N64ModernRuntime, RT64 and the title’s own UI/input glue have distinct roles; do not select a ROM, recompiler, test runner or another game’s executable. No original, helper, compiler or game is obtained or executed by this guide.

  3. Add the normal game player

    Select wg3d.exe, use the complete extracted package directory as working directory and leave arguments empty. Review the exact intent and request Play separately, then use the upstream UI to start the already selected game. The native entry starts the linked runtime in process and saves window state on return. Its --frames, speed, capture and console options are diagnostic controls, not normal Play arguments. Finish missing-ROM setup outside the attached attempt.

  4. Preserve Roaming data and the actual Controller Paks

    Keep the whole active data root, normally %APPDATA%/WG3DRecomp on Windows, including the validated ROM copy, settings/input/window files, logs/wg3d.log and saves/controllerpak_port<N>/ for the corresponding controller ports. An already established --data-dir can choose an external root; preserve that exact directory too. The source declares no cartridge save type and routes saves to Controller Paks; do not replace them with another title’s EEPROM file or infer real save compatibility. This guide performs no import, migration, backup or deletion.

  5. Check component and original-game permissions

    Keep the own-code license and all N64ModernRuntime, N64Recomp, RT64, renderer/audio/UI and font notices. They do not license the original Midway game or other titles, ROM revisions or mod content. Use only a complete copy you are independently permitted to use. Four controller ports and Controller Pak options in source are not physical-device, multiplayer or card import/restore acceptance; those observations remain separate.

  6. Maintain the external copy explicitly

    Quit the actual game normally before upstream replacement, ROM changes or Controller Pak operations. Preserve independent recovery copies and review/relink changed executable bytes; forced termination is not a save-flush guarantee. Upstream playability/input/audio reports remain upstream claims, with no native/installed-app, full-game, save/reload or Supported acceptance asserted. Removing registration preserves external files; managed install/update/rollback/backup/removal remain unavailable.
