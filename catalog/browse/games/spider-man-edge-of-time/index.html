Setup

  1. Finish the exact owned-input installation upstream

    Use a complete copy and components you are independently permitted to use. The inspected upstream route requires your own Spider-Man: Edge of Time Xbox 360 US game and its required title update; Identity Crisis DLC is optional and separately owned. Complete the supported first-run installer upstream using the accepted Xbox 360 containers/images. Folder input is explicitly unavailable in this release. Do not substitute PS3/Wii/other editions or modified inputs. Portcove does not dump originals, import containers, apply updates, generate code or run setup.

  2. Attach the actual installed native player

    After upstream installation succeeds, select EdgeOfTimeRecomp.exe in the actual complete installed program directory, with that directory as working directory and no extra arguments for normal launch. Keep the matching ReXGlue runtime, GameLogic module, graphics compiler libraries, resources and notices together. The Windows build uses the normal native application/game path; no private helper or per-title wrapper is introduced. Do not attach the downloaded first-run copy if it still needs to copy itself into the chosen installation.

  3. Finish setup and relaunch paths before attachment

    The first-run program can copy itself into the selected installation, spawn a replacement and exit; retry/self-relaunch are also upstream paths. Finish these outside the attached session, then attach the resulting installed player. Ordinary installed startup additionally owns the cleanup/copy behavior described below, so replacement is not confined to setup. Close every actual player/companion before maintenance, retain complete prior working copies and data outside disposable .old locations, then review/relink changed selected bytes. Registration does not adopt or terminate a successor and does not invoke an updater or uninstaller.

  4. Review Play and preserve external ownership

    Review and consent to the exact selected native executable, established working directory and literal arguments, then request Play separately. Portcove saves only the selected launch details and registration. Upstream and you retain preparation, runtime replacement/recovery, originals, settings and external files. Removing registration preserves external files; no external update, backup, rollback, migration, conversion or deletion is offered.

  5. Retain source, dependency and original-data limits

    Keep the project’s BSD3 licence and all dependency notices. They apply separately from rights to the original game, title update, DLC and bundled upscaled textures. SDK version labels do not confirm which SDK built the published executable. Use only components you are independently permitted to use; a framework licence does not grant rights to every package component. Portcove has not confirmed upstream renderer, performance, controller or platform claims.

  6. Respect upstream startup maintenance

    Select the current registered creating installation, not a newer loose executable from another folder. With eot_update_apply enabled by default, ordinary Windows startup may delete program_files.txt-listed .old leftovers even when already running from the install root. Starting a newer copy from a different location can copy newer runtime files into the registered installation without relaunching. Upstream owns these behaviors; Portcove neither disables them nor manages that replacement. Keep prior complete runtimes and recovery backups outside disposable .old locations, close actual players before maintenance, and review/relink changed selected bytes. Registration does not promise automatic adoption of successors.

Setup notes
Preserve the actual installation and every profile
Keep the complete actual EdgeOfTimeRecompiled installation, game/ with Default.xex and Data/GameLogic.dll, separate DLC packages and all profiles/. The source selects profiles/<name>/ for user data, cache/ and reeot.toml; preserve every effective profile and any established custom game_data_root/profile argument, not only default. Retain saves, settings, achievement data, mods, backups, caches, logs beside the program and all custom/external roots with the creating runtime. Upstream may adopt earlier user data from its legacy reeot location and publish DLC into a profile; preserve both locations before maintenance. Windows HKCU/Software/reeot/Install records the selected installation; Portcove neither rewrites nor removes it.

Limitations and evidence

  • Portcove has not run the setup tools or game, or tested saves, controllers or installed Desktop behavior.
  • Upstream may adopt earlier user data from its legacy reeot location and publish DLC into a profile; preserve both locations before maintenance.
