Setup

  1. Check your original game files

    Use the matching expansion build 1.0.34.0 (PC 3.3.94012), ExeFS, RomFS and your own prod.keys for extraction. Other build IDs are unconfirmed.

  2. Follow the project’s setup

    Use setup.sh to prepare modules and shaders. On Mac, mac_app.sh builds the app and DM_MAC_M3 selects the older API. The iOS shell ZIP and Android shell files need your own prepared data. Rebuild when updating.

Setup notes
Version and platform notes
The guide covers Apple silicon macOS 26 or later or an older API on 15–25, iOS 26 or an older API on 18–25, and Android ARM64 API 31+ with Vulkan 1.1. The early Mac has keyboard and gamepad limits. HarmonyOS is community-supported and tvOS has reached character selection only.
