Setup

  1. Supply your matching disc and BIOS

    Use the original European WipEout disc (SCES-00010) with all 12 tracks. This kit requires your own retail SCPH-5552 BIOS dump. Keep the CUE and every referenced track together when using CUE/BIN.

  2. Prepare the managed Windows or Linux player

    In Portcove, select the complete matching CHD and your SCPH-5552 BIOS. On Linux, use a native C/C++ compiler, CMake, Ninja and Python 3.10 or newer. Choose Play after Portcove builds the player.

  3. Prepare a separate Mac player

    Choose the official Mac ZIP from the upstream releases. Use -macos-x64.zip for Intel or -macos-arm64.zip for Apple silicon. Extract the complete kit to a writable folder and follow its README-SETUP.txt. Put Xcode Command Line Tools, CMake, Ninja and Python 3.10 or newer on PATH. The inspected Mac setup host requires macOS 11 or newer. The bundled game and BIOS generators require macOS 15 or newer.

  4. Build and add the player on Mac

    Run WipEout_Recompiled from the unpacked folder and choose Generate & rebuild. In Portcove, select build-release/WipEout_Recompiled as the program and build-release as its start folder.

Setup notes
Updates and backups
Keep the complete working folder and back up your disc image, BIOS, saves, settings and overlay captures before replacing the kit. Keep the player with the folder that built it.
Linux generator compatibility
The bundled Linux generators require glibc 2.14 or newer and libstdc++ with GLIBCXX_3.4.26.

Limitations and evidence

  • Before replacing your kit, make a normal in-game save, close the game and keep the previous kit and memory cards. Upstream warns that save states may be incompatible across versions.
  • The managed route checks the original European release. The European Rev 1 disc has a different identity.
  • Portcove checks the first data track and track count. Keep the entire original disc intact.
  • The kit records BIOS-stage audio and FMV placement defects. Portcove has not verified native setup or gameplay.

Setup

  1. Keep the matching original

    Use data from your own PlayStation USA-region WipeOut disc; the official PC version is incompatible. Upstream supports the matching multi-bin/cue image with nine BIN tracks and one CUE, first data track MODE2/2352 and other tracks AUDIO, or its complete 517-file loose game set. Preserve every original image/track and cue outside the player folder. A generic ISO, another region or another game is a different input.

  2. Finish upstream setup and select the real player

    Use the official v1.2.256 Windows x64 ZIP and keep its complete wipeout folder. Follow the packaged README: provide matching original image copies in diskimages for upstream extraction, or the matching complete loose set in wipeoutgame with optional correctly named music in music. Finish normal upstream setup successfully before registration. The upstream player performs extraction during startup; this is not Portcove disc preparation or source authentication. Register wipeout.exe from the wipeout folder, not an extraction helper. Use the selected player’s containing folder as working directory and keep the already working literal arguments; do not invent shell commands.

  3. Register the existing player and use explicit Play

    You manage this external game and all its original files and saved data. Portcove saves the executable, working folder and launch arguments you select; it does not authenticate the complete package or original game files. Choose Play explicitly when you are ready. Removing the registration leaves external files in place. Portcove does not offer updates, backups, rollback, data migration or external-file deletion for this copy. Finish setup with the project’s tools and add only a working game. These instructions do not confirm successful setup, gameplay or save-state compatibility.

Setup notes
