Setup

  1. Get Arena’s original game data

    OpenTESArena checks for an installed Steam copy of Arena and also checks for GOG on Windows. For manual setup, get Arena from https://elderscrolls.bethesda.net/en-US/arena. Open Arena106Setup.zip and extract Arena106.exe as a RAR archive with a tool that supports it. Keep the complete ARENA folder and your original archive.

  2. Start the Windows or Linux package

    Extract the complete Windows x64 ZIP or Linux x86-64 archive. For manual setup, copy ARENA into the player’s data folder. Start otesa.exe on Windows or run ./run.sh from the extracted Linux folder. Linux needs glibc 2.34 or newer, libstdc++ with GLIBCXX_3.4.30 and a Vulkan driver. Keep the supplied libraries beside the player.

  3. Use the Apple Silicon app

    On Apple Silicon with macOS 15.5 or later, copy otesa.app from the DMG. For manual game data setup, open Show Package Contents and put ARENA under Contents/Resources/data. Keep the app’s supplied libraries together.

Setup notes
Use the separate Raspberry Pi build
The upstream release has a Raspberry Pi 5 archive with a 32-bit ARM hard-float executable. Use a compatible Pi userland with the required libraries and Vulkan support, then follow the Linux original-data layout and run.sh instructions. The release supplies no Intel Mac build or Android APK.
Keep your OpenTESArena settings
Close the game before backing up options-changes.txt. Look in %APPDATA%/OpenTESArena/options on Windows, $XDG_CONFIG_HOME/OpenTESArena/options or ~/.config/OpenTESArena/options on Linux, and ~/Library/Preferences/OpenTESArena/options on Mac. Keep your original game files and optional music patches separately. You manage runtime replacement using the upstream package.

Limitations and evidence

  • In OpenTESArena 0.18.0, selecting a slot in Save Game or Load Saved Game shows Not implemented. Keep your original Arena saves for the player that created them.
