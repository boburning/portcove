Setup

  1. Keep the complete experimental Windows preview

    Use the complete SuperMarioRPGSNESRecomp-windows-x64-v0.0.5.zip folder, including SuperMarioRPGSNESRecomp.exe, its libraries, assets and notices. This early implementation has only two checked ahead-of-time variants and falls back to interpreter execution elsewhere; its SA-1 core is emulated. The Recomp name is not evidence of a wholly native game or complete playthrough. No other-platform observation or native/gameplay qualification is supplied here.

  2. Use your own exact SNES ROM

    Supply your own Super Mario RPG: Legend of the Seven Stars ROM. The accepted headerless content is 4,194,304 bytes with SHA-256 740646f3535bfb365ca44e70d46ab433467b142bd84010393070bd0b141af853 and SHA-1 a4f7539054c359fe3f360b0e6b72e394439fe9df. Upstream strips an optional 512-byte copier header before hashing; these are content hashes, not a headered-file digest. Place smrpg.sfc beside the player or choose the existing file in its first-run picker. Preserve PolyForm Noncommercial terms separately from framework/UI/component and original-game rights; no ROM or private translated-output redistribution is granted.

  3. Add the ordinary Windows frontend

    Select SuperMarioRPGSNESRecomp.exe, set its complete containing release folder as working directory and leave arguments empty. Review the selected program, folder and arguments, then choose Play when ready and use the upstream launcher. It remembers the selected original in rom.cfg; keep the ROM at that path. Do not substitute a debug, headless or coverage command as the play route. Preserve upstream launch settings and controls rather than replacing them with another SNES title’s defaults.

  4. Preserve this title’s actual state files

    Keep rom.cfg, keybinds.ini, the launcher’s settings and the entire saves folder beside the executable, including saves/smrpg.srm and all smrpg*.sav state slots as present. Keep mods, original files and related user data. This title does not use the other SNES family members’ game-owned config.ini; do not create or copy one as a registration step. SRAM, execution snapshots and another title’s saves are different formats; no conversion, cross-build compatibility, import or backup is performed.
