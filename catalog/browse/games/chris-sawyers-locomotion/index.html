Setup notes
Set up OpenLoco on Linux
For a separately prepared copy, use the official x86-64 AppImage with FUSE support. The reviewed player needs glibc 2.28 or newer. Make it executable and run it directly to select your installed Locomotion directory containing Data/g1.DAT. Preserve the whole profile under ~/.config/OpenLoco or the actual XDG_CONFIG_HOME location. Keep separately selected saves, landscapes, custom objects and original-game folders.
Set up OpenLoco on Apple Silicon
For a separately prepared copy, use the upstream macos-arm64 ZIP on macOS 15 or newer. If downloading through Portcove, clear “Extract the archive after downloading”. Extract it with the system archive tool and keep the entire OpenLoco.app bundle. Upstream describes this build as unsigned and unnotarized. Follow its Mac instructions if Gatekeeper blocks it. Start it directly, select the Locomotion directory containing Data/g1.DAT and preserve ~/Library/Application Support/OpenLoco and custom locations. You manage this external copy and its updates.
