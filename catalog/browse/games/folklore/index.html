Setup

  1. Check the required game files

    Use your own North American BCUS98147 disc version 1.00, in JB folder form with decrypted EBOOT.elf of 6518936 bytes. European and Japanese editions and update 1.10 are rejected.

  2. Follow upstream setup

    Follow setup.ps1, build.ps1 and run.ps1 to download tools and generate C++ locally. Setup may install Visual Studio Build Tools machine-wide; review those changes before running it. Keep your original disc folder available while playing.

Limitations and evidence
