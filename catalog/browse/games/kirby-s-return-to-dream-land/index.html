Setup

  1. Complete the title’s supported preparation upstream

    Use the Kirby-specific Windows package, keep every file in the same writable folder and complete its supported launcher setup from your own North American SUKE01 WBFS or ISO. Windows 10 or newer is documented. This game package accepts that title identity; other ModernGekko games do not establish Kirby source acceptance. The original image remains unchanged and the package supplies no Nintendo game data.

  2. Keep the exact original and preparation boundary

    The Kirby-specific launcher extracts the selected original, configures a Sideways Wii Remote profile, detects a controller and selects an audio backend. Complete that preparation upstream before attachment. Portcove does not obtain original data or firmware, run the extractor or certify gameplay/save behavior.

  3. Attach the completed supported native entry

    Select KirbyWiiRecomp.exe with its package directory as working directory and no arguments. Use the supported launcher rather than a private game runner: the inspected launcher starts its matching runner and waits for that process to exit. Keep the complete runner, DLLs, Sys files and game-specific package together.

  4. Review launch details and manage updates

    Review the selected game executable, working folder and launch arguments, then agree to use them. Choose Play separately when you are ready. You manage setup, game replacement and recovery. Removing the registration leaves external files in place. Before changing versions, close the game and its companion programs and keep the working copy and every data location it uses. Review and select the changed executable before playing again. Portcove does not offer updates, backups, rollback, conversion, data migration or deletion for these external files.

Setup notes
Preserve the whole creating copy and effective data
The game-specific default profile is %LOCALAPPDATA%/kirby-wii-recomp, containing extracted game data, saves and configuration. Preserve it and every effective custom user directory with the original disc image, controller profiles, NAND/system settings, mods, caches, backups and creating runtime. Retain the game package’s GPL-3.0-or-later and separate notices; framework licensing does not grant Nintendo content or establish cross-game save compatibility.
