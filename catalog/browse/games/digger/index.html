Setup

  1. Run the Windows x64 portable copy

    Extract digger-win64.zip to a writable folder. Start digger.exe with SDL2.dll and zlib1.dll beside it. The release already includes the game.

  2. Install on Debian or Ubuntu x64

    On the release page, choose the ZIP named for your distribution and version. Extract it and install the ordinary digger amd64 DEB with your distro package manager. Start digger from a terminal.

  3. Install on Apple Silicon

    The upstream 1.3 MB digger-macos.pkg contains an Apple Silicon player for macOS 26 or later. It installs into /usr/local. After installing, run /usr/local/bin/digger from a terminal.

  4. Keep scores, settings and recordings

    Close Digger before copying its files. In a Windows portable copy, keep DIGGER.INI, DIGGER.SCO, DIGGER.FRD and DIGGER.DRF when present. Linux and Mac keep .digger.rc, .digger.sco and .digger.frd in your home folder. Copy any named recordings and custom levels from the folder where you saved them.

Setup notes
Use the source or browser edition
The upstream release provides source for local SDL builds. The project README also links the browser edition. The inspected Mac installer contains only Apple Silicon code, and this release supplies no Linux ARM64 or native Android package.

Limitations and evidence

  • The upstream game includes the Digger soundtrack. Use a copy you already have permission to use, and keep your scores and recordings before replacing it.
