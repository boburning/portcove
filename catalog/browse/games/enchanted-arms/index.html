Setup

  1. Check the required game files

    Use your own supported USA or Europe Xbox 360 Enchanted Arms ISO. The exact title ID, media ID and executable hash are not specified in the root README; check the importer and SETUP_TROUBLESHOOTING before preparing files. Game files are not included.

  2. Follow upstream setup

    Extract EnchantedArmsPC-0.5.8-windows-x64.zip and open EnchantedArmsLauncher.exe. Select your ISO, choose Build game, then Play. Setup compiles locally, needs an internet connection on first use and uses about 20 GB beyond the ISO. The Linux x86-64 AppImage preview 0.1.0 offers the same ISO and local-build flow.

Limitations and evidence

  • Upstream reports Windows save/load, menu and early-game testing, with a full playthrough still in progress. Invisible or incorrectly shaded characters and stutters remain. Gameplay in the Linux preview has not been confirmed on Linux hardware.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
