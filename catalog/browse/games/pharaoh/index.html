Setup

  1. Prepare Pharaoh and Cleopatra upstream

    Use your own unmodified original Pharaoh patched to version 1.3 with the Cleopatra expansion, in a writable complete installation. Pharaoh: A New Era and the Pharaoh demo are different or unsupported data. Prepare the official Akhenaten Windows CI/itch.io copy upstream, keeping all accompanying runtime files and scripts. This is a work in progress; no stable campaign or save-compatibility claim is made.

  2. Keep the original-data picker and actual root

    Select the prepared native akhenaten.exe and its established working directory, not a packaging/build helper. Its normal start can ask for the original installation; preserve that useful picker. The selected source also accepts the original data directory as a positional argument; retain an already established absolute path as one literal argument. Do not bypass upstream validation or treat a successful registration as proof of original data.

  3. Retain both runtime and writable game data

    On Windows, data_dir_pharaoh.txt beside the executable remembers the selected original root. Preserve that file, the complete creating runtime, its scripts/configuration including actual akhenaten.conf, and the entire selected writable original-data directory where upstream stores saves. Keep existing mods, profiles, captures, logs, custom/unknown files and any configured alternate paths. Do not replace that data with a clean runtime archive or assume a second executable isolates the same original directory.

  4. Check the prepared copy before registration

    Finish setup with the project’s tools, then start and quit the copy you intend to add. Keep its game executable, working folder and supported launch arguments. Review those details in Portcove and agree to launch them, then choose Play separately. Adding a copy does not confirm its original game files, gameplay or save compatibility.

  5. Keep updates and removal under the existing owner

    Close every running copy of the game before changing files. Keep the working game version and every data and profile folder recoverable. Update it with the project’s tools, then review and select the changed executable in Portcove before choosing Play. You manage setup, updates, file changes, data migration and recovery. Portcove monitors the process you selected; it does not prevent other copies from running or restrict the game’s file access. Removing the registration leaves external files in place. This route does not offer Portcove downloads, setup, updates, backups, rollback, data migration or external-file deletion.

Limitations and evidence

  • Use only a copy and content you are already permitted to use. Engine licensing does not grant rights to original game assets, music, mods or bundled components.
  • Before updating the game, keep a copy of its working files and every location containing saved data. Choosing a different executable does not give it a separate profile.
