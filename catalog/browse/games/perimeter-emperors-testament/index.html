Setup

  1. Use the matching original game

    Use your own complete Perimeter: Emperor’s Testament resources (models, textures, sounds, text, Resource and Scripts). The other title does not automatically supply this game. Exact retail patch/localization and shared-base requirements remain unpinned; preserve the complete matching original installation.

  2. Prepare the Windows player

    The inspected 3.0.10 GitHub release inventory has no binary assets. Follow upstream INSTALL.eng.md to build the Windows player and its required DLLs, or use an already prepared working upstream player. Keep a private working game copy. Register perimeter.exe and retain its working directory. The upstream content override is one literal argument, content= followed by the absolute folder containing Resource and Scripts. Do not infer that the linked Legate Edition retail distribution includes both classic campaigns.

  3. Prepare the Linux player

    On a 64-bit Linux system with glibc 2.28 or later, use Perimeter Release x86_64 from a successful main-branch push on the official Linux Build workflow at https://github.com/KD-lab-Open-Source/Perimeter/actions/workflows/linux_build.yml. Unzip the download and unpack Perimeter.tar. Keep the perimeter executable beside libdxvk_d3d9.so and libsteam_api.so. Use the system SDL2, SDL2_image, SDL2_mixer and SDL2_net libraries and a working Vulkan graphics driver. If a build is unavailable, follow the upstream Linux build guide. Select the native perimeter file and its containing folder. For Perimeter: Emperor's Testament, add content= followed by the absolute path of your private copy as one argument line. The folder must contain Perimeter.ini, Resource and Scripts. Keep any spaces inside that one argument.

  4. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Select the game executable and its working folder, and put each launch argument on a separate line. Choose Play separately when you are ready. You manage this game’s files, originals, saves and settings. Removing its registration leaves those external files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Close the game and keep a working copy and every data and profile folder before changing versions.
