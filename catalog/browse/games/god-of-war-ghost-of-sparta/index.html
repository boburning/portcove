Setup

  1. Check the required game files

    Use your own USA UCUS98737 CHD or ISO. Keep that image available while playing.

  2. Follow upstream setup

    Extract GoW_PSP_Launcher-v1.2.1.zip and choose Build after reviewing and consenting to its tool setup. It uses hash-pinned portable Clang, CMake and Ninja to generate C code and game binaries locally; Visual Studio is not needed. Keep your CHD or ISO for disc reads while playing.

Setup

  1. Check the required game files

    Use your own PSP ISO or extracted disc; decrypted EBOOT via external PSP_DECRYPT; exact regional IDs not stated in README.

  2. Follow upstream setup

    On Linux, follow setup.sh, port.sh and serve.sh to compile generated C++ into WASM from your own input and separately decrypted EBOOT. The browser player reads original disc data over HTTP Range. The native flag creates a headless diagnostic tool rather than the normal player.
