Setup

  1. Finish setup in the upstream Android app

    Install this fork’s Starship Android APK, open it and use the system file picker for your own Star Fox 64 US 1.0 or US 1.1 .z64 ROM. The app converts the ROM on the device; no PC Torch or copied sf64.o2r is needed. Japanese/European ROMs may supply optional voice language data with a US base; they are not base-game replacements.

  2. Keep your data when changing versions

    The release provides in-game mods and saves managers. Use those to preserve your data before changing or removing the app, and retain your original ROM. It reads the chosen ROM through the system picker rather than requiring a broad storage grant. The release lists Android 7+ with ARM64 or ARMv7; these are upstream requirements, not Portcove device observations. Updates and profile handling remain upstream-owned.

Setup

  1. Choose your original cartridge dump on first Play

    Choose Play, then select your own North American revision 1.1 Star Fox 64 cartridge dump in the player. The player checks the file and keeps its own copy in its profile, so keep your original separately. Another edition is not accepted.

  2. Keep the complete player package

    For a copy you manage yourself, extract the whole Windows package and run Starfox64Recompiled.exe with its assets and the supplied SDL2 and DXC libraries beside it.

Setup notes
Keep your actual profile when updating
Preserve the player's profile before replacing a copy you manage yourself: normally %LOCALAPPDATA%\Starfox64Recompiled. It holds the copied original, saves, settings and mods. A copy you run with portable.txt keeps them in its own folder instead. Keep a working copy before replacing the player.

Limitations and evidence

  • The package includes Chiaro fonts by Fontworks that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.

Setup

  1. Download from the official Starship project

    Use HarbourMasters/Starship on GitHub, open its v2.0.0 release and download Starship-Barnard-Alfa-Windows.zip. Extract every file into a new folder outside your Portcove library. Keep existing originals, installations and saves in place.

  2. Prepare the supported Star Fox 64 original

    Supply your own Star Fox 64 US 1.0 or US 1.1 Rev A original in .z64 format. JP and EU originals can supply optional voices with a US base; they cannot create the base game. Follow upstream’s conversion instructions if your dump is .n64 or .v64, keeping the original unchanged. Portcove registration does not validate or authenticate these original files.

  3. Complete upstream setup before adding the game

    Open Starship.exe from the extracted folder and select the supported US .z64 original in the upstream file picker. Let it generate sf64.o2r. Keep that generated file, the separate shipped starship.o2r and all other package files in the game folder. A ROM launch argument or the shipped starship.o2r alone does not finish preparation. Close the game normally before registration.

  4. Select the prepared game in Portcove

    Open this game’s Files tab, expand Use an existing installation · Installation options, then choose Use an existing installation. Choose game executable and select Starship.exe from the prepared folder. Set Start in folder to that folder and leave launch arguments empty. Review launch details and confirm the registration, then choose Play. Selecting this executable records your intent to run it; it does not authenticate it as an official publisher package.

Setup notes
Download check
The inspected v2.0.0 release metadata did not publish a SHA-256 for Starship-Barnard-Alfa-Windows.zip. A locally calculated hash identifies the file but does not confirm who published it.
Updates and backups
Use the project’s tools to update this copy. Close the game and helpers, preserve the whole working folder including sf64.o2r, mods, saves, starship.cfg.json and any legacy config.json, then prepare an update separately before changing launch details. Portcove offers launch and registration removal; it does not offer managed updates, backups, rollback, migration or deletion for these external files. Removing the registration preserves them. Any existing managed installation retains its own management and integrity checks.

Limitations and evidence

  • Portcove cannot automatically install the v2.0.0 Windows package because the expected download check is missing. Choosing Starship.exe yourself does not confirm who published it.
  • If the game crashes with DirectX 11, upstream documents switching to OpenGL through Settings or starship.cfg.json, then restarting. Preserve the configuration before editing it. This guide covers Windows; it does not qualify other platforms.
