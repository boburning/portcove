Setup

  1. Check the required game files

    Use your own Xbox 360 Mushihimesama Futari Ver 1.5 files, including the title, shell and two game modules. The exact region, revision and module hashes are not confirmed here; check upstream’s configurations and status before setup.

  2. Follow upstream setup

    On Windows, follow build_win.sh or build_win_dll.sh with Git Bash, clang and lld. The matching workbench also needs XDK 9328. Linux build_linux.sh and macOS build_mac.sh are development builds requiring external dependencies and the decompilation tree. No ready-to-use game package is confirmed.
