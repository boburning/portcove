Setup

  1. Start the Windows version

    Install and select Play in Portcove. If Windows blocks the unsigned upstream program on first launch, see the publisher’s First Run instructions.

  2. Use the Linux or Mac package

    On Linux x86-64 with glibc 2.35 or later, unpack the full archive with a tool that preserves its links. Run ./Runner from the extracted Runner folder. Use the Apple Silicon ZIP on macOS 11 or later or the Intel ZIP on macOS 10.15 or later. Open the included app and see the publisher’s First Run instructions if macOS blocks it.

Setup notes
Play your first run
Use WASD or the arrow keys to move, Space to fire and Escape to quit. The desktop packages include the game and artwork. No original DOS files are required.

Limitations and evidence

  • Runner keeps progress and upgrades for the current play session. Quitting ends that run.
