Setup

  1. Prepare the separate ROM, BIOS and patch inputs

    Use a complete player and components you are independently permitted to use. The selected 1.0.8 guide identifies 32 MiB Japanese MOTHER 3 SHA1 4f0f493e12c2a8c61b2d809af03f7abf87a85776, English v1.3 SHA1 306fb8874533b0fd0796208faa8bed2db4ae77fb, and English plus HQ Audio SHA1 4ffe71ce5c5e1e8d9be5fbd09968b60787169b21. Desktop also requires your own 16 KiB GBA BIOS, identified as SHA1 300c20df6731a33952ded8c436f7f186d25d3492. These identify documented inputs, not ownership or cryptographic import enforcement. The setup checks BIOS/ROM size and the runtime permits some hash mismatches; unknown patches remain unqualified. Android’s BIOS substitute is not a desktop source route.

  2. Keep the complete Windows player

    The inspected official 1.0.8 Windows ZIP contains AMD64 Mother3Recomp.exe, matching libraries/assets and separate component license files. Keep its complete extracted folder. The game runs through the linked GBA framework: translated dispatch and runtime/interpreter fallback are distinct, and the source can force interpreter fallback when no dispatch table is present. A Windows PE is not proof every game instruction is statically native. A source build, Android APK and another GBA game are separate routes.

  3. Finish upstream setup before Play

    Finish the upstream ROM/BIOS picker, any independently permitted translation and settings first; keep independent originals. Request Play separately, then use the upstream Play UI for the already configured game. The selected native entry runs its setup UI and linked game in process. Complete missing input, patch application, imports or maintenance outside the attached attempt. This guide obtains or executes no BIOS, ROM, patch, compiler, helper or game.

  4. Preserve player data and maintain the external copy

    Legacy cfg paths can be relative to their own folder; do not silently reinterpret them under a new CWD. Upstream import accepts battery .sav/.srm, not emulator save states; this is not observed compatibility acceptance. This guide performs no patching, import, migration, restore, backup or deletion. Quit the actual game normally before upstream replacement, ROM/patch changes or save imports. Preserve independent recovery copies. Forced termination is not a save-flush guarantee. Upstream HQ audio, smoothing, translation and save-import reports remain upstream claims; patch-dependent interpreter behavior, performance and compatibility are not generalized. No native/installed, campaign, save/reload or Supported acceptance is asserted.

  5. Retain individual component and content terms

    Preserve the port/runtime PolyForm Noncommercial 1.0.0 notices, the separately shipped recomp-ui MIT notice, and SDL, TinyCC, toolchain and other component notices. The selected dependency lock binds the GBA/UI revisions and verified title-specific patches; those source bindings are not source-to-binary reproducibility. Component licenses do not provide Nintendo ROM/BIOS, translation-team or third-party mod rights. Use only a complete copy and patches you are independently permitted to use. Existing RetroAchievements/account settings remain upstream-owned; no login, credential change or online acceptance is provided.

  6. Select the prepared player

    Select Mother3Recomp.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: saves/mother3_en_v13.sav and its .sav.bak retained by upstream battery-save import; state/settings data, config.ini, keybinds.ini, game.toml, rom.cfg and bios.cfg; mods/rom-patches and existing external original/patch/save paths. Back up these locations separately; registration does not migrate or certify their compatibility.

Limitations and evidence
