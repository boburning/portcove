Setup

  1. Install the stable client

    On 64-bit Windows, run the official setup program and follow its installer prompts. The 0.5.1.2 installer filename says Win32 and contains a 64-bit client. On Mac, choose the Intel or Apple Silicon disk image and copy the complete FreeOrion app into Applications. The current package needs macOS 10.15 or newer on Intel and macOS 11 or newer on Apple Silicon. For Intel or Apple Silicon Mac registration, keep its name FreeOrion.app and select /Applications/FreeOrion.app/Contents/MacOS/FreeOrion with its containing folder. Keep the whole bundle and leave ordinary launch arguments empty. Review the details, add the client and choose Play. The later FreeOrion.exe selection and executable-containing folder instructions apply only to Windows. On Mac or Ubuntu, use the program and working folder specified for that platform.

  2. Use your Linux package manager

    On Ubuntu x64, install matching freeorion and freeorion-data packages with all dependencies. In the reviewed 0.5.1.2-1 package, select the native /usr/lib/freeorion/freeorion and set /usr/share/games/freeorion as the working folder, with no arguments. Keep the sibling server/AI programs and package data/libraries installed. /usr/games/freeorion is a shell wrapper, not the native selection. Review the details, add the client and choose Play. Other distributions can use different paths; verify their complete native installation first. Flathub remains a separate option: install and run org.freeorion.FreeOrion through Flatpak, which owns its runtime and updates. Do not select Flatpak’s internal /app/bin path as a host-native program. Update through the same package manager.

  3. Keep your saves and settings

    Close FreeOrion and any separately hosted local servers before backing up. A local server and its AI can finish shutdown after the client closes; wait for their exit before copying or changing the installation or data. Copy the FreeOrion folder under %APPDATA% on Windows or ~/Library/Application Support on Mac. On Linux, keep the freeorion folders under ~/.config and ~/.local/share, using your configured XDG folders if they differ. For Flathub, keep ~/.var/app/org.freeorion.FreeOrion. Also keep any separate save directory you chose in the game.

  4. Select the prepared player

    Select FreeOrion.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Client and server ownership
Portcove tracks the graphical client you select. FreeOrion starts its own server and AI processes for games; a local server you host can stay separate after the client closes. Portcove does not take ownership of those servers or certify that every companion has stopped. You and upstream own installation, updates, saves, settings, mods, backups and removal. Removing the registration preserves all external files. The current official release has no Android package or native Windows ARM64 build.
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: Windows %APPDATA%/FreeOrion saves, settings and mods; Linux XDG configuration and data/freeorion folders, or ~/.config/freeorion and ~/.local/share/freeorion; Mac ~/Library/Application Support/FreeOrion settings, saves and mods; every custom save or user-data location; separately running upstream servers and AI retain their own writes. Back up these locations separately; registration does not migrate or certify their compatibility.
