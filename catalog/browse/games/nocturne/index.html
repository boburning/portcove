Setup

  1. Choose an engine and keep the original install

    Use the v0.1.11 engine for your system and keep the full original Nocturne installation, including its POD files. Choose Vanilla for the original settings and behavior or Enhanced for the added features. If you use the in-place setup from the release notes, make a separate working copy before unpacking the engine.

  2. Set up Windows or Linux with separate saves

    Keep the executable and bundled libraries together. Open nocturne.exe on Windows or ./nocturne on Linux from a terminal with --data-dir pointing to the complete game installation and --user-dir pointing to a folder for that engine’s saves, settings and logs. Use separate user folders for Vanilla and Enhanced. Linux packages are available for x86-64 and ARM64.

  3. Prepare the Mac app and its shared data folder

    Choose the Intel or Apple Silicon app that matches your Mac. Follow the upstream first-launch instructions, then copy the complete original installation into NocturneDecomp under ~/Library/Application Support. Both Mac apps use that folder and share its saves by default. Back up the folder before switching editions or replacing files.

  4. Make the original movies available

    For cutscenes, use a working copy of the game files as your --data-dir on Windows or Linux, or as the Application Support copy on Mac. In that copy, create a video folder and copy the original .AVI files there from the AVI folder.

Limitations and evidence

  • Upstream reports limited testing on Macs and ARM64 Linux. The Mac apps lack a developer signature.
  • Upstream’s 0BSD license covers its original work. The release includes reconstructed game code that this license does not cover.
