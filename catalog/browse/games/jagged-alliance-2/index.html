Setup

  1. Keep a clean original installation

    Use your own unmodified Jagged Alliance 2 installation with its Data folder. In the launcher set JA2 Data Directory and Game Version. For Russian releases, use RUSSIAN for BUKA Agonia Vlasty or RUSSIAN_GOLD for Gold.

  2. Choose the Linux AppImage for your processor

    The inspected x86-64 AppImage opens the upstream launcher. The aarch64 and armhf AppImages start ja2 directly. For the direct entry, configure game_dir in ~/.ja2/ja2.json and use -resversion with your localization if needed. The armhf runtime uses libfuse.so.2. Keep the x86-64 launcher open until its game exits.

Setup notes
Open the Apple silicon Mac app
Mount the Apple silicon DMG and copy JA2 Stracciatella.app out of it. Both the launcher and player in this build need Apple silicon and macOS 15 or later. Start the app to configure your original data and localization.
Configure the Android APK
Use the upstream APK on a compatible device that allows its storage access. In the Data tab choose your original game folder and version, then choose a separate Save Game Directory if needed. Keep the originals and your effective save location before replacing the app. The inspected APK uses io.github.ja2stracciatella, targets Android API 26, and contains ARM64, ARMv7, x86 and x86-64 native libraries.

Limitations and evidence

  • Back up the whole effective profile and any custom save folder. On Linux and Mac the default is ~/.ja2. On Windows the player prefers AppData/JA2 and reuses Documents/JA2 when it is the existing profile.
