Setup

  1. Use the actual Community Edition player

    Keep a complete already permitted Fallout 2 Community Edition 1.3.0 Windows x64 copy and supported original Fallout 2 installation. Upstream documents fallout2-ce.exe as the drop-in player in that folder. Select it directly, not fallout2.exe, an installer or another mod engine. Native Windows entry owns the game loop and uses the shared GNW95MUTEX; another such running instance can prevent startup.

  2. Finish supported original setup upstream

    Use your own complete supported original game installation including master.dat/critter.dat/patch000.dat/data and other required files; keep the whole working game and data. Finish configuration and a normal upstream start/quit before registration. Restoration Project, EtTu and Olympus2207 are unsupported by the selected upstream contract; do not infer sfall features or compatibility for other mods. Portcove does not import or authenticate the original set or generated/private outputs.

  3. Retain the real working directory and configuration

    Use the actual prepared game folder as working directory and preserve its supported literal arguments. Windows entry does not chdir for you. fallout2.cfg is located from the executable path while actual DAT/patch/music paths can be relative or absolute. Keep those real paths and selected mod setup; do not rewrite a host root or force a fresh profile. Review exact consent and choose Play separately.

  4. Retain the engine license and original rights separately

    The selected engine uses Sustainable Use License 1.0, not GPL/MIT. Personal/noncommercial/internal-business scope, free noncommercial distribution conditions and notices remain applicable. This guide adds no general commercial, original/mod asset, repackaging or redistribution grant; attach only a copy you are already permitted to use.

  5. Update the game and remove its registration

    Close every running copy before changing external files. You manage setup, game replacement, profile changes, data migration and recovery. Keep the working game version and every data folder, update it with the project’s tools, then review and select the changed executable before choosing Play. Portcove monitors only the process you selected and agreed to launch. It does not prevent other copies from running, restrict file access or take over unrelated helpers or replacement processes. Removing the registration leaves external files in place. This route does not offer Portcove downloads, setup, updates, backups, rollback, data migration or deletion.

Setup notes
Preserve every actual player-data root
Keep the complete runtime/original data, fallout2.cfg, actual configured master-patches root (normally data) and its SAVEGAME/SLOT contents, music, mods, logs and unknowns, including configured external/legacy roots. Preserve the old creating copy before upstream replacement. Another runtime folder is not a save/instance isolation or cross-version state-compatibility guarantee.
Use the upstream Linux or Mac player
The Linux x86-64 tarball contains fallout2-ce and needs SDL2. The Mac disk image contains an app for Intel and Apple silicon. Use the tagged project instructions to put the player with your original Fallout 2 data. The featured Portcove registration instructions above are for the prepared Windows player.
Use the Android release from the project
The upstream APK includes ARM64, ARMv7, x86 and x86-64 builds. On first launch, choose a folder with your original master.dat, critter.dat, patch000.dat and the data folder. Open the same app again to use the imported data. Its release profile is under Android/data/com.alexbatalov.fallout2ce/files on typical Android devices. Debug builds use a separate profile. Keep the actual profile when updating.
