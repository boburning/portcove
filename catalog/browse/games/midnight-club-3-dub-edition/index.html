Setup

  1. Check the required game files

    Use your own original Xbox Midnight Club 3: DUB Edition NTSC-U or PAL Europe disc. Supply extracted default.xbe plus all disc files; make extract ISO=<own.iso> prepares Unix routes and the Windows installer can extract the owned ISO. Regional discs use separate game/ and game-eur/ folders. Exact XBE revision/hash is Unknown. Do not treat the separate Remix PAL development/NRO claim as an accepted desktop source profile.

  2. Follow upstream setup

    Source preparation owned by upstream/player. macOS: install Xcode command-line tools/Homebrew, make setup, extract own DUB Edition disc, make lift, then make mac-app DISC=<disc-folder> or make build run. Linux: make setup, own-disc extraction, make lift and make build run; CPU matrix remains Unknown. Windows: install_windows.bat installs MSYS2 in C:\msys64 if absent, obtains dependencies, lifts code and builds the personal runtime; this is local compilation, not a precompiled player download. No commands were executed by Portcove. Desktop Remix preparation is not established.

Setup notes
Choose the Android package for your own disc edition
The v1.1.0 release has separate ARM64 beta APKs. Open the matching app once, then copy your extracted disc with default.xbe to Android/data/io.github.laureladastra.mcdub3/files/game for DUB Edition or Android/data/io.github.laureladastra.mcdub3remix/files/game for Remix. Press Play in the app. Uninstalling deletes that app’s folder and saves.
