Setup

  2. Follow upstream setup

    Follow upstream instructions to merge your own CUSA08790 base 1.00 and update 1.13, run game_check.py, then build and run the game with its GTK launcher. Optional two-player mode runs two game instances; it is separate from original native local multiplayer.
