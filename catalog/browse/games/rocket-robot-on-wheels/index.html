Setup

  1. Select your own Rocket ROM on first Play

    On first Play, choose your own supported Rocket: Robot on Wheels US ROM in the upstream launcher. It verifies the game and remembers the chosen path. Use the upstream menus for controls and compatible mods; no game compilation or separate installer is needed for the published player.

  2. Keep saves and mod profiles separately backed up

    Default Windows saves, settings, mod profiles, mod-specific saves, logs and crash reports use %APPDATA%/Rocket-R. Keep a separate backup of the actual profile before changing versions; older versions may not read newer saves. Its external profile is outside Portcove backup and runtime rollback; rollback does not rewind saves. Keep each release’s own bundled engine/mod resources together, and keep custom --config or developer paths backed up separately.

  3. Choose the Linux package for your system

    Portcove manages the direct x86-64 AppImage. It needs working AppImage and FUSE support, glibc 2.35, GLIBCXX 3.4.30 and a Vulkan driver. For an external Linux copy, choose the matching x86-64 or ARM64 AppImage or follow the upstream Portable archive instructions. Steam Deck has a separate package and START-ROCKET-R.sh. You maintain those external copies.

  4. Open Rocket-R on Android

    Install the upstream ARM64 APK on Android 7 or later on a device with the required Vulkan 1.2 features. Choose your own matching US ROM in the app and keep the original separately. The app stores a private ROM copy and its own saves, settings and mod profiles. Preserve app data before clearing storage, uninstalling or changing packages. You update this Android installation yourself.

Setup notes
Check your original game file
Rocket-R accepts your own US game with code NSUE, 12 MiB and canonical SHA-1 622d71a44da0b81ea68092cac9198c66154a4f4a. The desktop launcher accepts .z64, .n64 and .v64 files.
Find your Linux profile and launch logs
By default the game uses $XDG_CONFIG_HOME/rocket-r or ~/.config/rocket-r for settings, saves and mod profiles. A custom --config path or the rocket-r-data fallback changes where you need to back up. The upstream launcher records logs in $XDG_STATE_HOME/rocket-r or ~/.local/state/rocket-r, with a temporary-directory fallback when needed.
