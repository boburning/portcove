Setup

  1. Download your system’s setup kit

    Extract the complete official kit into a separate writable folder and keep your working copy. Use the wizard’s build-tool check. Windows can use upstream’s portable pack, including Python 3, or suitable installed tools. Linux and Mac require Python 3 and system C/C++ compilers; on Mac, install Apple’s Command Line Tools. The current 0.2.0 kit uses the native Syphon_Filter_2_Recompiled setup program, replacing older SETUP.bat instructions; paths with spaces are supported. If CMake or Ninja is missing, setup can obtain a portable pack for your system; Linux and Mac still need their native compilers. Downloading, extracting and discovery do not run a helper, compiler or game. Windows, Linux and each Mac architecture have separate downloads; Mac executables are ad-hoc signed, not Apple notarized. Follow the selected release’s platform instructions.

  2. Prepare both discs and your BIOS

    When ready, deliberately open the upstream setup program. Supply your own Syphon Filter 2 USA Disc 1 (SCUS-94451) and Disc 2 (SCUS-94492) as the supported Redump CUE/BIN set or CHD, plus your own 512 KiB SCPH-1001 BIOS with SHA-256 71af94d1e47a68c11e8fdb9f8368040601514a42a5a399cda48c7d3bff1e99d3. OpenBIOS is not supported by this kit. Reuse valid prepared choices; follow Generate & rebuild to finish the native player. Portcove does not run this upstream preparation for you.

  3. Add the finished player, then choose Play

    After setup succeeds, select Syphon_Filter_2_Recompiled.exe in build-release on Windows, or the native Syphon_Filter_2_Recompiled in build-release on Linux or Mac. Keep the complete prepared kit and use the player’s folder as its working directory. Choose a different actual output location if you deliberately configured one. Saving launch details never starts the game; Play is a separate action. Keep the rich launcher. In the current version, Disc 2 can be changed through the F1 menu even when a CHD verification warning remains in the launcher. The game reads progress from memory-card slot 1.

Setup notes
Keep your working copy and data before updating
Use the project’s tools to rebuild or update this copy. The default cards, save states and options live under build-release/saves. Check your settings for any custom card or profile locations.

Limitations and evidence

  • Close the player and preserve the complete working kit, actual saves/card paths, settings.toml, keybinds.ini, config.ini, mods with their installed packages and state, original discs/BIOS and any custom locations before changing versions.
  • Keep older kits separately: upstream says v0.1.x cards/settings are not carried over, without establishing a safe migration. Do not copy an old generated cache or whole mods tree over a new runtime.
  • Portcove does not back up, roll back, replace or delete these external files.
  • Let the first session finish preparing optimized code. If the release’s known intro freeze occurs after early closure, follow its cache-only recovery for build-release/cache with the player closed; preserve saves and the working copy.
