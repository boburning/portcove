Setup

  1. Install Hedgewars on Windows or Intel Mac

    Use the publisher’s 1.0.0 installer on Windows with 32-bit application support, or copy the complete Hedgewars app from the Intel Mac disk image. Hedgewars also publishes 1.0.3 source with build and crash fixes. The Windows and Mac binaries are still 1.0.0. Check the publisher’s download page for a newer installer or disk image.

  2. Install Hedgewars on Linux

    Use your distribution’s hedgewars package or install the community package org.hedgewars.Hedgewars from Flathub on x64 or ARM64. Start the installed launcher so it can find its game data and engine. Use the same package manager for updates.

  3. Keep your teams, saves and replays

    Close the game before copying its profile. On Windows, copy Hedgewars from your Documents folder. If Windows could not find Documents, check %USERPROFILE%\.hedgewars. On Mac, copy ~/Library/Application Support/Hedgewars. On Linux, copy ~/.hedgewars or, for Flathub, ~/.var/app/org.hedgewars.Hedgewars/.hedgewars. If you used --config-dir, copy that folder. Keep the whole profile for teams, schemes, saves and replays.

Setup notes
Use an existing Ubuntu installation
When registering the Ubuntu package with the Portcove CLI, select /usr/lib/hedgewars/bin/hedgewars and use /usr/lib/hedgewars/bin as the working directory. The /usr/games/hedgewars shortcut is a symlink. Use the in-match quit prompt when you want to resume an unfinished match.
