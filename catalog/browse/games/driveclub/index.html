DriveClub (DriveClub Recomp)

An experimental PS4 DriveClub port for Windows 10/11 x64, requiring a Haswell/Excavator/Ryzen-class CPU and Vulkan 1.3. Use your own CUSA00093 or CUSA00003 v1.28 dump; the European edition has less testing. Online features do not work, and other patches or repacked dumps are untested. The Recomp name does not imply PowerPC translation. Other OS routes, exact accepted hashes and BIOS/firmware needs are unconfirmed. You and the project manage setup and updates; Portcove has not qualified a release package or confirmed gameplay.

Setup

  1. Prepare your own matching PS4 data

    Use your own DriveClub PS4 base-game folder containing game000.dat and its matching version 1.28 update folder containing eboot.bin. The selected upstream route documents CUSA00093; CUSA00003 version 1.28 is accepted but less tested. Other revisions or repacked dumps are not automatically compatible. The PS4 x86-64 program runs directly with reimplemented system services and Vulkan graphics translation; the name does not mean PowerPC translation or completely native PS4 hardware. Portcove supplies no game files, keys or extraction.

  2. Keep the complete upstream Windows package

    Use the complete inspected driveclub-recomp-0.4.0-win64 package in a writable folder you control, preserving DriveClub.exe, its frontend/backend/runtime programs, assets, DLLs and notices. The upstream baseline is Windows 10/11 x64, Intel Haswell or AMD Excavator/Ryzen onward and Vulkan 1.3 graphics. Finish upstream first-use preparation and choose your existing update/base folders there. Keep selected graphics/settings choices; an internal runtime executable alone does not reproduce the launcher’s initialization and environment.

  3. Add the ordinary native launcher

    Select DriveClub.exe in the complete extracted package root, use that root as working directory and leave arguments empty. Review the selected program, folder and arguments, then choose Play separately and use the ordinary upstream Play action. Do not use the benchmark, backend, wheel diagnostic or an internal game runner as this route. The normal launcher can start its game and close; Portcove observes the selected launcher only, so a finished activity does not establish that the game has exited.

Setup notes
Preserve the selected career and all prepared data
Keep the complete data folder, including data/user/savedata, data/profiles with active.txt, and data/backups/profileN, plus launcher.ini, input/camera settings, generated preparation, mods and existing recovery copies. Profile selection swaps the active savedata through the upstream launcher; its automatic per-start backups retain only the newest ten. Preserve your own independent copies and original PS4 folders. Portcove does not change profiles, authenticate original files, migrate saves or manage those backups.
Leave updates and recovery upstream
Use the game’s own Quit and close the actual game, launcher, helpers and any independently used server before replacement, rebuild or recovery. Upstream owns its update/settings/preparation behavior; retain the previous complete working package and data and review the native path after changes. Keep project GPL and all separate library, NVIDIA DLSS, mod and original-game terms. This guide offers the existing local player route, not online/server/firewall setup, DLC entitlement or managed update/backup/rollback. Upstream race, wheel, GPU and save reports are not Portcove native/gameplay or Supported qualification.
