Setup

  1. Prepare the game in Recompia

    Extract the package for your system. Open PokopiaLauncher.exe on Windows, PokopiaLauncher.AppImage on Linux, or PokopiaLauncher on Apple silicon Mac. Select your own Pokémon Pokopia game data at version 2.0.1a, then choose Set up. The launcher assembles the game and translates shaders on your computer. You can pause and continue setup from the launcher.

  2. Return to the launcher to Play

    After setup, open the same launcher and choose Play. To use Steam, add the launcher with no launch options. Version 0.15.0 removed direct --play so the launcher can check for updates before playing.

Setup notes
Use the upstream update and save controls
Use Recompia’s Update and Set up again controls when it asks to rebuild. Solo saves default to the save folder inside the game directory. Keep the actual folder if you changed save_dir in pkp.ini or set NXRT_FS_SAVE_DIR. Keep any separate co-op save folders as well. Recompia says its update retains saves and shaders. Back them up separately from Portcove.
Choose the native Linux ARM64 package
For Linux on ARM64, choose the linux-arm64 tarball from the upstream release page. It contains an ARM64 AppImage for setup. Follow the same upstream original-file and setup instructions.

Limitations and evidence

  • Keep a separate backup before switching between solo and co-op setups. Co-op uses a separate save and starts from the beginning.
