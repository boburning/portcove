Setup

  1. Prepare the PS4 Remastered edition upstream

    Use a complete copy and components you are independently permitted to use. The Windows 3.0.0 route targets God of War III Remastered for PS4, CUSA01623 or CUSA01715 at 01.00/01.02, with your own decrypted eboot.bin, sce_module and sce_sys folder. The original PS3 game is a different input. Follow upstream first setup outside Portcove, choose the actual game/update folders and save the intended configuration. No original, patch, installer, helper or build is obtained or run here.

  2. Keep the current complete Windows package

    The inspected spartanport-windows.zip contains spartanport-windows/SpartanPort.exe, Play SpartanPort.exe, compatibility-name launchers and bin/spartanport-probe.exe with matching DLLs and resources. Keep the entire package together in a writable folder. The current source is a Rust launcher/runner; do not apply older Python-only launch coordinates or select a compatibility shim, GPU helper, internal probe, DLL or PS4 eboot.bin. Upstream specifies Windows 10/11 x64, AVX and Vulkan 1.3; check that your CPU and GPU meet those requirements.

  3. Select the saved-settings play route

    After upstream preparation, select SpartanPort.exe, use its complete extracted spartanport-windows directory as working directory and set the single argument --play. Review and consent to the selected launch details, then choose Play separately. With a valid saved installation this runs its --run child and waits for the native game/probe result; missing setup opens the GUI instead. Finish that setup outside the attached attempt before retrying. Portcove has not tested Windows gameplay, dependency loading or whether all child processes close.

  4. Preserve current and legacy data roots

    The current ordinary Windows package stores settings.json and spartanport.ini beside the launcher, with user holding saves, shader cache and last_run.log. A saved user_dir or established SPARTAN_DATA_DIR, SPARTAN_USER_DIR or SPARTAN_CONFIG can select other roots; preserve every effective location without setting a new override here. Also retain any existing gow3.ini, old %APPDATA%/gow3-launcher/settings.json, original game/update folders and custom saves. Do not assume the earlier gow3 name, framework ancestry or another PS4 title implies save compatibility.

  5. Complete upstream migration and restarts separately

    The rename/migration code can copy old settings to new names and retains old files; that is upstream behavior, not a migration performed by this attachment. Finish migration, updater replacement, voice tools, edition/config changes that restart the game, and repairs outside an attached session. Close the actual game and all helpers/successors, retain independent recovery copies, then review/relink changed executable bytes. Normal game exit is preferred; forced termination is not proof of save flush or child quiescence.

  6. Keep ownership and qualification explicit

    SpartanPort/gow3_pc is this existing God of War implementation; Bloodborne ancestry names a shared framework, not a replacement original-game identity or inherited qualification. Preserve GPL and all bundled component/NVIDIA notices; their grants do not provide original-game rights. Experimental Linux/old-CPU and GPU limitations remain upstream claims at their own scope. Removing registration preserves every external file. Portcove offers no managed install/update/rollback/backup/deletion or Supported/native/installed-app acceptance for this external copy.
