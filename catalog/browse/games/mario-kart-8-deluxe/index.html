Mario Kart 8 Deluxe (nxport)

An experimental nxport Switch builder for Mario Kart 8 Deluxe, using an Apple Silicon NVN compatibility layer with game-specific support. The project reports macOS testing of v3.0.4. Time trials, multiplayer, online and wireless modes crash. There is no release package: clone and build nxport-builder, choose this game’s profile and the Mac or iOS target, then build a local app or IPA. You and the project manage preparation and rebuilding. Use your own extracted ExeFS/RomFS/Logo. Version 3.0.4 is documented. Windows and Linux players are unconfirmed. Portcove offers no setup or launch integration and has not tested gameplay.
