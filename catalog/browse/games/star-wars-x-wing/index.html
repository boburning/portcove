Setup

  1. Choose your original game data

    Select your complete original 1994 and/or 1998 installations when prompted. For 1998, choose the root containing X-Wing Data, IVFiles and MUSIC. If you have both editions, the upstream recommended configuration combines them.

  2. Start the Linux player

    On Linux x86-64, install the official portable engine in Portcove, then choose Play and select your original game data in the upstream picker. Use glibc 2.35 or later, libstdc++ with GLIBCXX_3.4.29, and a Vulkan driver. If you prefer an external copy, keep the resources, shaders and lib folder beside OpenXW.

Setup notes
Use the optional 1993 flight mode
An extracted original 1993 installation with B-Wing can supply flight graphics and missions. Keep an installed 1994 or 1998 edition for its menus and cutscenes.
Open the Apple silicon Mac app
Mount the upstream v0.0.3 macos-arm64-release.dmg and copy OpenXW.app out of it. Use Apple silicon, macOS 13 or later and Metal. Keep the app bundle intact and maintain this copy outside Portcove.
Keep your settings and pilots
The normal SDL profile is TotallyOpen/OpenXW under the Linux data home or Mac Application Support. Keep the whole profile with the player closed.

Limitations and evidence

  • Back up the entire effective profile, all original game folders, and the working player before updating. If the profile cannot be opened, check the working directory for pilots, settings and other files.
