Setup

  1. Install the stable desktop build

    On Windows x64, run the official installer. On Intel or Apple Silicon Mac, open the stable disk image and copy The Battle for Wesnoth.app into Applications. On Linux, use your distribution’s stable package or install org.wesnoth.Wesnoth from Flathub on x86-64 or ARM64. Use your package source for updates.

  2. Start a campaign and save your game

    Open Wesnoth and choose Tutorial or Campaign. The stable desktop package includes its base game and campaigns. Save from the in-game menu before closing Wesnoth.

Setup notes
Keep the profile for your release series
Open Game Version (i) from the main menu to find the active data and settings directories. Close Wesnoth before copying them. For 1.18, check Documents/My Games/Wesnoth1.18 on Windows. The sandboxed Mac app keeps its profile in ~/Library/Containers/org.wesnoth.Wesnoth/Data/Library/Application Support/Wesnoth_1.18. Older unsandboxed copies can use ~/Library/Application Support/Wesnoth_1.18. Linux normally keeps data in ~/.local/share/wesnoth/1.18 and configuration in ~/.config/wesnoth. Flatpak keeps them in data/wesnoth/1.18 and config/wesnoth inside ~/.var/app/org.wesnoth.Wesnoth/. Copy the actual locations the game shows if they differ.
Try the Android preview
F-Droid offers the upstream development series for Android. Choose its package for your device and keep its progress and add-ons separate from stable desktop profiles. Get it at https://f-droid.org/en/packages/org.wesnoth.Wesnoth/.
