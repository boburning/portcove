Setup

  1. Let the upstream launcher finish setup

    Extract the complete official unstable Windows x64 ZIP into a new empty folder. On first deliberate launch of OpenTricky.exe, choose your own USA original-Xbox SSX Tricky ISO or XISO. PS2, GameCube, PAL and Japanese editions are not supported by this route. Windows 10/11 x64 and Direct3D 11 are required. The package has no installer.

  2. Keep the launcher as the update owner

    Choose OpenTricky.exe with its folder as the working directory when registering it, then save launch details and choose Play separately. The launcher controls game settings, original-disc selection and consented signature-checked updates. Portcove leaves the external runtime under that owner; discovery never starts the updater. The documented Linux/Steam Deck route uses Wine/Proton with the Windows package; it is not a separate native Linux archive.

Setup notes
Preserve saves when changing versions
Back up Documents/My Games/SSX Tricky/Saves, or the local Saves directory and portable.txt if you chose portable saves. Keep settings.ini, screenshots and bug reports separately as needed. For 0.1.2 use the launcher’s updater. From 0.1.1 upstream requires a fresh folder, choosing the disc again and fresh settings; keep the old working copy and do not copy its settings.ini over 0.1.3. New launch shortcuts use bin/SSX Tricky.exe. External registration provides no Portcove-managed Update, Backup or Rollback.
