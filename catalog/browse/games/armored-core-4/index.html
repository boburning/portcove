Setup

  1. Check the required game files

    Use your own USA BLUS30027 disc folder containing PS3_GAME. Supply your own firmware 4.93 PUP and use RPCS3 for one-time decryption. This guide does not specify the exact supported disc revision; check the project’s requirements before setup.

  2. Follow upstream setup

    Run the release launcher with your own dump. It downloads a compiler of approximately 250 MB and compiles the game locally.
