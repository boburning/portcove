Setup

  1. Check the required game files

    Use your own USA GFZE01 disc in ISO or CISO form. Its main.dol must have SHA-1 421c88106697d3275a3fc26fb7a01bf6d816b271. Convert RVZ or GCZ files first using upstream instructions.

  2. Follow upstream setup

    Build from source and generate code locally. The first build briefly runs the game to capture a module assembled at runtime; review that step before starting it. Keep your disc image available while playing.
