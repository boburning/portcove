Setup

  1. Check the required game files

    Use your own USA SCUS94907 disc with all 45 tracks and boot executable SCUS_949.07.

    On Windows x64, extract the v0.3.3 ZIP. On Linux x86-64, use the v0.3.2 AppImage and check its setup instructions. Start the upstream player and choose the CUE file for your complete disc set. Keep your original disc files separately.
