Setup

  1. Complete the title’s supported preparation upstream

    Complete the supported upstream setup from your own USA SLUS-01105 CUE and every associated BIN before attachment. The release-root Street_Fighter_EX2_Plus.exe is a setup host; it generates and builds the completed game in build-release. Keep the whole creating project and output together. Portcove does not run that preparation or distribute its private generated game code.

  2. Use the matching original and setup procedure

    Provide your own USA SCPH1001 retail BIOS: this title requires the 512 KiB image identified upstream by CRC32 37157331 and sets openbios=false. The generic packaged README-SETUP description of optional BIOS/OpenBIOS does not override this title requirement. Complete the title-specific BIOS setup upstream.

  3. Add the completed supported game program

    Select the completed build-release/Street_Fighter_EX2_Plus.exe with its executable directory as working directory and --launcher as the literal argument. Do not attach the release-root setup host or an SDK emitter. The completed game-dispatch binary bypasses setup forwarding; its native main owns launcher/game execution.

  4. Prepare the official Linux or Mac kit

    Extract the complete Linux x86-64, Intel Mac or Apple Silicon Mac ZIP for your host. The observed Linux setup player needs glibc 2.38 and libstdc++ providing GLIBCXX_3.4.29, plus the host OpenGL and zlib libraries libOpenGL.so.0 and libz.so.1. The Mac setup player has a macOS 11 minimum. Select the Apple Command Line Tools or Xcode toolchain for its Clang and SDK. Install upstream’s required Python 3 and use its Generate & rebuild wizard and supported toolchain. Supply your own USA SLUS-01105 CUE and all referenced BIN files. Use your own USA SCPH-1001 retail BIOS, 512 KiB with CRC32 37157331. This title disables OpenBIOS, including on Linux and Mac. Start the completed build-release/Street_Fighter_EX2_Plus in its own folder after upstream setup. Keep it with its matching config, assets and the complete creating project.

  5. Review launch details and manage updates

    Review the selected game executable, working folder and launch arguments, then agree to use them. Choose Play separately when you are ready. You manage setup, game replacement and recovery. Removing the registration leaves external files in place. Before changing versions, close the game and its companion programs and keep the working copy and every data location it uses. Review and select the changed executable before playing again. Portcove does not offer updates, backups, rollback, conversion, data migration or deletion for these external files.
