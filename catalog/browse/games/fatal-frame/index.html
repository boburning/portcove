Setup

  1. Use a permitted copy and your matching game files

    Keep an existing permitted complete native player, including its resources and libraries. The Windows player is MikuPan.exe; register it with its folder as the working directory. Save launch details, then choose Play separately. Prepare your own IMG_HD.BIN and IMG_BD.BIN from the matching Fatal Frame disc in a separate retained data folder. Default upstream builds use NTSC-U USA; PAL/EU needs the matching EU build, and the Japanese edition is unsupported. No original files or PS2 BIOS are supplied by Portcove.

  2. Choose the original-data folder on first Play

    The native player asks for the folder containing the missing game files on first deliberate Play and remembers your selection. Keep that original-data folder outside any separately managed runtime so replacing a player does not replace your originals. The package is portable and has no installer. Source builds have their own CMake/dependency instructions. Linux is a separate upstream route; macOS is an experimental Apple Silicon community build with no maintained hardware coverage, not Windows qualification.

Setup notes
Back up the actual profile before updating
You or upstream update this external copy. Close the game, keep the working folder, and extract a new permitted player separately. Back up the SDL profile for Mikompilation/MikuPan, including mikupan.ini, memory-card saves, albums and PNG captures; on Windows this is normally under AppData/Roaming. If SDL cannot supply a profile directory, upstream uses the local MikuPan directory instead; retain that too. Preserve the original-data folder separately. External registration leaves every file untouched and provides no managed Update, Backup or Rollback. Runtime replacement does not rewind saves or establish older-version readability.
