Setup

  1. Prepare a separate Arcanum copy

    Upstream has no published GitHub release package. If you already have a permitted Community Edition build, use a separate copy of your own GOG or Steam Arcanum folder, including arcanum1.dat through arcanum4.dat, tig.dat and the required modules. Keep your original installation available. Follow the upstream guide if you need to prepare a build.

  2. Choose your prepared player

    On Windows, select arcanum-ce.exe inside that copied game folder and use the folder as its working directory. Linux uses the native arcanum-ce in the copied folder. For the macOS app bundle, retain the upstream application and its documented folder layout. Saving launch details never starts the game; Play is a separate action.

Setup notes
Keep the working copy and its data
You manage runtime updates, saves, settings and mods in this external copy. Back up the whole working folder before replacing files, and keep the current copy until the replacement is ready. Portcove does not build the engine, run a game installer or extractor, or back up, roll back or delete these external files.
