Setup

  1. Prepare the exact supported original upstream

    Use a complete player/components you are independently permitted to use, with your own GameCube USA GLME01 or Europe GLMP01 revision 0 disc. Supported main.dol SHA1 values are 77d49225e7d28b9777916cdbe5809345c570ecbc (USA) and a1e2bd82813787cfe0b11afb5d138f08fdbd94f1 (PAL rev0). Upstream validates that DOL digest, not merely the image name; ISO/GCM, RVZ and other nod-readable containers are separate representations of that original. Supply both originals only if you want upstream’s cross-region Hidden Mansion overlays. Finish disc selection, local recompilation/link, shader preparation and chosen-version settings outside Portcove. No disc, compiler, converter, helper or game is obtained or executed here.

  2. Keep the player and bundled compiler together

    The inspected official 1.1.5 Windows x64 ZIP contains AMD64 LuigisMansionRecomp.exe, matching Aurora/Dawn/SDL3/nod and other libraries plus llvm/bin/clang.exe and lld-link.exe. The runtime builds game/<id>/module.dll locally from the original’s main.dol; the release does not supply that original. Keep the whole package and actual generated data. The port’s decompilation and adapted code use their CC0 scope, Aurora MIT and LLVM Apache-with-exception; these do not relicense the original game.

  3. Attach the already prepared normal player

    Select LuigisMansionRecomp.exe, use the complete extracted LuigisMansionRecompiled-1.1.5-windows-x64 directory as working directory and leave arguments empty. Review and consent to the selected launch details, then choose Play separately. When configured discs/modules/overlays are current, the integrated setup is skipped and the module is loaded into this same native player. Missing/stale inputs can trigger local rebuilding; complete it upstream before retrying. Do not select a module DLL or compiler as the executable, and do not enable setup-auto, recovery-reset, finite-frame or test overrides.

  4. Preserve regional cards and destructive move recovery

    Normally keep the actual %APPDATA%/Luigi's Mansion Recompiled root, including install.ini, settings.ini, game/GLME01 or GLMP01 modules/keys, hidden_mansion/ overlays, USA/Card A and other regional card folders, caches, logs and recovery state. Older Luigi's Mansion PC folders can be renamed on first 1.1+ start; failed rename can copy while retaining the old folder. Existing portable.txt or portable/ instead selects the package-local portable tree. An upstream requested data move copies/checks and switches, then can delete the previous system root; interrupted portable.lm-tmp/portable.lm-old leftovers can be deleted on next startup. Keep independent copies of both old/new roots and any pending move evidence before starting or changing layout. This guide creates no marker and performs no move, recovery, backup or deletion.

  5. Maintain the external player and its rights explicitly

    Keep all own-code, decompilation, adapted Dusklight, Aurora and bundled component notices. Original Nintendo assets, other-region content and optional mods require independent permission. Existing external card/cache/source overrides remain authoritative; keep both disc originals and actual relative/absolute install.ini selections. Quit normally before upstream updates or card/data operations, retain independent recovery and review/relink changed executable bytes. The unfinished original two-player content and upstream campaign claims are not native/installed, co-op, gameplay, save/reload or Supported acceptance here. Removing registration preserves external files; managed lifecycle operations remain unavailable.

Limitations and evidence

  • Preserve the actual regional cards and both sides of any system/portable data move before startup. First-use builds, automatic stale-module rebuilding and recovery remain upstream-owned.
