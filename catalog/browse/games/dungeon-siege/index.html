Setup

  1. Open the Apple Silicon preview

    Use the upstream beta-3 DMG on macOS 27.2 or later. Drag Dungeon Siege.app into Applications. The upstream project also documents building from source with Apple’s Command Line Tools.

  2. Prepare your installed game

    Give the preview your installed GOG or Steam 1.11.1 folder containing DungeonSiege.exe and the original game archives. The setup checks the executable against the expected edition hashes, then copies your files into ~/Games/Dungeon Siege/game-files and builds native code. Keep the original folder when setup offers to move it to the Trash. The GOG offline installer is a separate input for the source-build script.

  3. Keep your saves and mods before updating

    For the downloaded app, back up the saves and game settings in ~/Games/Dungeon Siege/drive_c/Users/player/Documents/Dungeon Siege. Also keep mods and launcher.plist from ~/Games/Dungeon Siege. The app’s upstream updater owns replacement. A source build uses a different default folder, ~/Games/DungeonSiegeNative.

Limitations and evidence

  • The two downloaded preview packages both contain an Apple Silicon launcher built for macOS 27.2. Use a corrected package or verify the source-build route separately for earlier macOS versions.
  • This setup uses the base game executable. The publisher offers a separate owned Legends of Aranna archive route. Keep expansion files and saves separate from your base game.
