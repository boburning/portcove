Setup

  1. Pair the game module with its matching engine

    The reviewed mania-windows-x64.zip contains v5/Game.dll and v5U/Game.dll, not a player executable. Follow upstream’s guide to obtain the matching RSDKv5 or RSDKv5U engine, use only the matching Game.dll variant beside that engine, and supply assets from your own supported Sonic Mania (Plus) release. The Netflix Games version is not supported. Keep this prepared folder separate from your only working copy.

  2. Pair the Linux x64 player and module

    Use mania-linux.zip with the same upstream version of RSDKv5-Decompilation’s v5-linux.zip. Unpack linux.tar.gz from the engine download. Pair RSDKv5 with v5/libGame.so, or RSDKv5U with v5U/libGame.so, by placing the selected libGame.so beside the matching engine. Keep your own supported Data.rsdk in that writable game folder. The reviewed engine needs glibc 2.38, GLIBCXX 3.4.29, OpenGL, GLFW, GLEW 2.2, Ogg and Theora.

  3. Register the prepared player

    Choose the actual matching engine executable after upstream setup, with its prepared game folder as the working directory. Select the engine executable for Play. Keep Game.dll or libGame.so beside it as required for your platform. Read-only discovery and downloading do not run or combine modules/helpers. Upstream’s save-transfer guidance can bring over your own original PC save data; keep a separate original copy. Keep your actual save data, settings and mods with that prepared folder. Save launch details first, then choose Play separately.

Setup notes
Keep runtime replacement with upstream
Use upstream’s compatible engine and module pair and a separately prepared replacement folder when updating; keep the current folder and its saves recoverable until the replacement works. You or upstream provide runtime updates; Portcove does not back up or roll back this external copy. This download is a game module rather than a complete player, so finish pairing it through upstream before registering.
