Setup

  1. Keep your existing upstream installation

    Use an already permitted, complete upstream-installed ProjectR 0.7.1 Windows copy. Keep its bin DLLs and share/doc notices. Select the installed player, not the installer or uninstaller. Installation, prerequisites, setup and runtime replacement remain upstream/player responsibilities; this guide does not authenticate a download or run setup.

  2. Prepare this title through upstream

    Use your own arcade sfrushrk CHD or raw hard-drive dump plus all four audio ROM files: audio.u62, audio.u61, audio.u53 and audio.u49; upstream also accepts a ZIP containing those audio files. The original sfrush disk is optional for its white-car color. Rush 2049 and console releases are different inputs. The built-in graphical setup owns import. Portcove supplies no original files or extraction. Use a working gamepad or wheel/pedals; upstream lists Windows 10 1903+, x86-64-v2 CPU and Vulkan 1.2 graphics. Ordinary keyboard driving is not supported.

  3. Register the native player for Rush: The Rock

    Select the installed bin/project-r.exe, use its containing bin folder as working directory and add one argument: --rtr. The inspected installer creates this title shortcut with that argument. If setup is incomplete, upstream returns to its main menu. Review these coordinates, then choose Play separately. Keep the same installation available to the other ProjectR title; registration does not create a second runtime owner.
