Setup

  1. Choose the package for your computer

    The release supports Windows 10 or later on x64, Linux x64 with glibc 2.35 or later, and macOS Monterey or later on Intel or Apple Silicon. The same upstream release has separate Linux ARM64 and ARM32 builds.

  2. Extract the complete folder and start Celeste 64

    Keep Content/ and the adjacent libraries with the player. The official package includes the game. In Portcove, select Celeste64.exe on Windows or Celeste64 on Linux and Mac. Choose its containing folder as the working directory. Keep any arguments you already use. Review the registration, then choose Play.

Setup notes
Keep your progress when replacing a copy
Keep the Celeste64 user data folder in Roaming AppData on Windows, in XDG_DATA_HOME or ~/.local/share on Linux, or in Library/Application Support on Mac. Preserve save.json and the other settings files there when replacing the extracted game folder.
