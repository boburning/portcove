Amped 2 (Amped2-Recomp)

An experimental Linux x86-64 Amped 2 port. The Windows preview is explicitly unplayable and very slow, with only Wine/Proton testing. Use your own PAL/Europe original-Xbox disc: title 4D530041, XDK 5558, default.xbe SHA-1 38e63cd016bf084d999e0a911933a52191bfc378. The project supports a full Redump ISO, game-partition XISO or extracted folder. Keep every disc file in game_files/, with default.xbe directly at its root; other versions are untested. Portcove has not confirmed setup or gameplay.

Setup

  1. Play the experimental Linux release

    Use glibc 2.39 or later, SDL2 and a Vulkan driver. Extract the Linux tarball. Put your complete supported PAL Xbox disc files under game_files/ with default.xbe directly in that folder. Run ./run.sh from the extracted package. Run ./run.sh --settings to open graphics settings. Linux saves and cache live under ~/.local/share/xboxrecomp, while settings live in ~/.config/amped2-recomp/settings.ini. Preserve those paths and your original files when replacing the upstream package.
