Setup

  1. Open the Windows archive

    Choose the publisher archive for x64, ARM64 or x86 Windows. Extract it to its own writable folder, keep bin and data together and open bin/warzone2100.exe. To keep the game profile in the extracted tree, create an empty .portable file beside the executable before first launch.

  2. Install through upstream on Linux

    On Ubuntu 26.04 x64 or ARM64, install warzone2100 from the Ubuntu package repository and open it from your app menu. On Ubuntu 22.04 or 24.04 x64, you can install the publisher’s matching DEB through your package manager. The publisher also offers the net.wz2100.wz2100 Flatpak for Linux x64 and ARM64.

  3. Open the Mac application

    Extract the publisher's universal ZIP and open Warzone 2100.app on an Intel or Apple Silicon Mac. The Intel player targets macOS 10.14 or later. Apple Silicon and the bundled Vulkan renderer require macOS 11 or later.

  4. Keep your campaign progress and custom content

    In Options, open the actual Configuration Directory and back it up before replacing the game. Keep savegames, config, custom maps, mods and replays together, including any custom profile location. Ubuntu DEBs and the no-video Mac archive omit the campaign videos. Follow the publisher's video instructions if you want them.

Setup notes
Register the publisher Linux player with Portcove CLI
Use warzone-2100-official-maintained-source-port as the port ID in external select-preview and external select. For the extracted publisher Ubuntu x64 DEB, select the absolute usr/bin/warzone2100 path and set --working-directory to its usr/bin folder. Pass the absolute usr/share/warzone2100 directory as --arg=--datadir=<path> and your absolute profile path as --arg=--configdir=<path>. Quote each full argument if it contains spaces. Repeat the details with external select and pass the preview SHA-256 to --expected-preview. Start with portcove exec and the same port ID.
Keep the Ubuntu package’s campaign files
The Ubuntu 26.04 repository package starts through its own sandboxed launcher. Its default profile is ~/.local/share/warzone2100. Close the game before copying your campaign saves and other player data. When switching from a separately installed copy of the same release, keep the original backup until the loaded campaign is working.

Limitations and evidence

  • The upstream desktop player can register a handler for Discord join links when it starts. The publisher Linux package writes the handler and MIME association outside its selected profile. Removing a Portcove registration leaves those files in place. Package replacement and backups are player-managed.
