Setup

  1. Choose your original cartridge dump

    On first Play, select your own 1 MiB USA Gunstar Heroes cartridge dump in the file browser. Keep the ROM outside the player folder.

  2. Start the Windows or Linux player

    The Windows x64 ZIP runs gunstar.exe. The Linux x86-64 tar.gz runs gunstar and requires SDL2 and a system with glibc 2.28 or later. Keep each package together.

Setup notes
Open the universal Mac app
Unzip the macos-universal ZIP and keep gunstars.app intact. The Intel and Apple silicon app needs macOS 11 or later. Open it in Finder for the profile under ~/Library/Application Support/gunstars. A direct Terminal launch uses its working directory. Maintain this copy outside Portcove.

Limitations and evidence

  • Back up settings.ini, states, screenshots, videos and any custom destinations with the game closed. On Windows and Linux these paths default to the player working directory. Keep your original ROM and the compatible old player separately.
