Setup

  1. Prepare the exact Nintendo DS original

    Use a complete player/components you are independently permitted to use, with your own supported Nintendo DS Final Fantasy Crystal Chronicles: Echoes of Time ROM. USA CFIE SHA1 is 1df23d5a3a655bdd587c360b581202931d0f66e1; Europe CFIP is 18f7004f74c83feba40f003641ec00571e52a301. Japanese and Wii editions are not these inputs. Finish upstream ROM selection, its retained copy, local module build and Welcome/settings flow outside Portcove; an update can rebuild from that retained copy. No ROM, converter, compiler, helper or game is obtained or executed by this guide.

  2. Keep the complete alpha player and toolchain

    The inspected official 0.3.1-alpha Windows x64 ZIP contains AMD64 ffcc.exe, matching UI/runtime resources and bundled clang/lld tools. Keep the complete FFCCEOT-Recomp-0.3.1-alpha-windows-x64 folder, not only ffcc.exe. It builds from the player’s ROM rather than distributing that generated module as a ready-made original. The linked melonDS facilities include hardware modeling and interpreter fallback; building a native module does not mean every instruction is translated or that other games are supported.

  3. Attach the prepared normal program

    Select ffcc.exe, use its complete extracted package directory as working directory and leave arguments empty. The normal integrated start screen and game thread belong to this same native application; press its Play control when ready, or retain an existing Skip start screen preference. Review and consent to the selected launch details, then choose Portcove Play separately. Complete missing/stale module preparation upstream before retrying. Do not attach clang/lld, add finite-frame/replay/test overrides or select an original NDS program as the host.

  4. Preserve the real data root and regional saves

    Normally keep %APPDATA%/FFCCEOT-Recomp/EchoesOfTime with settings.ini, the retained ROM/module/build data, cfie.sav or cfip.sav, logs/ffcc.log and any reports/optional assets. An already existing portable.txt selects data/ beside the executable instead; an existing --data-dir or --save-file changes the actual roots. Preserve all actual and old roots plus independent originals. Upstream says a USA save can load in the European game, but that is not an observed migration or a permission to merge both copies. Cartridge saves, states and optional Wii-cutscene material remain separate. This guide performs no import, conversion, backup, restore or deletion.

  5. Keep optional services, terms and maintenance separate

    Retain project GPL-3.0-or-later, melonDS/component terms, SDL3 zlib, RmlUi MIT, FreeType, OFL fonts/icons, Dusklight CC0 and LLVM Apache-with-exception notices. They do not license the original DS/Wii games or other optional content. The current start screen opens the release page; it never downloads an update by itself. Community WFC revival/online servers remain separate and unobserved; no credentials/server operation is performed. Quit normally, keep recovery copies and review/relink replaced bytes. Upstream opening-area alpha reports do not establish full campaign, multiplayer, native/installed, real-save or Supported acceptance. Registration removal preserves external files; managed lifecycle operations remain unavailable.
