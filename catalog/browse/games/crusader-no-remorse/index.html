Setup

  1. Supply the original game on desktop

    Extract the x64 package into a fresh writable folder. Copy your owned French 1.08 or US 1.23 disc image, or the English 1.01 GOG GAME.GOG image, into the package's data folder. You can also copy the complete original game files using the layout in the upstream guide. Keep your original separately. A partial digital installation may lack files included on its disc image.

  2. Open the desktop player

    From the extracted package folder, run crusader.exe data on Windows or ./crusader data on Linux. The Linux player includes SDL2. It needs glibc 2.35 or later, GCC 11-era libstdc++ and your distribution's desktop audio and graphics libraries. The player extracts an image into the working data folder on first launch. If import is interrupted, preserve anything you need from that folder and retry in a fresh working folder.

  3. Use the upstream PortMaster package

    On a compatible ARM64 Linux handheld, follow the publisher's PortMaster README. Use the original French 1.08 or US 1.23 files or a copy of its .iso in ports/crusader/data. Keep the package's Crusader.sh launcher and open Crusader from the device's Ports menu.

  4. Keep saves and settings

    Close the game and keep the working data folder, especially SAVEGAME and CRUSADER.CFG, before replacing the upstream player. Back up any separately used mod save folder. On PortMaster also retain the port's conf folder. Keep your original media separate.

Limitations and evidence

  • The publisher owns the packages and setup. PortMaster is a separate Linux handheld route.
