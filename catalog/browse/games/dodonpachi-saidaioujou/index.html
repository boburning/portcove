Setup

  1. Add your own disc or Games-on-Demand files

    Before the first start, put exactly one supported ISO of your own Xbox 360 disc or converted Games-on-Demand copy beside the game program, with its matching Title Update 1 data. Disc default.xex SHA-256 is 709EB9FD2E4446E5754461616693B3BBB8B78FEF5AA613FFCDE6D643DA0133F5 and its TU1 file is 598,016 bytes with SHA-256 0A893048C761BA6CF8ED14637F326726BC616B5183CA1EE52DE02FC12B46B215. The Games-on-Demand default.xex is 41AB091576813248712A387B273398E5D700454505E83F6F1FEB7DE2C1027707 and needs CA022100.binp, CA022110.binp and default.xexp instead. On first start the game checks them, extracts game_data and applies the update; keep your originals separately and delete the copies afterwards.

  2. Use a copy you manage yourself

    Keep the complete package for your system together, including its runtime libraries, extractor and notices; the standard and Vulkan ZIPs are separate packages. Start DoDonPachi SaiDaiOuJou.exe (DoDonPachi SaiDaiOuJou on Linux) from its own folder with no arguments. Settings marked as needing a restart apply the next time you start the game.

Setup notes
Keep the game folder's data
By default the game keeps saidaioujou_recomp_tu1.toml, game_data, user_data (saves, the shader cache and update-check notes) and logs beside the program. A game_data_root or other path setting in the toml moves that data elsewhere. In a copy you manage yourself, back these up before replacing the program. The game checks GitHub for new releases and can open the release page; it never downloads or installs them.

Limitations and evidence

  • Disc and Games-on-Demand copies use different checks and are not interchangeable; do not mix their files. The game refuses incomplete or unsupported game_data rather than merging it. No gameplay, performance or save compatibility across versions is promised.
  • The package includes statically recompiled game code, icon art and an unlicensed project layer that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
