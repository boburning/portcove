Setup

  1. Choose your European PAL ROM

    Extract the ZIP into a writable folder and open Launcher.exe. Close Welcome, then use Browse ROM to select your own unheadered Theme Park (Europe) (En,Fr,De) ROM. The launcher checks the exact ROM identity. Use Run or press F7 to start the game.

  2. Start with the saved ROM path

    Once the launcher has remembered your ROM, use Launcher.exe --game to start the game directly. Start Launcher.exe without arguments to reopen the launcher and change the ROM or settings.

Setup notes
Keep your snapshots when updating
Settings and user files live beside Launcher.exe. Back up the Saves folder and settings.ini before replacing the upstream release. Snapshots preserve the machine state for their build and may not work in a different version.

Limitations and evidence

  • Portcove does not manage this installation or back up its snapshots.
