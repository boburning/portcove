Setup

  1. Check the required game files

    Use your own USA UCUS98701 ISO, decrypted EBOOT.elf and required decrypted modules with the local title manifest. Optional PSPPGF fonts must also come from your own files. Decryption tools are not included; PGD/amctrl-protected data is rejected.

  2. Follow upstream setup

    Build the Windows 11 x64 player and local package from source using your own inputs and the title manifest. A ready-to-run release is not available through this guide. Setup directly from a raw ISO without the manifest or developer toolchain is still in development.
