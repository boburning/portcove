Super Mario Odyssey (MacNativeGames)

An early community Super Mario Odyssey port running title-specific rewritten ARM64 code on Apple Silicon. The project reports only Cap Kingdom/Bonneton at 60 FPS on an M3, rather than a full game. Follow games/odyssey/README.md for the source build and exact prerequisites; generated app/game content stays private. Use your own version 1.3.0. Exact region, executable hashes, extraction, key and font requirements still need that title-specific guide; other platforms are unconfirmed. Portcove offers no setup or launch integration and has not tested gameplay.

Super Mario Odyssey (smo-recomp)

Build this Windows port of Super Mario Odyssey from your own extracted 1.4.1 Switch game. The project reports manual play from Cap Kingdom to a Cascade Kingdom checkpoint. Some tests used 1.0.0, and the additions in 1.4.1 remain untested.

Setup

  1. Check your original game files

    Supply your decrypted, updated 1.4.1 program, complete merged RomFS and update control data. This extracted-file route requires no separate keys or firmware.

  2. Follow the project’s setup

    Build the Windows x64 Vulkan player from source using LLVM 9, the VS2019 SDK, the Vulkan SDK, SDL3 and Python. Use Windows 10 or 11 with Vulkan 1.3 and the extensions listed by the project.
