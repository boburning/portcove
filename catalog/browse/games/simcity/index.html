SimCity (UrbanRecomp Enhanced)

An enhanced fork of blackerking/UrbanRecomp for the 1991 SNES SimCity, separate from PC SimCity and SimCity 2000. The project excludes its CPU interpreter from normal releases and keeps it for reference builds. Some cheats and full-game/device coverage are unconfirmed. The project offers Windows/Linux x64, universal macOS, Android ARM64/x86-64 and unsigned iOS ARM64 builds; iOS needs your own signing. Use your own compatible SNES ROM. Exact accepted revision/hashes and BIOS/firmware requirements are unconfirmed. You and the project manage installation and updates; release files are not qualified packages in Portcove. Portcove has not confirmed setup or gameplay.

Setup

  1. Use the permitted Enhanced Windows player

    Use your independently permitted UrbanRecomp Enhanced Windows copy. The reviewed enhanced-v1.0.4 Windows route is a single portable UrbanRecomp.exe, distinct from the upstream base project and mobile packages. Follow its component terms, including the documented noncommercial-use condition from the included engine. Finish upstream source preparation outside Portcove if using source. This registration offers no managed package acquisition, generation or redistribution-rights grant.

  2. Keep the portable player and its own original

    Select the outer portable UrbanRecomp.exe and use its containing writable folder as working directory. Leave arguments empty for the normal launcher and choose your own clean US SNES SimCity original there at the separate Play step. Upstream documents SHA-256 e9c0bc05511e05a0d7c3e7cc42e761e1e8e532d46f59b9854b6902e1a2e9dd0a. Registration does not import or authenticate the original. The portable wrapper unpacks runtime files into a versioned LocalAppData/UrbanRecomp/bundles cache and waits for its child player; it is not the same layout as a source-build tree.

  3. Review registration before choosing Play

    Portcove records the selected native executable, working folder and literal arguments after review; Play is separate. You and upstream own replacement, cache preparation and updates; relink changed portable EXE bytes after reviewing them. Only the selected process is supervised. Removing the registration preserves all external files. Managed installation, backup, rollback, migration, generation and deletion are not offered for this copy.

Setup notes
Preserve the data folder and complete save set
The portable wrapper normally runs its child with the portable EXE folder as data working directory. Keep sc-settings.ini, keybinds.ini, the selected original and location, save states, mods, diagnostics and the complete save set there. The US SRAM file is urbanrecomp-us.srm with its .bak; Enhanced also keeps matching .population and .world sidecars. Keep them together with their creating runtime. Preserve actual SC_PORTABLE_DATA_DIR or SC_SRAM_PATH locations when independently configured; registration does not recreate a per-shell environment, move data or certify cross-version state compatibility. Original-derived translation/scenario data remain your upstream preparation and permission responsibility.
