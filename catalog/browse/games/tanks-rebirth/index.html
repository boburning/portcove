Setup

  1. Use the release package for your computer

    The v1.9.2 release has Windows x64, Linux x64 and Intel Mac ZIPs. On Windows choose the ZIP without DEBUG in its name. Extract the entire archive into a folder you control, keeping Content beside the player. Base setup requires no Wii disc or ROM. Install the x64 .NET 8 Runtime for your operating system before opening the player.

  2. Create the Mods folder before first Play

    Under your Documents folder, create My Games/Tanks Rebirth/Mods if it is missing. On Linux use the configured XDG Documents location, or ~/Documents when there is no override. Create the Documents folder too if it is missing. This release writes TanksRebirth.targets in Mods during startup, before it creates that directory. No mod files are needed.

  3. Start the player from its folder

    On Windows, open TanksRebirth.exe in the extracted folder. On Linux or Intel Mac, open a terminal in that folder, run chmod +x TanksRebirth, then run ./TanksRebirth. The player looks for Content relative to its working directory.

Setup notes
Keep your saves and mods
Close the game and preserve My Games/Tanks Rebirth under the Documents folder used by .NET. This is where the player stores its saves, campaigns, mods and resource packs. Keep a known-working package to return to when trying another release.

Limitations and evidence
