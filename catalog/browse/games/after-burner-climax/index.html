Setup

  1. Prepare your original beside the program

    Copy your own purchased full After Burner Climax Xbox 360 LIVE package (title 58410A06), either the original release whose default.xex is 1.0.0.0 or the World release whose default.xex is 0.0.1.2, beside after_burner_climax.exe as the complete 58410A06 console export folder (58410A06/000D0000/<package>). Keep your original export separately.

  2. Use the documented Windows prerequisites

    The package README calls for 64-bit Windows 10 or 11 and the Microsoft Visual C++ 2015–2022 x64 Redistributable when its runtime libraries are missing.

  3. Complete first-run setup

    Start after_burner_climax.exe and let it prepare assets from your package on first start. For the World release it starts after_burner_climax_world.exe and closes itself; keep both programs together. If it says your files are a different version, delete assets, replace the 58410A06 folder with a supported package and start again.

  4. Keep your settings and saves

    Keep the generated assets, after_burner_climax.toml and the 58410A06 folder with the program. Saves and the shader cache stay in Documents\after_burner_climax.

Limitations and evidence

  • The package includes recompiled game code that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own purchased full game package; the program always runs as the full game and does not grant or change an entitlement.
  • Keep the upstream folder outside the Portcove library. Close the game before backing up or replacing the creating runtime and its data.
