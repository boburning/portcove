Setup

  1. Choose the package for your system

    Keep the complete Windows ZIP contents together. On Linux, make the extracted file executable and use glibc 2.38 or newer with SDL3 and zlib. On macOS 11 or later, extract the app. See the publisher’s packaged guide for the first open of the unsigned app.

  2. Provide your own game files once

    Start the program and choose your decrypted 1B200 folder or a ZIP of that folder. The program checks the files before copying them into your user data folder.

  3. Play again and change settings

    Start the same game under the same user profile. On Windows and macOS, use the game’s settings window. The Linux package has no settings window or background music.

Setup notes

Find saves and settings on Linux
Keep the game’s data under $XDG_DATA_HOME/ipod-lost, or ~/.local/share/ipod-lost.
Find saves and settings on macOS
Keep the game’s data under ~/Library/Application Support/iPod Lost.
Update the program
Get new versions from the upstream release page. Preserve your user data folder before replacing the program files.
