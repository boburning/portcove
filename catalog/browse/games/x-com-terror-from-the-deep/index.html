Setup

  1. Use this original game and edition

    Use your own complete unmodified original TFTD/TFD data folders. Copy the original subfolders into OpenXcom’s TFTD subdirectory, keeping their hierarchy. UFO/XCOM files do not supply this game. Keep your originals elsewhere unchanged; upstream handles its own data recognition and preparation. A Portcove registration does not authenticate original-game files.

  2. Prepare upstream and select the real player

    Use the official upstream download/setup route or a complete already prepared OpenXcom player, keeping its common data and standard mod resources. No GitHub release package was observed. Choose a build that documents TFTD support; an old UFO-only release is insufficient. Complete original-data and game selection through upstream before saving the player entry. On Windows, register openxcom.exe with its installation folder as working directory, retaining the upstream game selection rather than inventing a fixed argument. The upstream Windows installer may copy a detected Steam original when you deliberately run it.

  3. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Portcove saves your selected executable, working folder and launch arguments; choose Play separately when you are ready. You manage this game’s files, original files and profile. Removing its registration leaves those files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Keep a working copy and its data before changing versions.

  4. Choose the Windows nightly package

    In OpenXcom’s Nightly GitHub workflow, choose a successful upstream run. On Windows x64 download the Windows artifact, then extract the inner win64 ZIP into a dedicated folder. Keep its DLLs and data directories with OpenXcom.exe and open the player from that folder. The same artifact offers a separate win32 ZIP and an upstream installer.

  5. Choose the Linux or Mac nightly package

    In the same workflow run, download the matching artifact. On Linux unpack the ZIP and start the AppImage. If the loader reports libjack.so.0 missing, install your distribution’s JACK runtime package. On Mac unpack the outer ZIP and use Mac Archive Utility on the inner Mac ZIP, then open openxcom.app on Intel or Apple Silicon. On Linux x86-64, select the complete official Nightly AppImage and its containing folder. Provide the host JACK and PipeWire libraries required by the package. If FUSE is unavailable, enter --appimage-extract-and-run as a separate first argument. On Intel or Apple Silicon Mac, keep openxcom.app intact and select Contents/MacOS/openxcom with its containing folder. On Linux and Mac, enter -master and xcom2 as separate arguments, after --appimage-extract-and-run when you use it. Confirm the selected original and master game upstream before saving the registration. Use separate writable -user and -cfg folders for each game when you want to keep the profiles apart. Enter each option and its absolute path on separate lines.

  6. Prepare this title’s original data

    Copy the data subfolders from your X-COM: Terror from the Deep installation into TFTD inside the OpenXcom data or user folder. In the OpenXcom Mods menu, select the master game for this title.

Setup notes
Keep your originals and game data
Windows normally uses the actual Documents/OpenXcom user/config location; an installation-local user folder and explicit -data/-user/-config choices can change the searched locations. Preserve every actual selected data/user/config folder, including UFO/TFTD resources, mods, savegames and screenshots. Keep the two original games and their campaigns distinct even if they share one player/profile. Back up with OpenXcom closed before changing runtime or mods.
Back up the actual OpenXcom profile
On Linux back up the active user and config folders shown in openxcom.log. The user folder can be ~/.local/share/openxcom or ~/.openxcom. Also keep ~/.config/openxcom or any XDG or command-line overrides. On Mac keep ~/Library/Application Support/OpenXcom or the configured XDG directory. Preserve originals, settings, mods and saves before replacing an upstream nightly.
