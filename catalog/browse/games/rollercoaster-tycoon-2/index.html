Setup

  1. Start the game

    On first Play, select your installed RollerCoaster Tycoon 2 files if they are not detected. Optional RollerCoaster Tycoon 1 files can be configured through upstream menus. This is the standalone portable engine; the separate upstream auto-updating launcher remains an external alternative.

Setup notes
Use OpenRCT2 on Mac
For a managed copy on Intel or Apple Silicon, use Portcove Install and then Play. OpenRCT2 can ask you to select your installed RCT2 files on first Play. Keep your original files and the OpenRCT2 profile under ~/Library/Application Support/OpenRCT2. Portcove manages the bundle and leaves that profile under your ownership. The inspected upstream build declares macOS 10.14 or later on Intel and 11 or later on Apple Silicon. Portcove has its own OS requirements. For a separately maintained copy or a custom profile location, download the official macos-universal ZIP, extract the full OpenRCT2.app bundle and use upstream setup.
Use the external Windows ARM64 or Linux package
Choose the official Windows portable ARM64 ZIP on Windows ARM64. Keep the entire folder with openrct2.exe. On Linux, use the upstream x86-64 AppImage or the Flatpak documented by OpenRCT2. Follow upstream to select your original data. Preserve the actual OpenRCT2 profile before upgrading. Keep package-manager or upstream updates separate from a Portcove installation.
Set up OpenRCT2 on Android
Use the upstream Android APK for Android 7 or newer on arm64, ARMv7 or x86-64. Copy your installed RCT2 data to the shared-storage rct2 folder. The app requests All files access on Android 11 and later, or storage permission on older Android, for the original files and its openrct2 profile. Back up that profile and your originals. Follow upstream to install or update the app with the same Android package identity and signer.
