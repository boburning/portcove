Setup

  1. Prepare the supported desktop original

    Use a complete player/components you are independently permitted to use, with your own Xbox Buffy: Chaos Bleeds ISO/XISO. Desktop supports European PAL version 2 (region 4, first-section code size 1,196,336 bytes) and North American version 1 (region 3, 1,193,024 bytes), title 56550005. These certificate/section checks are not a whole-disc cryptographic fingerprint. PS2/GameCube discs and other revisions are not admitted. Complete Buffy Launcher.exe installation, optional movie conversion and settings upstream into its chosen game folder, keeping independent originals. No disc, FFmpeg, installer, helper or game is obtained or executed here.

  2. Keep both matching native programs

    The inspected official 1.0.2 Windows ZIP contains AMD64 buffy_chaos_bleeds.exe, buffy_chaos_bleeds_usa.exe and Buffy Launcher.exe with matching shaders/mods/resources. Keep the complete package and the prepared installation. The PAL player and USA player are built separately for their exact original code. Upstream Android is ARM64, Android 13+/Vulkan 1.3 and PAL-only: its reported Galaxy Z Fold7 test does not extend desktop or other-device qualification.

  3. Attach the actual regional game program

    In the prepared installation, select buffy_chaos_bleeds.exe for PAL v2 or buffy_chaos_bleeds_usa.exe for North American v1. Set the complete installed game folder as working directory and leave arguments empty; review and consent to those launch details, then choose Play separately. Source resolves default.xbe relative to the executable unless an existing BUFFY_GAME_DIR overrides it. If the other supported region is detected, upstream starts its matching companion and waits for it; do not remove the companion or enable a mismatch override. Missing/unsupported setup belongs in the upstream launcher before attachment.

  4. Preserve real saves and old recovery

    Keep SaveData/ with BUFFY A.sav, B.sav and C.sav, SaveBackups/, buffy_settings.ini, installed game/movie data, mods/, custom texture replacements/dumps, ShaderCache/, bug_reports/ and logs, plus existing external source paths. Pre-0.4 UDATA saves can be converted on first game start or opening the upstream Saves tab, with originals retained in SaveBackups. Preserve old UDATA/XboxData and every previous installation until existing saves have been checked; this guide does not follow upstream cleanup suggestions or perform conversion, backup, restore or deletion.

  5. Maintain the complete external installation

    The source tree contains xboxrecomp MIT and separately licensed audio/component notices; no project or toolkit notice licenses the original game, textures or third-party mods. Retain all applicable notices and use only a complete copy you are independently permitted to use. The upstream launcher owns download/update/restart, regional pairing, mods and optional movie preparation. Quit the actual player and companions normally before replacement or data changes, retain recovery copies and review/relink changed bytes. No native/installed, physical-device, gameplay, campaign/co-op, real-save or Supported acceptance is asserted. Registration removal preserves external files; managed lifecycle operations remain unavailable.

Setup notes
Use the Android Buffy package
Buffy-Chaos-Bleeds-Android-v1.0.3.apk requires ARM64, Android 13 or later and Vulkan 1.3, plus about 2 GB free. Open the app and grant All files access when prompted. In the Install tab, choose your own European (PAL) Xbox ISO or XISO. After extraction, use Play in the app and reopen Settings there. The game uses games/Buffy Chaos Bleeds on the phone. Use the app’s Saves tab to back up, restore or share saves.
