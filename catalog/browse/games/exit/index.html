Setup

  1. Choose this title’s player package

    The shared ReXGlue-EXIT release contains two different players and SDK downloads. Choose the actual EXIT1-Recomp.zip for EXIT; do not substitute the other title or an SDK. Check that the selected package matches this title; a recommendation does not check the downloaded files. Keep exit1.exe, its matching rexruntime.dll and notices together in a separate writable prepared folder.

  2. Complete this title’s owned-input preparation upstream

    Use your own legitimate full Xbox 360 EXIT XBLA package and your own required title-update package. Complete the supported extraction and title-update patching upstream before attachment, keeping the matching patched default.xex and dat tree beside exit1.exe. Portcove does not obtain or run the extraction/patching tools, import an original or change licence/trial settings.

  3. Attach the completed native player

    Select exit1.exe, its completed prepared folder as working directory and no arguments. The inspected source defaults game and update data to that working directory; retain a working explicit custom data argument only if your setup already needs it. Do not attach a preparation tool or reuse EXIT 2’s original or profile.

  4. Review launch details, then choose Play

    Select the completed game executable, its working folder and supported launch arguments. Review those details and agree to use them, then choose Play separately. You manage setup, game replacement and recovery using the project’s tools. Removing its registration leaves external files in place. Before changing versions, close the game and its companion programs and keep the working copy and all data. Review and select the changed executable before playing again.

Setup notes
Retain this title’s complete copy and effective data
Keep the entire separate EXIT folder and every effective external root. Its exit1.ini always lives in the working directory. Portable=True is the default: the inspected source puts user data in that working directory, cache in cache/ and runtime configuration in exit1.toml, overriding the normal platform user root. Portable=False and custom original/update paths can use external locations. Preserve all profiles, saves, owned DLC, settings, logs, screenshots, caches, backups and temporary files with the creating runtime; no cross-title or cross-version save compatibility is assumed.

Limitations and evidence

  • Use only a copy and components you are permitted to use. Before changing versions, keep a copy of the complete working game, original files and every profile, save, cache, mod, backup, temporary file and custom data location. Another executable may use the same data. Portcove does not offer updates, backups, rollback, data migration or deletion for these external files.
