Setup

  1. Check the required game files

    Use your own decrypted CUSA00063 base 01.00 folder containing eboot.bin, sce_module and sce_sys, with no merged update. Extract your own PKG using recent tooling.

  2. Follow upstream setup

    Follow the README for LittleBigPlanet3-port-x86_64.AppImage and its SHA-256 sidecar. Choose your own game folder in the launcher, prepare the image and shaders, then choose Play. A source build uses build.sh and the GTK4 launcher. Player data lives in ~/.local/share/lbp3-port. Run only one copy because the game uses /tmp/.lbpS.

Limitations and evidence

  • Early preview 0.1 reaches Pod, Prologue, completed Introduction/Legend of Bunkum, and walkable Needlepoint Peaks. Later levels, Create and saving untested; audio not checked in detail. Online servers unavailable, some imports stubbed; first cache fill can run 15–20 FPS.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
