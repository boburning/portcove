Setup

  1. Keep this game’s permitted working copy

    Keep a separate working folder for Abe’s Exoddus, with your own complete original game files including st.lvl and mi.lvl. The player uses these files to choose the game. Keep the other Oddworld game in a separate folder.

  2. Select the Windows player

    Select relive.exe from your permitted working copy and use the folder with your original game files as the start folder. Keep SDL3.dll beside relive.exe. Leave arguments empty to select Exoddus. Save the details, then choose Play.

  3. Use an already prepared Linux x64 copy

    For an existing permitted Debian-style installation, use the relive player with the folder containing your original game files as the start folder. The packaged player needs SDL3. Upstream’s relive-ae shortcut uses Zenity to pick a folder when needed. For direct Portcove registration, select relive and the actual original-game folder. Leave arguments empty to select Exoddus.

Limitations and evidence

  • Keep the complete original game files, working folder and existing saves backed up. Runtime replacement and backups belong to you or your upstream package manager.
