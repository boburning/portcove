Setup

  1. Choose the original game folder

    On Windows 10 or 11 x64, use your own installed full game. Find the folder with DATEN.PCK and thandor.exe. Close the game and back up the whole folder, including saves, before using a Patch 7 installer you are already permitted to use.

  2. Patch and play through upstream

    Check the folder in the upstream patch wizard before proceeding. Patch 7 replaces thandor.exe and adds its SDL3 runtime. The installer can change access permissions on the game and save folders. After setup, open thandor.exe from the patched folder.

  3. Keep your original and saves

    Keep your independent backup, plus the current save folder and thandor.ini. Patch 7 can retain the prior executable as thandor-1.05.exe. Its own uninstaller attempts to restore it when that backup exists and leaves the changed folder permissions in place.

Limitations and evidence

  • Use the upstream installer and uninstaller for replacement. The project publishes a Windows x64 route. It supplies no Linux, Mac, or Android build.
