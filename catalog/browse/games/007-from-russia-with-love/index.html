Setup

  1. Check the required game files

    Use your own original-Xbox 007: From Russia with Love USA or Europe ISO or extracted assets for the player. A source build instead needs extracted default.xbe and game folders; its documented regions are USA, Europe and Asia. This guide does not specify exact supported executable hashes or revisions.

  2. Follow upstream setup

    Download the project’s release kit, put your own ISO or extracted files in assets, then run 007FRWL.exe. The first start compiles the game code locally. If building from source, follow build.bat with VS2022 Clang and CMake; that route needs extracted data and cannot use an ISO directly.
