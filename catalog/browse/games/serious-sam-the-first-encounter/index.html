Setup

  1. Use the matching original game

    Use your own classic Serious Sam The First Encounter data, including matching *.gro files and original companion data. HD and Revolution editions are different products. Preserve the original installation and use a complete private working copy; the other encounter is a separate data scope.

  2. Prepare upstream and select the player

    Use the complete SeriousSamClassic-1.10.7-directx9-win64-bin.7z archive. The matching x64/SamTFE/Bin/SeriousSam.exe is the player. Retain all corresponding SamTFE DLLs and resources alongside your matching original data; do not select the other encounter, editor, dedicated server or conversion tools. Register the prepared player and its upstream working game directory. Keep the complete prepared tree rather than extracting only the EXE.

  3. Add the prepared Windows game

    On Windows, finish setup with the project’s tools before adding the game. Select the game executable and its working folder, and put each launch argument on a separate line. Choose Play separately when you are ready. You manage this game’s files, originals, saves and settings. Removing its registration leaves those external files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Close the game and keep a working copy and every data and profile folder before changing versions.

  4. Prepare and register the Linux player

    Use the official Linux x86-64 archive ending in -lnx-amd64-bin.tar.xz. Keep x64/SamTFE together. Place your own matching classic First Encounter .gro files and its Help and Levels folders in that encounter folder. Use glibc 2.34 or newer with system SDL2, zlib and Vorbis (libvorbisfile.so.3). Select x64/SamTFE/Bin/SeriousSam and choose that Bin folder as its working directory. Keep the supplied engine libraries beside the executable and keep the complete encounter and its effective player profile.

Setup notes
Keep your existing game data
Preserve the complete working SamTFE game folder, actual user profiles, saves, configuration and any redirected/mod storage.
