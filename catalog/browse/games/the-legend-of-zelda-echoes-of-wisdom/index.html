The Legend of Zelda: Echoes of Wisdom (EoWRecomp)

An early Echoes of Wisdom port for the original 1.0.0 Switch game. Linux reaches the first controllable scene. The Mac and Android packages have been tested through setup without game data. Saving and further progress remain unfinished.

Setup

  1. Check your original game files

    Use your version 1.0.0 game for title 01008CF01BAAC000 as NSP, XCI or NCA, plus your prod.keys. Updates are unsupported. Keep the original package available because the player continues to read it.

  2. Follow the project’s setup

    The alpha_1 release provides an Apple silicon macOS 15 or later ZIP and an Android ARM64 APK. Linux and Windows use source builds. The project has no packaged Windows player.
