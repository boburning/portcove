Setup

  1. Keep an untouched copy of the original

    Make a separate writable copy of your complete Call to Power II installation. Keep your original and your original saves. The Apolyton Edition needs data from the original game.

  2. Set up the Windows overlay

    Follow the release’s Apolyton_README.txt to overlay the community edition on the separate copy. Open ctp2_program/ctp/ctp2.exe from its folder. This is a 32-bit Windows program. If using the Chinese edition, follow the release notes for its data-directory and language settings.

  3. Prepare a Linux copy

    For a Linux source build, follow the upstream guide using data from your own game. Copy the map-generation libraries as directed and run ./ctp2 from ctp2_code/ctp. The release’s Debian package contains an x64 player under /opt/ctp2 and needs libavcodec59, libavformat59 and libswscale6. It still needs the original game files and a civpaths.txt configuration.

  4. Keep saves before changing versions

    Keep the active program folder’s save directory and back up any saves before opening copies in Apolyton. The release instructions say to enter /reloadslic in the game chat once after loading each older save. The upstream Linux guide links a separate converter for old Linux-format saves.

Limitations and evidence

  • The Apolyton Edition is a community project. Activision did not make or support it.
