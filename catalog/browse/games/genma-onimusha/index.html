Setup

  1. Check the required game files

    Use your own USA default.xbe with SHA-1 08bfe432eb55877b5af2dd401b713743c5b751cd and matching game files. Upstream accepts a Redump ISO, XISO or complete extracted folder.

  2. Follow upstream setup

    Use the GenmaOnimusha-*-win64.zip v0.5.1 package named in the README. First launch imports your own USA disc or XBE and compiles locally with the included compiler. Later launches reuse that work, rebuilding after runtime updates. Portcove has not inspected the release ZIP.
