Setup

  1. Choose the upstream package for your device

    On Windows, choose the x64, ARM64, or 32-bit ZIP, extract the complete folder, and start DDNet.exe. On Mac, use the universal disk image for Intel or Apple Silicon and copy the complete DDNet app into Applications.

  2. Install DDNet on Linux

    Use your distribution’s DDNet package or install tw.ddnet.ddnet from Flathub on x86-64 or ARM64. To use the official Linux archive instead, choose the x86-64 or x86 build, extract the full package with its data directory, and start DDNet from that folder. The archive expects system dependencies such as libnotify. Use the same package source when you update.

  3. Set your player name and choose a map

    Set a player name in DDNet and choose a server. For local practice, start the included DDNet-Server from a desktop archive and choose it in the DDNet client’s LAN tab. To connect manually, use the local server’s address and its actual listening port.

  4. Back up the profile you use

    Close the client and server, then keep %APPDATA%/DDNet on Windows, ~/Library/Application Support/DDNet on Mac, or $XDG_DATA_HOME/ddnet on Linux (normally ~/.local/share/ddnet). For Flatpak, keep ~/.var/app/tw.ddnet.ddnet/data/ddnet. Keep the settings, custom maps, skins, and demos you want to restore. If you changed storage.cfg or still use a Teeworlds profile, keep the actual folders that DDNet reads.

Setup notes
Get DDNet on Android
Use the Android APK on the official Downloads page. Its current build includes ARM64, ARMv7, x86, and x86-64 libraries. Android and your package source handle installation and updates.
