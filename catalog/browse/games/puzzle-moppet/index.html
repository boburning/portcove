Setup

  1. Start the publisher package

    On Windows x64, extract the whole Win64 ZIP and open PuzzleMoppet.exe. On Linux x86-64, allow the AppImage to run as a program, then open it on a system with FUSE support. Both packages include the puzzles and game data.

  2. Keep your completed puzzles

    Step into a portal and advance from the result screen so the game records your progress. Close the game before copying the Puzzle Moppet profile. Find it in %APPDATA% on Windows, in $XDG_DATA_HOME on Linux when set, or in ~/.local/share on Linux by default.

Setup notes
Install the Windows runtime if needed
The Windows player uses the Microsoft Visual C++ v14 x64 runtime. If Windows reports a missing MSVCP140 or VCRUNTIME140 DLL, get the x64 Redistributable from https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/.

Limitations and evidence

  • Keep a copy of the whole profile when moving the game. The progress files and levelscores folder hold different parts of your progress.
