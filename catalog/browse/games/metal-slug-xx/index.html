Setup

  1. Prepare upstream or keep an existing game build

    Follow the title-specific Metal Slug XX build guide with your own extracted game data. Select metalslugxx.exe, keeping the matching rexruntime.dll, rexruntimerd.dll or rexruntimed.dll build companion beside it. Set the documented --game_data_root argument to your actual extracted data location and retain the prepared working folder. rexglue.exe is code generation, not the player; a ReXGlue SDK archive alone is not this game's prepared runtime. Build/code-generation commands remain deliberate upstream actions.

  2. Keep your files and update through upstream

    Keep the game in a separate folder you control, and retain a working copy. Review its executable in Portcove, then add it without changing its files. Choose Play separately when you are ready. You manage updates, original files, generated data, saves and settings. Portcove does not replace, back up or roll back this external copy. Follow the project’s instructions for the version you use when changing it.
