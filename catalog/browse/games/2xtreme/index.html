Setup

  1. Check the required game files

    Use your own USA SCUS-94508 CUE/BIN disc image. The app copies it into its private ApplicationSupport/2Xtreme/disc folder and generates native game code locally on first launch. MIT-licensed OpenBIOS is included; no retail BIOS is required.

  2. Follow upstream setup

    Extract the project’s early-preview 2Xtreme.zip and open 2Xtreme.app to import your own USA CUE/BIN. The project says the first launch builds the game locally in about 15 seconds. The app is not notarized. The player package needs no Xcode, Homebrew or Python; building from source with make_app.sh additionally needs Apple tools, Homebrew and the pinned Zig version. Portcove has not inspected the downloaded package.

Project testing notes
This early preview has project-reported disc preparation, intro and keyboard pause-menu support. Controller testing, full-speed play, settings, widescreen, original Options bindings, rumble, player 2, save states and notarization remain unfinished. Full playthroughs are unconfirmed.
