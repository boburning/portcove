Setup

  1. Add the Windows client to Portcove

    After extracting the complete official Windows x64 ZIP, select teeworlds.exe and its containing folder. Keep the data folder and the accompanying files together. Leave launch options empty, review the details, and add the game. Choose Play separately. teeworlds_srv.exe is the dedicated server, not the client.

  2. Add the Linux client to Portcove

    Select the teeworlds client from your complete Linux x64 package and use its containing folder as the start folder. A distribution package normally installs it at /usr/games/teeworlds; install its data package and dependencies through the same package manager. Leave launch options empty. Update the installation through upstream or your package manager. The separate community Flathub client is available on Linux x64 and ARM64; install and update that copy through Flatpak rather than selecting a Flatpak launcher as a native executable.

  3. Add the Intel Mac client to Portcove

    Copy the complete Teeworlds.app from the publisher disk image into Applications and open it normally once. In Portcove, select /Applications/Teeworlds.app/Contents/MacOS/teeworlds, use its containing folder as the start folder, and leave launch options empty. Keep the complete app bundle together. Teeworlds Server.app is a separate dedicated server. The later teeworlds.exe choice applies to Windows; Mac uses the native file inside Teeworlds.app. The bundled 0.7.5 Intel runtime requires macOS 10.13 or later; Portcove has its own system requirements.

  4. Play and record a match

    The Teeworlds 0.7 client connects to Teeworlds 0.7 servers. In a match, press F1 and enter record followed by a demo name. Enter stoprecord to finish, then open the recording from Demos.

  5. Select the prepared player

    Select teeworlds.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Find your data folder
The defaults are %APPDATA%/Teeworlds on Windows, ~/Library/Application Support/Teeworlds on Mac, and ~/.local/share/teeworlds on Linux. On Linux, the game prefers an existing ~/.teeworlds folder or uses $XDG_DATA_HOME/teeworlds if XDG_DATA_HOME is set. For the Flathub installation, check ~/.var/app/com.teeworlds.Teeworlds/.teeworlds. If you changed storage.cfg, use its save location.
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: Windows %APPDATA%/Teeworlds settings07.cfg, demos, maps and skins; Linux ~/.local/share/teeworlds, existing ~/.teeworlds or $XDG_DATA_HOME/teeworlds; Intel Mac ~/Library/Application Support/Teeworlds and any storage.cfg save path; the save location selected by storage.cfg, and any custom maps or skins kept with the installation. Back up these locations separately; registration does not migrate or certify their compatibility.

Limitations and evidence

  • Before moving your setup, close the game and copy the data folder with settings07.cfg, demos, custom maps, and any skins you want to keep.
