Setup

  1. Use this original game and edition

    Use your own installed Morrowind Data Files and Morrowind.ini through the OpenMW installation wizard. Tribunal and Bloodmoon need their own corresponding installed data and deliberate load order. Console originals and saves are not interchangeable PC inputs. Keep your originals elsewhere unchanged; upstream handles its own data recognition and preparation. A Portcove registration does not authenticate original-game files.

  2. Prepare upstream and select the real player

    The official Windows EXE is an installer, not the game to register. Complete upstream setup, run the OpenMW wizard/launcher deliberately to locate Morrowind.ini and Data Files, and choose the desired content/mod order. Then register the installed openmw.exe with its installation folder as working directory. Keep openmw-launcher.exe for setup and mod/profile choices; discovery does not run that wizard automatically.

  3. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Portcove saves your selected executable, working folder and launch arguments; choose Play separately when you are ready. You manage this game’s files, original files and profile. Removing its registration leaves those files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Keep a working copy and its data before changing versions. The Linux and Mac instructions below use the upstream launcher outside Portcove.

Setup notes
Keep your originals and game data
Windows normally keeps OpenMW configuration, logs, saves and screenshots under the actual Documents/My Games/OpenMW folder. Custom configuration/user-data paths and external mod/data directories remain part of your setup. Preserve those actual locations, selected originals and load order with the player closed before upstream updates. OpenMW saves and original-engine saves are separate formats; keep their creating runtime rather than assuming conversion.
Set up OpenMW on Linux x86-64
Download the non-debug Linux-64Bit tarball. If you download through Portcove, clear “Extract the archive after downloading”. Unpack it with your system archive tool so its library links are preserved. The inspected build requires glibc 2.38 and libstdc++ with GLIBCXX_3.4.32. For an older host, check the upstream-documented distro or Flatpak route. Keep the complete extracted tarball directory together and start its openmw-launcher to finish the wizard. Use the upstream launcher for Play. Preserve configuration and logs in ~/.config/openmw and saves in ~/.local/share/openmw, or their actual XDG locations. The Flatpak has separate configuration and data under ~/.var/app/org.openmw.OpenMW.
Set up OpenMW on Mac
Use the official Intel or Apple Silicon DMG for your Mac. Copy OpenMW.app out of the disk image and open it to finish the wizard and select your owned Morrowind files. Preserve ~/Library/Preferences/openmw and ~/Library/Application Support/openmw, plus any custom configuration, saves, mods and original-data locations. OpenMW-CS is the separate editor.
