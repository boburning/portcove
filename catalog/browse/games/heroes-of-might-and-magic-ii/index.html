Setup

  1. Copy your Heroes II resources to the personal fheroes2 folder before Play

    Copy your own supported Heroes II ANIM, DATA, MAPS and MUSIC directories when present. Use HOME/.fheroes2 on Windows or Intel Mac, or APPDATA/fheroes2 on Windows when HOME is unset. On Linux, use XDG_DATA_HOME/fheroes2 or ~/.local/share/fheroes2. Use absolute personal profile locations outside the managed game folder and the same account and environment for setup and Play.

  2. Finish and back up the prepared Windows copy

    Use a permitted complete fheroes2 Windows copy with its matching libraries and your own supported Heroes of Might and Magic II resources, or a demo you are separately permitted to use. The Windows ZIP instructions require upstream resource extraction or the documented manual ANIM/DATA/MAPS/MUSIC copy before normal play. The Linux Flatpak first-start resource picker is a different route. Portcove does not run the extraction BAT, acquire demo/original assets or install Windows redistributables for this prepared-copy route. Select native fheroes2.exe after setup. Keep the creating working directory, complete runtime/resources and all original/custom maps and music. Windows profile selection checks an existing HOME environment first, using HOME/.fheroes2, then APPDATA/fheroes2, with an SDL preference fallback. Preserve the actual creating account/environment and selected config/data directories rather than assuming AppData is always used; Portcove does not inject environment variables. Keep fheroes2.cfg, the full data/profile tree including files/save, saves, custom files and unknowns. Do not force a new portable profile or treat the missing-resource error window as an original-data picker. Finish setup with upstream’s tools and start and quit the intended copy before registering it. Keep the creating version and actual data locations recoverable when replacing an external copy.

  3. Choose an independent Linux or Mac package

    For a separate Linux x86-64 or ARM64 ZIP, keep the complete archive contents in a permanent folder and use upstream’s extraction script or manually copy your own ANIM, DATA, MAPS and MUSIC when present. Start fheroes2 from its folder. The Linux ZIPs need SDL2, SDL2_image, SDL2_mixer, zlib, glibc 2.35 and libstdc++ providing GLIBCXX_3.4.30. Flathub’s io.github.ihhub.Fheroes2 uses its own first-start import and sandbox profile. On Apple Silicon, use the native Homebrew or MacPorts route and upstream’s fheroes2-extract-resources tool. For the Intel Mac ZIP, follow upstream’s SDL library setup. The Intel binary needs macOS 10.15 or later and matching Intel SDL2 compatibility, SDL2_image, SDL2_mixer and libpng at its /usr/local/opt paths. Standalone Mac builds use ~/.fheroes2 with an ordinary HOME; source-built Mac app bundles use separate Library/Preferences and Library/Application Support profiles. Keep the actual profile and the package that created it.

  4. Import your originals with the Android Toolset

    Extract the official fheroes2_android.zip and install fheroes2.apk. The package documents Android 5.1 or newer. Put your own original ANIM, DATA, MAPS and MUSIC directories that are present in one ZIP, copy it to the device, and choose Extract HoMM2 assets in fh2 Toolset. Open fheroes2 after the import. Keep the original ZIP and an accessible backup of the actual Android profile before clearing app data or replacing the package.

  5. Select the prepared Windows player

    Select fheroes2.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: the actual external fheroes2 profile and the original and custom resources of your prepared copy. Back up these locations separately; registration does not migrate or certify their compatibility.
Managed runtime ownership
Portcove installs and replaces its separate official runtime using the declared release rules. Existing external registrations retain their files and user/upstream ownership. Runtime rollback carries current declared data; it does not rewind saves or establish older-runtime compatibility. Gameplay and populated-save compatibility remain separate qualification. The managed copy has no declared local player data to back up. Back up the external profile separately.

Limitations and evidence

  • Use only a copy and content you are already permitted to use. Engine licensing does not grant rights to original game assets, music, mods or bundled components.
  • Before updating the game, keep a copy of its working files and every location containing saved data. Choosing a different executable does not give it a separate profile.
  • Back up the actual upstream profile before replacing the runtime. The Linux ZIP normally uses ~/.config/fheroes2 for settings and ~/.local/share/fheroes2 for data, including files/save and custom maps. If you set XDG_CONFIG_HOME or XDG_DATA_HOME, preserve those actual locations and use absolute paths outside the runtime folder. Flatpak, Mac and Android keep their own profiles.
  • The Windows x64 ZIP may need the Microsoft Visual C++ x64 Redistributable linked by upstream. Portcove runs no bundled resource, demo or prerequisite installer.
  • The Linux x86-64 ZIP needs SDL2, SDL2_image, SDL2_mixer, zlib, glibc 2.35 and libstdc++ with GLIBCXX_3.4.30. Intel Mac requires macOS 10.15 or later and matching Intel SDL2 compatibility, SDL2_image, SDL2_mixer and libpng at the upstream /usr/local/opt paths.
  • Keep a separate backup of the actual external fheroes2 profile, including files/save, settings and custom maps. Use a separately prepared copy for custom profile or resource locations. Real save compatibility across versions remains unverified.
