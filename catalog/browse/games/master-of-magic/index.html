Setup

  1. Choose the engine archive

    Extract the full Windows ZIP and open ReMoM.exe. On Linux, extract the tarball and run ReMoM with SDL2 and SDL2_mixer installed.

  2. Point ReMoM at your own Master of Magic files

    ReMoM looks for version 1.31 files in the usual GOG, Steam and CD install locations. If it cannot find them, follow the upstream guide to set game_data in ReMoM.ini, or put the original .LBX files next to the executable. Open the same program again to play.

Setup notes
Keep the working save folder
The default save folder is %APPDATA%/ReMoM on Windows or ~/.local/share/ReMoM on Linux. The program can copy SAVE1.GAM through SAVE9.GAM from your original on first run. Keep the working copies before replacing the engine with a newer upstream release.

Limitations and evidence

  • Portcove does not back up your ReMoM saves.
