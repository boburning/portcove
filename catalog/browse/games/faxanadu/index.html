Setup

  1. Open the upstream Windows player

    Download the official Windows x64 ZIP from Faxanadu Recomp Releases. Extract the complete package into a separate folder and open FaxanaduRecomp.exe with its DLLs and assets alongside it.

  2. Select the matching USA original

    Choose your own USA Faxanadu ROM in the launcher. The reviewed package expects payload CRC32 57DD23D1, excluding the cartridge header. Keep your original file separately.

  3. Keep your progress with the player

    Close the game and back up its settings, mantras and saves before replacing the package yourself. Keep save states with the build that created them.

Setup notes
Keep optional mods separate
Play as Link requires your own matching Zelda II USA ROM. Seamless and Play as Link are separate experimental modes. Keep both off for ordinary Faxanadu setup.
Reviewed Windows package
See https://github.com/mstan/FaxanaduRecomp/releases/tag/v2.5.0 for the reviewed package, optional mod details and save-state limits.

Limitations and evidence

  • The retained USA Rev 1 input was rejected. Use a matching original with the reviewed package. This is upstream setup.
