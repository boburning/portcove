Setup

  1. Complete the exact original and BIOS setup upstream

    Use an independently permitted complete Windows playtest copy. Supply your own legally dumped USA disc: extracted SCUS_942.54 in disc/, matching CUE/BIN in game/, and your own US SCPH1001.BIN in bios/. The documented CUE name is Legend of Legaia (USA).cue; retain the matching game.toml if your upstream working copy uses another path. A filename is not a whole-disc identity certificate. Portcove obtains or extracts no disc, executable, BIOS or helper.

  2. Attach the completed native player

    The upstream v0.1.7 diagnostic-playtest README explicitly supports direct LegaiaRecomp.exe with its complete creating player directory as working directory and no extra arguments; keep SDL2.dll and bundled game.toml, settings.toml, bios/, disc/, game/ and matching resources together. Do not attach the batch file, package script, compiler or a setup-host output. Complete preparation upstream first. Retain supported literal arguments already required by your working copy; no renderer or input mode is newly qualified.

  3. Review launch details, then choose Play

    Review and consent to the exact native executable, established CWD and literal arguments; request Play separately.

Setup

  1. Check the required game files

    Use your own USA SCUS-94254 BIN or CUE. The engine reads the original data while playing. Other regions may extract, but the engine and patcher target USA. Whole-image hashes can vary with the dumping method.

  2. Follow upstream setup

    Follow the README for platform archives containing legaia-engine and its supporting tools. Open the engine or desktop app, select your own disc and choose Play. Browser play reads the image locally. A source build uses cargo build --release with Rust edition 2024. The asset viewer and Studio are tools, not separate game ports.
