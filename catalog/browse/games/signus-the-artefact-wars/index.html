Setup

  1. Use the full game and matching Windows patch

    Extract the full v1.96.0 Windows ZIP into a new writable parent folder. Extract the matching v1.96.1 patch into the same parent so its signus-1.96.0 folder overlays the base. Keep the base game data and DLLs, then start signus.exe.

  2. Set up the Linux player and data

    On a compatible RPM distribution, install the official x86-64 v1.96.1 engine RPM and the separate signus-data 1.96 package from the full v1.96.0 release through your package manager. Use the upstream source build instructions for other distributions. Start the installed signus player with the full data available.

  3. Add a working copy to Portcove

    Choose the working native player and preserve its start folder. Save the launch details, then choose Play. During a mission, answer both of the game’s quit and save prompts to finish closing. Removing the registration leaves the external player and its data in place.

Setup notes
Find the creating profile
Linux settings and saved_games are under ~/.signus. Windows uses %APPDATA%\signus when available. A Windows run without APPDATA uses the resolved game-data folder instead. Preserve the profile used by your existing copy.
Keep the package manager or upstream copy
Leave replacement with your package manager or update the separate Windows copy using the matching upstream files. The Linux player also accepts SIGNUS_DATA_DIR when using a separate data location.

Limitations and evidence

  • The Windows v1.96.1 ZIP is a patch. Keep the full v1.96.0 data and apply only the matching x86 or x64 patch.
  • Back up the active Signus profile and saved_games before changing the player or applying a patch.
