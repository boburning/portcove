Metroid Dread (Metroid-Dread-Recomp)

The Windows preview launcher builds Metroid Dread from your own extracted game files for version 2.1.0. It handles later updates and undo. The project reports setup failures and crashes in the previews. Linux and Steam Deck scripts have limited verification.

Setup

  1. Check your original game files

    Use your 2.1.0 ExeFS, including main, main.npdm and companions, and the full update-merged RomFS. The project accepts separate base and update dumps. RomFS by itself is insufficient.

  2. Follow the project’s setup

    Start with the Windows x64 ZIP. The launcher bundles GCC and Python and compiles on first start. Its setup for extracted files has no separate keys or firmware input.

Setup notes
Version and platform notes
The 0.x builds have hardware limits. A 1.0 release is planned. Exact native Linux build and test coverage and accepted regional hashes are unconfirmed.
