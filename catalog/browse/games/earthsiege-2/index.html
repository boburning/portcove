Setup

  1. Prepare the original-game installation upstream

    Use your own independently permitted Earthsiege2 game files. HERCULAN 1.1.0 documents retail 1.0, the 1.0 Hi-Rez release without music, and 1.10 GoldGames including French/German variants. The engine’s MIT grant does not redistribute or license original game files. Follow its original-install/CD/ISO setup outside Portcove, choose a writable installed game folder and retain the source disc/image. A disc itself is not the writable installation; no third-party game mirror, original acquisition or setup is performed here.

  2. Choose the engine package, not the editing tools

    The inspected HERCULAN-1.1.0-win-x64.zip contains AMD64 Herculan.exe with native DLLs, Assets, notices and other matching companions. Keep the complete extracted package. It is a self-contained .NET release; HercWorksCSharp is a different data-viewing/editing tool and is not this player. Upstream specifies Windows 10 or newer, x86-64 and OpenGL 3.3; Portcove has not tested runtime compatibility.

  3. Select the prepared normal player

    After upstream setup has remembered the intended original installation, select Herculan.exe, use its complete extracted package directory as working directory and leave arguments empty. Review and consent to the selected launch details, then choose Play separately. The normal host runs the shell/game loop in its own process. If an install prompt opens, finish that setup outside the attached attempt before retrying. An established ES2_GAME_PATH or remembered install can select a different data root; confirm the intended copy rather than creating an override here.

  4. Preserve original saves and separate engine settings

    Back up the retail installation before switching engines, as upstream requests. Keep the entire writable Earthsiege2 install: SAV holds save slots and GAMEFILE.STR, while DATA contains working mission/player files. Engine preferences and install-path.txt live separately in %APPDATA%/Herculan; current logs are in %LOCALAPPDATA%/Herculan, with older logs potentially in the roaming folder. Retain every established custom install/root, disc/music source and settings file. This attachment does not migrate, test compatibility, import or back up saves.

  5. Keep maintenance and acceptance explicit

    Quit the actual game normally and close tools before upstream replacement or repair, retain independent recovery copies, and review/relink executable bytes after changes. Preserve MIT and all bundled component notices; those grants do not extend to Earthsiege2. HERCULAN is beta and upstream feature/retail-save compatibility statements remain upstream claims, not a Portcove play or save/reload pass. Removing registration preserves every external file. Portcove offers no managed install, update, rollback, backup or external removal and no Supported/native/installed-app acceptance here.
