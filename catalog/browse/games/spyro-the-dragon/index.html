Setup

  1. Choose the accepted managed copy or current upstream player

    The managed route retains its accepted v0.1.4 setup and data contract. For the current upstream Windows release, download the complete player from the official OpenPete page and prepare it in a separate writable folder. Compare the download with the checksum published there. Keep your existing working copy intact.

  2. Supply your own Spyro disc through upstream setup

    Use your own original Spyro the Dragon NTSC-U disc, SCUS-94228. Follow the current player’s first-run import instructions: it copies the disc into library and compiles game code alongside it. Keep the bundled compiler and runtime companions together. Save the completed Windows player’s launch details with that folder as its working directory, then choose Play separately. Portcove discovery does not run the compiler or import a disc automatically.

  3. Prepare the upstream Linux x86-64 AppImage

    Get the complete AppImage from the official OpenPete page and compare its SHA-256 there. Make it executable and run it on a system with glibc 2.31 or newer and Vulkan 1.2. If FUSE is unavailable, pass --appimage-extract-and-run. Supply your own NTSC-U Spyro disc as a BIN/CUE pair. OpenPete copies it into its private library before building the game, so a failed build can leave a copied disc entry. Keep your original and your existing working library separately.

Setup notes
Keep progress and generated files with their working version
You or upstream update the separate current copy. Preserve your ordinary .mcr memory cards, settings, states, mods and the library folder before changing it. Keep the creating runtime with its generated code and states, and confirm your ordinary game saves in the new copy before retiring the old one. This external copy has no Portcove-managed Update, Backup or Rollback; removing its registration preserves every file. The Linux AppImage keeps settings under ~/.config/openpete, cards and states under ~/.local/state/openpete, and the copied disc, compiled code, mods and other game data under ~/.local/share/openpete. Use the corresponding paths if you have set XDG overrides.
