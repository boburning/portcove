Setup

  1. Unpack the setup kit

    Choose the official ZIP for your system from the upstream releases and extract it to a writable folder. On Mac, use -macos-x64.zip for Intel or -macos-arm64.zip for Apple silicon. Follow the setup instructions included in your kit.

  2. Install the build tools

    On Windows, install Python 3 and follow the wizard’s portable build-tool instructions. On Linux and Mac, put a native C/C++ compiler, CMake, Ninja and Python 3 on PATH. On Mac, install Xcode Command Line Tools.

  3. Supply the matching original files

    Use your own European Devil Dice disc (SCES-01312) with all 12 tracks present. Supply your own retail SCPH-5552 BIOS. Use the matching CHD or keep the CUE and every referenced BIN together.

  4. Build and add the player

    From the kit folder, run Devil_Dice (with .exe on Windows) and choose Generate & rebuild. In Portcove, select build-release/Devil_Dice (with .exe on Windows) and use build-release as the start folder. Save the details, then choose Play.

Setup notes
Linux and Mac compatibility
The Linux setup host requires glibc 2.29 or newer, libstdc++ with GLIBCXX_3.4.26, OpenGL and zlib. The Mac host and bundled generators require macOS 11 or newer.
Updates and backups
Keep the complete working folder and back up your disc images, BIOS, saves, settings and mods. Use the upstream setup kit when replacing your player.

Limitations and evidence

  • Use the retail European disc for this kit. A prerelease disc shares its first data track and 12-track count.
  • Portcove has not verified native setup, gameplay or save compatibility for this kit.
