Setup

  1. Check the required game files

    Use your own Japanese retail Xbox disc as ISO, XISO or a complete extracted default.xbe and Media folder. The default.xbe SHA256 is 6c249401369ed41c2a319762f0b56b80aefde3efe766ac0d8731889a4150deac; the project provides a complete 3515-file manifest. Chinese translation is optional. Import a separately patched English ISO only after the initial Japanese build.

  2. Follow upstream setup

    Build from source with setup.cmd and build.cmd on Windows using Python3.14, VS2022 and Rustup. Release assets update an existing installation; they are not initial game packages.

Limitations and evidence

  • The project tested startup, save/load, movies, streets and shops, story battles, RTS tutorials and entry into chapter 2. It explicitly does not guarantee a full playthrough or stable 60 FPS.
