Setup

  1. Use the matching original

    Use your own installed copy of Itsuka, Todoku, Ano Sora ni., product ItsukaTodokuAnoSorani. The tagged guide identifies engine version 1.66. Keep the game folder together, including its original boot files.

  2. Start with the game folder

    Use bgi.exe from the upstream preview. It is a 32-bit Windows program. Open it outside a game folder and use Select game to choose your original folder.

  3. Open the same game again

    Choose the remembered folder in Select game. A frontend can start bgi.exe with the game folder as its working directory to enter directly. Reopen Select game to change the folder or use Advanced to change the launch options.

Setup notes
Keep saves and settings
OpenBGI writes BGI save files with a .cad extension in the game’s base folder. Keep your game folder and the games.json profile beside bgi.exe or in the game folder before manually replacing the engine.
Linux builds
The upstream project documents building the engine for Linux from source. This preview publishes a Windows executable.

Limitations and evidence

  • The project reports limited play testing. Portcove has not run this original or restored a save.
