Setup

  1. Start the Windows game

    Run the official 2020_12_21 Windows installer and use its game shortcut or open sauerbraten.bat from the installed game folder. Keep the game data and player files together. The batch launcher selects the native x64 player on x64 Windows.

  2. Install the Ubuntu game

    Install sauerbraten from Ubuntu Multiverse when available. The package manager supplies the separate Cube 2 engine and the game data. Launch Sauerbraten from your application menu or run sauerbraten.

  3. Open the Intel Mac bundle

    Use the official 2020_12_21 Mac disk image. Keep the Sauerbraten app and its game files together and open the complete app. Its player and SDL libraries contain Intel x64 code. A separate Apple Silicon build or translated execution requires its own compatibility check.

  4. Keep the actual profile

    With Sauerbraten closed, preserve the folder that contains config.cfg and your local maps or add-ons. The supplied Windows launcher uses My Games/Sauerbraten inside your Windows Documents folder, the Mac app uses ~/Library/Application Support/Sauerbraten, and the Ubuntu launcher uses ~/.sauerbraten. Save any profile override and custom game files you added to the installation.

Setup notes
Use the community Flatpak
Flathub offers org.sauerbraten.Sauerbraten for Linux x64 and ARM64. With that package, preserve ~/.var/app/org.sauerbraten.Sauerbraten/.sauerbraten. Your package manager owns replacements and updates.
