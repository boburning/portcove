Setup

  1. Check the required game files

    Use your own USA PlayStation 2 Guitar Hero II disc (SLUS-21447) as an ISO, CHD or BIN. Other original Guitar Hero discs are optional imports.

  2. Set up the Windows or Linux package

    Extract the ZIP and put the disc image in PUT_DISC_HERE beside the game.

  3. Set up the Apple Silicon package

    Open the disk image and drag GHClassic to Applications. Run it once to open the PUT_DISC_HERE folder in ~/Library/Application Support/GHClassic. Put your disc image there.

Limitations and evidence

  • This release uses a disc-folder setup and remains in development. GHClassic is not confirmed to be the same project as Recomp-Hero-2; use the instructions for this implementation.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
