Setup

  1. Prepare a separate Ballance folder

    Keep your owned Ballance installation intact. Make a separate writable copy of the game folder, including its original base.cmo, Database.tdb and asset directories. Extract the publisher's v0.2.0 runtime archive for your OS and architecture into that working copy, keeping Bin, RenderEngines, Managers, Plugins and BuildingBlocks in the supplied layout.

  2. Run the upstream player

    On Windows open Bin/Player.exe from the working copy. On Linux or macOS enter that game's root folder in a terminal and run ./Bin/Player. The Linux runtime needs glibc 2.43 or later. The Intel and Apple Silicon Mac runtimes need macOS 15 or later.

  3. Preserve the working copy

    Close the player and back up the working game folder, including the actual Player.ini and player data, before replacing or deleting it. Keep your original installation and prior working copy available while trying a new release.

Limitations and evidence

  • The publisher also supplies Windows ARM64, Windows x86 and Linux ARM64 runtime archives through the release page. Choose your actual architecture. Use the reviewed runtime archive for this layout. Upstream setup and backups are player-managed.
