packages

Get Mindustry from the publisher or your package manager. That choice determines how you update the game.

A release may contain research reports rather than a playable package.

Setup

  1. Choose your desktop download

    The publisher’s itch.io page has downloads for Windows x64, Linux x64, and Mac. Extract the whole ZIP and open its launcher. On Linux ARM64, use the community Flathub package.

  2. Run the publisher’s Java download

    The GitHub release also offers Mindustry.jar for Windows x64, Linux x64, and Intel or Apple Silicon Mac. Use a matching 64-bit Java runtime. Build 160.7 requires Java 17 or later. On Windows or Linux, run java -jar Mindustry.jar. On Mac, run java -XstartOnFirstThread -jar Mindustry.jar.

  3. Start and save a local game

    Choose Play, then Campaign or Custom Game. To save a custom game, open the pause menu, select Save Game, then New Save. Open Play and Load Game from the title screen to resume it.

Setup notes
Find your desktop data
For the standalone game, look in %APPDATA%/Mindustry on Windows, ~/Library/Application Support/Mindustry on Mac, and ~/.local/share/Mindustry on Linux. On Linux, use $XDG_DATA_HOME/Mindustry if you set XDG_DATA_HOME. Flathub keeps the folder at ~/.var/app/com.github.Anuken.Mindustry/data/Mindustry.
Get the Android version
The publisher links to Google Play and F-Droid from the Mindustry website and offers an APK on itch.io. Use the same store for future updates so the app keeps its signing identity.

Limitations and evidence

  • Before updating the game or moving it to a new computer, close it and copy the whole Mindustry data folder. Keep settings.bin with saves so named saves and preferences come across, and include any maps, schematics, and mods you want to keep.
