Setup

  1. Choose your original files on Play

    On first Play, select your own Stunts 1.1 folder or ZIP in the game’s welcome screen.

  2. Select an existing native player

    For an existing Windows copy select Stunts HD.exe; on Linux select stunts-hd with its containing folder.

  3. Set up the upstream Mac app

    If you download the universal Mac ZIP in Portcove, clear Extract the archive after downloading. Expand it with macOS Archive Utility and keep the complete Stunts HD.app. The inspected app needs macOS 11 on Intel or Apple silicon. Start the app and choose your own Stunts 1.1 folder or ZIP. Follow macOS security prompts for a copy you trust.

Setup notes
Profile locations and alternatives
Saves, tracks, replays, high scores, preferences, imported originals and cached maps live outside the runtime: %APPDATA%/Stunts HD on Windows, or $XDG_CONFIG_HOME/Stunts HD (normally ~/.config/Stunts HD) on Linux. The upstream browser player at https://stunts-recomp.pages.dev/ has separate browser-site storage. On Mac, preserve the app's effective user profile and export destinations. Mac, Windows ARM64 and Linux ARM64 or AppImage setup stay with upstream.

Limitations and evidence

  • Other 4D Sports Driving revisions are outside this input claim. Setup requires Internet access to fetch its translation map; it normally caches that map by app version and imports the original into its profile. Retain your original files for reimport if storage fails. No original game files are supplied.
  • Back up the whole Stunts HD profile with the app closed. Portcove manages the downloaded runtime only; its backup does not include the Stunts HD profile or chosen screenshot/export destinations. F6 exports are not a complete restorable profile backup.
  • A missing version cache downloads a mutable upstream map, so first setup after a version change or runtime rollback may need Internet and may fail if that map no longer matches. Preserve existing cached maps; offline/historical-map and save compatibility are not guaranteed.

Setup
