Setup

  1. Check the required game files

    Use your own USA PlayStation Dragon Warrior VII disc 1 of 2, SLUS01206. The second disc ID is not confirmed; check upstream’s current requirements before proceeding beyond disc 1.

  2. Follow upstream setup

    Initialize the pinned PSXRecomp and its submodules, generate the game C code from your own USA Dragon Warrior VII disc 1 CUE, then build psx-runtime with CMake and Ninja. Upstream warns that regeneration loses a required correction: apply its documented three generated-code edits or emitter fix before rebuilding. This source project is unfinished; no ready-to-play package has been confirmed.

Limitations and evidence

  • Upstream reports the intro, title, main menu and name entry. The opening field, story, battles and remaining overlays are still being developed. A working disc 1 menu does not establish disc 2 or full-game support.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
