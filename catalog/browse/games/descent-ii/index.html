Setup

  1. Use this original game and edition

    Use your own retail descent2.hog, descent2.ham, descent2.s22 and all six alien1/alien2/fire/groupa/ice/water PIG files. Optional movies stay optional. The separate documented PC/Mac Descent II demo uses its own complete demo set; Descent I shareware does not supply this game. Keep your originals elsewhere unchanged; upstream handles its own data recognition and preparation. A Portcove registration does not authenticate original-game files.

  2. Prepare upstream and select the real player

    Use the upstream Windows DXX-Rebirth-Windows-x86_64 Actions artifact or a complete player prepared with upstream’s supported build instructions. The observed tagged releases do not provide a matching binary asset. Keep the package complete and select d2x-rebirth.exe, with its own player folder as the working directory. Put this game’s data beside that player, or use two argument lines, -hogdir then its full data-folder path. D1X and D2X are separate players; a source archive is not their native executable.

  3. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Portcove saves your selected executable, working folder and launch arguments; choose Play separately when you are ready. You manage this game’s files, original files and profile. Removing its registration leaves those files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Keep a working copy and its data before changing versions. Other platforms need their own supported application and setup instructions.

  4. Choose the upstream Linux or Mac artifact

    From a successful upstream DXX-Rebirth CI run, choose DXX-Rebirth-Linux-AppImage-x86_64 or DXX-Rebirth-MacOS14-arm64. Unpack the artifact and use D2X-Rebirth.AppImage on Linux x64 or D2X-Rebirth.app on Apple Silicon with macOS 14 or newer. On Linux x64, make D2X-Rebirth.AppImage executable before selecting it and its containing folder in Portcove. If your host cannot mount the AppImage, add --appimage-extract-and-run as the first launch argument. Add -hogdir and the full original-data folder path as separate literal arguments.

  5. Point this engine at its own data

    Put the retail descent2.hog, descent2.ham, descent2.s22 and alien1.pig, alien2.pig, fire.pig, groupa.pig, ice.pig and water.pig from your Descent II copy in a separate directory. Start D2X-Rebirth with -hogdir followed by the quoted directory path. For the packaged Apple Silicon app, use open -a /path/to/D2X-Rebirth.app --args -hogdir followed by the quoted data directory. For an Intel source build, run the compiled player with -hogdir and that same directory. The upstream instructions also list supported shareware or demo files.

  6. Use the distribution package on Ubuntu

    On Ubuntu 26.04 x64 or ARM64, use the d2x-rebirth package from Multiverse. Launch d2x-rebirth with -hogdir followed by the quoted path to your separate Descent II data folder. Keep your originals outside the package, preserve ~/.d2x-rebirth or your chosen profile override, and use the distribution package manager for updates. Use the complete retail data with the reviewed Ubuntu package. Its 0.60~git20250524-2 build fails to load the interactive demo. On Linux x64 the current upstream AppImage can open that demo instead.

Setup notes
Build for a current Intel Mac
The upstream macOS build instructions cover SCons and SDL 2. Use those instructions to build D2X-Rebirth on your Intel Mac. The current Actions Mac package needs Apple Silicon. The old 0.58.1 Mac disk image includes only 32-bit Intel and PowerPC code.
Preserve this game’s profile
On Linux preserve ~/.d2x-rebirth. On Mac preserve ~/Library/Preferences/D2X Rebirth. Keep any D2X_REBIRTH_HOME override, original files, saves, missions and settings with the creating engine.

Limitations and evidence

  • Keep separate player/profile copies for Descent and Descent II. Preserve the build’s actual writable directory, player profiles, saves, missions and configuration; custom D1X_REBIRTH_HOME/D2X_REBIRTH_HOME or build choices can change it. Preserve the complete working player folder as well.
