Setup

  1. Start with the included courses

    The package is ready for Play. Press Enter at the title screen, select Practice, choose a course, and select Race. On Linux, install libGLU.so.1 from your distribution if needed.

  2. Choose the package for your computer

    Use the Windows 10 or 11 x64 ZIP, the Linux x86-64 archive, or the universal macOS 11 or later ZIP for Intel and Apple Silicon. The Linux game needs glibc 2.35 or later and libGLU.so.1. Debian and Ubuntu provide the latter in libglu1-mesa.

  3. Extract the whole package and start the game

    On Windows, run tuxracer.exe. On Linux, run tuxracer. Keep the data folder next to the player. On macOS, open the complete Tux Racer.app without moving files out of it.

  4. Keep your original Tux Racer profile

    With the game closed, copy %APPDATA%/TuxRacer on Windows or ~/.tuxracer on Linux and Mac. Keep that backup when replacing your extracted game folder. Extreme Tux Racer uses a different profile.

  5. Keep captures you want to retain

    The game writes tux_sshot_*.ppm and its optional diagnostic_log.txt beside the player. In an extracted copy, keep those files when replacing the runtime. Move screenshots you want to keep before playing again, because the game restarts screenshot numbering at zero.

Setup notes
Check other platforms
The SDL2 port publishes an x86-64 Linux package and a universal Mac package. Its release page does not offer Linux ARM64 or Android packages.
