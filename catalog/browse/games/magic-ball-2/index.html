Setup

  1. Prepare a writable copy of your original game folder

    Use your own Magic Ball 2 or Smash Frenzy 2 installation. Keep its original data together, including any .pak or .dat archives. The engine writes player files in the game-data folder.

  2. Start the Windows engine

    If you have permission to use the Windows x64 OpenMB2 package, put OpenMB2.exe and the OpenMB2 folder in your writable game folder. Run OpenMB2.exe. The upstream guide also gives --game and --overrides options for keeping the engine files separate.

Setup notes
Keep your progress when replacing the engine
Close both engines and back up the writable game-data folder. Keep score.dat, the s<pack>.sav progress files, other save slots and openmb2.ini. OpenMB2 reads the original params.txt and keeps its own settings in openmb2.ini.
Set up the ARM64 Linux handheld package
Use the matching MuOS or PortMaster layout in the upstream instructions. Copy your original game files into that port’s openmb2/gamedata folder and start OpenMB2 from the handheld launcher. Back up gamedata to retain your progress and settings.

Limitations and evidence

  • OpenMB2 writes progress and settings in the selected game-data folder, even when the engine is in a separate folder.
