Setup

  1. Choose your Windows or Mac package

    On Windows, run the publisher installer for x64, x86, or ARM64. On Mac, open the disk image for Intel or Apple Silicon and copy Widelands to Applications. Use macOS 15 or later with the 1.3.1 disk images because bundled libraries target it.

  2. Choose your Linux package

    The publisher offers an x86-64 AppImage. Make it executable before opening it. The AppImage needs FUSE and can also need your distribution's JACK compatibility library. If the AppImage cannot open, use the Widelands Flatpak for x86-64 or ARM64.

  3. Start and save a settlement

    Choose Single Player, then New Game or a campaign. In a game, open the menu and choose Save Game. From the main menu, choose Single Player and Load Game to continue.

Setup notes
Find your Windows or Mac data
Look in %USERPROFILE%/.widelands on Windows or ~/.widelands on Mac.
Find your Linux data
Keep an existing ~/.widelands directory. On new standalone setups, save data goes under $XDG_DATA_HOME/widelands or ~/.local/share/widelands, and settings go under $XDG_CONFIG_HOME/widelands or ~/.config/widelands. For Flatpak, keep the app profile under ~/.var/app/org.widelands.Widelands, including its .widelands folder when present.

Limitations and evidence

  • Close Widelands before copying its data. Keep your saves, settings, maps, add-ons, and replays together. If you started the game with --homedir, keep the folder you selected. Use the same game version and required add-ons when opening an older save for the first time.
