Setup

  1. Use your own USA disc and the complete kit

    Use the complete upstream v0.4.4 Windows package with your own Def Jam Vendetta USA SLUS-20639 ISO or supported CHD. The preparation tool checks for SLUS_206.39 and prepares a plain sector ISO and extracted files; that serial/member check is not a whole-disc cryptographic or entitlement certificate.

  2. Finish upstream preparation first

    Complete Def Jam Vendetta Recompiled Settings.exe setup outside Portcove. Upstream extracts your own disc, generates C++ and builds locally, including supported compiler/tool installation and prompts. Use Windows10/11x64, Vulkan1.3 and upstream hardware requirements. Wait until the game and its complete matching files are built. The release build kit applies this title's pinned PS2Recomp patch; do not mix an unpatched framework or another game's output.

  3. Select the completed player

    Select files/Def Jam Vendetta Recompiled.exe in the complete creating installation, use files as working directory and pass the one literal argument game/SLUS_206.39. Keep the complete game/, disc/, DLLs, settings and companion runtime files. The official settings Play consumer passes that same extracted ELF with the files working directory; the generated player owns its normal runtime.run loop. Do not select the settings bootstrapper, run.bat or incomplete output.

  4. Keep Update and Rebuild outside the tracked game session

    The normal startup check can offer Play or hand off to the upstream settings program for Update/Rebuild and end the game process. Finish pending preparation and replacements before registration. If you choose maintenance, let the selected game session end, complete upstream work, then revalidate the resulting native player before another Play. Portcove does not follow that successor, suppress the feature or own upstream repair.

  5. Update and repair through the project’s tools

    The upstream settings program owns journaled file updates and rebuilds; its setup publishes the generated game and DLLs through staged .new replacements. Keep recovery copies outside upstream update/build scratch locations. Portcove only registers the explicitly selected completed native copy; it does not acquire originals, build, update, roll back or delete external saves/runtime files. Requesting Play remains a separate consent action.

  6. Keep required notices and check this guide’s limits

    Retain GPL PS2Recomp/title notices, paraLLEl-GS LGPL and all other individual component notices. The title's name/logo and settings-app artwork are explicitly outside its project licence. This guide does not establish source/output byte correspondence or save compatibility.

Setup notes
Back up effective data before startup or maintenance
With the game closed, keep a separate complete prior installation plus current files/settings.toml, files/game/mc0, sibling card-port roots, extracted game data, original disc and logs. Cards are filesystem folders derived from the selected ELF directory; ordinary guest operations can create, overwrite, delete or format their files. VENDETTA_SETTINGS can select another settings file; preserve it if configured, and preserve any external roots from your own installation. Startup can rewrite legacy fullscreen settings to borderless through a temporary replacement; logs are recreated. Do not assume save compatibility or restore older player data with an old runtime.
