Setup

  1. Use the matching original game

    Use your own complete Call of Pripyat 1.6.02 resources in a private working copy. Shadow of Chernobyl, Enhanced Edition and Legends of the Zone data are outside this route. Preserve the original installation and mod-specific files.

  2. Prepare the Windows player

    Follow the upstream Windows installation guide for the exact selected release. The inspected latest-nightly OpenXRay.Release.Master.Gold.64-bit.7z contains the x64 bin/xrEngine.exe player. Preserve the old bin and extract the complete matching archive into the working game root. Register the prepared bin/xrEngine.exe using the working directory and arguments of the upstream installation. Keep its companion DLLs; do not register a helper or replace a live original installation.

  3. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Select the game executable and its working folder, and put each launch argument on a separate line. Choose Play separately when you are ready. You manage this game’s files, originals, saves and settings. Removing its registration leaves those external files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Close the game and keep a working copy and every data and profile folder before changing versions.

Setup notes
Keep your existing game data
Preserve the actual app_data_root selected by that installation’s fsgame.ltx, all saves/configuration/logs and the complete working original/runtime copy. Locations and mod requirements can vary. Upstream warns that incompatible or malformed mods can fail; neither save migration nor mod compatibility is established by registration.
Prepare the Linux player yourself
Follow the upstream Linux/macOS guide with your own Call of Pripyat 1.6.02 resources. Open https://github.com/OpenXRay/xray-16/actions/workflows/cibuild.yml and choose AppImage Release amd64 from a successful push on the official dev branch. Use a system with glibc 2.38 or later. Unzip the download and make the AppImage executable. Select the AppImage and its containing folder. Where FUSE is unavailable, enter --appimage-extract-and-run as the first argument line, before any other argument. Call of Pripyat is the default. Leave out -cs. For a custom fsgame.ltx, enter -fsltx and its space-free absolute path on separate lines.
Prepare the matching Mac build yourself
From the same official Build workflow, download macOS Intel Release x86_64 or macOS Release arm64 for your Mac. These builds target macOS 14 or later. Keep bin and share/openxray together, including the supplied fsgame.ltx template and gamedata. Use the matching Homebrew architecture to install sdl2-compat, lzo, libogg, libvorbis, theora and jpeg-turbo. Follow the upstream guide to arrange your own Call of Pripyat 1.6.02 resources. Select bin/xr_3da and the unpacked folder that contains bin and share. Call of Pripyat is the default. Leave out -cs. For a custom fsgame.ltx, enter -fsltx and its space-free absolute path on separate lines.
Keep the effective profile for this copy
Keep the required resource folder names lowercase and confirm a normal launch and quit in your prepared copy before registering it. Keep the complete runtime, original files and the app_data_root selected by that copy's fsgame.ltx. Use separate player profiles for the two games.
