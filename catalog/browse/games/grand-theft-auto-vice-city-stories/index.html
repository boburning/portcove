Setup

  1. Prepare the exact PSP title

    Use a complete copy and components you are independently permitted to use. Finish upstream preparation outside Portcove, keep independent originals and recovery copies. No original, helper, compiler or game is obtained or executed by this guide. Use your own Grand Theft Auto: Vice City Stories PSP ULUS-10160 input targeted by the selected profile. Complete upstream preparation of a decrypted game executable and full PSP_GAME/USRDIR; keep independent original media. This is not GTA Vice City/reVC, the PS2 edition or another PSP title. No decryption, firmware, key or credential operation is authorized by this guide.

  2. Keep the complete Windows player

    The inspected official Windows ZIP contains AMD64 VCSNative/VCSNative.exe, VCSLauncher.exe and matching runtime libraries. Keep the complete VCSNative directory. The native program uses the generated Allegrex profile, linked PSP services and Vulkan graphics; native CPU output does not remove those system/graphics compatibility layers. Do not select a PSP executable, build helper, macOS application or settings launcher as the attached game.

  3. Add the player with its supported local files

    After upstream preparation, keep PSP_DATA beside VCSNative.exe with PSP_GAME/SYSDIR/EBOOT_DECRYPTED.ELF and complete PSP_GAME/USRDIR. Select VCSNative.exe, use the full VCSNative directory as working directory and leave arguments empty. Review the exact intent and request Play separately. Source discovers that package-local layout and runs the game on its native worker while the main thread services events until the worker finishes. A launcher-only remembered external path is not silently substituted for this direct route.

  4. Preserve all data roots and originals

    Keep VCSNative.ini, ProperShaders.ini, the full active save/profile/memory-stick data, textures, logs and PSP_DATA, plus any established external paths. Preserve complete package and separately configured save roots before replacement; the macOS Application Support path is not a Windows save-path claim. This guide does not migrate PSP saves or verify mission/save compatibility. Keep independent original data and do not treat a linked working tree as its backup.

  5. Keep optional packs and component grants separate

    Retain the PSPRecomp MIT notice and each profile/component notice, including separately credited graphics/mod components. Those do not license original game code/assets or third-party textures. The optional VCSTexturePack is a separate download and is not part of this guide; keep only existing components you are independently permitted to use. No pack is fetched, generated or executed here.

  6. Maintain upstream explicitly

    Quit the actual game normally before upstream replacement or data operations; forced termination is not a save-flush guarantee. Review/relink changed executable bytes. Source, package and upstream playability reports do not establish native gameplay, complete-game, save/reload, installed-app or Supported acceptance. Removing registration preserves external files; managed install/update/rollback/backup/removal remain unavailable. Upstream reports playable 60 FPS but less testing of missions/saves than opening areas. Windows Vulkan and macOS platform claims remain distinct; no full campaign or physical-client qualification is asserted.

Limitations and evidence

  • Keep the exact PSP ULUS-10160 data and complete save/configuration roots. Optional textures, other editions and upstream playability claims have separate scope.
