Setup

  1. Finish the supported European game setup

    Use your own inFamous European PS3 BCES00220 files and complete the upstream Windows setup, translation and build before adding the player. An already decrypted supported folder avoids a key-input route; encrypted images have their separate owner-supplied requirements. This guide provides no keys, decryption or game data. The selected 1.1 Windows setup is a preparation program, not an already compiled game. Windows 10/11 x64, Direct3D 12 and the upstream build/runtime prerequisites remain required.

  2. Keep the complete prepared installation

    Retain the full completed port directory, its native inFamous.exe launcher, installer/launch.txt, build-install/inFamousRecomp.exe, the prepared game/ELF, libraries, settings and notices. The producer writes executable, working-directory, argument and environment values into launch.txt. The normal launcher reads those values; selecting the bare game without its published context is not an equivalent shortcut. Keep project/runtime/compiler/component terms separate from original game rights and do not share private translated outputs.

  3. Add the native upstream launcher

    Select the completed inFamous.exe in its existing port directory, use that directory as working directory and leave arguments empty. Review the selected program, folder and arguments, then choose Play when ready. Its native launcher supplies the producer-written launch configuration and environment. Portcove observes that launcher only; it can report the launch finished after handoff while inFamousRecomp.exe and helpers still run. Use the game’s own controls to quit and do not interpret the launcher’s exit as full-game completion.

  4. Preserve the current saves and launch configuration

    Keep the whole existing port, installer/launch.txt, settings.ini, all original/generated content and gamedata/. Default saves are under gamedata/dev_hdd0/home/00000001/savedata relative to the configured port working directory; retain all profiles, trophies and related data as present. Existing SAVEDATA_ROOT and other producer/user path overrides must remain intact. Do not transplant launch.txt into a different layout, reset populated settings or merge saves merely to add the launcher. No save conversion, migration, backup or restore is performed.

  5. Leave updates and recovery upstream

    Close the actual game and helpers before upstream replacement, rebuild, repair or recovery, even if Portcove’s activity has finished. Upstream owns imports, build tools, runtime replacement and launch configuration; review/select the current launcher again after changes. Early-release PPU/SPU, rendering and campaign claims do not establish gameplay/controller/real-save acceptance here. Removing the library reference preserves all external files. No managed installation/update/backup/rollback, full-session tracking or Supported qualification is supplied.
