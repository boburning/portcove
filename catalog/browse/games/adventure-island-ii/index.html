Setup

  2. Supply the exact original image

    Provide your legally obtained Adventure Island II (USA).nes in the Rom folder beside Launcher.exe, or choose it through Browse ROM. The selected frontend requires a 262160-byte iNES file with SHA-256 10dd53fd62c95e77856b09c693b3bdd14b62a89988902eea111257cafe9b8acc and its exact header; a different revision, payload-only dump or modified header is not accepted. The ROM is opened read-only.

  3. Preserve the portable player files first

    With the game and launcher closed, separately back up the complete old and new game folders, settings.ini, Snapshots/ including Quick Save.ai2state, Screenshots/, the original ROM location and any custom copies. Startup creates or updates settings.ini beside the executable, including its welcome flag. Snapshot save overwrites its selected slot; capture failure can delete an incomplete screenshot. No cross-build snapshot compatibility is established.

  4. Complete the upstream first-run screen

    Open the ordinary Launcher.exe, dismiss its first-run Welcome window, select the verified ROM, and use Run. The launcher starts its own --game child internally and retains its process handle; do not select that internal child mode or copy its private control arguments into Portcove.

  5. Link the outer launcher

    Add Launcher.exe through the existing-copy route, use the folder containing it as the working directory, and leave arguments empty. Keep the launcher open while the actual game is running; its message loop observes the child and retains its own window when play stops.

  6. Exit the actual game before the launcher

    Quit the game window normally, then exit Launcher before maintenance, replacement, relinking or removal. Closing the launcher with a running game offers to exit both: upstream posts close to the game, waits two seconds, then may force termination. Avoid relying on that path for a final save or assuming that forced shutdown preserves progress.

Portcove only links this completed external copy; it does not install, update, roll back, back up or delete it.
