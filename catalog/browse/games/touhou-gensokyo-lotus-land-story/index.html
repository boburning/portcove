Setup

  1. Add your own game files

    Put your own th04.hdi PC-98 image, FREECG98.BMP font and ym2608_adpcm_rom.bin rhythm ROM beside th04-port64.exe. Compare them with the tested input identities in the upstream guide; the game does not check them.

  2. Register a Windows copy you manage yourself

    Extract the x64 preview into a writable folder and check the release SHA-256. Choose th04-port64.exe with its own folder as the working directory. Add these arguments as separate entries: --hdi th04.hdi --font-bmp FREECG98.BMP --save-dir save-normal --title --audio --pmd-driver pmd86 --opna-rom ym2608_adpcm_rom.bin. Save the launch details and choose Play. Play.bat starts the ordinary game outside Portcove.

  3. Build a Linux x86-64 copy

    Follow the pinned Portable 64-bit Linux build with CMake, a C++17 compiler and SDL2 development files. Start the built th04-port64 from your prepared folder and set the input paths and save directory as shown in the upstream Linux command.

Setup notes
Keep scores and settings
Keep MIKO.CFG and GENSOU.SCR together under your effective save directory. The bundled launchers use save-normal and save-no-life-loss. A direct run without --save-dir uses %LOCALAPPDATA%/TH04 on Windows or $XDG_DATA_HOME/th04 on Linux, usually ~/.local/share/th04. Close the game before replacing its player.

Limitations and evidence

  • The player contains program code reconstructed from the original game, which the project’s MIT licence does not cover. Portcove downloads it only from the project’s own releases. You need your own game image, font and sound ROM.
  • The upstream preview offers an assisted mode with its own save directory. Use the ordinary player for regular play and keep both profiles separately.
