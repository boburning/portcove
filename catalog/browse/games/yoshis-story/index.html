Setup

  1. Prepare the exact game upstream

    Use a complete player and components you are independently permitted to use, with your own Yoshi’s Story ROM: USA En/Ja .z64 SHA1 B13072FEF6C6DF48C07D8822C01E5BC59036F6DA. These SHA1 values identify the documented representation, not ownership or a signature. Upstream also accepts supported byte-order variants; do not apply a .z64 hash to differently ordered bytes. Finish the upstream Load ROM flow before attachment and preserve the independent original. No ROM, BIOS, helper or game is obtained or executed by this guide.

  2. Keep the matching Windows package

    The inspected official Windows ZIP contains the AMD64 DinoTale.exe native player. Keep its complete extracted directory, assets, renderer/runtime libraries and notices together. The player runs the recompiled game through its linked runtime within the selected process; do not select a ROM, build tool, AppImage or another title’s executable. Source and PE observations do not establish Windows gameplay or dependency resolution.

  3. Add the prepared native player

    Select DinoTale.exe, set its complete extracted package directory as working directory and leave arguments empty. Review that exact intent and request Play separately. Use the upstream player UI to choose/start the already prepared game. Complete missing-ROM setup outside the attached attempt before retrying. Quit the actual game normally; forced termination is not a save-flush or recovery guarantee.

  4. Keep the game’s existing data folder

    The selected source sets program_id to dinotale; its pinned Frontend normally uses %LOCALAPPDATA%/dinotale on Windows. An existing portable.txt in the working directory instead selects that directory. Keep the complete active root, imported ROM, saves, settings, input profiles and mods, plus any existing external paths. This guide creates no marker, moves no files and does not infer compatibility from another game. The selected game uses EEPROM storage. Other Yoshi games and ROM revisions are separate.

  5. Retain the exact component terms

    Preserve the project GPLv3 notice, title-specific authored patches, N64ModernRuntime, RT64 and all dependency notices. This source pins the unchanged official RecompFrontend base b1a1477c6556aeb7ed45defbfb5924f721efebc1 covered by the existing official license follow-up; that correspondence does not license unrelated forks or original game code/assets. The selected source uses Exo 2, Noto Emoji and promptfont with separate SIL Open Font License notices. Keep those notices and use only components you are independently permitted to use.

  6. Maintain the external copy explicitly

    Quit the game before upstream replacement, ROM changes, mods or data operations. Preserve independent recovery copies and review/relink changed executable bytes. The selected game uses EEPROM storage. Other Yoshi games and ROM revisions are separate. Upstream playability and platform reports remain upstream claims; no installed-app, campaign, save/reload or Supported acceptance is asserted. Removing registration preserves external files; managed installation, updates, rollback, backup and removal remain unavailable.
