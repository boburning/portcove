Setup

  1. Keep only an independently permitted completed copy

    Fresh acquisition remains held on the separate project-code permission condition. The framework’s licence applies to its own components, not the title’s separately modified code. Continue only with an actual copy and components you are independently permitted to use.

  2. Complete the owned-input preparation upstream

    Use your own USA Final Fantasy Tactics PlayStation disc, SCUS-94221, as its CUE and every referenced BIN. The official Windows setup ZIP is a local build kit, not a ready game: it supplies no original disc, retail BIOS or generated game code. Complete upstream’s supported Generate & rebuild flow with its Python/toolchain outside Portcove. OpenBIOS is generated locally by default; an optional retail BIOS must be your own permitted copy. Keep the actual working disc and BIOS selections. Portcove does not run compilers or setup helpers, or import your original files.

  3. Attach the completed product

    After successful upstream preparation, select build-release/Final_Fantasy_Tactics_Recompiled.exe, the completed executable’s parent directory as working directory and the supported --launcher literal argument. Keep its staged game.toml and matching resources in place. The root setup executable starts a replacement product and exits on Windows, so select the completed product instead. Keep Generate/Rebuild and SDK/toolchain changes as deliberate upstream maintenance outside the active attached session; an intentional rebuild can end or replace the process.

  4. Review launch details, then choose Play

    Select the completed game executable, its working folder and supported launch arguments. Review those details and agree to use them, then choose Play separately. You manage setup, game replacement and recovery using the project’s tools. Portcove does not offer updates, backups, rollback, conversion, data migration or deletion for this external copy. Removing its registration leaves external files in place. Before changing versions, close the game and its companion programs and keep the working copy and its data. Review and select the changed executable before playing again.
