Setup

  1. Keep the portable package together

    Choose the upstream MinGW x64 ZIP on Windows x86-64 or opentyrian2000-MSVC-ARM64.zip on Windows ARM64. Extract the complete package into a writable folder. Keep opentyrian2000.exe, its libraries and the included data directory together.

  2. Use the included player

    On Windows x86-64, finish setup with opentyrian2000.exe and its folder, then choose Play in Portcove. On Windows ARM64, start opentyrian2000.exe directly. For other packages that require additional data, follow the upstream Tyrian 2000 data instructions.

  3. Install the upstream Linux package

    On Debian-compatible Linux choose the official amd64 or arm64 DEB for your machine. Install it using your package manager and start opentyrian2000. Use the same package manager to replace it.

  4. Open the upstream Mac app

    If downloading in Portcove, clear Extract the archive after downloading. Unpack opentyrian2000-macOS.zip with Mac Archive Utility to retain its framework links. Open opentyrian2000.app from its permanent folder on Intel or Apple Silicon.

  5. Keep the Tyrian 2000 data

    Use the Tyrian 2000 files included with the official package. Keep the Tyrian 2000 profile and game data together with the version you use.

  6. Use the upstream Android package

    On Android 11 or newer, unpack opentyrian2000-android.zip and install its signed APK with the included Tyrian 2000 data. Review and grant the app’s All files access permission to use its shared profile under Internal storage > Android > tyriandata. Back up that folder before replacing the app.

Setup notes
Keep your current copy when updating
Apply upstream updates separately and keep your existing data, configuration and progress backed up. This downloaded copy remains upstream/player-owned.
Preserve the Tyrian 2000 profile
On Linux, back up $XDG_CONFIG_HOME/opentyrian2000 or ~/.config/opentyrian2000. The reviewed Mac app uses ~/Library/Containers/com.AnV.Software.opentyrian2000/Data instead. Use Quit in the game menu before backing up or replacing the Mac app. In Finder, choose Go > Go to Folder and open that path. Find and back up your actual tyrian.sav, tyrian.cfg and opentyrian.cfg before replacing the app. Keep Tyrian 2000 data separate from the OpenTyrian 2.1 profile.

Setup

  1. Start with the required game files

    The official archive includes the freeware Tyrian 2.1 data. Choose Play after installation; no commercial game files or separate setup program are required.

  2. Choose an upstream sibling package

    On Mac save the official universal ZIP. If downloading in Portcove, clear Extract the archive after downloading. Unpack it with Mac Archive Utility and open OpenTyrian.app on Intel or Apple Silicon. On Linux ARM64 choose the matching tarball and run opentyrian from the extracted folder. The current ARM64 build needs glibc 2.34 or newer. The upstream release also provides a native Windows ARM64 ZIP for an external setup.

  3. Use this edition’s game data

    Keep the bundled Tyrian 2.1 data with the upstream player, or use the upstream --data option to point to your own compatible Tyrian 2.1 folder.

Setup notes
Keep the OpenTyrian profile
Back up $XDG_CONFIG_HOME/opentyrian or ~/.config/opentyrian on Linux and Mac. For a portable copy keep the actual configuration, saves and game folder. Use the upstream package for replacement.

Limitations and evidence

  • On Windows, choose a short installation folder using basic Latin characters. The official runtime can fail to find its packaged data in folders with non-ASCII names. This Windows runtime-path requirement does not restrict Linux installation paths.
