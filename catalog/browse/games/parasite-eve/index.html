Setup

  1. Prepare your own disc

    A permitted existing Linux copy requires Parasite Eve USA SLUS-00662 Disc 1 as the raw BIN/CUE set; the documented Disc 1 BIN is 495531120 bytes. Keep all referenced tracks together. ISO and CHD are not direct equivalents. Newer native-only builds also describe Disc 2 support; use the selected release instructions rather than treating the old Day 1 build as the current runtime.

  2. Keep the upstream launcher and profile

    For an existing copy you are permitted to use, launch its parasite-eve wrapper with your disc folder, BIN or CUE using the selected release guide. The wrapper can remember disc1 in ~/.config/parasite-eve-port/config; the documented card is ~/.local/share/parasite-eve-port/memcard1.mcd. Preserve any customized XDG profile. Keep using the OS shortcut when the wrapper is required; Portcove does not register a shell script or assume its private binary has equivalent arguments. No files are adopted or replaced.

Limitations and evidence

  • The prebuilt route identifies imported upstream functions outside the project MIT grant. Resolve the applicable component permission before obtaining or building a copy. Experimental route coverage and upstream test claims are not Portcove gameplay qualification.
  • Updates and profile preservation remain with you/upstream; Portcove makes no external backup, rollback or file-removal promise.
