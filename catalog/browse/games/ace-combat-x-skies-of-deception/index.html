Setup

  1. Prepare your own game files with the project’s tools

    Use an independently permitted completed native build for Ace Combat X: Skies of Deception USA ULUS10176. Upstream preparation uses your own UMD ISO and your own decrypted EBOOT.elf, generates image.bin and matching native code, and builds the windowed SDL3/Vulkan player. Decryption and extraction tooling remain the user’s upstream preparation, outside Portcove. Preserve disc.manifest and cdi.manifest with extracted data: the runtime uses original sectors. Do not use another Ace Combat game’s disc, BIOS or save contract.

  2. Select the completed game player

    Select completed build/pspreco-sdl3.exe with its creating project root as working directory. Pass the absolute generated/image.bin and the absolute own ISO or complete extracted-game directory as its two literal arguments, exactly the documented native running route. Do not select the headless developer target, Python tools or a different game. Keep the matching SDL3/Vulkan dependencies and prepared tree.

  3. Review launch details, then choose Play

    Review and consent to the selected game executable, working folder and launch arguments, then choose Play separately. You and the project manage setup, version changes and recovery. Removing the registration leaves all external files in place. Portcove does not offer updates, backups, rollback, migration or deletion for this copy. Before changing versions, close the game and all companions and keep the complete working copy and every data location. Review and select the executable again if its files change.

Setup notes
Use the completed game player
The player loads its generated image and your own disc data, then keeps running until shutdown. This guide is based on source inspection of the completed-copy route. Portcove has not inspected public RAR contents or observed the game running.
Keep the working game and every data location
Keep the entire creating project, generated image/native code, original UMD-derived files, extraction manifests, runtime libraries and permitted fonts. Default saves use memstick/PSP/SAVEDATA relative to the chosen CWD; PSPRECO_MEMSTICK overrides that root. Default pspreco.toml is CWD-relative; PSPRECO_SETTINGS overrides it. Keep textures/ULUS10176 and PSPRECO_TEXTURES, PSPRECO_FONTDIR and every other actual custom path, with mods/scripts, caches, logs and backups. Retain project GPL-2.0 and separate ImGui, ATRAC decoder, Basis/zstd and font notices. The source calls its PPSSPP PGF fonts freely licensed; this is an upstream attribution, not a new grant for PSP firmware or the original game. No cross-game/save compatibility is assumed.
