Setup

  1. Prepare upstream or keep an existing game build

    Use your own Advance Wars USA Rev 1 original with the upstream Windows alpha guide. Run Setup.cmd deliberately; it records setup.log, skips completed work and can be resumed. The generated Advance Wars (recomp).cmd launches the prepared game. For native registration, choose build/Release/AWRE.exe, use the prepared project root as working directory and game/aw.gba as the argument in Change launch details. Compiler tools are not the game; the reviewed alpha has no audio.

  2. Keep your files and update through upstream

    Keep the game in a separate folder you control, and retain a working copy. Review its executable in Portcove, then add it without changing its files. Choose Play separately when you are ready. You manage updates, original files, generated data, saves and settings. Portcove does not replace, back up or roll back this external copy. Follow the project’s instructions for the version you use when changing it.

Setup notes
Keep the save next to the selected ROM
Use your own Advance Wars USA Rev 1 ROM with SHA-1 15053499d5b3f49128a941d7f2d84876f5424d0c. The player derives the Flash save path from its ROM argument. With game/aw.gba this is game/aw.sav. Close the game and preserve both files and the creating runtime before replacing it. Keep locally generated game code private.
