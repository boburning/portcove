Setup

  1. Extract the original game files

    Use your own copy of Animal Crossing: New Horizons with update 3.0.3. Following the v0.11.0 release instructions, extract the game’s ExeFS and RomFS for the launcher. Keep the working inputs separate from your original copy.

  2. Prepare the selected desktop player

    Open the launcher from the package for your computer, choose Prepare the game from your extracted files, and select the files, a writable game folder and its target platforms. Let the launcher finish building before choosing Play.

  3. Prepare the Android copy

    Use the Android APK and select a game folder with the extracted exefs and romfs directories, or choose Android as a target on your computer and copy the prepared folder to the phone.

  4. Keep your saves

    Keep the user folder inside the game folder or use the upstream save backup before replacing the player.

Limitations and evidence

  • The publisher describes the v0.11.0 preparation tests as using synthetic input. Game dumps, saves, graphics drivers and gameplay can still behave differently. Portcove has not qualified setup or gameplay.
