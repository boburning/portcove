Setup

  1. Open the package for your desktop

    Open the linked stable Meitou Launcher release. Extract the full Windows or Mac Launcher Portable ZIP, or make the MeitouLauncher Linux AppImage executable. Standard Mac builds require macOS 14 or later and the project documents the first-run Gatekeeper prompt. The release also links separate legacy packages for macOS 13.

  2. Choose your Kenshi installation

    Open the launcher and let it find your existing Steam or GOG copy, or select its folder when prompted. Return to the launcher on later starts. The launcher updates itself and the game. In the game, Tab opens settings and F5 quicksaves and F9 loads the quicksave.

Setup notes
Keep the original saves and Meitou data
Back up your original Kenshi saves and your Meitou profiles separately before changing versions or mods. Meitou's Windows quicksave is in %LOCALAPPDATA%/Meitou/save/quicksave. Keep the separate recorded Kenshi folder setting. The launcher packages are separate from the .nupkg updater payloads.

Limitations and evidence

  • The published launcher and game builds have separate version numbers. Portcove does not install game updates or back up either game's saved data.
