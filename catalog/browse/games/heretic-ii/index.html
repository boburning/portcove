Setup

  1. Prepare a separate Heretic2R copy

    Use the Windows runtime ZIP in a separate folder. Copy your Heretic II version 1.06 base folder into it, excluding the original DLL files; keep the original installation untouched. Finish setup with Heretic2R.exe.

  2. Optional CD music

    For OGG music, place your own CD tracks named track02.ogg through track14.ogg in base/music inside the separate runtime folder.

  3. Add the game and manage your files

    Complete the upstream setup in your permitted working copy before registration. Select the actual Heretic2R.exe and its containing folder as the working directory; keep every packaged companion. Leave arguments empty for the normal upstream startup flow, or supply separate literal arguments only when deliberately following that version’s documented options. Registration binds your explicit executable, folder and arguments with consent; Play is a separate action. You and upstream own runtime replacement, original files, saves, settings and profiles. Close the game and preserve every actual data/profile location and the working player before upstream updates. Registration-only removal preserves all external files. Managed Install, Update, Backup, Rollback, migration and external deletion are unavailable.

Setup notes
Keep saves and settings
Heretic2R stores saves, settings, screenshots and logs in your Windows Saved Games/Heretic2R folder. Keep that folder when updating the upstream runtime.

Limitations and evidence

  • Heretic2R saves and runtime modules are incompatible with the original Heretic II versions. Use Heretic2R’s supplied modules and retain the original copy separately.
  • Keep that folder when updating the upstream runtime.
