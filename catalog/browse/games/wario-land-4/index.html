Setup

  1. Open the upstream Windows launcher

    On Windows, select the Windows x64 release, extract the entire ZIP into a folder you own, and open wl4-launcher.exe. Keep both EXEs, SDL3.dll, and the notices together.

  2. Select the Linux AppImage

    Use the official Linux x64 AppImage on a host with glibc 2.38 or later. Make the file executable. In Portcove, select the AppImage and use its containing folder as the working directory. If FUSE is unavailable, enter --appimage-extract-and-run as one argument.

  3. Choose your original game

    In the launcher, choose Browse and select your own unmodified US Game Boy Advance ROM. The launcher checks for an 8 MiB file with game code AWAE and MD5 5fe47355a33e3fabec2a1607af88a404. Choose Launch Game.

  4. Select the prepared Windows player

    Select wl4-launcher.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: Windows %APPDATA%\wl4\wl4.sav and settings.cfg; the Windows user registry entry for the original ROM path; Linux ~/.local/share/biorhythmicstudios/warioland4/ and ~/.config/biorhythmicstudios/warioland4/ (or your XDG overrides). Back up these locations separately; registration does not migrate or certify their compatibility.

Limitations and evidence

  • The packages contain recompiled game program code. Upstream's MIT notice covers its identified sources, and upstream documents inherited code with no recorded license. The launcher reads game data from your own original ROM.
  • The Windows v0.3.2-beta runtime could not start on the Windows 11 build 26300 host tested by Portcove. This release could not reserve the memory range it needs for the game. See upstream for newer beta releases.
  • The Windows launcher saves the selected ROM path in your user registry. Windows v0.3.2-beta can read earlier settings, but beta 1 and beta 2 cannot read the newer settings it saves. Back up settings before downgrading.
