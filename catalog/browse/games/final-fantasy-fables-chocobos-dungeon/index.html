Setup

  1. Prepare your disc image

    Copy a single image of your own NTSC-U Chocobo's Dungeon disc (R7FEGD, .iso or .ciso) beside the program (chocobo.exe on Windows), and keep your original separately. On first start the game extracts it into its extracted folder, which takes up to a minute; leave its console window open while it runs. After that the copied image is no longer needed. You can instead put the sys and files folders of an already extracted disc into extracted.

  2. Build the windowed Linux player from your original

    Follow the tagged upstream build instructions. Obtain sys/main.dol from your own matching extracted disc and run the documented Python recompilation into a clean gen directory. Build the windowed USE_SDL=ON target with CMake, Ninja, a C++17 compiler, SDL2 and OpenGL development libraries.

  3. Keep each profile with its actual root

    Use the upstream player with the matching extracted sys and files. With the standard layout preserve extracted, nand and chocobo.ini beside the creating runtime. The Windows player also accepts an explicit extracted-folder path, where save placement can follow that external root. Preserve the actual data locations before switching layouts.

Limitations and evidence

  • The package includes recompiled game code and a bundled font that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • Keep the upstream folder outside the Portcove library. Close the game before backing up or replacing the creating runtime and its data.
  • The Linux instructions cover the windowed source route. The upstream headless EGL test build is a separate target.
