Setup

  1. Supply your original game files

    If your permitted existing copy has not already prepared its original chips, supply your own dirtdash.zip (World DT2 Ver.A); also keep dirtdasha.zip beside it when using a split MAME set. The Japanese DT1 program is a different revision. On Windows, keep the ZIP files packed in roms beside DirtDash.exe; the game unpacks its chips on first Play. Completed copies can keep their extracted chips without importing the ZIPs again. This does not establish permission for the bundled BIOS or translated program.

  2. Use the Windows player

    Select DirtDash.exe inside your existing windows-release folder, with that folder as its working directory. Keep mesa beside the player.

  3. Use the upstream Linux AppImage

    For an existing Linux copy you are permitted to use, select the upstream DirtDash-x86_64.AppImage rather than its internal binary. If needed, mark it executable; upstream supports --appimage-extract-and-run without FUSE. If original chips are not already prepared, placing your ROM ZIPs beside the AppImage lets its launcher copy them into its selected profile. Keep the existing selected profile’s roms folder when using legacy namco22 or portable data. The fresh default is $XDG_DATA_HOME/namco-2x-systems/dirtdash/roms (normally ~/.local/share/namco-2x-systems/dirtdash/roms).

Setup notes
Preserve the complete Windows runtime and arcade data
Preserve the whole copy, including roms, extracted, controls, arcade records, log, screenshots and recordings, before any permitted upstream update. Portcove registers the copy without owning or replacing its files.

Limitations and evidence

  • Permission for the bundled original C71 BIOS and Namco-derived program is still unresolved. The project’s MIT grant covers its own work and excludes the game code. Review that condition before obtaining or building a copy.
  • External files stay owned by you or upstream. Preserve the whole Windows copy or Linux dirtdash profile, including any existing namco22 or portable data folder. Portcove does not manage its updates, backup, rollback or removal. Replays may need their creating runtime.
