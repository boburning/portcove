This early Astral Chain port reaches the File 01 motorcycle chase. Start with an Apple silicon Mac to import your version 1.0.0 game. The Windows build needs that import. Linux support is experimental, and the project has not confirmed saving or loading.

Setup

  1. Check your original game files

    Supply your own version 1.0.0 base NSP without updates and the matching keys or title keys where required. The optional firmware fonts provide icons and characters missing from the fallback font.

  2. Follow the project’s setup

    Use the macOS 13 or later Apple silicon setup kit to prepare the game locally. Keep the imported files and control receipt for a Windows x64 build with AVX2 and Vulkan 1.3. Verify source availability upstream because the reviewed release omitted the mentioned Windows source ZIP.

Setup notes
Version and platform notes
The Windows tests were scripted. An 8 GiB limit can stop longer sessions after around ten minutes. Linux x64 headless tests had crash and rendering issues. Linux desktop, sound and controllers are untested, and iOS work is paused.
