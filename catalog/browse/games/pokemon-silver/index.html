Setup

  1. Get the official player

    Obtain the official upstream release. On Windows x64 extract the entire Windows ZIP. On Linux x86-64 make the official AppImage executable. On either Mac architecture extract and keep the complete gen1recomp.app bundle.

  2. Import your original

    Use your own canonical US English 2 MiB Pokémon Silver Game Boy Color ROM, SHA-1 49b163f7e57702bc939d642a18f591de55d92dae. Import it with the upstream player and verify it has accepted this edition. The upstream player validates the ROM. Import may start the game directly.

  3. Add the game and play

    On Windows select gen1recomp.exe and its containing folder. On Linux select the AppImage and its containing folder. On Mac select Contents/MacOS/love and the Contents/MacOS folder. Review the one literal argument --game=silver and save the registration. Start the selected player with Play. Gen II gameplay is in development upstream. On Linux without FUSE, add --appimage-extract-and-run before --game=silver as its own argument.

  4. Keep your game data

    The upstream player owns import, runtime replacement and the shared profile. Keep your original separate and retain imports, saves, settings, mods and the actual shared profile locations. Removal clears the Portcove registration only. Launch and update Flatpak and mobile copies through upstream.

Limitations and evidence

  • Keep the original outside the player’s working data. Gen1Recomp owns the imported data and profile.
