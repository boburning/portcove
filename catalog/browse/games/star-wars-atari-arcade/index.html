Setup

  1. Prepare your own Star Wars arcade ROM set

    Use your own starwars.zip from Atari’s 1983 arcade game, matching the MAME starwars revision 2 set, and keep a separate copy. Put it in your home folder as starwars.zip (%USERPROFILE% on Windows); each Windows, Linux and Mac build finds it there. The game checks the 13 ROM and PROM parts by content. The tagged README lists their sizes, CRCs and accepted original-revision alternatives.

  2. Start the Windows or Mac player

    Choose the release tagged V1.1.0b. On Windows, use starwars.exe; it also finds the ZIP beside it. On Intel Mac or Apple Silicon, extract the universal Star Wars.app and open it.

  3. Keep your high scores and settings

    Back up nvram.bin and settings.json from the starwars folder under your user configuration directory. This is normally %APPDATA% on Windows, ~/.config or XDG_CONFIG_HOME on Linux and ~/Library/Application Support on Mac.

Limitations and evidence

  • The Linux x64 binary requires glibc 2.38 or later, X11 and ALSA libraries.
  • The publisher does not provide a license for its project code.
