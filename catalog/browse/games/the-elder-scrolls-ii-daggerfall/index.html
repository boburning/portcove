Setup

  1. Start the game

    On first Play, use Daggerfall Unity’s setup wizard to select your compatible original Daggerfall game folder. It validates the game data. The package is a native Unity player and needs no separate game compilation. Keep external originals where they are.

  2. Use the security-updated Intel Mac app

    Download the Mac ZIP from the Daggerfall Unity v1.1.1-cve-2025 release. Unpack DaggerfallUnity.app into a permanent folder separate from your DOS Daggerfall game. The current app executable is Intel x64. In the setup wizard choose the compatible game folder containing ARENA2.

Setup notes
Keep the Mac profile and originals
Back up the actual Daggerfall Unity profile, saves, settings, mod files and the original game folder before replacing the upstream app. Retain the app version that created your saves.

Limitations and evidence

  • Use a short library path on Linux. If class names appear as placeholders, keep your existing saves, settings and originals before setting up a copy in a shorter library.
