Samurai Shodown (Neo Geo, original) / Samurai-Shodown-Recomp (omegakatana92)

Native recompilation of Samurai Shodown (Neo Geo MVS/AES) built with NeoGeoRecomp. The 68000 program runs as generated C, not an emulator wrapper. Includes Windows x64 and Steam Deck AppImage builds, real MVS BIOS boot, SDL2 video/audio/gamepad support, 100% measured native coverage, and verification with 0 CPU mismatches. ROMs/BIOS not included.
