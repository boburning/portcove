Setup

  1. Keep the complete permitted Friend Edition package

    Use a complete Moon Child FE copy you are independently permitted to use. The reviewed 1.1.1 WindowsX64 ZIP contains AMD64 Moon Child FE.exe and its data tree. Keep them together in a writable extracted directory; do not select a browser build, macOS bundle or internal asset. This Friend Edition is based on the later iOS game with restored Windows95 features; the README does not require a player-supplied retail disc or original executable for this package. This guide does not obtain or execute upstream software.

  2. Respect separate code and asset terms

    The pinned project LICENSE grants MIT terms for code and CC BY-NC4.0 terms for non-code assets, naming Metin Seven for graphics and Ramon Braumuller for music/sound. Retain those attributions, license terms and any component notices with the complete copy. Assets are restricted to noncommercial use; the code grant does not remove that restriction or grant trademark rights. The inspected ZIP did not include a standalone LICENSE file, so retain the authoritative upstream notice separately rather than assuming the absence removes its terms.

  3. Select the normal native game

    Select Moon Child FE.exe, set its complete extracted package directory as working directory, and leave arguments empty. Review the exact selected intent, then request Play separately. The selected Windows entry runs the game host in the same process; no external launcher, compiler, original-game argument or helper is needed by this route. Static source/header inspection establishes those coordinates, not observed Windows play or dependency resolution.

  4. Preserve the actual progress and settings root

    Keep the entire active MoonchildFE per-user preferences folder (normally %APPDATA%/MoonchildFE on Windows), including high scores, options and progress, plus the complete package/data directory. An already present .portable marker beside the executable redirects writable files to that package folder; preserve that existing root too. Do not add/remove the marker to move saves: this guide performs no migration. Keep independent recovery copies before updates and do not infer compatibility across editions or versions.

  5. Maintain the external installation upstream

    Quit the actual game normally before replacing its package; source shutdown requests progress saving, while forced termination is not a save-flush guarantee. Complete upstream replacement outside an attached session, preserve the whole effective data root and review/relink changed executable bytes. Upstream features and automatic-progress claims remain upstream claims; no Portcove playthrough, save/reload, installed-app or Supported acceptance is asserted. Removing registration preserves all external files. Managed install/update/rollback/backup/removal are unavailable.
