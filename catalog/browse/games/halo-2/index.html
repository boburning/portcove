Setup

  1. Check the required game files

    Use your own original retail Xbox disc as Redump ISO, XISO or extracted default.xbe. The launcher checks one supported retail revision. This guide does not include its exact accepted fingerprint; check the project’s release manifest before setup.

  2. Follow upstream setup

    Run OpenHalo2.exe to import your own disc and generate and compile halo2_recomp.exe locally. LLVM and the code-generation tool are bundled. Supply Microsoft CRT/SDK libraries from an existing Visual Studio installation or the documented licensed xwin download. OpenGL3.3 is required.
