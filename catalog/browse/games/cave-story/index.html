Setup

  1. Prepare a separate Cave Story folder

    Keep your current game and store installation. For the original freeware edition, put the official Windows or Linux player beside a copy of your Doukutsu.exe and data folder. First launch reads Doukutsu.exe to extract the additional original resources. For supported Cave Story+ editions, use your own data folder as described by upstream. Use Steam legacy-branch data in a separate copy. The 2026 Steam release uses incompatible data and saves. If an Epic copy contains the stray opengl32.dll described upstream, apply its fix only to your separate prepared copy.

  2. Register the prepared Windows player

    Select the x86_64 doukutsu-rs executable and its containing game folder as the working directory. Keep the matching data folder in place. Confirm the launch details and choose Play separately.

  3. Start doukutsu-rs on Linux

    On x86-64, make the official Linux ELF executable and start it in your prepared game folder. The v1.0.0 ELF needs glibc 2.39 or newer and the ALSA library libasound.so.2. Flathub provides io.github.doukutsu_rs.doukutsu-rs for x86-64 and ARM64. Place your permitted prepared data folder under ~/.var/app/io.github.doukutsu_rs.doukutsu-rs/data/doukutsu-rs for the Flatpak. Open and update that copy through Flatpak.

  4. Use the Intel or Apple Silicon Mac app

    Choose the official archive for your Mac’s processor and keep the full doukutsu-rs.app. Follow the upstream Mac guide to put your prepared data folder in Contents/Resources before opening the app. Back up the old app, data and profile before replacing it.

  5. Set up the upstream Android app

    Install the official universal Android APK. Use Android Files to open the doukutsu-rs game-data location, then copy your permitted prepared Cave Story data folder there. Keep a separate copy of your game data and the app’s saved progress. Install newer releases through the same upstream channel.

Setup notes
Keep the chosen edition and user data
You own updates to this external copy. Prepare another version separately and keep your current player, original data and saves until it works. The engine normally uses the operating system’s doukutsu-rs user-data folder, or a sibling user folder in portable mode. Its Advanced menu can open the user-data folder; keep a separate backup of it, including settings.json and saves, before changing versions or editions. Portcove does not back up, roll back or delete this external game/data tree.

Limitations and evidence

  • The 2026 Steam remaster is not established by this guide, and remastered saves are incompatible with original-version saves.
