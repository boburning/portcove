Setup

  1. Keep the complete upstream player

    Extract the whole Windows x64 ZIP, keeping NFSMW Recomp.exe and its data folder together. There is no installer. Register NFSMW Recomp.exe with its folder as the working directory, save the launch details, then choose Play separately. Keep the integrated launcher and both included edition players.

  2. Choose your own game on first Play

    In the upstream launcher, select your own Xbox 360 Most Wanted ISO or extracted game folder. The current player recognizes PAL Spain and USA default.xex editions and selects the matching included player. Choose Play inside that launcher; it extracts a selected ISO and builds the shader library from your own disc. Valid remembered choices can be reused. Portcove does not run the player or extraction/compiler helpers during discovery.

Setup notes
Preserve the actual saves and settings
Keep your original ISO or external game folder, the complete working copy, data/game_root, data/nfsmw.toml, data/nfsmw_trucos.txt, data/capturas and the readable data/saves copies (including current and previous saves). Actual live saves normally use Documents/nfsmw and can be separate from those readable copies. Back up the actual live profile and any custom game, update or backup folders too. A different player folder does not isolate the shared profile. After custom path changes, verify which profile the upstream save tools are using before importing or restoring; their folder is not guaranteed to match the running game.
Follow upstream updates with a recoverable copy
Close both the launcher and the game before replacing files. Upstream provides update notices; keep your old copy recoverable and extract the new release separately. Let the new runtime regenerate its shader libraries and renderer caches from your own files. Keep upstream controls and save import/export/restore tools available, with separate backups of your actual profile. You or upstream own runtime updates and backups; Portcove registration provides no managed Update, Backup or Rollback. Removing the registration leaves every external file untouched.
