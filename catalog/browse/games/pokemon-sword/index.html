Pokémon Sword (swsh-recomp)

Build Pokémon Sword for Windows from your own extracted 1.3.2 game. The project reports play with DLC on one RTX 3080 PC. Online play, trades and raids are unavailable, and memory use grows during play.

Setup

  1. Check your original game files

    Extract the updated 1.3.2 ExeFS and RomFS before using the launcher. Add matching owned DLC manually if desired. The launcher has no keys input and does not extract XCI or NSP files.

  2. Follow the project’s setup

    Use the Windows x64 ZIP on Windows 10 or 11 with AVX2, FMA, BMI2 and Vulkan 1.3. The launcher copies and recompiles locally. The project estimates 40 minutes on 20 threads.

Setup notes
Version and platform notes
AMD, Intel and integrated graphics are untested. Title flicker and memory growth remain, and the 60 FPS mode is experimental. The project offers no other desktop route.
