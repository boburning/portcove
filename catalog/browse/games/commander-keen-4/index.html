Setup

  1. Use the bundled Keen 4 shareware

    The official Windows x64 and Linux v1.1 packages already contain Keen 4 v1.4 EGA shareware and its matching support files. Extract the complete package and keep its GAMEMAPS.CK4, EGAGRAPH.CK4 and AUDIO.CK4 beside the player. If you want to use your own matching v1.4 EGA files, keep the bundled player and original source separate and use a separate working copy.

  2. Register the Windows x64 player

    Use the official stable omnispeak-win64-1.1.zip. Register omnispeak.exe and its containing folder. Use separate argument lines for /EPISODE and 4 if selecting the episode explicitly. Use /GAMEPATH for a separate original-data folder and /USERPATH for a separate writable save/config folder, with each option and its value on separate lines. Confirm the launch details and choose Play separately.

  3. Use the official Linux v1.1 launcher

    Extract the complete omnispeak-linux-1.1.tar.gz, including the architecture-specific SDL2 folders. From the extracted folder, run the upstream launcher with ./omnispeak /EPISODE 4. This package supports Linux x86-64 and 32-bit x86. Use a path without spaces if you add an explicit /USERPATH for the save/config directory.

  4. Keep upstream update ownership

    Use upstream packages to update the player and back up your game data and actual save/config folder separately. Removing the Windows registration keeps all external files. For Linux, use the upstream launcher directly.

Setup notes
Keep saves and support files with their chosen profile
Preserve your original-data folder, matching episode support files, complete working player and actual writable profile before changing versions. /USERPATH explicitly selects the save/config directory; otherwise the upstream build can use its default directory or an SDL user-path fallback. Keep separate episode profiles and all custom paths backed up with players closed. Upstream claims DOS-save compatibility; Portcove has not exercised your saves and does not promise automatic conversion, managed backup or rollback.
