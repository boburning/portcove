Setup

  1. Finish setup in the upstream Android app

    Install the APK from this fork, open it once to create its data folder and support files, and select your own supported Majora’s Mask MM.z64 when prompted. The app creates mm.o2r on the device. Its Android route needs no desktop 2Ship extraction or separate native plugin package.

  2. Keep your data when changing versions

    The selected 2S2H data folder is shown and changed under Settings > General, including an SD card location. Preserve that actual folder’s saves, configuration, generated mm.o2r, mods and presets before changing or removing the app. If diagnosing an O2R problem, preserve the existing data before regenerating it from your own ROM. Android 7+/OpenGL ES 3.0 are upstream requirements; Portcove does not qualify every device or back up this external app profile.

Setup

  1. Finish setup in the upstream Android app

    Choose the Android App APK from this fork, not its separate Android randomizer-mod ZIP, and install it on an ARM64 Android device with a working Vulkan driver. Open the app and choose your own supported Majora’s Mask ROM when asked; it contains no game assets. Grant the requested storage access for its /sdcard/Zelda64 profile.

  2. Keep your data when changing versions

    Back up /sdcard/Zelda64, including saves, config and mods, before replacing or removing this beta app. Install mods through its own Mods menu. Native-code mods require Android ARM64 .so libraries; desktop Linux, Windows or macOS plugins cannot substitute for them. This beta APK is debug-signed, so keep data safe before a future signing change. Its profile and updates remain upstream-owned and outside Portcove runtime backup/rollback.
