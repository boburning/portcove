Setup

  1. Prepare the exact USA PlayStation original

    Use your own The Simpsons Wrestling USA SLUS-01227 CUE with every referenced BIN. The selected game.toml identifies data Track 01 by size 506830128 bytes and SHA1 38602a1b9482670dbbd8ab25aa4a8bb520b5bebe, boot SLUS_012.27; this is not a whole-CUE or arbitrary-region fingerprint. Complete disc selection, controls and settings in the official v1.0.0 Windows player’s top-level SimpsonsWrestling.exe first. Keep your original at that remembered location.

  2. Keep the launcher and private game folder together

    Retain the complete official package, including top-level SimpsonsWrestling.exe and game/SimpsonsWrestling_Recompiled.exe, runtime resources, OpenBIOS, generated mods, configuration and notices. The top-level TRG launcher writes the runtime settings and input files, then starts a child and exits; it is a preparation interface rather than the process to register for a supervised game session. A shared PSX framework does not qualify another title or edition.

  3. Attach the actual native game with its disc

    Select game/SimpsonsWrestling_Recompiled.exe, set working directory to that complete game/ directory and use --no-launcher --disc "the exact already selected USA CUE path". Review the exact paths and intent and choose Play when ready. This reproduces the selected top-level launcher’s native target, CWD and literal argument contract while retaining direct supervision of the actual game. Keep the settings/control files it already wrote; finish future launcher configuration or updates upstream before the next reviewed attachment. Do not register the detaching launcher, updater, setup/compiler or a diagnostic mode as Play.

  4. Preserve cards and launcher-written settings

    Keep the whole package, especially game/launcher.txt, game/settings.toml, game/input.ini and binding files, disc/config sidecars, mods, game/saves/card1.mcd and card2.mcd or the actual existing slot paths, plus states/cache, originals and recovery. The selected Windows runtime anchors relative paths to its own executable directory. Preserve explicit memory-card directory/slot overrides and historical copies; do not add --memcard-dir to create a new profile. Launcher-only gameplay choices are read by this title’s plugin too. No card move, merge, import, restore or deletion is performed.

  5. Keep component and acceptance limits

    The exact psxrecomp fork revision retains PolyForm Noncommercial 1.0.0; keep those restrictions distinct from title/launcher, OpenBIOS, fonts and other library notices. Original game artwork, text and audio remain separate content rights, even when the launcher reads them from your own disc. Upstream owns configuration, replacement and recovery; close the actual game, preserve populated data and review/relink changed bytes. Upstream campaign, controller and two-player claims are not observations here. No installed/native, real-save restore, Supported or managed lifecycle acceptance is asserted.

  6. Play on Linux

    Make the Linux x86-64 AppImage executable on a system with glibc 2.38 or newer and OpenGL 3.3. Start the AppImage and choose Browse for the .cue file on the Game page. Keep the matching BIN files beside the CUE. On later starts, the project launcher can reuse that CUE when you press PLAY.

Setup notes
Keep the Linux files and update through the project
The AppImage creates SimpsonsWrestling-data beside it or falls back to XDG_DATA_HOME/SimpsonsWrestlingRecompiled, normally under ~/.local/share. Back up the actual game/saves folder and launcher settings. Use the launcher’s About page to find saves or update the AppImage. Keep the launcher available for changing controls or the disc. Once the disc is configured, you can turn off the launcher. Hold Shift at startup to reopen it.

Limitations and evidence

  • Register the native game inside game/ after upstream configuration, with the exact own CUE. The top-level launcher detaches; preserve all launcher-written settings, per-player cards and noncommercial framework terms.
