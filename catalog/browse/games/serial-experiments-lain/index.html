Setup

  1. Prepare both original Japanese discs upstream

    Use a complete copy and components you are independently permitted to use. The reviewed 0.2.0 native client documents your own Japanese discs SLPS-01603 and SLPS-01604 as Redump .cue/.bin pairs. The data-track SHA1 values are 6426fbdb45f27e089af650cddb8c41929c7890de and 409668af454a0e0a33a71c1d22918d765e718608 respectively; they are not the original executable hash. Upstream import checks those identities but can also retain an unverified/modded dump with a warning. This guide qualifies only the documented source pair, not every accepted file or language modification. Finish import/setup outside Portcove and keep independent originals.

  2. Keep the complete native client package

    The inspected Lain-windows.zip contains Lain/lain.exe as an AMD64 native player with its resources and thirdparty notices. Keep the complete matching Lain directory. This is the native client using a reimplemented PlayStation SDK; an original-PsyQ byte-identical rebuild is a different build result, not the selected Windows executable. Do not select a retail PS1 executable, disc image, compiler, script or another platform’s player. No original, subtitle pack, helper or game is obtained or executed by this attachment.

  3. Select saved-disc direct play

    After both discs have been imported and settings saved upstream, select lain.exe, use its complete extracted Lain directory as working directory and set the single argument --play. Review the exact selected intent, then request Play separately. This skips the setup UI and enters the game within the selected native process using the saved discs/settings. If data is missing, complete setup outside that attached attempt before retrying. Static source/header observations do not establish native gameplay, disc swapping or dependency resolution.

  4. Preserve imported discs, settings and the actual card

    Keep the whole active data folder, normally %APPDATA%/LainNative/lain-native on Windows, including imported discs, settings.ini, memcard1.mcd, packs, mods and other player data. The card is a raw 128 KiB image; that format alone is not save-compatibility acceptance. An already established LAIN_DATA_DIR or LAIN_MEMCARD can select an external data/card path; preserve those too, and the package directory used as a fallback if no per-user path was available. This guide adds no override and performs no card import, migration, backup or deletion.

  5. Keep original, translation and component rights separate

    Preserve the upstream MIT notice, PsyCross and all thirdparty notices, including the separately linked OpenAL LGPL terms. Those grants do not provide original-game, memory-card-icon or third-party fan translation rights. The optional laingame.net subtitles are downloaded separately by upstream and are not bundled; review the exact pack’s permission and scope independently. Lua/native-plugin mods remain upstream-managed executable content, not newly trusted Portcove packages. Keep only components you are independently permitted to use.

  6. Maintain the external client explicitly

    Quit the actual game normally before upstream replacement, disc reimport, card operations or mod changes. Preserve complete independent recovery copies and review/relink changed executable bytes. Source/frontend behavior and upstream whole-game/ending/timing reports remain upstream claims; no Portcove gameplay, swap, save/reload, installed-app or Supported acceptance is asserted. Forced termination is not a save-flush guarantee. Removing registration preserves all external files; managed install/update/rollback/backup/removal are not offered.

Limitations and evidence

  • Keep both original disc pairs and the actual imported-disc/card data root; the native client, original-PsyQ rebuild and fan subtitle packs have separate boundaries.
