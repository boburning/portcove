Setup

  1. Check the required game files

    Use your own USA Sonic Adventure 2 Dreamcast disc in CUE or GDI form, including IP.BIN, 1ST_READ.BIN and PRS code modules. Keep your original files separately.

  2. Follow upstream setup

    Follow upstream instructions to extract your disc with gdrom_extract and prs_modules, then generate code with dcrecompemit and build the native sa2 player with CMake. Keep your original disc available. Portcove does not install or prepare this source project automatically.

Limitations and evidence

  • Upstream reports a memory-card warning, title/file-selection screens and sound. The first stage and GPU renderer are planned rather than completed. The framework and game belong to the same project; Portcove has not confirmed runtime behavior or gameplay.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
