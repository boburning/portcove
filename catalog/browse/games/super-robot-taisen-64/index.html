Setup

  1. Prepare the exact Japanese Rev0 original

    Use a complete player/components you are independently permitted to use, with your own Super Robot Taisen 64 Japan Rev0 N64 ROM. The selected variant pins normalized ROM SHA256 ee5f4a21d8e5f7827d21199e27800edf250df9a8e4d10befb1a6992df597b13e and XXH3-64 bb8703e9d7c77f4f, game ID srw64-jp-rev0. Upstream normalizes accepted N64 byte orders; these are not identical raw-file hashes for every representation. Finish upstream original selection and derived-data preparation first. No ROM, converter, helper, compiler, art/voice pack or game is obtained or executed here.

  2. Keep the actual player release

    The inspected official 0.5.2 Windows x64 ZIP contains AMD64 Marchwind64-windows-x64/Marchwind64.exe and matching runtime resources/notices. The newer mod-battle-voices-originals-ai-1.0.0 release contains a voice mod, not this player. Keep the full player package. HD art and optional voice mods are separate downloads with their own terms; the original pixel-art route does not require them. Windows and other handheld/device support remains experimental upstream.

  3. Add your configured player

    Select Marchwind64.exe, use the complete Marchwind64-windows-x64 directory as working directory and leave arguments empty after upstream setup. Review the exact intent and request Play separately. The native desktop entry uses the remembered/validated original and continues into the linked runtime/UI. Complete missing-ROM, preparation or conflicting-data prompts upstream before retrying; do not add debug-server, sample campaign, probe, save-export or mod-preparation arguments to normal Play.

  4. Preserve system, local and synchronized copies

    Without an existing portable choice, Windows uses %LOCALAPPDATA%/SRW64Recomp. An already existing user-data/ beside the program opts into local precedence; missing settings and complete absent save/campaign groups can be imported from the system root, while existing local groups are not silently merged. Normal exit can synchronize present local groups back to the system root, with confirmation and sync-backups before replacing different data. Keep both roots, sync-backups, presentation.json, rules.json, input.json, saves/, campaigns/, retained/derived ROM data and actual external paths. An existing --user-dir selects one root without automatic import/sync. This guide creates no marker and performs no synchronization, conversion, backup, restore or deletion.

  5. Check component licences and maintenance limits

    Keep project GPLv3, RT64/N64 runtime, RmlUi, font, shader and other component notices. The renderer dependency declares the exact official RecompFrontend b1a1477c6556aeb7ed45defbfb5924f721efebc1 base; its later official GPL notice/grant does not license original game, independent modifications, fonts or optional art/voices by itself. Quit the actual game normally and allow upstream confirmation/sync to finish before replacement, keep recovery and review/relink changed bytes. No native/installed, campaign, physical Windows/handheld, real-save, sync/restore or Supported observation is asserted. Registration removal preserves external files; managed lifecycle operations remain unavailable.
