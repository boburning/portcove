Setup

  1. Complete the original Burnout preparation upstream

    Use only an already completed native copy and components you are permitted to use. This targets the original Burnout for Xbox, not Burnout 2, Burnout 3 or a PS2 edition. Complete the supported Burnout.exe disc-selection and local-build flow separately with your own USA Xbox ISO. Its pinned source manifest identifies title 0x41430006, a 1,986,560-byte default.xbe with SHA-256 42bd7d38feb39c17783197c4433435bfc06d8f5872d6f4b45048d9daac82013b. That published identity does not make registration a disc authenticator or authorize proprietary output redistribution.

  2. Select the completed game player

    Select Burnout.exe, its containing package directory as working directory and no arguments. Keep its complete matching tools folder and the completed external build together. The supported launcher loads work/build/burnout_game.dll in its own process and runs the game on a thread there; normal Play does not detach to a private game executable. Do not select an internal tool, Python build driver or generated DLL as the entry.

  3. Keep preparation and rebuild restarts outside the attached session

    Finish the upstream build before attachment. The upstream Rebuild flow deliberately starts a fresh launcher process and exits the old one; Portcove does not claim to supervise that successor. Perform rebuild or update preparation separately, close all resulting players and companions, then review the completed copy and start a new Play session through the selected entry.

  4. Retain one replacement owner and all creating data

    Review and consent to the exact selected executable, working directory and empty argument list, then choose Play separately. You and upstream own preparation, runtime replacement and recovery. Preserve the whole program, tools, original ISO and %LOCALAPPDATA%/BurnoutRecomp, including settings.ini, work/, logs/ and saves/. Keep every chosen save folder and any effective BURNOUT_DATA or BURNOUT_TOOLS location; choosing another saved-games folder does not move old saves. Retain prior creating runtimes, backups, caches, mods and unknown custom files before replacement.
