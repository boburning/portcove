Setup

  1. Open the project launcher

    Extract the archive for your system and open FZeroXRecompiled.exe on Windows or FZeroXRecompiled on Linux from the extracted folder. Keep the assets beside the program. Windows needs the Visual C++ 2015–2022 x64 Redistributable. Linux needs glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType.

  2. Load your original game

    Choose Load ROM and select your own first-revision USA F-Zero X cartridge dump, a 16 MiB big-endian .z64. Then choose Start Game. Other regions and the 64DD expansion are outside this release’s ROM support.

Setup notes
Keep your racing records and settings
The project uses %LOCALAPPDATA%/FZeroXRecompiled on Windows and ~/.config/FZeroXRecompiled on Linux by default. Keep the actual profile if you use the project’s portable.txt marker or a Linux APP_FOLDER_PATH override. You maintain the downloaded program and should back up the profile separately.

Limitations and evidence

  • The project’s game saves and settings stay outside Portcove’s backups.
