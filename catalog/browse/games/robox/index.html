Setup

  1. Check the required game files

    Before configuring source build, supply own unpacked Robox USA.dol plus Assets/fonts/title.brfna and other original Assets. Original data stays user-owned. Runtime importer can accept owned WAD plus Wii common key or manually selected DOL+Assets, but that importer cannot bootstrap its own clean source build without pre-unpacked font assets.

  2. Follow upstream setup

    Obtain WiiRecomp source and supply your own unpacked DOL and original Assets before configuring CMake. Build Release on Windows with MSYS2 mingw64, CMake and Ninja, or build.bat. ROBOX_DOL and ROBOX_RECOMPILER can identify your input and compiler. A WAD alone does not establish a working clean-checkout build, and no precompiled package has been confirmed.
