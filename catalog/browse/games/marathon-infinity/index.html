Setup

  1. Play the complete official game package

    The complete official Windows package includes this game’s scenario data and native player; no separately supplied commercial original, ROM or setup helper is required. Keep all package companions. This route pins release-20260930; automatic updates are not offered. Explicit Play can read and update an existing shared upstream profile. Core does not adopt that profile. Do not copy legacy Prefs or other old-runtime files into this fresh package. This route starts this bundled game; use a separate upstream copy for custom scenarios or extra data-search paths. Upstream owns shared profiles in Documents/AlephOne (saves, quick saves, recordings, screenshots and logs) and LocalAppData/AlephOne (preferences). Existing legacy Prefs in a separately owned upstream copy remain external. Core manages this separate runtime only; its backups do not include those external profiles. Preserve the creating runtime and actual profile before upstream replacement or older-runtime use; no save/state conversion, populated profile adoption or gameplay compatibility is inferred.

Setup notes
Install the matching Marathon scenario on Linux
Use the official MarathonInfinity x86-64 Flatpak bundle and install it with Flatpak. Start Classic Marathon Infinity from the desktop launcher or run flatpak run org.bungie.source.MarathonInfinity. Its packaged scenario data is included. The current publisher bundle uses the end-of-life Freedesktop 23.08 runtime. It has home-directory and network access. Keep network play off with this build. Preserve your actual ~/.alephone profile, which the three games can share, and any overrides before replacement.
Open the matching Marathon application on Mac
Use the official MarathonInfinity Mac disk image. Copy Classic Marathon Infinity.app to Applications and open the complete app. The package includes the scenario and supports Intel and Apple Silicon. Preserve the actual Aleph One or title-specific data in ~/Library/Application Support, its preferences in ~/Library/Preferences and custom scenarios before replacing it.

Limitations and evidence

  • Core backups exclude upstream-owned Aleph One profiles. This pinned runtime does not offer automatic updates.
  • Use a short Windows output folder. Core checks packaged-file path lengths before publication and Play; this runtime cannot use every long installation path.
