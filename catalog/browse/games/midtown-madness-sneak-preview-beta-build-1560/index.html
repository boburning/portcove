Setup

    Use a permitted complete Open1560 Windows x86 copy with your own Midtown Madness Sneak Preview Beta/build 1560 data. The selected upstream setup names audio.ar, core.ar and ui.ar as the minimum fresh inputs; keep the complete original preview and existing player data. Retail Midtown Madness is a different target. No preview download, original-file digest acceptance or general retail compatibility is supplied by this registration.

  2. Select the player and retain its arguments

    Select native Open1560.exe, keeping all accompanying runtime files and the prepared game directory as working directory. Keep commandline.txt and established literal options. This is a partial native rewrite with retained assembly; a source repository or installer is not a prepared player. Upstream says its XP patch and dgVoodoo are unnecessary.

  3. Preserve the creating directory before upstream cleanup

    Retain the entire creating game directory, original archives, settings, player/progress files, replays, custom and unknown files, and any actual external profile used by that copy. Open1560.log is written relative to the working directory. Final upstream builds default to -cleandir and delete last.rpl, crash.rpl, portals.s and root *.csv at exit; back up existing files before a run and use the supported -nocleandir option if retaining those diagnostics is intended. Portcove does not prevent the player’s writes or cleanup. Exact legacy save-file mapping and cross-version compatibility remain unverified.

  4. Check the prepared copy before registration

    Finish setup with the project’s tools, then start and quit the copy you intend to add. Keep its game executable, working folder and supported launch arguments. Review those details in Portcove and agree to launch them, then choose Play separately. Adding a copy does not confirm its original game files, gameplay or save compatibility.

  5. Keep updates and removal under the existing owner

    Close every running copy of the game before changing files. Keep the working game version and every data and profile folder recoverable. Update it with the project’s tools, then review and select the changed executable in Portcove before choosing Play. You manage setup, updates, file changes, data migration and recovery. Portcove monitors the process you selected; it does not prevent other copies from running or restrict the game’s file access. Removing the registration leaves external files in place. This route does not offer Portcove downloads, setup, updates, backups, rollback, data migration or external-file deletion.
