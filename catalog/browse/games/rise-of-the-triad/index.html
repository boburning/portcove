Setup

  1. Prepare your original game

    Before Play, copy your matching Rise of the Triad data beside barrett.exe on Windows or barrett on Linux and Apple silicon Macs. Use DARKWAR.RTC, DARKWAR.RTL and DARKWAR.WAD for the registered edition, or the matching HUNTBGIN.RTC, HUNTBGIN.RTL and HUNTBGIN.WAD for a supported shareware edition. Include DEMO1_3.DMO through DEMO4_3.DMO and REMOTE1.RTS. Keep the uppercase filenames and your separate original copy.

  2. Set up the upstream Linux player

    On Linux, use glibc 2.38 or later, install SDL2 and SDL2_mixer through your distribution, and supply a General MIDI soundfont. Put it at userdata/barrett.sf2 or use a system soundfont path listed by Barrett. If Play stops during userdata setup, keep your original files and existing userdata while checking the reported error.

  3. Keep the Windows or Mac dependencies

    Keep the packaged SDL2 and SDL2_mixer libraries alongside the Windows player. On Apple silicon, use macOS 15 or later and install both libraries with Homebrew in /opt/homebrew. Choose Preview for these upstream beta packages.

Limitations and evidence

  • The Linux v1.3-beta player failed to start with the public Apogee v1.3 shareware files. The player reported a missing WAD resource. Keep those original files intact and use a release with verified support for that edition.
