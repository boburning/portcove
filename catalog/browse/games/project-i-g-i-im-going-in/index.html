Setup

  1. Use your own Project I.G.I. files

    Open the upstream OpenIGI Launcher and choose your retail installation in Settings if it does not find it. The launcher installs and updates OpenIGI. Select Beta in its settings to use v0.6.9-beta.4.

  2. Choose the right standalone player

    Use the self-contained player on Windows 10 or 11 x86-64, Linux x86-64 with Vulkan or macOS 13 or later on Apple silicon. The separate .NET downloads require .NET 10. On Linux, make the exact openigi-game-0.6.9-beta.4-linux-x64 file executable. On Mac, extract its app and follow the project release's first-run instructions.

  3. Launch a standalone player again

    Run the player with -game followed by the path to your own retail Project I.G.I. folder, or set IGI_GAME_PATH before launching. Keep the same original install location. The project's launcher is a separate way to reopen Settings and play.

Setup notes
Keep your OpenIGI data
Keep OpenIGI in your per-user application-data folder, including %APPDATA%/OpenIGI on Windows, the XDG configuration directory on Linux or ~/Library/Application Support on Mac. Also keep any settings.cfg beside the executable. The upstream launcher updates its own installations. When using standalone players, replace the runtime yourself and keep your profile.

Limitations and evidence

  • This guide applies to Project I.G.I. The separate I.G.I. 2 project has its own setup and release status.
