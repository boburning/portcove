Setup

  1. Check the required game files

    Use your own original Xbox Far Cry Instincts ISO or extracted disc files, title ID 55530008, version 1.

  2. Follow upstream setup

    Extract the source release package and drag your own disc onto BuildGame.cmd as upstream directs. It compiles the game locally from C; it does not download a complete game. Windows x64 with Direct3D 12 is required.

Limitations and evidence

  • Upstream describes story and map-editor support in v0.2.1. A complete playthrough is unconfirmed. Rare single-player crashes and Windows DPI blur remain; Xbox Live and System Link are unavailable.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
