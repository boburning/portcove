Setup

  1. Choose your classic game data

    Use the original PC retail files or the classic installation from GOG or Steam. When the engine asks, choose the folder containing LBA2.HQR and keep the other game files and media directories together. In a store installation, look for the classic data under Common or CommonClassic. For an owned disc image, follow the publisher’s game-data guide.

  2. Open the package for your desktop

    On Windows x64, extract the ZIP and run lba2cc.exe. On Linux x86-64 or ARM64, choose the matching AppImage, make it executable and open it with FUSE available. The matching TAR.GZ avoids FUSE and needs glibc 2.38 or later. On Intel or Apple Silicon Mac with macOS 11 or later, open the universal DMG, copy the app to Applications and follow its first-run instructions.

Setup notes
Set up the Android release
Use the publisher’s arm64-v8a or armeabi-v7a APK on Android 7 or later and follow its Android guide to place your original data. The shared lba2cc folder requires Android’s All Files Access on Android 11 or later. Check the active save folder in the startup log. With shared storage, back up lba2cc/user/LBA2. App-owned fallback folders can be erased on uninstall, so verify a separate copy of your saves before uninstalling.
Keep your saves when changing packages
With the game closed, copy Twinsen/LBA2 under %APPDATA% on Windows, $XDG_DATA_HOME or ~/.local/share on Linux, or ~/Library/Application Support on Mac. If you chose --user-dir or LBA2_USER_DIR, copy that directory with its profiles. If you added portable.txt, copy User/LBA2 beside the engine. Keep originals and profiles separate from replacement package files.

Limitations and evidence

  • These stable packages need the classic retail data. The 1997 demo has different game files and needs its own engine build.
