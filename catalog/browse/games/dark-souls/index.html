Dark Souls: Remastered — Switch edition (lordran-native)

An experimental Apple port of the Switch edition of Dark Souls: Remastered. Build locally on an Apple silicon Mac with your own base game and 1.0.3 update. The iOS download is an unsigned build component. Windows tools only package Apple output.

Setup

  1. Check your original game files

    Use both the base NSP and the 1.0.3 update NSP, v196608, for title 01004AB00A260000, plus prod.keys. Both packages are needed to prepare shaders even for the base version.

  2. Follow the project’s setup

    Use Xcode on an Apple silicon Mac with the matching project source and shell. The iOS build targets version 26 or later. The ZIP still needs a build and signing before installation.
