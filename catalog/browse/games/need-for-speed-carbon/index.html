Setup

  1. Check the required game files

    Use your own Need for Speed Carbon Xbox 360 disc, with its executable extracted to game/files/default.xex. The title ID is 454107EC. The project provides an installer manifest with full-file SHA-256 values; this guide does not include the exact source revision or digest.

  2. Follow upstream setup

    On Apple Silicon, follow setup_tools.sh and survey.sh, build the native ReCarbon target with CMake, then use --install with your own image. App packaging is documented, but there is no public release. The bundled libraries require macOS27. This guide does not establish a downloadable player package.
