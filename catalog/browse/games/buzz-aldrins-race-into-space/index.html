Portcove downloads are on hold because the Windows installer and Linux archive include music from the project’s nonfree soundtrack repository. The setup guide covers copies you have permission to use.

A release may contain research reports rather than a playable package.

Setup

  1. Use the Windows or Linux upstream setup

    For a permitted v2.0.0 Windows copy, use the publisher’s Win32 installer and open Race Into Space after setup. On Linux x64, extract the complete portable archive and run run.sh from its folder. Keep the share/raceintospace data beside the player.

  2. Open the Apple Silicon Mac package

    On Apple Silicon with macOS 15 or newer, open the v2.0.0 Darwin disk image, copy raceintospace.app to Applications and open it. The publisher’s Mac package omits music.

Setup notes
Keep your campaign and configuration
Keep the .raceintospace folder in your home directory when changing versions. If you set BARIS_SAVE, preserve that folder instead. The same location stores the game’s config file.
