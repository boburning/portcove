Setup

  1. Extract the matching Windows player

    Choose the rednukem_win64 archive. Extract the complete archive to a folder for this game and keep rednukem.exe with its packaged files.

  2. Add your game files to this copy

    Use REDNECK.GRP and REDNECK.RTS from your own Rides Again installation. Keep the files separate from the first Redneck Rampage game, which uses the same names. Keep the original copy separately.

  3. Run setup and play again

    Use the extracted folder as the working directory and start rednukem.exe with -usecwd. Complete the startup window if it opens. After saving a working configuration, try -nosetup for direct Play. Use -setup to reopen the startup settings.

Setup notes
Keep the game folder and its saves
With -usecwd, keep the game folder, settings and saved data together. Back up this folder before replacing a working copy with a newer upstream release. You manage replacement and backups for this upstream copy.
