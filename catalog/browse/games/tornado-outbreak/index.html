Setup

  1. Check the required game files

    Use your own PS3 USA BLUS30371 disc; update/digest unknown.

  2. Follow upstream setup

    On Windows, follow the source build with your own BLUS30371 disc and decrypted EBOOT.elf. Run tools/relift.sh, then Python build.py, and start build/tornado with the documented PS3_VFS_ROOT, RSX_LIVE_DRAW and PS3_MAIN_STACK_LV2 settings. Keep required keys and decrypted inputs local.
