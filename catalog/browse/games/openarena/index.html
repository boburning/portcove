Setup

  1. Use the complete Windows release

    Extract openarena-0.8.8.zip into a dedicated folder and keep baseoa and missionpack beside openarena.exe. The full release includes the base game and both patches. The Windows player is 32-bit and needs Windows support for 32-bit applications. Start openarena.exe from that folder.

  2. Choose the upstream Linux player

    On Debian or Ubuntu, install openarena with your package manager and let it install the engine and map packages. For the older publisher ZIP, extract openarena-0.8.8.zip and run ./openarena.x86_64 from the openarena-0.8.8 folder with baseoa and missionpack beside it. That binary needs SDL 1.2, Vorbis and a working OpenGL driver.

  3. Back up your OpenArena profile

    Close the game and copy %APPDATA%/OpenArena on Windows or ~/.openarena on Linux, including baseoa/q3config.cfg, custom maps, demos and mods. Keep any custom content you added to the installation separately before replacing it.

Setup notes
Use the separate Android port
The separately maintained PlayFDroid OpenArena Android release has touchscreen controls and downloads the official game data into app-specific storage on first launch. Follow its release and installation instructions. Desktop profile folders do not apply to that app.
Check Mac compatibility
The official 0.8.8 ZIP contains legacy 32-bit Intel and PowerPC Mac binaries. Use those only with a matching legacy Mac environment. Current Intel and Apple Silicon Macs need a separately built player.

Limitations and evidence

  • Use OpenArena’s own data and add-ons. If you join a server, use the game version and assets the server expects.
