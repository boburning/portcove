Setup

  1. Import your own Pub Games container

    Use your own purchased Fable II Pub Games Xbox 360 container. Extract the complete official Windows package to a writable folder outside the Portcove library, and keep the launcher, game executable, DLLs and extraction tool together. Open Fable2PubGamesLauncher.exe, choose your container, and use Install Game Files to prepare it with the upstream tool before Play Pub Games.

  2. Preserve the upstream data

    The launcher creates data, saves, logs and cache in its folder. Keep the original container and preserve the creating runtime and actual save folder before replacement.

  3. Add the game and manage your files

    In Portcove, select Fable2PubGamesLauncher.exe with its containing folder as the working folder and no arguments. Play opens the upstream launcher; choose Play Pub Games there. Portcove registers and launches the copy you keep. It does not download, prepare, update or replace this copy. You and upstream own the package, your container, game files, saves and settings. Removing the registration leaves all of them in place. Backups, rollback and data migration are not offered for this copy.

  4. Review optional Fable II save sync separately

    The upstream Advanced Options can link the Fable II Recompiled saves folder and sync when Pub Games closes. This can update Fable2PubInfo.xml bridge records in the other game’s profile. Keep your own backups as well as the upstream pubgames-sync-backups, and close both games before any maintenance. Leave sync off for independent profiles.

Limitations and evidence

  • The package includes recompiled game code that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • Keep the upstream folder outside the Portcove library. Close the game and its helpers before backing up or replacing the creating runtime and its data.
  • The upstream launcher owns the import and game handoff. Selecting the launcher or its script does not establish managed installation or save synchronization in Portcove.
