Setup

  1. Open the project launcher

    Extract the archive for your system and open MarioGolfRecompiled.exe on Windows or MarioGolfRecompiled on Linux from the extracted folder. Keep the assets beside the program. Windows needs the Visual C++ 2015–2022 x64 Redistributable. Linux needs glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType.

  2. Load your original game

    Choose Load ROM and select your own USA Mario Golf cartridge dump in big-endian .z64 format. The launcher accepts the 32 MiB image or the common 24 MiB dump and pads the latter. Choose Start Game.

Setup notes
Keep your tournaments and settings
The project uses %LOCALAPPDATA%/MarioGolfRecompiled on Windows and ~/.config/MarioGolfRecompiled on Linux by default. Keep the actual profile if you use the project’s portable.txt marker or a Linux APP_FOLDER_PATH override. The project reports that Save and Quit writes tournament progress. Resuming it after restart remains unverified. You maintain the downloaded program and should back up the profile separately.

Limitations and evidence

  • The project’s game saves and settings stay outside Portcove’s backups.
