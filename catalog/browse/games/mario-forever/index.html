Setup

  1. Use your permitted existing player

    Keep the complete existing Windows or Linux package together. Select its native Mario Forever Community Edition game executable and containing folder. This is a self-contained community remake of Mario Forever; it does not ask for a commercial Super Mario ROM.

    Choose Play explicitly after registering the existing player. Runtime updates and external profiles remain with you and upstream; Portcove does not replace, back up or remove those files.
