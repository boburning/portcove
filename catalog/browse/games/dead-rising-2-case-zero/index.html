Setup

  1. Use a completed copy you already have

    Continue with a complete player you already have. The reviewed v1.1.3 package also includes compiled-in libxlive, whose licence it defers to XenonLive; offline use does not remove it. The preparation and data-preservation guidance below applies to that copy.

  2. Prepare the own-game offline Windows copy upstream

    Use your legally obtained Xbox Live Arcade Dead Rising 2: Case Zero package, Title ID 58410A8D: the approximately 825 MB extensionless package under Content/0000000000000000/58410A8D/000D0000, not the full Dead Rising 2 game. Follow the standalone package’s first-run instructions outside Portcove. Its native runtime performs STFS extraction, shader preparation and game-data overlays; no external compiler or setup helper is run by this guide. The project’s PolyForm Noncommercial grant covers its own work, not the original game or separately licensed components.

  3. Select the actual offline native runtime

    The reviewed v1.1.3 Windows x86-64 ZIP contains CaseZeroRecomp/cz_runtime.exe, its DLLs and the initial assets/package marker. Attach the completed cz_runtime.exe with its executable directory as the established working directory. An online XenonLive launcher is not required for this offline entry; do not enroll one copy under competing runtime updaters. The package’s independent published SHA-256 is recorded in the source dossier, but attachment is explicit user-selected trust, not curated tree certification.

  4. Attach the completed native player and choose Play separately

    Finish setup with the project’s tools, then select the Windows game executable, working folder and supported launch arguments in Portcove. Review and agree to those details, then choose Play separately. Keep the complete package together and close the game and companion programs before changing files. You manage this external copy; Portcove does not replace it or back up, convert, migrate or delete its data. Removing its registration leaves those files in place.
