Setup

  1. Finish the original-disc and player preparation

    Use your own original Xbox 360 King Kong USA/Europe multilingual disc, title 555307D3, game version 0.0.0.1. Upstream identifies the 7,834,892,288-byte ISO by SHA-1 075F43709E9C9A095E099AB5056CC04B768288D1. This is a disc-image identity, not a default.xex digest. The 2005 PC version and other-platform discs are different inputs. Finish upstream game import, shader/runtime preparation, renderer/settings changes and any startup/recovery notices independently before attachment.

  2. Keep the full independently permitted Windows player

    Use the complete v2.1.3 Windows x64 KingKong folder with king_kong.exe, graphics plugins, DLLs, resources, launcher support and component notices. Do not select the separate easter-egg game as King Kong. Project MIT, SDK, graphics/upscaler, fonts, media and captured-shader rights are separate from your original game rights; attachment neither redistributes those components nor grants permission to use third-party packs. Use only an existing player and optional content you are independently permitted to use.

  3. Use the upstream launcher or retain direct-game play

    Select king_kong.exe in the complete existing KingKong directory and use that directory as working directory. Leave arguments empty for its ordinary upstream launcher and full settings/start-mode choices. Review the selected program, folder and arguments, then choose Play when ready. The previously documented --kk_launcher=false option remains available for a prepared direct-game start; internal skip-once and diagnostic flags are not substitutes. Upstream can relaunch for settings, game or co-op handover. Portcove observes the selected process only, so its activity may finish while the actual game or a successor continues. Use upstream/game controls to quit continuing processes.

  4. Preserve the actual portable or legacy user root

    Windows normally uses KingKong/userdata for saves, settings-owned content, mods, cache, downloads and crash/recovery evidence. Earlier Documents/king_kong may remain the active root if migration fails or the program folder is not writable. Preserve both roots, king_kong.toml, full-path installed.txt receipts and moving-from-documents.txt, cleaning-documents.txt and documents-done.txt witnesses; finish upstream recovery before attachment. Existing user_data_root/cache_root overrides take precedence and must be retained. Do not copy only an executable or replace populated saves/configuration with package defaults.

  5. Leave maintenance and separate conditions upstream

    Upstream owns imports, shader packs, component updates, portable-folder moves, renderer restarts, online/co-op services and failed-start recovery. Close all actual games/helpers before these changes, even when Portcove’s activity has ended; then review/re-select the current player as needed. Full campaign, controller, multiplayer, captured-shader permission and real-save recovery are not established. No managed installation/update/backup/rollback/migration or external-file deletion is offered.

  6. Play on Linux

    Put KingKong-linux-x86_64.AppImage in its own writable folder and mark it executable. Use Vulkan. Open the AppImage, choose Select disc image and let the launcher prepare your files. Use PLAY again in the launcher after restarting. The upstream guide names FUSE 2 for mounting the AppImage and curl for downloads.

Setup notes
Keep the Linux files and update through the project
Keep game, king_kong.toml and logs beside the AppImage. Use About > Open save folder to find and back up your actual saves. AppRun uses XDG_CACHE_HOME or ~/.cache for its separately extracted program copy. The upstream launcher offers version changes and controls automatic checks. Keep the same AppImage location for an existing upstream shortcut. Turn off the launcher for direct starts after setup. Hold Shift at startup to reopen it.

Limitations and evidence

  • Use king_kong.exe with empty arguments for its ordinary launcher, or retain --kk_launcher=false for the existing prepared direct-game choice. Preserve userdata, legacy Documents/king_kong and recovery witnesses. Portcove follows the selected process only; close actual games/helpers before maintenance.
