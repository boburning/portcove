Setup

  1. Install and import on Windows

    Run the upstream setup and point it to your own installed GOG Chaos Overlords folder when asked. Setup imports a local asset pack. Keep the original folder separately. To play, open Chaos Overlords New Chrome from the Start menu.

  2. Install and import on Linux or Mac

    On Linux x86-64 use the upstream Debian-package instructions or the separate extraction instructions for your distribution. On macOS 12 or later select the PKG for Intel or Apple Silicon. Open the installed app, then choose the extracted folder of your own GOG game containing DATA, HELP and MUSIC. On Linux, you can use chaos-overlords-new-chrome-import followed by the quoted original folder if the picker is unavailable.

  3. Keep your New Chrome profile before replacing it

    Keep the Rechaos Overlords folder in your operating system’s local application data. It holds New Chrome’s preferences, saves and replays. Keep the imported Assets folder separately. Windows setup keeps Game/Assets on upgrade and deletes it on uninstall. Linux and Mac typically keep Assets under the ChaosOverlordsNewChrome application data folder.

Limitations and evidence

  • Original Chaos Overlords saves are a separate format. Keep the creating New Chrome version with your saves and replays because the upstream development format can change.
  • Upstream describes its Mac installers as unsigned. Review the publisher and follow its macOS setup instructions.
