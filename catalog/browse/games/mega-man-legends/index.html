Setup

  1. Check the required game files

    Use your own USA PlayStation Mega Man Legends disc. This guide does not specify the exact required serial number or revision; check this game’s game.toml and DISC requirements rather than another game’s settings.

  2. Follow upstream setup

    Initialize the pinned submodules and regenerate gameC from your own Mega Man Legends disc with the documented psxrecomp_cli.py generate command. Build psx-runtime with CMake and Ninja. Keep generated code private; publishing it is not part of setup. The project’s release and launcher packages have not been inspected or confirmed by this guide.
