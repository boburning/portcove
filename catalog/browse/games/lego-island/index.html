Setup

  1. Prepare your original game

    Use the linked upstream guided installer/setup instructions for your own English LEGO Island 1.1 data. For this portable archive, run the included bin/isle-config.exe yourself, choose the original data and save locations, and save the configuration. Portcove’s Play target is bin/isle.exe; read-only discovery and installation do not run the configuration helper. On Linux x86-64, run the included bin/isle-config yourself (it needs Qt 6 from your distribution); Portcove’s Play target is bin/isle. Keep bin/ and lib/ together. The Linux player and its bundled libraries need glibc 2.43 or later, GCC 13’s libstdc++ and OpenGL ES 2 with GLVND. The continuous channel follows upstream’s ongoing builds and may regress.
