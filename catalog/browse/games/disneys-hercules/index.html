Setup

  1. Prepare the matching PAL language upstream

    Use a complete copy and components you are independently permitted to use. The selected 0.5.6 release documents your own PS1 PAL SCES-00891 English, 00892 French, 00893 German, 00894 Italian or 00895 Spanish disc, with the upstream-supported disc image format. Finish language/disc selection upstream and retain independent originals and matching disc.cfg/disc-ID configuration. USA SLUS-01029 and the original PC release are different inputs; a title match is not compatibility.

  2. Keep the complete native player

    The inspected official Windows ZIP contains AMD64 Hercules_Recompiled.exe, matching language builds, runtime resources and overlay_toolchain. The published native game program is already compiled; original graphics, sound, videos and level data still come from your own disc. Optional overlay/HD generation is a separate upstream operation. Keep the whole extracted package; select neither a PS1 executable, disc image, Python nor toolchain helper.

  3. Add the project’s native app

    Select Hercules_Recompiled.exe, set the complete extracted folder as working directory and leave arguments empty. Review the exact intent and request Play separately. Choose the already prepared language and start through the upstream UI. Its Play path launches the selected language build with its own disc/working directory and waits before showing the UI again. Language choice is not three or five separately fixed launch intents. Quit the actual game normally before closing the UI; forced termination does not guarantee child cleanup or save flushing.

  4. Preserve language-specific saves and settings

    Keep launcher.ini, keybinds.ini, all disc configuration, game.toml/settings.toml, saves and caches in the package and each lang/<disc-ID> tree. An existing runtime.memcard_dir can select an external card/state location; retain it too. Keep imported original images independently. Save states and memory cards are distinct; no cross-build or language compatibility is claimed. This guide performs no migration, restore, backup or deletion.

  5. Keep optional packs and permissions separate

    Retain upstream provenance and all PSX runtime, SDL and other component notices. Those terms do not grant rights to original game code/assets or third-party HD packs; use only components you are independently permitted to use. Separate published HD packs are not silently part of this route. Existing permitted packs and locally prepared overrides stay upstream-managed; no pack is downloaded, generated or executed here.

  6. Maintain the external package explicitly

    Finish upstream updates, language replacement, overlay generation and HD operations outside an attached Play attempt. Upstream update/restart helpers can replace files or launch successors; review/relink changed executable bytes and retain independent recovery copies before maintenance. The five-language and enhancement reports remain upstream claims; no complete-game, save/reload, installed-app or Supported acceptance is asserted. Removing registration preserves external files; managed lifecycle operations remain unavailable.

Limitations and evidence

  • Preserve the exact PAL language/disc and its data tree. Optional HD packs, overlays, upstream updates and other editions have separate boundaries.
