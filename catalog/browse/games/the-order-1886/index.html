Setup

  1. Use the new-install archive

    Extract the Windows ZIP or Linux tarball to a writable folder. Keep the entry points and bin together. On Linux the launcher needs WebKitGTK 4.1 and the runtime needs glibc 2.39 or later and a Vulkan driver.

  2. Choose the original once

    Open The Order 1886, then select the supported extracted PS4 game on Game & Content. Use game update 1.02, required for v0.2.33. The publisher tested CUSA00785 USA with that update. Choose the folder containing eboot.bin, archivemap.bin, _data, sce_sys and sce_module. Press Play. The separate Play The Order 1886 entry on Linux starts the game with that saved folder and settings. Reopen the launcher to change them. Press F1 in the game to open its menu.

Setup notes
Preserve the shared profile
Keep user/order1886 beside the launcher. It holds settings, saves and logs. Use the publisher's new-install ZIP for manual Windows updates. The upstream launcher uses the separate go-windows archive for its own automatic update.

Limitations and evidence

  • The publisher reports actual play on Linux. The exact release notes identify physical Windows testing as unavailable. Portcove does not manage this runtime or protect its saves.

The Order: 1886 — The-Order-1886-PC-Port (IgorAugustoHH)

Experimental project. Upstream claims native Windows gameplay, original PS4 cinematic camera, DLSS, controls and in-game settings with 30/60/90/120FPS limits. Heavy-scene examples on i5-10400F/RTX2060/16GB report about 45-50 FPS with original TAA,40-45 FPS DLSS Quality and up to80 FPS DLSS Performance; the 120 FPS option is not a universal measured result. All chapters are still being tested. Known lighting flicker, black facial spots on some characters and one cutscene sync issue remain ; 1440p/4K unsupported. No complete playthrough or Portcove build/package/gameplay qualification is established. See below for original-file requirements and setup. Portcove has not confirmed setup or gameplay.

Setup

  1. Check the required game files

    Use your own PS4 The Order: 1886 CUSA00785 base dump with your own update 1.02 already merged as version 01.02, including eboot.bin and all original game files. TOport checks the title and version and rejects others. The README does not establish exact executable or asset hashes. Upstream says original executables, data, shaders and extracted artwork are not distributed; the shader cache is generated locally.

  2. Follow upstream setup

    Upstream README advertises TOport-Windows.zip v0.1.3 prerelease via Releases. Extract, open TOport.exe, select the owned version01.02 folder containing eboot.bin and click Play. First start prepares the game and compiles shaders locally while playing; original files remain needed. Alternative Windows source build uses MSYS2 CLANG64, bash build.sh and bash packaging/windows/package_toport.sh. No ZIP was downloaded or inspected; this is a manual discovery route, not managed acquisition or runtime qualification.
