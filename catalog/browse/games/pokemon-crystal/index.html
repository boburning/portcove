Setup

  1. Get the official player

    Obtain the official upstream release. On Windows x64 extract the entire Windows ZIP. On Linux x86-64 make the official AppImage executable. On either Mac architecture extract and keep the complete gen1recomp.app bundle.

  2. Import your original

    Use your own canonical US English 2 MiB Pokémon Crystal Game Boy Color ROM, revision 1.0 SHA-1 f4cd194bdee0d04ca4eac29e09b8e4e9d818c133 or revision 1.1 SHA-1 f2f52230b536214ef7c9924f483392993e226cfb. Import it with the upstream player and verify it has accepted this edition. The upstream player validates the ROM. Import may start the game directly.

  3. Add the game and play

    On Windows select gen1recomp.exe and its containing folder. On Linux select the AppImage and its containing folder. On Mac select Contents/MacOS/love and the Contents/MacOS folder. Review the one literal argument --game=crystal and save the registration. Start the selected player with Play. Gen II gameplay is in development upstream. On Linux without FUSE, add --appimage-extract-and-run before --game=crystal as its own argument.

  4. Keep your game data

    The upstream player owns import, runtime replacement and the shared profile. Keep your original separate and retain imports, saves, settings, mods and the actual shared profile locations. Removal clears the Portcove registration only. Launch and update Flatpak and mobile copies through upstream.

Limitations and evidence

  • Keep the original outside the player’s working data. Gen1Recomp owns the imported data and profile.
