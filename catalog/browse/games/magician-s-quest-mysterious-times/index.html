Setup

  1. Check the required game files

    Use your own USA YNNE Nintendo DS ROM, SHA-1 ab2e495f6206b5c9b69043f8b4114d760f7298b2. The European Enchanted Folk edition is unsupported.

  2. Follow upstream setup

    Follow the README for the rolling latest prerelease ZIP containing MagiciansQuest.exe and its compiler. Choose your own ROM and compile once locally. A developer source route also exists; its Windows bootstrap may install tools machine-wide, so review those changes before running it.
