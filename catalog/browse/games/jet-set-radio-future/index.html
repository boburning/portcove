Setup

  1. Check the required game files

    Use your own European disc files with title ID 49470018, XDK 4134 and default.xbe SHA-1 edd8547185025834df914724069aa1e63109cbc1, plus the complete Media folder.

  2. Follow upstream setup

    Follow the README for JSRF.zip in Releases. Extract it, place your own Europe PAL ISO in assets, or supply its default.xbe and Media folder, then run JSRF.exe. First launch translates and compiles the game locally; later launches reuse that work and still need the original files. A source build uses Visual Studio 2022 C++, Clang, CMake and build.bat. Upstream says release.bat creates a ZIP without original game code; Portcove has not inspected that ZIP.

Setup

  1. Prepare the standalone US Xbox game upstream

    Use a complete copy and components you are independently permitted to use. The reviewed 0.6.1 engine targets the standalone US NTSC 2002 Jet Set Radio Future disc (version 1, built 28 January 2002), not the Sega GT2002 combo, European or Japanese releases. Follow upstream setup outside Portcove with your own folder containing default.xbe and Media, or your own disc image for upstream unpacking. Its XBE section-layout check can accept patched copies with that layout; it is not a full-image digest or entitlement check. No original, unpacker, helper or game is obtained or executed here.

  2. Keep the entire Windows engine and launcher package

    The inspected JSRF-Unleashed-windows-x86_64.zip contains JSRF Unleashed.exe, engine/jsrf_recomp.exe, companion DLLs and licences. Keep the complete extracted directory in a writable location. The selected Windows instructions require OpenGL 3.3. The release contains recompiled game code but no original game assets according to upstream; MIT for project code does not grant rights in the original game. Do not select the internal engine, a DLL, original default.xbe, mobile app or build helper for this route.

  3. Select the prepared ordinary launcher

    After first setup has remembered the correct game folder and storage mode, select JSRF Unleashed.exe, use its complete extracted package directory as working directory and leave arguments empty. Review and consent to the selected launch details, then choose Play separately. The launcher starts its matching engine with the saved game folder as the child working directory and waits for that engine’s exit. Finish a repeated setup prompt outside the attached attempt. Portcove has not tested gameplay or child-process cleanup.

  4. Preserve separate game saves and launcher storage

    Keep the selected game folder and its UDATA saves. Settings, cache, logs and upstream-unpacked images normally live in %LOCALAPPDATA%/JSRF Unleashed; an existing portable.txt places them beside the launcher instead. Preserve the active settings file, last-run.log, actual unpacked-image directories, original disc/image and any previously chosen external game folder. Do not add --portable or change the marker to move saves here. The guide performs no migration, backup, import or external-file deletion.

  5. Maintain the complete copy outside attachment

    Finish upstream setup, data-root changes, resolution/restart paths and runtime replacement outside an attached session; close the actual engine and any helper before changing files. Keep independent recovery copies, then review/relink changed executable bytes. Quit the game normally; forced termination is not a save-flush or quiescence guarantee. Upstream owns runtime replacement and external files. Removing registration leaves those files intact.

  6. Retain component and platform limits

    Keep licences/LICENSE.txt, NOTICE.txt and all component notices, including LGPL2.1-or-later terms for xemu-derived MCPX/APU code and the separate library terms. No own-code grant is extended to SEGA game code/assets or other components. Upstream’s early playable status and incomplete full playthrough remain upstream claims; Android emulator-only boot and iOS user signing establish no Windows/native/physical acceptance. No Portcove gameplay, save/reload, installed-app or Supported claim is made; managed install/update/rollback/backup/removal are not offered.

Setup notes
Use the Android JSRF Unleashed package
JSRF Unleashed v0.6.10 publishes JSRF-Unleashed-android-arm64.apk. Open it once and select your supported original Xbox disc image. If you copy the extracted game into Android/data/com.jumatt.jsrfunleashed/files/game instead, tap I copied the folder: start. Later launches use that copy. Keep the app’s profile when updating. The project reports Android emulator testing.

Limitations and evidence

  • Use the standalone US disc data; preserve game-folder UDATA separately from the actual per-user or portable launcher storage.
