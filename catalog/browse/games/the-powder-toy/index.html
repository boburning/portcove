Setup

  1. Choose a desktop package

    On Windows x64, download and extract the standard ZIP, then open Powder.exe. For Windows on ARM, choose Older, then Browse and open the current build page. Extract the ARM64 ZIP and open Powder arm64.exe. On Linux x86-64, extract the archive and run powder. The current Linux build needs glibc 2.35 or later. On Mac, choose the disk image for Intel or Apple Silicon.

  2. Create and reopen a local stamp

    Cancel the optional installation prompt to try the sandbox without registering file types. Draw in the canvas, press S, and drag around the area to keep. Press K to open your stamp library. Stamps work locally without a website account.

  3. Keep your local data

    Use Open Data Folder in the game’s settings. Close the game before copying that folder, including local saves, stamps, scripts, and preferences. Keep a separate copy before updating. The game’s updater or the original package source handles runtime updates.

Setup notes
Check Android and other Linux builds
The publisher links the official Android app in Google Play. Its GitHub APKs are experimental. The tagged GitHub release has a Linux ARM64 build. See the publisher’s notes before using a non-website desktop build.
Check the current Mac packages
The publisher supplies separate Intel and Apple Silicon disk images. The current Apple Silicon release has a signing limitation. macOS decides whether it can open either app. The publisher’s browser player is available from Play online.
