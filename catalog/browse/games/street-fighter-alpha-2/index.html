Setup

  1. Use the exact original arcade set

    Use your own exact arcade ROM set sfa2u (USA 960430), including its game key file, from a board you own. Another region or revision does not substitute for it. Keep originals separate and unchanged. The launcher accepts the set ZIP or its files folder and checks the files by checksum; when shared files are split, keep the matching parent ZIP beside it. Portcove registration does not authenticate the set or supply copyrighted game files.

  2. Prepare the shared launcher and this game

    Extract the complete official Preview package for your system: CPS2Recomp-windows-x64.zip, CPS2Recomp-linux-x86_64.tar.gz, or the universal CPS2Recomp-macOS.zip with CPS-2 Recomp.app. Keep cps2recomp-launcher (cps2recomp-launcher.exe on Windows), every game program and all packaged companions together. Run the upstream launcher deliberately, choose your ROM folder or this game’s exact set, then finish its settings before registering the player. Register the launcher for your system with the CPS2Recomp folder as working directory: cps2recomp-launcher.exe on Windows or cps2recomp-launcher on Linux. On macOS, register CPS-2 Recomp.app/Contents/MacOS/cps2recomp-launcher with Contents/MacOS as working directory. Enter two literal argument lines: --play then sfa2. The launcher owns this game’s configuration and child programs; do not register a source archive, update manifest or arbitrary other game executable.

  3. Add the game and manage updates

    The project’s shared launcher checks for updates and can replace the collection after its games close. Before using its update controls, keep a copy of the working game files and profile. Add this external copy to Portcove, then choose Play separately when you are ready. Removing its registration leaves the package, originals and profiles in place. Portcove does not offer updates, backups, rollback, data migration or deletion for these files.

Setup notes
Preserve the actual game and launcher data
Use the launcher’s Your files / Show controls to find its folder and each game’s data folder. Windows normally stores game data under %APPDATA%/<Game>/. A portable.txt file beside the launcher selects CPS2Recomp/user/, with separate launcher and game subfolders. Close all games and launchers before copying settings, save states, board memory, custom colours, scores, soundtrack files and logs. The launcher offers the initial copy to portable mode; Portcove does not move that data. Removing portable.txt changes where future sessions store data without moving existing files. Keep both locations and the working game version until the replacement works. Save-state compatibility and importing existing data have not been confirmed.
Linux ARM64 and Android
For Linux ARM64, use CPS2Recomp-linux-arm64.tar.gz and run cps2recomp-launcher. On an ARM64 device running Android 9 or later, install CPS2Recomp-android.apk and use Games → Add ROM sets. Get both packages and their checksums from the upstream release page.

Limitations and evidence

  • This is beta software. The project reports fighting-game and scripted checks; Portcove has not confirmed gameplay or saving from those reports.

Setup

  1. Get the matching arcade files

    Use your own Street Fighter Zero 2 Alpha (Asia 960826) arcade ROM set (`sfz2al`).

  2. Set up the game in the collection

    Extract the complete package for your system. Open CPS-2 Recomp and select the ROM folder on its Games page. Pick the game and press Play.

    Choose Play in CPS-2 Recomp. On desktop, a frontend can call the collection launcher with two arguments, `--play` and `sfz2al`. Open the launcher without arguments to change the ROM folder or settings.
