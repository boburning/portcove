Setup

  1. Choose your original USA PlayStation 2 disc

    Use an ISO from your own TimeSplitters 2 USA disc, SLUS-20314. Setup checks SHA-1 01f074637a0328dd8e4ae62ac7564548e56ee126 for SLUS_203.14 inside the ISO. This identifies the game executable inside the disc.

  2. Prepare on Windows x64

    Extract the Windows package into a new writable folder. Run TS2-Recomp.bat from that folder, choose your ISO and wait for the launcher to build the game. Choose Play when setup finishes. Keep the launcher, compiler and app folder together.

  3. Prepare on Linux x64

    Extract the Linux package into a new writable folder. With Python 3 available, run TS2-Recomp.sh, choose your ISO and wait for setup before choosing Play. The included graphics bridge requires glibc 2.34 or newer, libstdc++ with GLIBCXX_3.4.30, and the X11, udev, D-Bus, curl and zlib libraries. The graphical launcher also needs glibc 2.39 and WebKitGTK 4.1. If its dependencies are missing, the script falls back to setup and launch without automatic updates.

Setup notes
Preserve saves and settings
To move from 1.0.x to 1.1, keep the old folder and prepare the new release separately. Copy the contents of the old app/build/spielstand into the new savedata folder. Keep any separate savedata_onlineplus folder and your ts2-recomp settings under %APPDATA% on Windows or XDG_CONFIG_HOME on Linux, normally ~/.config. Keep the original ISO and working copy until you have confirmed your saves.
Use the upstream Steam Deck launcher
Follow the upstream Steam Deck guide in Desktop Mode, then add TS2-SteamDeck.sh as a non-Steam game. Return to Desktop Mode to use the graphical launcher for updates.

Limitations and evidence

  • Keep the disc image, extracted game files and generated game code private. Keep a complete working copy before replacing or updating it.
  • Use this route with a copy you already trust and are permitted to use. The upstream launcher owns updates and may rebuild the game from your remembered ISO.
