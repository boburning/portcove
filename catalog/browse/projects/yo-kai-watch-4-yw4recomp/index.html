Yo-kai Watch 4++ (YW4Recomp)

This Windows port targets Yo-kai Watch 4++ update 2.2.0. Build it from your own extracted files. The project reports starting a game, visiting the house and town, and autosaving. Effects are missing and later areas can crash.

Setup

  1. Check your original game files

    Use hash-checked ExeFS and RomFS for the 4++ 2.2.0 update. The original Yo-kai Watch 4 requires a different profile. The root guide has no separate instructions for keys or firmware.

  2. Follow the project’s setup

    Follow the project’s Windows x64 source build with Python, Git, Clang, GCC and the Vulkan SDK. The player needs Vulkan 1.3. There is no release package.
