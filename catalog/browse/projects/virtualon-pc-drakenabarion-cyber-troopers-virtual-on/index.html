Setup

  1. Check the required game files

    Use your own PS4 VirtualOnMasterpiece CUSA16156 decrypted collection folder with eboot.bin,pjv3.elf,sce_module,sce_sys and assets. Select original VirtualOn component omg, not ot/force. Exact update/digests unbound.

  2. Follow upstream setup

    Use Virtual-On-x86_64.AppImage or the Windows ZIP, or build with build.sh. Select your own folder and the omg component in the launcher (or BB_EXE=omg). This is the collection’s shared native runtime.
