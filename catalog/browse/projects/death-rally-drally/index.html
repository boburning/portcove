Setup

  1. Prepare a separate game folder

    Extract the v0.2 archive for your x64 system into its own writable folder. Copy the files listed in the upstream guide from the full DOS game into that working folder. The v0.2 player rejects the 1.1 shareware MENU.BPA. Keep the upstream uppercase names, including CINEM and the .BPA files. In the working folder, set CDROM.INI to ./CINEM and leave your original installation unchanged.

  2. Start the upstream player

    On Windows, keep the supplied SDL2.dll and SDL2_net.dll beside dRally.exe and open it from the working folder. On Linux, use your distribution's SDL2 and SDL2_net runtimes and run ./dRally from the same working folder. The normal player is the file without the _debug suffix.

  3. Keep your progress

    Close the player and save a separate copy of the working folder's DR.CFG and any DR.SG save files before replacing or removing that folder. Keep the original game files independently so you can prepare a fresh copy.

Limitations and evidence

  • The upstream alpha omits the original game data and does not offer multiplayer. Setup, runtime replacement and backups are player-managed.
