Setup

  1. Prepare a complete matching original upstream

    For this guide use your own Fable II Xbox 360 GOTY USA/Europe copy, title 4D5307F1. The selected source’s supported-version table binds default.xex SHA-256 88c4ef2e18e65409444d1b068eff921d1f7e180a5ae64edc64ba6b0872372662 and requires matching GOTY content. Complete upstream’s supported preparation and normal hash/content validation. Keep the complete original data and any $SystemUpdate folder together; do not mix an executable from another edition. Portcove imports no ISO, runs no extractor/compiler and provides no hash-check bypass.

  2. Select the actual completed native entry

    Select the completed fable_2.exe, its parent directory as working directory and no arguments when default.xex and data/ are already beside it. For an already working external original folder, retain its explicit supported --game_data_root=<path> literal argument instead. Keep matching rexruntime/rexgpu DLLs and resources. Fable2Launcher.exe starts the native player and closes; select the native player for the attached session.

  3. Review launch details, then choose Play

    Select the completed game executable, its working folder and supported launch arguments. Review those details and agree to use them, then choose Play separately. You manage setup, game replacement and recovery using the project’s tools. Removing its registration leaves external files in place. Before changing versions, close the game and its companion programs and keep the working copy and all data. Review and select the changed executable before playing again.

Setup notes
Preserve the portable player, original and custom roots
The inspected title source forces saves/ and cache/ beside the executable even when a platform user-data default or argument differs. Preserve the complete creating copy, fable_2.toml, fable2_config.toml, launcher-settings.toml, one-time backups, logs, data/scripts, original game tree, mods and every custom path. Upstream may repair the original-data file manifest; retain the old complete data before preparation or replacement. Save and mod compatibility across runtime versions remains upstream-owned.

Limitations and evidence

  • Use only a copy and components you are permitted to use. Before changing versions, keep a copy of the complete working game, original files and every profile, save, cache, mod, backup, temporary file and custom data location. Another executable may use the same data. Portcove does not offer updates, backups, rollback, data migration or deletion for these external files.
