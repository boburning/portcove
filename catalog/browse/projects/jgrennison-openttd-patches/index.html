Setup

  1. Start the game

    On first Play, choose a base graphics set when requested. Upstream supports the free OpenGFX/OpenSFX/OpenMSX sets or your own compatible original Transport Tycoon Deluxe data. JGR Patch Pack is a separate game build, not a loadable mod; its saves and multiplayer peers must be compatible with that build.

  2. Use the Linux managed player

    Portcove installs the official generic Linux AMD64 archive and starts it with the default XDG profile. The inspected player needs glibc 2.28 or newer. Keep your configuration under XDG_CONFIG_HOME/openttd and your saves and downloaded content under XDG_DATA_HOME/openttd, or the usual home-folder defaults. These folders can be shared with other OpenTTD copies and stay outside Portcove backups.

  3. Set up the Mac app yourself

    Mount the upstream universal Mac DMG and copy OpenTTD.app into your Applications folder. The inspected player needs macOS 10.15 on Intel or macOS 11 on Apple silicon. Keep the JGR Patch Pack app and its effective profile with saves created by that build.

Limitations and evidence

  • On Linux, use a separately prepared copy for a portable configuration, native social plugins or a custom library search path. Keep the effective OpenTTD profile and the runtime that created your saves.
