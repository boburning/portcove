Setup

  1. Check the required game files

    Use your own USA NTSC original Xbox The Warriors retail disc as ISO or extracted data. PS2, PSP and PAL editions are rejected. This guide does not include the supported default.xbe digest; check the project’s importer or configuration requirements before setup.

  2. Follow upstream setup

    Use the project’s alpha release and importer with your own ISO and assets. First launch compiles game code locally with XboxXBERecomp. The player targets Windows 10/11 x64 with D3D12 and XAudio2. The recorded review did not run compiler commands.
