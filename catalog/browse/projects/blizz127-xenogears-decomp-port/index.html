Setup

  1. Prepare the reviewed original files

    The published r5 route requires Xenogears USA SLUS-00664 Disc 1 as a 718738272-byte raw BIN plus SLUS_006.64, field.bin, menu.bin, shop_menu.bin, member_change_menu.bin and world_map.bin extracted from your own disc. An ISO is not equivalent. Follow the upstream extraction guide; no extractor is run by discovery and the runtime checks missing or different files.

  2. Use the existing upstream launcher

    For an existing copy you are permitted to use, run xenogears.sh with the prepared data folder on the first start; it remembers the folder. Keep its lib directory and OS launcher because the wrapper supplies the library environment. Preserve ~/.config/xenogears-port and ~/.local/share/xenogears-port (or the selected XDG locations), including cards and quick checkpoints. Portcove does not register the shell script, adopt files or replace this runtime.

Limitations and evidence

  • The published r5 binary expressly includes about 6.6 KB of transcribed retail tables and upstream contributor code outside the project MIT grant. A statement about future v0.6.0 source is not a repaired released package.
  • This preview has known on-foot battle crashes and an unfinished route beyond map 15. Runtime replacement, external backup and checkpoint compatibility remain with you/upstream; no native gameplay or real-save acceptance is established.
