Setup

  1. Check the required game files

    Use your own European disc files with title ID 49470018, XDK 4134 and default.xbe SHA-1 edd8547185025834df914724069aa1e63109cbc1, plus the complete Media folder.

  2. Follow upstream setup

    Follow the README for JSRF.zip in Releases. Extract it, place your own Europe PAL ISO in assets, or supply its default.xbe and Media folder, then run JSRF.exe. First launch translates and compiles the game locally; later launches reuse that work and still need the original files. A source build uses Visual Studio 2022 C++, Clang, CMake and build.bat. Upstream says release.bat creates a ZIP without original game code; Portcove has not inspected that ZIP.
