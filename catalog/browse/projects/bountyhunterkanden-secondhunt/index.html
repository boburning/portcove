Metroid Prime Hunters (Second Hunt)

Setup

  1. Set up Second Hunt

    Use a complete official Windows copy you have permission to use for personal, noncommercial play. You need Windows 10 or 11 (x64), OpenGL 3.3 or newer, and your own Metroid Prime Hunters USA .nds (AMHE, revision 0/v1.0 or revision 1/v1.1). Open the program after taking the precautions above. Choose or drop your ROM in Second Hunt and let it finish extracting the game files.

  2. Add the game program to Portcove

    Choose SecondHunt.exe from the complete release folder. Keep all supplied files and notices with it. Set the start folder to that same folder and leave the arguments blank. Review the launch details, add the game, then choose Play.

Setup notes
Preserve the whole effective data root
The public default is %LOCALAPPDATA%/Second Hunt, distinct from development MPH Recomp. Preserve game/files and .extracted, recomp_settings.json, saves/, mods/, cache/, crash/, logs/, replays/imports and all other established state under that root. portable.txt beside the exe selects data/ beside it; the supported --data argument selects its exact full path instead. Preserve the chosen root and any original or imported external sources without inferring another MphRead fork’s saves, migration or compatibility. This guide does not import/export DS saves or promise cross-version/mod save compatibility.
Windows release and file checks
The v0.4.2-beta tag points to 6a41f47fa6ed580c0b3ff8f90b2f841acd1d738c. Startup cleanup was inspected in that source. The release ZIP and program were not inspected or run. The ROM picker checks the header game code and revision byte and creates game/.extracted. This does not identify the ROM by its full hash or establish entitlement.
Updates and recovery
Update this installation through Second Hunt outside Portcove. If its updater replaces the program or restarts it with --after-update, let it finish and review the changed program in Portcove before playing again. Close all game and helper processes before replacing files. Portcove leaves external files in place when you remove the entry and does not update, back up, restore or migrate this installation.
Optional content and license terms
The base Hunters route does not require Prime1/2/3/Trilogy discs, Prime4Beyond files/keys or optional imported characters/music/arenas. Each additional source has its own ownership/permission requirements. Online/LAN/voice/chat/profile sharing and replay-preparation workers are upstream features, not qualifications or operations offered through this guide. Replay preparation can use background helper invocations; close all actual players/helpers/successors before replacement or another attachment. Second Hunt original post-October20 code/art/documents uses PolyForm Strict with additional personal/noncommercial private modification permission and a redistribution prohibition; MphRead-derived and earlier MIT parts and third-party components retain their own terms. Official licensor-published builds are distinguished in that license; do not mirror or redistribute a copy through this guide. These terms grant no Nintendo/game rights.

Limitations and evidence

  • Before opening Second Hunt v0.4.2-beta on Windows, keep recovery copies outside its entire program folder and its update and staging folders. Every normal startup can delete files ending in .old or .old followed by digits (such as .old1) anywhere inside the program folder, including portable saves stored there.
  • Use a separate test copy. Portcove has not tested setup, gameplay or saving with this release.
