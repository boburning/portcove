Setup

  1. Complete the PS2 title’s supported setup upstream

    Use only a completed native copy and components you are permitted to use. This implementation targets Burnout 3: Takedown for PS2, NTSC-U SLUS-21050, using your own ISO. It is separate from the Xbox Takedawn and original Burnout projects. Complete disc selection and upstream setup before registration. Portcove does not acquire original data, run an extractor or compiler, or certify the full disc image; the inspected runtime identifies the disc by its boot executable.

  2. Attach the supported Windows native entry

    Select burnout3.exe in the writable completed package, its containing directory as working directory and no arguments. Keep burnout3-sse4.exe and every matching DLL, notice and companion together. The inspected supported entry runs the native player in-process on AVX2 machines; on a supported SSE4.1 processor without AVX2, its documented CPU entry starts the matching SSE4 build, waits for it and returns its exit code. Do not attach a build tool or invent arguments for a private runner.

  3. Retain one runtime replacement owner

    Review and consent to the exact selected executable, working directory and empty argument list, then choose Play separately. You and upstream own preparation, deliberate replacement and recovery. Close the actual player and companions before replacing files, retain the prior working copy and all effective data, then review and relink changed selected bytes. Registration removal preserves every external file; Portcove offers no external update, backup, rollback, conversion, migration or deletion.

Limitations and evidence

  • Use only a completed copy and components you are permitted to use. Preserve originals, the whole creating runtime, saves, settings, mods, caches, backups, unknown files and every custom root. Static source/release metadata review is not a package-byte certificate, native gameplay, real-save, installed-client or Supported acceptance.
  • Another executable may use the same locations. Preserve the creating runtime with saves before upstream updates; cross-version or cross-platform card compatibility is not certified.
  • Retain the project and engine MIT notices plus each bundled component’s separate notices. Their grants cover their own code, not Electronic Arts game code or assets; original-game rights and any third-party texture or music permissions remain separate.
