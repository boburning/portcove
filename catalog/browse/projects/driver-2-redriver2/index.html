Setup

  1. Keep the standard player and its dependencies together

    Use the standard release archive, keeping REDRIVER2.exe on Windows or REDRIVER2 on Linux with its complete data, configuration and install/ companions. The Windows player is Win32 and can run on a Windows x64 host; the Linux package is x64 and needs the upstream SDL2/OpenAL dependencies. Follow upstream instructions for any missing Windows Visual C++ runtime. Development archives are separate alternatives.

  2. Prepare both of your original discs with upstream setup

    You need both of your Driver 2 discs. Upstream documents English US/EU revisions 1.0 and 1.1. On Windows, put the upstream Launcher.exe in the player folder, install the required Java runtime for media conversion, and use its Setup wizard with both disc images. The Launcher is a separate native program; Java runs the bundled jPSXdec conversion tools. Back up a working prepared folder before allowing setup to replace its contents. Portcove never starts the Launcher, scripts or JARs during discovery.

  3. Use the manual setup alternative only when needed

    If you are not using the Windows Setup wizard, the supplied conversion scripts expect raw disc data at install/Driver2CD1.bin and install/Driver2CD2.bin, with config.ini pointing to the first image. Renaming a CHD or a cooked ISO does not convert it into the required raw data. Follow the upstream guide and deliberately run the Windows/Linux conversion step with Java to prepare the media. Review any conversion errors and keep originals and failed work recoverable before retrying.

  4. Add the prepared player, then choose Play

    Register REDRIVER2.exe or the Linux REDRIVER2 executable with its complete prepared folder as the working directory. Keep the upstream Launcher for its setup and configuration functions. Read-only discovery only suggests a launch target; saving launch details and choosing Play remain separate choices.

Setup notes
Preserve your prepared copy and actual profile
You or upstream provide runtime updates. Keep the whole prepared folder, config.ini, cutscene_recorder.ini, original images, generated media, mods and any custom data-folder paths before trying a new version separately. Profiles live under USERPROFILE/.driver2 on Windows or HOME/.driver2 on Linux, including config.dat and progress.dat; they are not isolated by choosing another player folder. Preserve that actual profile too. Portcove registration provides no managed Update, Backup or Rollback, and removing it leaves every external file untouched.
