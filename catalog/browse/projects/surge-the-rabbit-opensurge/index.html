Setup

  1. Install through Portcove on Windows

    Install the publisher’s portable game and choose Play on a 64-bit Windows PC. Portcove backs up the bundled game’s preferences, captures and levels stored in its managed data folder. Keep separate backups for custom projects you open from other folders.

  2. Install an upstream copy

    On Windows, extract the entire publisher ZIP into a folder you can write to and open opensurge.exe. The package includes the game and uses a 32-bit Windows executable. On Linux, install Open Surge from your distribution or install Surge Engine from Flathub for x86-64 or ARM64.

  3. Start the bundled adventure

    Choose Start Game from the Surge the Rabbit title screen. The package already includes the levels and other game files. No separate game data is needed.

  4. Keep your settings and creations

    Close the game before copying your files. For a manually extracted Windows copy, back up the extracted game folder. On Linux, copy the Surge the Rabbit folder under ~/.local/share/opensurge, or use the matching path under XDG_DATA_HOME if you set it. For Flatpak, look under ~/.var/app/org.opensurge2d.OpenSurge/data/opensurge. If you set OPENSURGE_USER_PATH, copy the folder it points to for your player data. Also keep any separate folders you use for your own games or levels.

Setup notes
Get the publisher’s Android build
The publisher offers an Android APK for ARM64 and 32-bit ARM in the release downloads. Keep your own copies of any projects you import. The Android app stores its active data in its own app storage.
