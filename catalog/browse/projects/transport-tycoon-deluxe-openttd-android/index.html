Setup

  1. Install the Android community app

    Use pelya’s OpenTTD listing on Google Play (org.openttd.sdl). Follow the app’s setup for its graphics and optional content. This Android community version has its own releases; the official desktop download and JGR Patch Pack are separate variants.

  2. Keep your Android saves recoverable

    Before updating, reinstalling or changing the app’s download source, export or back up every actual save, configuration and content folder with the app’s supported tools. Android can restrict access to app data. Keep the working app version and exact content recoverable before transferring a save to another OpenTTD version.

  3. Keep Android setup under the app’s control

    Install, start and update the game with Android and the publisher’s tools. Portcove provides this upstream setup reference; it does not install Android apps, launch this APK or manage its updates, saves, backups or removal.

Setup notes
Use the publisher’s app route
Use the linked Google Play listing for Android installation. Historical GitHub APKs are older releases, not a current-build recommendation. The available APK and its signing identity can differ from the store version.

Limitations and evidence

  • Do not uninstall the working app to replace it with a differently signed APK until you have confirmed that its data can be restored. Reinstallation can remove app data.
  • Use your own original Transport Tycoon Deluxe files only if you choose them instead of the free base graphics. This guide does not supply original assets.
