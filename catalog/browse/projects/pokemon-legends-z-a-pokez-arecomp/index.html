Pokémon Legends: Z-A (PokeZ-ARecomp)

The Windows launcher builds Pokémon Legends: Z-A from your own 1.0.0 Switch game, with an optional 2.0.0 update. The project reports exploring parts of Lumiose and playing battles on NVIDIA hardware. Back up saves before converting them to 2.0.0.

Setup

  1. Check your original game files

    Select a 1.0.0 base XCI or NSP, prod.keys and title.keys. Add the matching update and DLC you own if desired. Firmware fonts are optional. The Windows fallback omits button icons.

  2. Follow the project’s setup

    Use the Windows x64 ZIP on Windows 10 version 1903 or later, or Windows 11, with Vulkan 1.3. The launcher compiles on first setup. AVX2 is preferred, with a slower SSE4.2 path.

Setup notes
Version and platform notes
Black flashes and stripes on walls at night remain. The Linux and Mac builds inherited from another project have not been tested with this game.

Limitations and evidence

  • Keep a copy of the old save before converting it. Version 1.0.0 cannot load a 2.0.0 save.
