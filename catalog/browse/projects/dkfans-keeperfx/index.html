Setup

  1. Use the upstream setup for your own Dungeon Keeper

    The upstream Windows web installer is the simplest setup route. Follow the linked instructions, choose a separate KeeperFX folder and supply your own supported Dungeon Keeper CD, GOG, EA or Steam files. If you downloaded the complete .7z package here, extract it with your archive tool and open keeperfx-launcher.exe yourself; it prompts for the original files. The archive is not an installer, and patches/alphas alone are not a complete game.

  2. Select original CD data

    Select the CD’s keeper folder when upstream asks for original CD data; other editions have their own folder rules in the linked guide.

  3. Choose the upstream launcher

    On Windows 10 or newer, choose keeperfx-launcher.exe from the prepared KeeperFX folder, with that folder as its working directory. It provides setup, settings and upstream updates. Save launch details in Portcove, then choose Play separately. Upstream also documents keeperfx-launcher-legacy.exe or the direct keeperfx.exe route for older environments; those are deliberate alternatives, not another required setup question.

Setup notes
Preserve the external copy when updating
Let the upstream launcher provide updates, and keep a separate copy of your working folder before replacing files. Preserve save (including settings.toml), keeperfx.cfg, original data, screenshots and any custom maps, campaigns or mods. Portcove does not own these files or provide managed Update, Backup or Rollback for them.
