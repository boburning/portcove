Setup

  1. Start the official desktop package

    On Windows, use the installer for your architecture or extract the complete portable ZIP and run run_game.bat at its root. On Linux, extract the complete archive for your architecture, open its folder in a terminal and run ./run_game.sh. On Mac, extract the signed ZIP and open the SuperTuxKart application as a complete bundle. The 1.5 universal package contains Intel and Apple Silicon players.

  2. Make an offline profile

    Start the game and select Offline Account in the new player setup. Enter a player name and select that profile at sign-in to play without an online account. All required base game data comes with the full packages.

  3. Keep your profile and custom data

    Close SuperTuxKart and copy %APPDATA%/supertuxkart on Windows, ~/Library/Application Support/SuperTuxKart on Mac, or both ~/.config/supertuxkart and ~/.local/share/supertuxkart on Linux. If you have customized the data or configuration locations, preserve those actual folders. Keep any custom files you added to the package separately.

Setup notes
Get the Android release
Use the Android store link or the official APK on the upstream Downloads page. Android handles installation and updates. Preserve your Android app data before uninstalling or switching package sources.
