Setup

  1. Use the official Windows player

    Download the Windows x64 ZIP from Yoshi’s Cookie Recomp Releases. Extract the whole archive, open YoshisCookieRecomp.exe and select your own matching USA ROM before registering the prepared copy in Portcove.

  2. Register your prepared Windows copy

    After setup, close the player. In Portcove select YoshisCookieRecomp.exe and its extracted folder. Add the original ROM’s full path as one argument line without quotes. If you leave the argument empty, keep the upstream launcher enabled.

  3. Build the Linux player from upstream source

    On Linux x86-64, use the upstream source and its pinned submodules, CMake, a native C/C++ toolchain and system SDL2 development files. Set SDL2_DIR to the system SDL2 CMake package and NESRECOMP_ROM to your matching USA original. Build and launch through the upstream instructions.

  4. Keep your settings and saves

    Back up your actual settings and saves with the game closed before updating the player. Keep cycle save states with their creating build. Removing a Portcove registration leaves the player, original and profile in place.

Limitations and evidence

  • The existing Portcove registration route is for the Windows package. Linux setup uses the player’s own upstream build.
