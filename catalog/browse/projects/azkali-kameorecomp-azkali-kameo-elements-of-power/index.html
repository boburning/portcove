Setup

  1. Check the required game files

    Extract your own Kameo Xbox 360 ISO with extract-xiso into assets/game/, keeping default.xex and all remaining game files. This guide does not specify exact accepted region, revision or executable hashes.

  2. Follow upstream setup

    For the source route, build and install ReXGlueSDK, run rexglue codegen Kameo_config.toml, then configure the Linux AMD64 CMake preset with REXSDK_DIR and compile using Clang 18+, CMake 3.25+ and Ninja. This guide does not identify a completed player release.
