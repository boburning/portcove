Setup

  1. Check the required game files

    Use your own decrypted CUSA00004 update 01.07 folder containing eboot.bin, sce_module, sce_sys and art, about 30 GB. Upstream explicitly requires no PS4 firmware files.

  2. Follow upstream setup

    README offers SecondSonPC-win64.zip. Extract beside owned eboot.bin and run play.cmd; first launch compiles shaders, not the game CPU executable. Alternative build.ps1 uses LLVM 20+, CMake/Ninja and Visual Studio headers/SDK, with pinned shadPS4 source patches. Saves stay in userdata and are backed up by play.cmd.

Limitations and evidence

  • Upstream reports city gameplay, saves and 46–51 FPS on one PC. Frame-time measurements and experimental presets are separate results; a full playthrough and broader hardware compatibility remain unconfirmed.
  • Portcove has not confirmed setup, gameplay, saves or updates for this experimental port.
