  2. Keep a permitted existing player together

    If you already have a native copy you are permitted to use, keep its complete matching runtime. On Windows x64 choose saboteur2.exe beside SDL2.dll, with its folder as the working directory. Setup notes
Preserve actual settings and progress
The player normally stores fullscreen settings and high scores in SDL’s per-user petarov/saboteur2 preferences folder. When that folder is unavailable, high scores can fall back to SAB_II.SCR in the working directory; preserve that file too. Forced quit keys do not save scores. Before changing versions, close the game and keep a separate copy of the working runtime and actual preferences/fallback file. You or upstream own runtime updates. Portcove does not manage, back up, restore, roll back or delete these external runtime or player-data files.
