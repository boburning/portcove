Setup

  1. Set up the managed copy on first Play

    Use Load ROM to select your own 16 MiB, big-endian Super Smash Bros. USA .z64 (SHA-1 e2929e10fccc0aa84e5776227e798abc07cedabf). The player verifies it and keeps a private copy in its profile with SRAM and settings. Back up that profile separately before changing versions.

  2. Prepare the game

    Install the Microsoft Visual C++ 2015–2022 Redistributable (x64) if needed. On first start, choose Load ROM and select your own 16 MiB, big-endian Super Smash Bros. USA .z64 (SHA-1 e2929e10fccc0aa84e5776227e798abc07cedabf), then choose Start Game. The player checks the file and keeps a copy in its profile; keep your original separately.

  3. Select the prepared player

    Select SmashBrosRecompiled.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Limitations and evidence

  • Keep the profile that contains your SRAM and settings. Changing portable mode does not move existing data.
  • The package includes Chiaro fonts by Fontworks that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • Use a separate upstream copy for portable.txt mode. A separately prepared copy without portable.txt uses the same %LOCALAPPDATA%\SmashBrosRecompiled profile as the managed copy.
