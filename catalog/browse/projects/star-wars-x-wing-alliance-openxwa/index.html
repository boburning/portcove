Setup

  1. Choose your original game data

    Select your complete installed X-Wing Alliance folder. For a raw CD copy, use the upstream instructions to merge the contents of ALLIANCE into the game root first.

  2. Start the Linux player

    On Linux x86-64, install the official portable engine in Portcove, then choose Play and select your original game data in the upstream picker. Use glibc 2.35 or later, the GCC 12 runtime or newer, and a Vulkan driver. If you prefer an external copy, keep the resources, shaders and lib folder beside OpenXWA.

Limitations and evidence

  • Back up the entire effective profile, all original game folders, and the working player before updating. If the profile cannot be opened, check the working directory for pilots, settings and other files.
