Setup

  1. Check your original game files

    Use your own base NSP 0100606026F12000 and 1.0.1 update NSP 0100606026F12800 v65536, plus prod.keys. The project has not confirmed firmware needs, region or file hashes.

  2. Follow the project’s setup

    Follow the project’s make build instructions on an M1 or later Mac. Install the Xcode Metal toolchain, Homebrew, .NET and Python and allow 60 GB of disk space. The first shader build is estimated at two hours. Keep the rewritten game code, shaders and icons on your own device.
