Setup

  1. Choose your original on first Play

    Choose Play, then Load ROM in the player and pick your own 8 MiB Pilotwings 64 USA Rev 0 cartridge image. The project recommends an unmodified big-endian .z64; the picker also converts byteswapped images of the same cartridge. The player checks the file and keeps its own copy in its profile, so keep your original separately.

  2. Start a copy you manage yourself

    Extract the whole package to a writable folder. On Windows open Pilotwings64Recomp.exe. On Linux run Pilotwings64Recomp.sh or the Pilotwings64Recomp program from the extracted folder. To add that copy to Portcove, select the player and its folder and leave arguments empty; removing it from Portcove leaves every file in place.

Limitations and evidence

  • The package includes recompiled game code that the project license does not cover, plus two RT64 shaders adapted from Shadertoy, possibly under a noncommercial Creative Commons license. Portcove downloads the package only from the project’s own releases. You need your own original game files.
  • Portcove has not observed native setup, gameplay or saves. The Linux player needs glibc 2.43, libstdc++ with GLIBCXX_3.4.32, SDL2, GTK 3, FreeType and a working Vulkan driver.
