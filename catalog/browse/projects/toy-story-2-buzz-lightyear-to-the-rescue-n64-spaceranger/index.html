Setup

  1. Choose your own USA Rev0 original on first Play

    Choose Load ROM in the SpaceRanger title screen. The player verifies and stores a private copy in spaceranger-config. Keep your independent original and use Start Game in the same player.

  2. Prepare the exact USA Rev0 source

    Use a complete player and components you are independently permitted to use, with your own Toy Story 2: Buzz Lightyear to the Rescue N64 USA Rev0 ROM. The selected game registration checks normalized ROM bytes with XXH3-64 FD53C5EC8CE2530A; this is the actual revision-matching digest, not a SHA1, ownership test or package signature. The pinned runtime normalizes supported .z64/.v64/.n64 byte orders first. Other regions, revisions and console editions remain unsupported. For a prepared copy, finish Load ROM upstream before attachment and retain the independent original.

  3. Keep exact dependency and font terms

    Retain the project GPLv3 notice and each runtime/renderer/frontend/component notice. The dependency manifest identifies official RecompFrontend base b1a1477c6556aeb7ed45defbfb5924f721efebc1, covered by the existing unchanged-base license follow-up, plus this title’s separate authored patch; the base grant does not license unrelated forks or original Disney/Pixar game data. Keep the Inter, Noto Emoji, PromptFont, renamed Fredoka and Bungee OFL notices and credits. Use only components you are independently permitted to use; source bindings are not binary reproducibility or a broader permission grant.

  4. Select the prepared player

    Select SpaceRanger.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Limitations and evidence

  • Back up spaceranger-config before using the upstream reset procedure. Resetting the folder to reselect a ROM also removes settings and any Controller Pak data.
  • Quit the game normally before updating or moving profile files. The upstream preview reports incomplete interpolation and frame pacing tested mainly on one PC.
  • This is a preview. Keep the portable profile and its Controller Pak recovery files backed up before updating. The managed backup includes the ROM copy and is for your own recovery. Real saves and all-level compatibility remain unverified.
