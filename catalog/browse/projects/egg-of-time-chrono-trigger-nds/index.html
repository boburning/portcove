Setup

  1. Choose your original Nintendo DS game

    Use an unmodified .nds dump from your own cartridge. The accepted SHA-1 values are USA (YQUE) 11f9e8204e484eab42181b210c9f214584be75bf, Europe (YQUP) a6c69d789a6f2e31b27fba950423bea3c2f30a37, and Japan (YQUJ) afc91a3f1f6c1bd02845b76416239e4dabfae19f.

  2. Start the Windows x64 package

    Use a trusted EggOfTime Windows x64 ZIP ending in -windows-x64.zip. Extract it into a writable folder and open Egg of Time.exe. The package includes the tools for the local first-start build.

  3. Start the Linux x64 package

    The current Linux x64 packages need glibc 2.35 or newer, Python 3 and libcurl. They include Zig for the first-start build. The file picker uses xdg-desktop-portal or zenity. Extract the -linux-x64.tar.gz package and start Egg of Time from its folder, or make the separate x86-64 AppImage executable and open it.

  4. Let Egg of Time build your game

    Choose the .nds file when asked and wait for the local build to finish. The launcher copies the original to rom/CT.nds. If the build fails, open game/build.log in the same data location.

Limitations and evidence

  • Use these steps with a copy you already trust and are permitted to use. Follow your operating system’s security prompts.
  • Keep your ROM, extracted assets, generated game code and saves private. Close Egg of Time and wait for any build to finish before replacing the package or copying its data.
  • The upstream macOS runtime compiles from source. Upstream lists a full Mac game build as untested.
