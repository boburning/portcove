Setup

  1. Prepare your Windows copy

    Extract the complete Windows x64 ZIP into a writable folder. Use Windows 10 or 11 with Vulkan support. Install the Microsoft Visual C++ 2015–2022 Redistributable (x64) if needed. Open WinBackRecompiled.exe and select your own big-endian WinBack USA .z64 (SHA-1 fa04477b321a95e1f7a2edcac5c09bfa6ef72041). The game verifies and keeps a copy in its folder.

  2. Select the prepared player

    Select WinBackRecompiled.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: ROM copy, settings.json, saves/ including Controller Pak and checkpoints, mods and renderer data in the game folder. Back up these locations separately; registration does not migrate or certify their compatibility.

Limitations and evidence

  • Save through the game before quitting. The BASIC level-select option does not restore previously recorded checkpoint progress. The project reports limited testing beyond the first mission.
  • The project reports that this release can crash on exit.
