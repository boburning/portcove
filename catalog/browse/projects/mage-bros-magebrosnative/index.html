Setup

  1. Keep the original Mage Bros. files together

    Get the freeware 2.0 release from Saito Games, using the publisher link in the setup guide. Keep MageBros.exe and Music01.mid through Music06.mid together. The native engine checks the original executable before reading its game data.

  2. Start the native Windows engine

    Extract the Windows x64 package into a writable folder. Run MageBrosNative.exe with --game followed by the quoted path to the original MageBros.exe. Use Windows 10 or 11 with OpenGL 3.3. If Windows reports missing MSVCP140.dll or VCRUNTIME140.dll, install Microsoft’s Visual C++ v14 x64 Redistributable.

Setup notes
Keep settings and progress before replacing the engine
Close the game and copy magebros_native.ini and your screenshots from the engine directory. Back up %APPDATA%/MageBrosNative/saves/original or the folder you chose in save_path. Keep the original executable and music in their own folder.
Build for Apple Silicon or a Linux handheld
The publisher’s build guide covers Apple Silicon on macOS 12 or later and the R36S Linux handheld. The Apple Silicon build stores settings and saves under ~/Library/Application Support/MageBrosNative. The R36S needs the original files and a General MIDI SoundFont for music. The tagged release provides a ready-made package for Windows.

Limitations and evidence

  • The upstream package includes reconstructed Mage Bros. and DirectX framework code. The MIT grant covers the port’s own code. Rights to the reconstructed code remain with their original owners.
  • Mage Bros. Native keeps its own progress. Start a new native save if you previously played the original game.
