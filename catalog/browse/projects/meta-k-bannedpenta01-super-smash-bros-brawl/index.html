Setup

  1. Check the required game files

    Use your own Wii Super Smash Bros. Brawl disc as ISO or RVZ. This guide does not specify the exact supported revision; check the project’s requirements before setup.

  2. Follow upstream setup

    Upstream documents Windows source setup with VS2022 Build Tools,CMake,Ninja,Python3.8+ and recursive DolRecomp/ModernGekko submodules. Use run_gui.bat with an owned SSBB ISO/RVZ for local extraction, static recompilation and runtime launch. The README clone example uses a placeholder owner; use this exact upstream repository identity. The fat-module/nativeREL research route can crash; the alternate stable slim-module route uses JIT and is not all-static native. No package or runtime was obtained or executed here.
