Setup

  1. Choose your package

    The Windows x64 installer includes Java. On Mac, choose the Intel or Apple Silicon disk image with bundled Java. The Mac apps are unsigned. If macOS blocks one, use the portable ZIP with your installed Java. On Linux, use your distribution's package or the community FreeCol Flatpak for x86-64 or ARM64.

  2. Run the portable Java download

    The publisher also offers a portable ZIP that uses your desktop Java runtime. Use Java 11 or later. The publisher recommends Java 21. Extract the whole ZIP, open a terminal in the extracted freecol folder and run java -Xmx2G -jar FreeCol.jar.

  3. Start and save a game

    Choose New, then Single player game. Use Game and Save to keep your progress. Choose Continue Playing to resume the latest game, or Open to choose a saved game.

Limitations and evidence

  • Close FreeCol before copying your data. Keep your saves, autosaves, maps, mods, and configuration. If you specified a custom user data or config directory, copy that directory too. Keep autosave enabled when using the publisher's Mac packages.
