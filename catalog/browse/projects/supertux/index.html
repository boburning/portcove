Setup

  1. Back up existing SuperTux profiles

    Close SuperTux and copy your active profile and any older SuperTux profile to a separate location before starting a new release. For the Windows portable edition, include the user folder next to the launcher. On Linux, check for an older ~/.supertux2 folder. Keep the backup until you have checked your story progress and settings.

  2. Start the package for your computer

    On Windows, extract the complete portable ZIP and run run_supertux_portable.bat, or use the official installer. On Linux, make the publisher’s AppImage executable and start it. If FUSE is unavailable, pass --appimage-extract-and-run when starting the AppImage. The publisher’s download page also links to Flatpak for Linux. On Mac, pick the Intel or Apple Silicon disk image and copy the complete SuperTux.app into Applications. On first launch, choose whether to allow Internet access for the in-game add-on catalog. You can decline and still play the built-in worlds.

Setup notes
Keep saves, settings, and add-ons
The Windows portable launcher uses the user folder next to the batch file. Keep that folder and any profile chosen with --userdir or SUPERTUX2_USER_DIR. Keep older folders such as .supertux2 before changing versions. The 0.7.0 release notes explain the .old story saves left by the betas.
Install the Android build for your device
Open the project’s GitHub Releases page and expand the 0.7.0 release assets for the ARM64, ARMv7, x86, and x86-64 APKs. Use the package for your device. Keep your Android app data before uninstalling or switching package sources.

Limitations and evidence

  • SuperTux can move files out of an older profile and remove its directory even when you choose a separate portable user folder. Back up both profiles before first launch.
