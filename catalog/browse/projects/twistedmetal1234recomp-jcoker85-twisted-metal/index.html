Setup

  1. Check the required game files

    Use your own PS1 USA TwistedMetal retail SCUS94304 CHD or CUE/BIN. Other launcher games have different disc profiles and are not interchangeable.

  2. Follow upstream setup

    Use the shared Windows launcher release, or tools/generate.sh for a source build with your own disc. Select TwistedMetal tm1 with your own SCUS94304. Recompiled C is generated locally, and the discs remain required. This is the existing shared launcher implementation.
