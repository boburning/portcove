Setup

  1. Prepare the supported PS2 original upstream

    Use a complete player/components you are independently permitted to use, with your own Ridge Racer V USA SLUS-20002 as CHD or a complete CUE/BIN pair. The selected extractor verifies nine original files, including SLUS_200.02 at 1,295,332 bytes / SHA256 fb5b4d3f6d74384cee9da4c8b954b40a0205da0a9ae7db9e68d670156f5e706f. This is a per-file source contract, not a hash of every disc representation. Complete upstream disc selection/extraction and settings first; keep the original independently. No original, converter, extractor, helper, compiler or game is obtained or executed here.

  2. Keep the complete Fukami product layout

    The inspected official 1.1.0 Windows x86-64 ZIP contains AMD64 Fukami/Fukami.exe and its matching libraries, resources/ package and share/fukami-default.ini/workload contract. Keep that full layout. It differs from a developer runtime, an extracted ELF or the macOS/Linux products. The app recognizes this complete Windows layout before applying its normal preparation and launch path.

  3. Add the prepared app that waits for the game

    Select Fukami.exe, use its complete extracted Fukami folder as working directory and leave arguments empty. Review the exact intent and request Play separately. Source creates a same-image child with the configured environment and original ELF, waits without a play-session timer and returns its exit status; it can restart that child after an upstream settings restart. Keep that supported parent rather than inventing environment/child flags or attaching a resource DLL. Finish missing-disc preparation outside the attached attempt. The source attempts a kill-on-close job on a best-effort basis; this is not an observed universal descendant-cleanup or save-flush guarantee.

  4. Preserve actual cards and resource/data roots

    Normally keep %LOCALAPPDATA%/Fukami with fukami.ini, mc/ memory cards, disc/ extracted originals, sessions/ when logging is enabled and all other player data. The real Windows known folder can be relocated; an established FUKAMI_DATA_DIR selects another per-run root. Keep the source CHD or complete CUE/BIN and any external texture/settings/card paths, plus the matching immutable resource package. Card persistence, state files and session logs are distinct. This guide changes no environment and performs no extraction, migration, backup, restore or deletion.

  5. Keep licences and use the project’s maintenance tools

    Keep project GPLv3, PCSX2-derived notices, libchdr, font/icon, renderer and other shipped component terms; they do not license the original game, optional replacement packs or third-party content. Quit the actual game and its waiting app normally before upstream replacement or data work, retain independent recovery and review/relink changed executable bytes. The reported long-session stall remains an upstream limitation; static source/archive checks do not establish native/installed, whole-game, real-save, hardware or Supported acceptance. Removing registration preserves external files; managed lifecycle operations remain unavailable.
