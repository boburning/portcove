Setup

  1. Check the required game files

    Use your own USA NTSC-U Dreamcast release as GDI with tracks 01/02/03, Redump CUE/BIN or CHD. Setup checks the SHA-1 of 1ST_READ.BIN; this guide does not include the expected value.

  2. Follow upstream setup

    Follow the README’s setup bundle with your own disc. It extracts the files, checks the program, translates the main program and 111 character overlays, and compiles locally. The native setup app creates player shortcuts and VMU data.
