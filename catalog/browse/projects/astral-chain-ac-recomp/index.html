Astral Chain (AC-Recomp)

An experimental Astral Chain port derived from Wonder, translating AArch64 code to C++ with NVN/Vulkan/MoltenVK. AC here means Astral Chain. The project reports only the File 01 motorcycle chase; saving and loading are untested. Windows cloud tests are scripted, and an 8 GiB guard can stop long sessions at around ten minutes. Linux has crash and rendering problems. Initial import needs the Apple Silicon macOS 13+ setup DMG/ZIP build kit, which generates locally. Windows x64 AVX2/Vulkan 1.3 source use needs those imported files and their control receipt; the source ZIP is mentioned but absent from the latest assets. Linux x64 is an early headless route with desktop, audio and gamepads untested; iOS work is paused. Use your own version 1.0.0 base NSP without updates, plus your own keys/titlekeys where required. Firmware shared fonts are optional, with Noto fallback missing some icons/CJK. Portcove offers no setup or launch integration and has not tested gameplay.
