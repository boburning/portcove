  2. Keep the complete matching package

    Keep Uncharted Launcher.exe with the complete python, launcher, tools, gow3_pc and other package directories from the same prepared Uncharted-windows package. The native starter invokes its bundled python/pythonw.exe and launcher script; it is not a standalone game.   3. Select the Drake’s Fortune play intent

    Select Uncharted Launcher.exe, use its complete extracted package directory as working directory, and set the two arguments --play u1. Review the exact selected intent, then request Play separately. The pinned launcher maps u1 specifically to eboot.bin; the native starter waits for the launcher, and direct play keeps it until its game/probe job completes. Finish any missing setup outside the attached attempt. Collection switching is an upstream feature, not independent qualification of the other titles.

Do not assume that changing copies, region, profile or runtime migrates or preserves compatible saves automatically. No import, save migration, backup or external-file deletion is performed here.
