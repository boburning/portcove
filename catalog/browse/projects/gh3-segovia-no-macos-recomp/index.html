Setup

  1. Open GH3 Builder on Apple Silicon

    Download the publisher’s v0.1.0 ZIP and open GH3 Builder on macOS 26.5 or later. The builder needs Apple’s Command Line Tools and internet access to fetch the checked Visual C++ runtime. Keep the builder separate from the game app it creates.

  2. Build from your own PC installation

    Select your own compatible Guitar Hero III 1.3.1 folder with GH3.exe, DATA/, AWL.dll and fmodex.dll. The builder checks the specific executable and FMOD hashes. The developer tested with BetterGH3. Choose a destination for the generated app, then use Play after the build completes. Keep the original folder in place for the default linked setup.

  3. Preserve your app and profile before rebuilding

    Close the game and back up ~/Library/Application Support/gh3, including AspyrConfig.ini and the drive_c saves. Keep your original installation and custom songs separately. A build replaces Guitar Hero III.app at its selected destination and recreates the shared game links in linked mode. A separate destination protects the previous app. Linked builds still share the same profile and game links. Keep the generated app and its game files for your own use.

Limitations and evidence

  • The publisher describes this builder as experimental and unnotarized. Review the publisher and this package before using Apple’s per-app approval to open it.
