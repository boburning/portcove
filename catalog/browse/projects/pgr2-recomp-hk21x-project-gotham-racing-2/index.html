Setup

  1. Check the required game files

    Use your own title 4D53004B game with PALv2 XBE SHA1 676895b86f01938804c5f1cdcad8b44044295cb4 or NTSCv5 XBE SHA1 ec6e902fc167de349f1dc1838a7441dfff932c62. Media-patched profiles are listed separately by the project.

  2. Follow upstream setup

    README advertises PGR2Launcher.exe via latest release. On Windows 10/11 x86-64, select an owned supported PAL/NTSC ISO or disc folder; the launcher downloads portable Clang/CMake/Ninja/Git/Microsoft build tools plus project source and compiles the game locally (upstream estimates 30–90minutes, about 15 GB space and1.4GB tools). It does not download original game code. Later Play/Update reuse or rebuild local output; owned game data remains required. Source route uses recursive submodules, assets/default.xbe plus disc data, VisualStudio2022 C++/Clang/CMake and build.bat. No launcher artifact was downloaded or its digest inspected.
