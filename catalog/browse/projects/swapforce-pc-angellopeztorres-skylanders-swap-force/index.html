Setup

  1. Check the required game files

    Use your own European English/German Xbox 360 Skylanders Swap Force XGD2 ISO of 8738846720 bytes. Game files and generated C++ or binaries are not included. Other source editions have not been confirmed.

  2. Follow upstream setup

    Run setup.ps1 with your own ISO to extract it, decrypt the XEX and generate runtime/ppc_gen using the pinned XenonRecomp tools. Then build runtime/build/SwapForceRT.exe. This guide does not establish a published game-runtime package.
