Setup

  1. Choose the original game data

    Use the Little Fighter 2 v2.0a installer offered by the original developers at lf2.net. Keep it as a file. OpenLF2 verifies the file and reads its game data without running the original installer.

  2. Install OpenLF2 on Windows

    Run the OpenLF2 v1.2.0 setup program for your Windows architecture. If you already have the original, clear the Download the original Little Fighter 2 installer task. OpenLF2 can read your file from %APPDATA%\OpenLF2 or through the --installer argument. Add the installed openlf2.exe to Portcove after confirming it starts.

  3. Set up Linux or macOS

    On Linux, make the matching AppImage executable, or let your package manager install the matching Debian package. On macOS 13 or later, extract and keep the complete Intel or Apple Silicon app. Keep the original in the OpenLF2 profile, or launch the player with --installer followed by its absolute path.

  4. Add a working desktop copy

    Select the existing native player and keep its working directory. If it needs explicit paths, enter --installer and the absolute path to the original as two arguments. Use --config-dir and the creating profile's absolute path as two more arguments if you already use that override. Save the launch details, then choose Play. Removing the registration leaves the player and its profile where you put them.

Setup notes
Find the desktop profile
The upstream player uses the operating system's OpenLF2 data folder. An explicit --config-dir keeps config.json and the recording directory in that selected folder. Keep the original separately and retain any .lfr recordings and mods you add.
Choose an upstream package
The v1.2.0 release includes Windows x86, x64 and ARM64 installers, Linux x86, x64 and ARM64 AppImage and Debian packages, and separate Intel and Apple Silicon Mac apps. Android previews cover ARM32, ARM64, x86 and x64 on API 21 or later. Choose the package for the device's architecture. On Linux, use APPIMAGE_EXTRACT_AND_RUN=1 for a manual AppImage launch if FUSE is unavailable.

Limitations and evidence

  • Back up the original installer, config.json and the recording folder before replacing the player. On removal, the upstream Windows uninstaller can offer to erase the default profile. Decline that option to keep its data.
  • Android v1.2.0 packages use the project's public debug signing key. Keep this package family separate from any differently signed Android installation and preserve its data before changing packages.
