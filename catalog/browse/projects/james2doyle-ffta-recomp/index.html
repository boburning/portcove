Setup

  1. Use your own supported USA original

    On first Play, choose your own Final Fantasy Tactics Advance USA GBA ROM (AFXE, SHA-1 4ac05441f4de70a4ec3dd932116346c61b8783d9) in the player's file picker. The player rejects other files after selection and remembers the path in rom.cfg, so keep the ROM where it is. Save-state slots are written beside that ROM with .stateN names. The package includes the clean-room emibios replacement, so no Nintendo BIOS dump is needed.

  2. Run a copy you manage yourself

    Keep the complete package for your system together. Start FFTARecomp.exe on Windows, or the FFTARecomp AppImage on Linux, from its own folder; the launch screen and game run in one process. To add that copy to Portcove, select the player and its folder with no extra arguments, then choose Play.

Setup notes
Keep saves, settings and external states
The battery save is saves/ffta_us.sav beside the player unless --save or --save-path points elsewhere. rom.cfg, bios.cfg, skip_launcher_on_boot, config.ini and keybinds.ini also sit beside the player, and imported mods go to mods/packages with mods/state.toml. Save-state slots live beside your ROM, or in the --state-dir folder. Back up all of these before replacing a copy you manage yourself.

Limitations and evidence

  • The project uses the PolyForm Noncommercial License 1.0.0; observe its noncommercial terms. The package also includes retail box art that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • This upstream preview is experimental. Portcove has not observed native setup, gameplay or saves, and no compatibility of saves or save states across versions is claimed.
