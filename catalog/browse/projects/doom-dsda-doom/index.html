Setup

  1. Choose your game data

    Use the IWAD from your own Doom installation or a freely available Freedoom IWAD. Pass -iwad followed by the path to that file. Keep the supplied dsda-doom.wad with the engine. It supplies engine resources. Heretic and Hexen require their own IWADs and follow the upstream setup instructions.

  2. Start DSDA-Doom on Windows

    Extract the complete publisher x64 ZIP. From that directory, run dsda-doom.exe with your IWAD.

  3. Start DSDA-Doom on Linux

    Use your distribution’s dsda-doom package if available. If you already have the publisher’s x86-64 AppImage, make it executable and run it with your IWAD. Without FUSE, extract it with --appimage-extract and run AppRun from the complete extracted directory. Install your distribution’s JACK client library if the player reports libjack.so.0 missing.

  4. Start DSDA-Doom on a Mac

    The publisher’s v0.30.1 universal ZIP has a Terminal executable for Intel and Apple Silicon. Both slices require macOS 26 or later. Keep dsda-doom and dsda-doom.wad together and run ./dsda-doom with your IWAD. Homebrew also packages DSDA-Doom for Apple Silicon and Linux, including Linux ARM64.

Setup notes
Keep the profile and matching runtime
On Linux preserve $XDG_DATA_HOME/dsda-doom, normally ~/.local/share/dsda-doom. It holds dsda-doom.cfg and per-IWAD saves and statistics in dsda_doom_data. Keep the engine version, IWAD and any add-ons used by a save or demo when changing packages.

Limitations and evidence

  • The package manager or your external installation owns updates. The player owns its save and settings files.
