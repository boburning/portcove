Perfect Dark (Perfect Dark: Recompiled)

A Perfect Dark port with project-reported Defection mission progress and persistent saves. Linux WSL/Dozen GPU tests caused hangs and a host freeze; Windows audio was tested only with a disk driver and short plays. Full-game progress, long sessions and physical controllers remain unconfirmed. Windows/Linux x86-64 and browser routes are documented; Windows uses Direct3D 12. Use your own USA revision 1 N64 ROM, NPDE version 01, 32 MiB, MD5 e03b088b6ac9e0080440efed07c1e40f. Further accepted revision/hashes and BIOS/firmware requirements are unconfirmed. You and the project manage setup and updates; Portcove has not qualified a release package or confirmed setup or gameplay.

Setup

  1. Keep the complete permitted Windows player

    Use an independently permitted completed Windows copy of this specific implementation; the reviewed upstream route is v0.1.3. Keep PerfectDarkRecompiled.exe, assets and all matching companions together. Finish any upstream source build outside Portcove. This is an existing-copy route, not managed package acquisition, source generation or a redistribution-rights grant.

  2. Select the native player and matching original

    Select PerfectDarkRecompiled.exe and use the completed runtime folder containing assets as working directory. Leave arguments empty for the normal launcher, then use Load ROM and Start Game at the separate Play step. Use your own Perfect Dark USA Rev 1, cartridge NPDE version 01, big-endian .z64 of 32 MiB; MD5 e03b088b6ac9e0080440efed07c1e40f and source-documented SHA-1 af8788ac4d1a57260eae9c53ffe851fcf2a3319b. The upstream player performs its own original check; Portcove registration does not import, normalize or authenticate the original.

  3. Review registration before choosing Play

    Portcove records your selected native executable, working folder and literal arguments after review; Play is separate. Only the selected process is supervised. You or upstream own updates and runtime replacement; relink changed executable bytes after reviewing them. Removing the registration preserves all external files. Managed installation, backup, rollback, migration, generation and deletion are not offered for this copy.

Setup notes
Keep the creating profile and portable mode
The reviewed Windows profile defaults to %LOCALAPPDATA%/PerfectDarkRecompiled. An existing portable.txt in the working folder selects that folder instead. Keep the creating mode and actual locations; adding or removing the marker does not migrate existing data. Keep the whole profile, its selected original/EEPROM data, all JSON settings, controller profiles, mods and any separately chosen outputs. Preserve the complete runtime folder and any custom or external paths too. Edit settings only while the player is closed; registration does not move profiles or certify state compatibility between versions.

Limitations and evidence

  • Upstream reports the Defection mission and only short Windows sessions. Windows hardware audio, long sessions and physical rumble were not established in the pinned report. The reported Linux/WSL GPU-device losses and host freeze remain unresolved; this Windows route does not qualify that path.
