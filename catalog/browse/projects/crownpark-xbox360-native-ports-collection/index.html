Setup

  1. Choose your game’s launcher

    Find the release for your game in the upstream project and read that release’s source and testing notes. Extract its Windows x86-64 ZIP or Linux x86-64 .tar.zst to a separate folder for that game. Both platforms need a Vulkan-capable driver. On Linux, follow the upstream guide for gamescope, Python 3 and archive tools.

  2. Import your original files and play

    On Windows, open Launcher.bat and choose Import game files. For a disc title, use the matching disc image or extracted files. For an XBLA title, use an extracted game folder containing default.xex. On Linux, run ./run.sh, select the matching title and follow its import prompt for the disc or XBLA package. Use the edition and region in the bundle’s content/SOURCE.txt. Resolve any checksum warning before playing.

  3. Keep each game’s saves and settings

    Keep the user-data folder beside each launcher. Back it up before replacing or removing that game’s extracted folder. Keep your original disc image or XBLA package outside the launcher folder.

Limitations and evidence

  • Upstream testing varies by title and platform. Check the notes for the package you choose.
