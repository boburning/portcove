Saru Get You: Saru Saru Daisakusen (Ape Escape Mind Over Monkey)

An experimental PSP Saru Get You: Saru Saru Daisakusen port. Its game profile reports early macOS startup/audio, Linux ARM64 startup and a Windows cross-build. Later root documentation and releases claim broader support and contradict the profile’s no-release/Android-unavailable statements; neither proves Android installation or gameplay. The SaruSaru launcher builds locally from your own Japanese UCJS10060 v1.00 compatible ISO; exact ISO hashes are unconfirmed. Source preparation needs CMake, Ninja, Python and a compiler, and PSPRecomp does not supply decryption. An optional interpreter handles code outside translated coverage. macOS ARM64, Linux x86-64/ARM64, Windows x86-64 and Android ARM64 launcher/build routes are documented, with their evidence differences unresolved. Portcove has not confirmed setup or gameplay.

Setup

  1. Prepare the exact Japanese PSP original

    Use your own Saru! Get You! SaruSaru Daisakusen Japan UCJS10060 version 1.00 ISO. The selected profile identifies PSP_GAME/SYSDIR/BOOT.BIN by size 3226216 bytes and SHA256 ee738a85dcd74a512430d1933226cc744c60b5dfb6e61bcc81eca1d5a208ec4b; this is not a whole-ISO digest. The profile does not supply EBOOT decryption. Finish original verification and local module generation through the supported upstream launcher before attachment.

  2. Keep the complete Windows shell and local title module

    Use the official v0.2.1 Windows x64 package with sarusaru.exe, its runtime DLLs, code generator, toolchain resources and notices together. psp_recomp.exe is the generator, not the game. The title-specific native shell loads sarusaru_game.dll from its prepared matching ABI location; this is not permission to use another PSP profile’s module. Source/profile maturity notes and Android/Linux/macOS packages are separate evidence, not Windows/native acceptance.

  3. Attach the integrated normal player

    Select sarusaru.exe, use its complete extracted player directory as working directory and leave arguments empty after upstream preparation. Retain an existing supported --settings FILE argument if that installation already uses one. Review the selected program, working folder and arguments and choose Play when ready. The selected shell keeps its launcher and in-game interface alive in the same session and calls the title’s play route in process. Use the original Japanese game-content mode for this route; optional English text/texture packs have separate content permissions and preparation, and are not required here. Close the actual player normally.

  4. Preserve settings, memory stick and compiled data

    On Windows, settings normally live at %APPDATA%/SaruSaruRecomp/settings.ini, with existing SARUSARU_SETTINGS or explicit --settings taking the documented override path. Keep the whole actual per-user SaruSaruRecomp root, including game/<module-ABI>/ locally compiled output, memstick/PSP/SAVEDATA, states, caches, pack choices and backups. An existing SARUSARU_MEMSTICK selects another memory-stick root; retain it and all legacy copies. Real PSP/PPSSPP save compatibility and experimental quick states remain distinct claims, not a demonstrated transfer/restore here. Do not create a new profile or merge/delete existing saves.

  5. Keep optional content and maintenance separate

    Retain project/PSPRecomp MIT, FFmpeg, compiler, SDL and other library/notices; original game text, translations, HD assets and fonts are separate rights boundaries. Do not infer permissions or qualification from another PSP title. Upstream owns import, local generation, content selection, updates and recovery; finish those outside a session, retain the prepared module/data and review/relink changed bytes. No private-input or credential operation, full playthrough, physical controller, installed/native, Supported or managed lifecycle acceptance is asserted.
