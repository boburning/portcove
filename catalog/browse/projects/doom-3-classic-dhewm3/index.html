Setup

  1. Choose your original game folder

    Choose the folder containing base from your own classic Doom 3 installation patched to 1.3.1. Portcove checks and prepares the nine original PK4 files, then you can select Play. BFG Edition is a different product. Keep your original installation separately. On Windows, keep the managed library path short and use plain ASCII. On Linux, keep the packaged modules and install SDL2, OpenAL, libcurl and the GNU C++ and GCC runtime libraries. Keep backups of the external save and settings folders. Use a separately prepared copy for custom paths or native mods.

Limitations and evidence

  • Use a short library path containing plain ASCII characters for this Windows build. Its external profile locations have their own upstream path limits. Older installations retain their original path contract.
  • Use the existing non-owning route for custom fs_basepath/fs_savepath/fs_configpath, custom mods, the separate dedicated server or another upstream workflow.
