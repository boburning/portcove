Setup

  1. Finish setup in the upstream Android app

    Install this fork’s Android APK and choose the folder containing your own licensed Jill of the Jungle data on first launch. The guide recommends the GOG data and accepts one episode or all three. Keep the episode files together: .sha, .vcl, .mac, .dem, .ddt, jill.dma and numbered files 0–50. Copying your complete original game folder avoids a missing-file sort; no desktop executable is the Android player.

  2. Keep your data when changing versions

    Keep the chosen game folder available and preserve it plus the Android app’s actual save/config data before an update or uninstall. The reviewed guide does not establish an exact save/export path or transferable-save contract. A close immediately after folder selection can indicate the wrong data version. This is an upstream beta; Portcove has no device/gameplay qualification or Android runtime backup/rollback promise.
