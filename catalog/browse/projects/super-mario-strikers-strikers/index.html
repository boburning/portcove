Setup

  1. Set up one of the v2.0.0 packages

    Extract the archive and use the packaged Settings program to select your own supported US, European or Japanese game data. The package contains a separate player and Settings program. Keep your working strikers.ini, effective profile folders and original data when replacing the upstream package. The separate upstream Linux ARM64 tarball is available from Releases.

Setup notes
Prepare a retained v1.3.0 Windows copy
Use the complete official v1.3.0 Windows x64 package for new-coke/strikers, keeping its dependencies and notices. Supply your own supported US, European or Japanese disc image or extracted game files following this version’s guide. Header/file presence checks are not complete region/revision identity verification. This implementation is distinct from StrikersRecomp and AuroraStrikers; do not mix their binaries, preparation or save assumptions.
Register the v1.3.0 Windows player
Finish the upstream settings application and a normal working launch first. Select strikers.exe. Its installation is the normal working folder, but preserve the established working directory and literal paths if the actual working launch differs; relative INI/source/profile paths can otherwise change. A configured copy normally needs no extra arguments. The settings app starts the game detached, so select the game itself. Preserve your actual strikers.ini and source paths. Portcove saves launch details without starting setup; choosing Play is separate.
Keep your configuration and profile paths
The runtime looks for strikers.ini beside its executable before the working-folder fallback; an explicit STRIKERS_CONFIG selects another file. Existing USER_DIR and CACHE_DIR configuration or STRIKERS_USER_DIR/STRIKERS_CACHE_DIR can select other profile/cache paths. Keep the same established configuration and absolute paths; this route does not invent environment redirects or migrate data. The Windows default user folder is APPDATA/Super Mario Strikers. Another runtime folder does not isolate a shared profile.
Preserve the complete copy and actual external roots
Before upstream replacement keep the whole runtime, strikers.ini, original images or extracted files, actual user/card/save and cache folders, imgui settings, texture packs, mods, screenshots, logs, custom paths and unknown files. You or upstream manage versions; no matching release metadata proves save compatibility. Portcove registration provides no managed preparation, update, backup, rollback, migration or deletion. Removing registration preserves every external file.
