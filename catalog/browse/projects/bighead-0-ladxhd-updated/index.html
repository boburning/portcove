Setup

  1. Use upstream preparation for your existing copy

    Keep a backup of your permitted original PC-port copy. Follow upstream Patching to the Latest Version: place its platform-specific patcher in that copy’s root, select the target platform/graphics backend, and apply the patch yourself. Keep the complete resulting game, Content and Data folders together. Portcove does not run the patcher, migration tool, signing script or installer during discovery or registration.

  2. Add the completed game executable

    For Windows, select Link's Awakening DX HD.exe from the finished game folder; for an already prepared native Linux copy, select Link's Awakening DX HD. Use that game folder as the working directory, review and save the launch details, then choose Play explicitly. The separate Launcher starts another player and exits; use upstream’s Launcher yourself for its configuration, mods and update features. macOS application-bundle preparation remains with upstream’s specific guide.

Setup notes
Preserve the actual game profile
Upstream’s Launcher and patcher own runtime replacement. On Windows, normal saves/settings/achievements and launcher state use %LOCALAPPDATA%/Zelda_LA, with SaveFiles/ under that profile; existing portable.txt mode instead uses the game folder. Mods normally stay in the game folder’s Mods/; an AppImage uses its external Zelda_LA/Mods profile. Preserve the actual profile, mods and permitted original assets before updating and keep the old working copy until progress is checked. Registration grants no managed Update, Backup or Rollback; removing it preserves all external files.
