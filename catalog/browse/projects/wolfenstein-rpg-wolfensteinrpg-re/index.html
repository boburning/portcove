Setup

  1. Keep the player and required libraries together

    The Windows release ZIP contains the 32-bit WolfensteinRPG.exe, SDL2.dll, zlib.dll and its README. Keep them together in a writable folder; Windows x64 can use the Win32 player. If OpenAL is missing, follow the packaged README’s official OpenAL 1.1 Windows Installer link and install it yourself. Portcove does not run that installer during discovery or registration. Linux has a separate x86-64 AppImage and an upstream CMake build route.

  2. Supply your matching original iOS archive

    Put your own matching original iOS archive, named Wolfenstein RPG.ipa, in the player’s working folder. This player expects Payload/Wolf...RPG.app/Packages/ and its sounds/ subfolder inside the archive. J2ME, BREW and other iOS bundle layouts are not substitutes. Keep your original archive intact and use upstream’s matching-data preparation; this guide supplies no game data or extraction workaround.

  3. Register the player, then choose Play

    On Windows, add WolfensteinRPG.exe with the folder containing your IPA as its working directory. For the Linux AppImage or a user-prepared native WolfensteinRPG binary, use a writable working directory containing that same required archive. Read-only discovery never runs the player or a helper; Play is a separate choice.

  4. Add the game and manage your files

    Register the real Windows player or already working Linux AppImage/native player with its matching working directory and separate literal arguments; do not select a converter, installer or updater as the game player. Complete any original-data or prerequisite setup deliberately through upstream instructions. Registration does not perform or authenticate that preparation, and Play is a separate explicit action. You and upstream own this external runtime, original files, saves, settings and profiles. Preserve the complete working copy and every actual data/profile location with the game closed before upstream replacement. Registration-only removal preserves all external files; managed Install, Update, Backup, Rollback, migration and external deletion are unavailable.

Setup notes
Preserve the writable game folder when updating
The player reads and writes local data under WolfensteinRPG.app/ relative to its working directory, separate from the similarly named app inside the IPA. Preserve that complete writable folder, original IPA and current working player before preparing an upstream update in a separate location. You or upstream own runtime updates. Portcove registration does not adopt, back up, roll back, replace or delete those files; removing the registration preserves every external file.
