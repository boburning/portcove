Setup

  1. Choose your own Muppet RaceMania USA disc image

    Choose Play. If no readable disc is configured, enter the full path to your own supported disc image in the game window. Keep the disc files outside the Portcove runtime. Choose a path without # so the game can remember it in its profile.

  2. Keep the original disc image separate

    Use your own USA Muppet RaceMania disc (SLUS-01237) as a supported CUE with its matching BIN, or the track BIN. Convert CHD upstream before Play. Keep the files at a stable location outside the runtime. The engine reads them during play and can warn about a nonmatching track digest.

  3. Prepare an external copy if you want custom paths

    Use the complete official Windows x64 package. Upstream specifies Windows 10 or 11 and a GPU with Vulkan or Direct3D 12. In an external copy, use the in-game disc prompt. Back up the actual AppData profile or your chosen data directory before replacing it.

  4. Select the prepared player

    Select rustmania-racing.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: the actual %APPDATA%/MuppetRaceMania profile, portable or custom profile, and the external original disc image. Back up these locations separately; registration does not migrate or certify their compatibility.
Managed runtime ownership
Portcove installs and replaces its separate official runtime using the declared release rules. Existing external registrations retain their files and user/upstream ownership. Runtime rollback carries current declared data; it does not rewind saves or establish older-runtime compatibility. Gameplay and populated-save compatibility remain separate qualification. Portcove preserves only these declared local inputs during replacement and backup: profile, crash.txt, disc-check.txt, save.bin, save.bin.bad, save.bin.tmp, settings.txt, saves. Its backup does not include external profiles.

Limitations and evidence

  • Gameplay and real save compatibility remain unverified. Keep the original disc image and back up any existing save separately.
  • This runtime starts with a separate profile and does not import your external AppData progress. If its profile folder cannot be created, the engine can write beside the player. Portcove preserves the declared fallback files as well. Use a prepared copy for custom paths. Runtime rollback does not establish save compatibility.
