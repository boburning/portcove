Setup

  1. Run the upstream Windows setup

    Open the download folder and run the portable Windows EXE yourself. It is a setup program: choose a folder for the upstream War1gus copy.

  2. Choose your original Warcraft files

    Start the installed War1gus player. When it asks, select the DOS game’s DATA.WAR file or your GOG offline installer. War1gus extracts the required data using its own setup tools.

  3. Use the installed player

    Select the installed player in Portcove, using its own folder as the start folder. Review the launch details and add the game, then choose Play.

  4. Keep the complete prepared runtime

    Finish extraction with upstream before registration. Keep war1gus.exe, its matching Stratagus engine, DLLs, scripts, campaigns and extraction tools together; the portable setup includes these components. Select war1gus.exe with its installed folder as working directory and leave arguments empty for the normal game. Do not select the downloaded setup program, war1tool.exe, a converter, the MIDI helper or uninstaller. The documented Windows launcher waits for its engine; Portcove supervises the selected launcher rather than adopting arbitrary replacement processes.

Limitations and evidence

  • The current extractor does not fully support demo, shareware or Mac original-game data; upstream reports that those extracted data sets fail to launch.
  • Preserve the complete actual locations with the creating runtime. Upstream version checks can trigger in-place extraction or migration; back up before changing versions and do not infer compatibility with older saves or different original editions. Demo, shareware and Mac data remain outside this supported preparation.
