Setup

  1. Use a separate Augustus copy

    Use the native package for your system in a separate folder; the Windows player is augustus.exe, Linux uses the AppImage and macOS uses augustus.app. On first Play, select your writable Caesar III game folder, patched to version 1.0.1.0.

  2. Add the game and manage your files

    Complete the upstream setup in your working copy before registration. Select the actual augustus.exe and its containing folder as the working directory; keep every packaged companion. Leave arguments empty for the normal upstream startup flow, or supply separate literal arguments only when deliberately following that version’s documented options. Registration binds your explicit executable, folder and arguments with consent; Play is a separate action. You and upstream own runtime replacement, original files, saves, settings and profiles. Close the game and preserve every actual data/profile location and the working player before upstream updates. Registration-only removal preserves all external files. Managed Install, Update, Backup, Rollback, migration and external deletion are unavailable.

Setup notes
Keep your game folder and saves
Augustus keeps saves in the selected Caesar III data folder and remembers its location in its own profile. Keep both when replacing the upstream runtime.
Keep the upstream Linux alternative
The upstream Linux package has its own native setup, game-data selection and profile rules. Follow those instructions for a Linux copy. Portcove offers registration for Windows in this entry; Linux operation through Portcove has not been confirmed.

Limitations and evidence

  • Augustus can read Caesar III and Julius saves, but Augustus saves cannot be loaded by Caesar III or Julius. Keep your original saves separate.
  • Keep both when replacing the upstream runtime.
  • Portcove offers registration for Windows in this entry. It downloads the Linux and macOS packages from upstream but has not run them.
