Setup

  1. Keep a complete stable Windows copy

    Use your independently permitted prepared Recharged Windows copy. The reviewed stable v1.1.1 route is distinct from test-pr prereleases. Keep recharged.exe, both game modules, assets, graphics DLLs and notices together in a writable folder. Finish upstream’s original-image selection and initial graphics preparation outside Portcove. The source-development bootstrap is not the game player.

  2. Select the player and keep its launch settings

    Select recharged.exe, use its complete program folder as working directory and leave arguments empty for the normal launcher. Use your own supported Mario Strikers Charged Wii image through upstream’s picker; the pinned install guide documents ISO, RVZ or WBFS for USA R4QE01 revision 1 or Europe R4QP01 revision 1 or 2. Renaming an image does not change its revision. Keep Advanced → Interface → Reopen after the game off ([launcher] reopen_after_game=false). Normal Play continues into the game in the selected process; that optional setting instead starts another launcher after the game ends.

  3. Keep upstream updates outside Portcove Play

    Perform upstream updates separately, outside a Portcove Play session: an update replaces program bytes and restarts another process. Review and relink the changed recharged.exe before the next Portcove launch. Registration records your selected native executable, working folder and literal arguments; Play is separate and supervises only that process. Removing the registration preserves every external file. Managed installation, runtime updates, backup, rollback, save migration and deletion are not offered for this copy.

Limitations and evidence

  • The project’s CC0 dedication covers its own contributions, not reconstructed game code, third-party components, original assets or trademarks. Use only a copy and originals you are permitted to use. Nintendo WFC is unavailable. Upstream gameplay and controller claims are not Portcove native or gameplay observations; image authenticity and cross-version save compatibility remain unqualified.
