Setup

  1. Set up the managed copy

    Use a separate official VCMI Launcher to import your own Heroes III game data into the default Windows profile. Close the launcher before choosing Play in Portcove.

Limitations and evidence

  • Heroes III Restoration of Erathia and the HD Edition are not supported; use Complete or Shadow of Death game data.
  • VCMI saves from different major versions are usually incompatible. Finish ongoing games or keep your current runtime and a profile backup before changing major versions.
  • Windows game data, saves and settings normally live in Documents/My Games/vcmi; back up that profile before changing VCMI versions.
