Setup

  1. Choose your game data

    Use the IWAD from your own Doom installation or a freely available Freedoom IWAD. Pass -iwad followed by the quoted path if you start the engine from a terminal. Keep doomretro.wad in the engine resources directory.

  2. Start DOOM Retro on Windows

    Extract the complete official x64 ZIP. Start doomretro.exe from that directory and choose your game data. Keep the support files with the executable. In the game console, discordpresence off disables the Windows Discord Rich Presence feature.

  3. Build DOOM Retro on Linux

    Use tagged upstream source, CMake and the SDL2 and SDL2_mixer development packages. Install the result into a local prefix so bin/doomretro and share/doomretro stay together.

  4. Find the Mac source build

    The upstream source includes a macOS build target. The v6.3 release supplies no Mac binary. Intel and Apple Silicon builds and runtime behavior still need verification.

Setup notes
Keep your actual configuration and saves
The Windows ZIP stores settings and saves beside the executable. An installed Linux build writes to ~/.config/doomretro, with saves grouped by IWAD under savegames. If your Linux home lacks ~/.config, create it before the first run so the player can make its profile. A portable build can write beside the executable.

Limitations and evidence

  • The upstream package or your external build owns runtime updates. Keep your game data separate and preserve the active profile before replacing the player.
