Setup

  1. Use your original disc and BIOS

    Use your own MediEvil (USA) disc (SCUS-94227) with both its data and audio tracks, and your own retail SCPH-1001 BIOS. Keep the original files separately.

  2. Build the managed Windows or Linux player

    In Portcove, select the complete matching CHD and BIOS. Keep both files in place. Choose Play after Portcove builds the game.

  3. Prepare a separate Mac copy

    Extract the official ZIP for your Mac into a writable folder. Check the release notes for its macOS minimum, Python version and Homebrew dependencies. The v0.1.5 setup host requires openssl@3, sdl3, freetype and harfbuzz. Make the Xcode Command Line Tools, CMake, Ninja and Python 3 available, then choose Generate & rebuild in the upstream setup host with your matching CUE, both BIN files and retail BIOS.

  4. Add the completed Mac player

    In Portcove, select build-release/MediEvil_Recompiled and use build-release as the start folder. Keep the complete working kit and its companion files. You manage replacement and backups for this copy.

Setup notes
Keep your saves and diagnostics
Close the game before backing up. Portcove retains the declared files of its managed Windows and Linux players. For a Mac copy, preserve the complete working folder, including saves, settings, installed mods and any diagnostic location named beside the player.

Limitations and evidence

  • Portcove checks the first data track and track count. Keep the complete disc intact.
  • The v0.1.4 playtest build records offline diagnostics by default, including starting memory cards, settings and inputs. Turn off Input Recording in that build to stop new recordings. The v0.1.5 standard kit omits the title's playtest diagnostics package. Review any capture or replay before sharing.
