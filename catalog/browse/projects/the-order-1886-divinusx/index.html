Setup

  1. Use the new-install archive

    Extract the Windows ZIP or Linux tarball to a writable folder. Keep the entry points and bin together. On Linux the launcher needs WebKitGTK 4.1 and the runtime needs glibc 2.39 or later and a Vulkan driver.

  2. Choose the original once

    Open The Order 1886, then select the supported extracted PS4 game on Game & Content. Use game update 1.02, required for v0.2.33. The publisher tested CUSA00785 USA with that update. Choose the folder containing eboot.bin, archivemap.bin, _data, sce_sys and sce_module. Press Play. The separate Play The Order 1886 entry on Linux starts the game with that saved folder and settings. Reopen the launcher to change them. Press F1 in the game to open its menu.

Setup notes
Preserve the shared profile
Keep user/order1886 beside the launcher. It holds settings, saves and logs. Use the publisher's new-install ZIP for manual Windows updates. The upstream launcher uses the separate go-windows archive for its own automatic update.

Limitations and evidence

  • The publisher reports actual play on Linux. The exact release notes identify physical Windows testing as unavailable. Portcove does not manage this runtime or protect its saves.
