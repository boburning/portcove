Phoenix Wright: Ace Attorney Trilogy (nxnative-aa-port)

An experimental nxnative-based Phoenix Wright: Ace Attorney Trilogy compatibility fork for Apple Silicon Mac and iOS. The project reports play and a save/load fix, with keyboard, controller and mouse-as-touch input; a complete collection playthrough is unconfirmed. There is no release package. Follow the Mac dm/host/dmhost source build with the title’s GAME setting and explicit patched-module, RomFS, shader, font and save paths; the iOS script builds an IPA. Use your own base game and 1.1.0 update for title 0100CB000A142000, prod.keys, patched_v196608 and matching extracted resources. Exact region and file hashes, compatibility across updates/saves and other desktop platforms are unconfirmed. You and the project manage rebuilding. Portcove offers no setup or launch integration and has not tested gameplay.
