Portcove downloads are held for the bundled Wolfenstein 3D shareware data. Debian-derived packages supply the C-Dogs campaigns without that bundle.

A release may contain research reports rather than a playable package.

Setup

  1. Install from your Linux distribution

    On Debian or Ubuntu, use your package manager to install cdogs-sdl. It brings in the matching C-Dogs data package and SDL libraries. Debian provides x86-64 and ARM64 packages. Start C-Dogs SDL normally from your applications menu or run cdogs-sdl. Your distribution handles software updates.

  2. Use a permitted Flatpak copy

    Flathub provides C-Dogs SDL for x86-64 and ARM64 as io.github.cxong.cdogs-sdl. Open it from your application menu. Flatpak owns its updates. The package includes the Wolfenstein 3D shareware files.

  3. Use an existing copy you have permission to play

    Keep the full copy, including bin, graphics, data, missions and libraries. On Windows, the publisher ZIP uses the 32-bit bin/cdogs-sdl.exe player. On Linux x86-64, the publisher tarball needs glibc 2.34 or later, SDL2 and SDL2_mixer. Open a terminal in bin and run ./cdogs-sdl so it finds the data in the parent directory.

  4. Register your existing Windows player

    In Portcove, choose bin/cdogs-sdl.exe from your permitted Windows copy and choose its bin folder as the working directory. Review the selected player and folder, then choose Play. Keep backups of the complete package and your actual C-Dogs profile. Removing this registration keeps those external files; you and upstream still own updates and backups.

Limitations and evidence

  • The publisher Windows, Linux and Mac packages bundle Wolfenstein 3D shareware. The Debian-derived data package excludes that bundle. Use only originals and additional campaigns that you have permission to use.
