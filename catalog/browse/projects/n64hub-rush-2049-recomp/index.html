Setup

  1. Keep the complete permitted Windows player

    Use an independently permitted completed Windows copy of this specific implementation; the reviewed upstream route is v0.1.54. Keep Rush2049Recompiled.exe, assets and all matching companions together. Finish any upstream source build outside Portcove. This is an existing-copy route, not managed package acquisition, source generation or a redistribution-rights grant.

  2. Select the native player and matching original

    Select Rush2049Recompiled.exe and use the completed runtime folder containing assets as working directory. Leave arguments empty for the normal launcher, then use Load ROM and Start Game at the separate Play step. Use your own San Francisco Rush 2049 N64 USA, big-endian .z64; documented SHA-1 3f99351d7bb61656614bdb2aa1a90cfe55d1922c. Arcade and Dreamcast editions are different inputs. The upstream player performs its own original check; Portcove registration does not import, normalize or authenticate the original.

  3. Review registration before choosing Play

    Portcove records your selected native executable, working folder and literal arguments after review; Play is separate. Only the selected process is supervised. You or upstream own updates and runtime replacement; relink changed executable bytes after reviewing them. Removing the registration preserves all external files. Managed installation, backup, rollback, migration, generation and deletion are not offered for this copy.

Setup notes
Keep the creating profile and portable mode
The reviewed Windows profile defaults to %LOCALAPPDATA%/Rush2049Recompiled. An existing portable.txt in the working folder selects that folder instead. Keep the creating mode and actual locations; adding or removing the marker does not migrate existing data. Keep the whole profile, cached original, all JSON settings, controller profiles, mods, generated textures and logs. Controller Pak files are saves/controllerpak_<port>.mpk under that profile. Preserve any actual linked save targets and their adjacent temporary files too; these remain external data. The normal log is rush2049.log with rush2049.old.log beside the settings. Preserve the complete runtime folder and any custom or external paths too. Edit settings only while the player is closed; registration does not move profiles or certify state compatibility between versions.
