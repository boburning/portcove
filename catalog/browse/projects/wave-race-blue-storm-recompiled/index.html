Setup

  1. Prepare upstream or keep an existing game build

    Follow upstream's recursive gcnrecomp/build guide with your own GWRE01 USA Wave Race: Blue Storm disc. The Windows player is build/waverace.exe; use the repository root as working directory. Before Play, use the configured original image or keep only the intended .iso in rom/; alternatively set the image-path argument in Change launch details. Use the ordinary invocation unless you deliberately prepare optional VR. Preserve saves/memcard_a.raw as actual player data outside Portcove backup; shader cache is separate. Upstream prohibits redistribution of the game-derived output. Keep the prepared source/data/runtime together; this project offers no complete game package for Portcove to replace.

  2. Keep your files and update through upstream

    Keep the game in a separate folder you control, and retain a working copy. Review its executable in Portcove, then add it without changing its files. Choose Play separately when you are ready. You manage updates, original files, generated data, saves and settings. Portcove does not replace, back up or roll back this external copy. Follow the project’s instructions for the version you use when changing it.

Setup notes
Build on Windows or an Apple silicon Mac
Follow the pinned upstream guide with CMake, Ninja and Python. Run build.ps1 on Windows x64 or ARM64 with Clang and the Windows SDK and C++ tools. On Apple silicon, use build.sh with Xcode or its command line tools and SDL2. Start build/waverace.exe on Windows or build/waverace on Mac from the repository root.
Keep the matching original and memory card
Use your own USA GWRE01 image. The build checks SHA-1 d500d8f5bab39ae5fed67d0a0864095a9ea190d9 for the disc’s main.dol. Keep the configured image available at runtime. Preserve saves/memcard_a.raw and any input recordings that include memory-card copies. Keep game-derived code, binaries and saves private.
Build for a Quest 3
Follow upstream’s Windows build-android.ps1 and package-apk.ps1 instructions with the Android SDK, NDK and JDK. Install your private build on your own headset after enabling developer mode. Keep game.iso and the memory card under Android/data/com.ethannicholas.waverace/files, along with any vr.txt settings. The APK and original disc are separate.
Build for Apple Vision Pro
Follow build-visionos.sh on a Mac with Xcode 26 and the visionOS SDK. Use your own Apple development team and paired headset in Developer Mode. Select the owned image in Files or use upstream’s push option. Keep the disc, memory card, settings and logs in the app’s Documents folder.
