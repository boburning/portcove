Setup

  1. Prepare upstream or keep an existing game build

    Follow upstream's recursive gcnrecomp/build guide with your own GWRE01 USA Wave Race: Blue Storm disc. The Windows player is build/waverace.exe; use the repository root as working directory. Before Play, use the configured original image or keep only the intended .iso in rom/; alternatively set the image-path argument in Change launch details. Use the ordinary invocation unless you deliberately prepare optional VR. Preserve saves/memcard_a.raw as actual player data outside Portcove backup; shader cache is separate. Upstream prohibits redistribution of the game-derived output. Keep the prepared source/data/runtime together; this project offers no complete game package for Portcove to replace.

  2. Keep your files and update through upstream

    Keep the game in a separate folder you control, and retain a working copy. Review its executable in Portcove, then add it without changing its files. Choose Play separately when you are ready. You manage updates, original files, generated data, saves and settings. Portcove does not replace, back up or roll back this external copy. Follow the project’s instructions for the version you use when changing it.
