Saints Row (Saints Reborn)

Saints Reborn is the renamed SaintsRowPC implementation, retaining its existing updates. The project claims start-to-finish story, side missions and free roam, with multiplayer issues remaining. SaintsReborn-Setup.exe downloads compiler/tools, imports your own 2006 Xbox 360 Saints Row disc and builds locally, creating play/update shortcuts. Setup or UpdateSaintsReborn manages replacement. Windows x86-64 is documented; Linux setup is explicitly planned rather than available. Exact accepted revision/hashes and BIOS/firmware needs are unconfirmed. Portcove has not qualified a release package or confirmed setup or gameplay.

Setup

  1. Finish the supported upstream game setup

    Use your own 2006 Xbox 360 Saints Row disc ISO or supported extracted folder containing default.xex and packfiles. Complete SaintsReborn-Setup.exe and its local toolchain/build first. Only the disc executable revision the port was made with is supported; setup warns about a different default.xex. An exact accepted original-file digest is not established by this guide. No private game import, compiler execution or source compatibility is performed by Portcove.

  2. Keep the complete prepared distribution

    Retain the full existing installation with dist/WhompaysModLoader.exe, dist/saintsrow.exe, libraries, core files, game data, notices and existing mod configuration. Use the documented Windows x86-64 setup/runtime prerequisites. SaintsReborn is the SaintsRowPC rename, not a new independent save or installation identity. Linux setup remains a separate upstream development claim. Project, framework, original-game and optional mod permissions remain separate.

  3. Add the normal upstream launcher

    Select dist/WhompaysModLoader.exe, set its containing dist directory as working directory and leave arguments empty. Review the selected program, folder and arguments, then choose Play when ready and use the launcher’s normal Play control. The launcher manages mod selection and starts saintsrow.exe in dist. The direct dist/saintsrow.exe player with the same working directory and empty arguments is a separate upstream choice. Do not select setup, update helpers or a script interpreter as the player.

  4. Preserve saves, profiles and mod choices

    Keep the entire populated dist/game directory, dist/mods with mods/modlist.ini, dist/core, settings, original/generated files and any existing data-path choices. The normal game defaults to game beside its executable and supports upstream game_directory context; preserve an existing nondefault route. Do not activate unknown Lua/DLL mods, reset a mod list, move saves or merge profiles merely to add the library reference. Controller, save and multiplayer behavior remain unobserved here.

  5. Keep upstream ownership after launch

    The native mod launcher hands off to the game and may exit while the game continues. Portcove observes only the selected launcher, so a finished activity does not prove the game or helpers are closed. Quit them before using Setup or UpdateSaintsReborn for replacement, rebuild or recovery. Upstream maintains runtime and mod compatibility; review/select the executable again after changes. Removing the reference preserves external files. No managed installation/update/backup/rollback, full-session tracking or Supported qualification is supplied.

Limitations and evidence

  • Select the completed dist/WhompaysModLoader.exe with dist as working directory, or the documented direct saintsrow.exe choice. Preserve dist/game and the existing mod list; launcher handoff can outlive Portcove’s activity.
