Setup

  1. Install Colobot

    On Windows x64, extract the whole ZIP into one folder and run colobot.exe there. On Linux x64, use your distribution’s package or mark the publisher’s AppImage as executable and open it. Flathub offers a community package for Linux x86-64 and ARM64. On Intel Mac, open the disk image and copy Colobot to Applications. The publisher’s Mac build is Intel-only. It needs Rosetta on Apple Silicon where Rosetta is available.

  2. Start or resume a mission

    Create or choose a player, open Missions, and choose a mission. Press Escape during play and choose Save to keep your progress. To resume, choose the same player, open Missions, and use Load to select the saved mission.

Limitations and evidence

  • Close Colobot before backing up or restoring its data. Keep the whole profile folder, including colobot.ini and savegame. If you set COLOBOT_SAVE_DIR or started with -savedir, back up that folder too.
