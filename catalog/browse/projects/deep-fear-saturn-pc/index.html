Setup

  1. Prepare upstream or keep an existing game build

    Use both of your own complete Europe MK-81804 V1.001 (1998-07-13) cue/bin disc sets with upstream's recursive saturnkit checkout. Its CMake/Ninja, clang and SDL3 preparation needs both extracted discs and audio. Run any documented tools/run.py --play command deliberately from the repository root; discovery does not invoke it. The reviewed milestone reaches the first room and walking, not a packaged full-game release. Register only a native game output you have prepared with its required working folder, not a Python disc or compiler tool.

  2. Keep your files and update through upstream

    Keep the game in a separate folder you control, and retain a working copy. Review its executable in Portcove, then add it without changing its files. Choose Play separately when you are ready. You manage updates, original files, generated data, saves and settings. Portcove does not replace, back up or roll back this external copy. Follow the project’s instructions for the version you use when changing it.
