Setup

  1. Finish setup in the upstream Android app

    The upstream guide describes this Android ARM64 setup: CHOOSE ROM for your own Yoshi’s Island: Super Mario Advance 3 USA ROM, CHOOSE BIOS for your own GBA BIOS, then PLAY. It identifies the 4,194,304-byte ROM by SHA-1 7352d2bd064d9ebaec579e264228aa21c7345b80 and the 16,384-byte BIOS by SHA-1 300c20df6731a33952ded8c436f7f186d25d3492. The published APK names a different version from that guide, so check its release instructions before changing a working copy. Portcove supplies neither original file.

  2. Keep your data when changing versions

    The published APK and setup guide name different versions (0.10.6 beta and 0.4). The input and save-transfer details for that APK are still being checked. Keep existing saves, app data and your originals separately before changing builds; a locally signed build cannot update a differently signed app in place. Preserve a working copy’s data before any uninstall required by a signing change.
