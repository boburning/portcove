Super Mario 64 (Super Mario 64: Recompiled)

A Super Mario 64 recompilation separate from matching-decompilation ports. The project reports Bob-omb Battlefield through the King Bob-omb star and a return to the castle, rather than a complete campaign. Windows/Linux x86-64 packages and a WebGPU browser route are documented. Linux needs glibc 2.35+, Vulkan, GTK 3 and FreeType. Use your own USA N64 ROM with SHA-1 9bef1128717f958171a4afac3ed78ee2bb4e86ce. Further accepted revisions and BIOS/firmware needs are unconfirmed. You and the project manage setup and updates; Portcove has not qualified a release package or confirmed setup or gameplay.

Setup

  1. Keep the complete permitted Windows player

    Use an independently permitted completed Windows copy of this specific implementation; the reviewed upstream route is v0.1.2. Keep the player, assets and all matching companions together. Finish any upstream source build outside Portcove. This is an existing-copy route, not managed package acquisition, source generation or a redistribution-rights grant.

  2. Keep the matching original

    At the separate Play step, use Load ROM and Start Game in the upstream launcher. Use your own Super Mario 64 USA, big-endian .z64; documented SHA-1 9bef1128717f958171a4afac3ed78ee2bb4e86ce. The upstream player performs its own original check; Portcove registration does not import, normalize or authenticate the original.

  3. Select the prepared player

    Select SuperMario64Recompiled.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Setup notes
Registration ownership and removal
Portcove records the selected executable, working folder and literal arguments after review. Play is separate and only the selected process is supervised. You and upstream own replacement and updates; relink changed executable bytes after reviewing them. Removing this registration preserves every external file. Managed installation, backup, rollback, migration and deletion are not offered for this external copy.
Player-data ownership
You and upstream own the external copy's data: %LOCALAPPDATA%/SuperMario64Recompiled, or the existing portable.txt working-folder mode; whole creating profile including original/EEPROM data, JSON settings, controllers, mods and hires_font; custom or external paths. Back up these locations separately; registration does not migrate or certify their compatibility.

Limitations and evidence

  • Upstream reports Bob-omb Battlefield through King Bob-omb and return to the castle. Full-campaign, gameplay, physical controls and save compatibility are not established by this registration.
  • Use only software and original data you are permitted to use. Registration and owned-probe tests do not certify the upstream binary, full-game behavior or real save formats.
  • Keep the creating mode and actual locations; adding or removing the marker does not migrate existing data.
  • Edit settings only while the player is closed; registration does not move profiles or certify state compatibility between versions.
