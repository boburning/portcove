Setup

  1. Prepare the game from your Xbox disc image

    On Windows, use MM3-Setup.exe. On Linux, extract the tarball and run sh install.sh from the extracted MM3-Linux folder. Linux needs Python 3.9 or newer, a Vulkan driver, and python3-tk if you use the setup window. Use your own original USA or Europe/Australia disc image. Check the release’s supported disc notes for other regions.

  2. Play again and reopen settings

    Use the installed Midtown Madness 3 shortcut. For Steam or another frontend that accepts scripts, use mm3_recomp.exe on Windows or play-midtown-madness-3.sh on Linux. Add --play to start the game directly or --settings to open settings.

Setup notes
Back up the installation’s player data
Your saves stay in game_files inside the installation. Keep that folder and display.ini, launcher.ini and language.ini. On Windows, use the project’s update control. On Linux, download the new tarball from the project and install it over the existing installation to keep saves and settings.

Limitations and evidence

  • Back up the game’s files yourself before replacing or removing an installation.
