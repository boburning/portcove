Setup

  1. Prepare upstream or keep an existing game build

    Use your own complete Europe MK-81380 V1.000 (1995-06-30) cue/bin track set with upstream's current saturnkit source guide. Follow its compiler/SDL3 preparation from the repository root and keep extracted data plus audio with the resulting native player. The reviewed milestone provides video, input and sound with upstream's interpolation and remaining limitations. Register only a prepared native game output with its actual working directory. Portcove runs no disc or recompiler helper during discovery.

  2. Keep your files and update through upstream

    Keep the game in a separate folder you control, and retain a working copy. Review its executable in Portcove, then add it without changing its files. Choose Play separately when you are ready. You manage updates, original files, generated data, saves and settings. Portcove does not replace, back up or roll back this external copy. Follow the project’s instructions for the version you use when changing it.
