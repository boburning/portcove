Setup

  1. Complete supported preparation upstream

    Use a complete FFTARecomp copy and components you are permitted to use. Complete the official upstream Installer.exe preparation in a writable folder first; select the resulting installed FFTARecomp.exe, not Installer.exe or the payload template. The v3.0 package carries both FFTARecomp.exe and recomp.exe. Keep them, gamedb.sqlite, TinyCC/compiler support and their applicable notices together. Upstream owns setup, native translation/cache generation and replacement; Portcove does not run the installer or build the game.

  2. Keep the exact owned original

    Use your own supported original FFTA USA ROM (SHA-256 43fc8204c6dceee58828aebc7af0c72eb807e99f35ad641c8bb0a4fa8b6edc19) or Europe ROM (8fab1e390cb9d5e695bfdb86e81246892e1aa8c0cb4014db8235ff76538ea632). v3 source supports both, despite older USA-only README wording. No BIOS is needed. The installer can warn and install an unverified image without FFTA patches; this guide covers only the ROM hashes above. A completed installation does not mean an unknown ROM matches either edition.

  3. Attach the supported prepared player

    Select the completed installed FFTARecomp.exe with its installed directory as working directory and no arguments. This supported wrapper finds its adjacent ffta.gba or the LocalAppData/FFTARecomp fallback, starts its matching recomp.exe play and waits for that initial game process to exit. Keep the exact prepared tree and private generated translations.

  4. Keep optional successor sessions separate

    The optional in-game Switch ROM operation deliberately starts a successor process and ends the current game. The attached wrapper does not wait for that successor after its initial child ends. Treat switching as upstream activity outside this attached session: close every actual player before replacement or another attachment. Do not infer successor tracking, adoption or termination from the registration’s status. Keep the feature intact; no argument or private entry is used to disable or bypass it.

  5. Review Play and retain external ownership

    Review and consent to the exact selected executable, established working directory and literal arguments, then choose Play separately. Removing registration preserves external files. Upstream and you retain one runtime-replacement owner; Portcove provides no external update, backup, rollback, migration or deletion. Close actual players and companions before deliberate maintenance, keep the old working copy and all effective data, then review/relink changed selected bytes.

Setup notes
Preserve the whole copy and effective data
Preserve the installed tree and originals, %LOCALAPPDATA%/FFTARecomp data and shared-save-path.txt, %APPDATA%/FFTARecomp/input.cfg and av.cfg, and every effective custom root. Saves resolve FFTA_SAVE_PATH first, then a remembered existing save, then the ROM basename .sav; one neighboring .sav may be chosen and several open a picker. Normal gameplay writes the chosen save. Keep old saves and creating runtime: upstream cross-region compatibility claims and a shared path are not Portcove save qualification. Preserve caches/FFTARecomp translated libraries, mods, logs and backups; upstream may sweep superseded translation-revision caches. MIT project code, MIT/Apache foundation, CC0 gamedb, TinyCC LGPL and font/dependency notices apply separately; code grants do not grant ROM or third-party artwork rights.

Limitations and evidence

  • Use only a copy and components you are independently permitted to use. Portcove has not confirmed that the installed player matches the source, or tested gameplay, saving or installed behavior. Preserve every original, runtime, save, setting, mod, cache, backup and custom location; another executable can share the same data.
  • Normal gameplay writes the chosen save. Keep old saves and creating runtime: upstream cross-region compatibility claims and a shared path are not Portcove save qualification.
  • Preserve caches/FFTARecomp translated libraries, mods, logs and backups; upstream may sweep superseded translation-revision caches.
