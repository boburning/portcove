Setup

  1. Windows x64 separate upstream copy

    If you already have a permitted Open Nectar 1.3 or 1.1.1 Windows x64 copy, run nectar-launcher.exe from a separate folder outside the Portcove library. Choose Install under Pikmin, provide your own supported USA Rev. 1 or Europe disc and choose a separate writable destination. Keep verification enabled. Preserve the installation and its active config folder or LOCALAPPDATA/Open Nectar.

  2. Linux x64 upstream launcher

    For a permitted 1.3 or 1.1.1 Linux x64 copy, extract nectar-linux.tar.gz and open nectar-launcher, or make Open_Nectar-x86_64.AppImage executable and open it. The 1.3 package needs glibc 2.30 or newer. Use OpenGL 3.3 and zenity or kdialog for the file picker. Choose Install under Pikmin, select your own USA Rev. 1 or Europe ISO or GCM and a separate writable folder. The launcher can use Dolphin Tool for RVZ, WIA and GCZ. Keep disc verification enabled. After setup, use the launcher in the selected installation for Play and updates.

  3. Android ARM64 upstream launcher

    For an already permitted 1.1.1 Android ARM64 copy on Android 11 or later, allow All files access for its chosen data folder. Use Install under Pikmin with your own matching ISO or GCM. The default folder is OpenNectar in shared storage. Pikmin 2 uses its own disc and setup.

  4. Android ARM64 1.2 and 1.3 data folder

    For an already permitted 1.2 or 1.3 copy, use Android 10 or newer and OpenGL ES 3.0. On Android 10 grant the storage permission. On Android 11 or newer use Allow access to all files. Choose a writable folder in shared storage outside the Android folder. The default is OpenNectar in shared storage. Choose Install under Pikmin and select your own matching ISO or GCM in the system picker. Preserve your selected folder and export the memory cards before updating.

  5. Set up a separate Apple Silicon copy

    For a permitted Open Nectar 1.3 copy, extract nectar-macos.tar.gz on Apple Silicon with macOS 11 or newer. Follow the bundled README.txt for first launch, then open nectar-launcher. Choose Install under Pikmin and supply your own matching USA Rev. 1 or Europe disc and a writable installation folder. Use the launcher in that installation for later Play and updates.

  6. Build a separate Intel Mac copy

    With an already permitted 1.2 source checkout, use Xcode Command Line Tools, CMake and a Mac with OpenGL 4.1. Follow scripts/build-macos.sh. It builds both Pikmin regions and also builds a separate Pikmin 2 player. Start build/pikmin1/bin/nectar-launcher, choose Install under Pikmin and select your matching disc and a writable destination.

  7. Keep the creating installation and data

    Close the game and launcher before copying their data. On Linux preserve the installed folder, including saves, and the active settings location, either its config directory or open-nectar under XDG_CONFIG_HOME (usually ~/.config). On Android retain the actual chosen data folder and use the upstream export for memory cards. The card ZIP covers the cards only.

Setup notes
Keep the Mac and Android data you actually use
On Mac keep the selected installation, its saves and the active settings folder. The launcher defaults to pikmin-native under XDG_DATA_HOME, or ~/.local/share/pikmin-native. On Android preserve the actual chosen OpenNectar folder and export the memory cards before replacing the copy. The card export covers only the cards.

Limitations and evidence

  • Use only a copy and bundled components you are already permitted to use. The upstream CC0 notice excludes Nintendo and other third-party material, and the package includes a separate Pikmin 2 runtime. An attributable grant for that bundled game code or a separately qualified package is needed before fresh acquisition can be offered.
  • Keep the player-managed folder outside Portcove's managed installation. Preserve the creating installation and profile. The existing managed Windows acquisition hold remains in place.
