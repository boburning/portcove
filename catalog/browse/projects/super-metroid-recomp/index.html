Setup

  1. Preserve the older copy and exact original

    Use your own exact unchanged headerless Super Metroid (Japan, USA) original, SHA-256 12b77c4bc9c1832cee8881244659065ee1d84c70c3d29e6eaf92e6798cc2ca72. Keep the original unchanged outside the new player folder and place a matching copy named game.sfc in that folder. A headered, modified or other-region file is a different input. No original is supplied or downloaded; upstream handles its input recognition. Portcove registration does not authenticate this original or package. Keep every older runtime and its complete data separately; these instructions do not upgrade or adopt them.

  2. Prepare the separate Preview player

    Open the linked v0.3.16 Preview release page and use its official Windows x64 ZIP in a new writable folder. Keep SuperMetroidSNESRecomp.exe, packaged config.ini, assets, framework pins, notices and all other companions together inside supermetroid-0.3.16-windows-x64. Use the packaged defaults without old configuration, states, mods, donor assets or developer/path overrides. Finish upstream setup deliberately. Register that folder’s SuperMetroidSNESRecomp.exe with the same containing folder as working directory and two literal argument lines: --rom then game.sfc. Do not select replay_diagnostic.py or a source/build helper as the player.

  3. Choose Play and manage updates through the project

    You and upstream own this external package and its data. Play is explicit; removing its Portcove registration preserves the external files. Managed Update, Backup, Rollback, migration and external deletion are unavailable for this copy. Settings changes can restart into a successor game window while the initial registered process exits. Do not rely on that initial process’s completion as proof that every game copy has stopped: close all windows/processes before copying or replacing runtime or data. Keep the shipped PolyForm Noncommercial and dependency notices; do not run Generate & rebuild, debug/replay helpers or extra mods as part of these instructions. A Portcove library containing any managed installation of this identity cannot also attach this external copy. Keep that managed installation and use the new upstream copy directly, or register only in a separate library with no managed installation, other registration or pending launch for this identity. Do not remove an older managed runtime or kept data just to enable registration.
