Super Mario Odyssey (smo-recomp)

An early Super Mario Odyssey port translating AArch64 code to C in a game DLL with a native Windows Vulkan player. It claims no interpreter/JIT or running firmware. Scripted Cap Kingdom and short stress tests are separate from manual Cap-to-Cascade checkpoint play. Some observations concern 1.0.0 rather than 1.4.1; update additions are untested, and online play is unavailable. There are no releases: local preparation uses LLVM 9, VS2019 SDK, Vulkan SDK, SDL3 and Python. Windows 10/11 x64 needs Vulkan 1.3 and the documented extensions; development used RTX 4090. Supply your own decrypted 1.4.1 updated program, merged RomFS and update control data. Keys and firmware are explicitly unnecessary for that extracted route; exact region/build hashes and other desktops are unconfirmed. Portcove offers no setup or launch integration and has not tested gameplay.
