Setup

  1. Get the original SkiFree file

    Get ski32.exe from Chris Pirih’s site at https://ski.ihoc.net/#download. Keep that original file in a separate folder. The upstream installer builds SkiFree using this file.

  2. Prepare and play a desktop build

    Open the installer for Windows x64, Linux x86-64 or Apple Silicon with macOS 15 or later. Choose the folder containing ski32.exe. Open Choose what to build, select This computer and start the build. Select Play when the build finishes. Keep the generated launch script with its build folder so it can find the game files.

Setup notes
Open the installer for the first time
The upstream Windows and Mac installers can prompt on first launch because they lack a trusted publisher signature. If your system blocks the installer, see the publisher’s first-launch instructions.
Install build dependencies
On Windows the upstream installer may install Python, CMake, Visual Studio Build Tools and SDL2. On Linux install a C and C++ compiler, CMake, Python 3, pkg-config, SDL2 and SDL2_ttf development files. The Linux installer needs glibc 2.34 or later and uses zenity or kdialog to select folders. On Mac use Homebrew and Xcode’s command line tools.
Build for Intel Mac or Android
The release publishes an Apple Silicon installer. For Intel Mac, use the tagged project’s setup.sh and its documented build dependencies. Android is a separate target in the upstream installer and uses Docker to build an APK from your original file. An APK is not included in the release.
Keep files created by the game
Before rebuilding, close the game and copy skifree.ini, skifree_save.json and skifree.replay if present. Look in the working folder used by the launch script. The upstream installer owns preparation and replacement of the runtime.

Limitations and evidence

  • The Linux v0.4.0 build can create skifree_save.json, but File > Load crashed when opening that saved run. Keep a backup of the file for a later version with working load.
