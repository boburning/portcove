Setup

  1. Select the original Vyruz data

    Keep your own vz-data.rsc in a writable original-game folder outside the engine. Intro.avi in the same folder is optional. The original and this player can both write vzconf.txt, session and vz.sco there. Back up that whole folder before starting.

  2. Start the Linux player

    The v1.1.0 Linux x86-64 tar.gz contains Vyruz. Use a Vulkan driver and loader, glibc 2.38 or later, and libstdc++ with GLIBCXX_3.4.31. The picker uses zenity or kdialog. You can pass the original archive or folder to the upstream executable if the picker is unavailable.

Limitations and evidence

  • Keep your original folder and effective user profile. A runtime backup cannot restore files stored in those external folders.
