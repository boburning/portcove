Setup

  1. Choose the Windows package that matches your original

    Use the official USA Windows x64 ZIP with your Japan/USA Rev 1 original for the Portcove registration route. For an original European ROM, use the official EU Windows x64 ZIP and its upstream player.

  2. Set up the Windows player

    Extract the full ZIP with its DLLs and assets. Open DrMarioRecomp.exe from that folder and select your own matching original. Keep the USA NTSC and European PAL copies and their profiles separate.

  3. Register your prepared USA copy

    After setup, close the player. In Portcove select DrMarioRecomp.exe and its extracted folder. Add the original ROM’s full path as one argument line without quotes. If you leave the argument empty, keep the upstream launcher enabled.

  4. Build the Linux player from upstream source

    On Linux x86-64, use the upstream source and its pinned submodules, CMake, a native C/C++ toolchain and system SDL2 development files. Set SDL2_DIR to the system SDL2 CMake package and NESRECOMP_ROM to your matching original. Set DRMARIO_REGION to usa or eu and use separate build folders. Launch the result through the upstream instructions.

  5. Keep your player data

    Back up the actual settings and saves with the game closed before updating the upstream player. Keep cycle save states with their creating build and region. Removing a Portcove registration leaves the player, original and profile in place.
