Setup

  1. Check the required game files

    Use your own GoldenEye 007 Nintendo 64 USA ROM. Check the required size and SHA-1 in games/goldeneye-us/profile.toml before importing. Keep the original separately. These instructions do not download or run it.

  2. Build from source on Linux

    Follow the upstream Linux prerequisites. From the checkout root, run .venv/bin/python tools/import_rom.py --profile games/goldeneye-us/profile.toml --rom "/path/to/your-ROM.z64" with your own .z64, .n64 or .v64 file. Run cmake --workflow --preset goldeneye-us-release, then ./build/goldeneye-us-release/bin/goldeneye-us. The default keeps the ROM external. Keep the ROM and any locally generated game code private, including builds that embed it.
