Setup

  1. Choose your game data

    Use the IWAD from your own Doom installation or a freely available Freedoom IWAD. Pass -iwad followed by the quoted file path when starting the engine directly. Keep the full base folder supplied by the package or generated by the build.

  2. Start Eternity on Windows

    Extract the official x64 ZIP into its own directory and open eternity.exe. The release also provides a separate 32-bit ZIP.

  3. Start Eternity on a Mac

    Choose the separate Intel or Apple Silicon disk image and copy the complete Eternity Engine.app. In 4.06.00, the Intel launcher and engine require macOS 10.15 or later. The Apple Silicon launcher and engine require macOS 11 or later.

  4. Install Eternity on Linux

    Use a distribution package if available or follow the upstream CMake build instructions. Nixpkgs carries the eternity package. The publisher's 4.06.00 release has Windows and Mac binaries. For a Linux source build, include the pinned submodule, use an out-of-tree build and keep the generated base and user folders.

Setup notes
Configure a source build with CMake 4
Install the SDL2, SDL2_mixer, SDL2_net, OpenGL and zlib development packages. With CMake 4, add -DCMAKE_POLICY_VERSION_MINIMUM=3.10 to the configuration command for the older bundled build files.
Keep the actual user directory
For an explicit Linux profile, use -user followed by the path to a complete user directory. Preserve that directory for settings, screenshots and per-game saves such as doom/etersav0.dsg. Keep it with the version and IWAD that created the save.

Limitations and evidence

  • The package manager or your external installation owns runtime updates. Preserve your original IWAD, mods and profile before changing the engine or game version.
