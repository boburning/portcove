Setup

  1. Check the required game files

    Use your own original-Xbox Burnout 3: Takedown ISO. Keep the extracted default.xbe beside Data/Tracks/ovid and every other disc file. The reviewed README does not establish the exact supported retail revision or hash; check the project’s requirements before setup.

  2. Follow upstream setup

    Windows Burnout3-Installer-windows-x64.exe or Setup.cmd imports own ISO, fetches xboxrecomp toolkit pinned afeb69f, generates C and compiles locally with VS2022/CMake/Python3.10+/capstone/Git. First generation/build roughly1–2hours; setup can provision missing tools.
