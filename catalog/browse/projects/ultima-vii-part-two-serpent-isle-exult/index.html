Setup

  1. Use this original game and edition

    Use your installed original Serpent Isle data, especially its complete STATIC folder. Silver Seed is optional and remains a separately owned add-on. Black Gate data does not supply Serpent Isle. Keep your originals elsewhere unchanged; upstream handles its own data recognition and preparation. A Portcove registration does not authenticate original-game files.

  2. Prepare upstream and select the real player

    Choose the official Windows installer from Exult’s download page, or keep a complete upstream-prepared player with its runtime data. Configure this installed game’s path in Exult, keeping Black Gate and Serpent Isle entries distinct. Register exult.exe with its installation folder as working directory, using the upstream game picker or the documented single argument --si. Do not register Exult Studio or a usecode/compiler helper as the player.

  3. Set up the upstream Linux package

    Install info.exult.exult from Flathub and open it once to create its sandbox folders. Put this game’s own STATIC directory in ~/.var/app/info.exult.exult/data/serpentisle or configure the actual working path. Preserve the sandbox config, serpentisle data, saves and gamedat. A native non-Flatpak Exult uses a separate profile, normally ~/.exult.cfg and ~/.exult/serpentisle.

  4. Prepare the official Mac app

    Use Exult’s official Intel/Apple Silicon DMG. Keep the complete app and point it to your own Serpent Isle installation. The documented default original folder is /Library/Application Support/Exult/serpentisle. Back up ~/Library/Preferences/exult.cfg, ~/Library/Application Support/exult/serpentisle, and every custom savegame, gamedat and mod location before replacing the app.

  5. Import this edition in the Android launcher

    Choose the official Android APK under the stable release on Exult’s download page and check its Android version requirement. Zip your own Serpent Isle STATIC folder and its contents, then choose the matching game in the upstream launcher and select that ZIP. Exult installs the files in its app-private serpentisle/static directory. Keep your original ZIP separately. It does not contain Exult’s settings or saves. Use an in-place update from the same signer and keep the app data intact unless you have a verified backup of the actual profile.

  6. Add the game and manage your files

    Finish setup with the project’s tools before adding the game. Portcove saves your selected executable, working folder and launch arguments; choose Play separately when you are ready. You manage this game’s files, original files and profile. Removing its registration leaves those files in place. Portcove does not offer updates, backups, rollback, data migration or file deletion for this external copy. Keep a working copy and its data before changing versions. Other platforms need their own supported application and setup instructions.

Setup notes
Keep your originals and game data
On current Windows, exult.cfg normally lives under the actual Local AppData/Exult folder. Preserve the complete Exult profile and each game/mod’s configured savegame and gamedat locations, including any path overrides and original STATIC data. Keep optional add-ons separate from base-game choices. Close all copies before upstream updates; preserve the creating runtime until its game/mod saves work in a replacement.
Set up this edition on iPhone or iPad
Use Exult’s TestFlight build if you receive an invitation, or build the pinned 1.12.1 source yourself in Xcode for iOS or iPadOS 13 or later. Prepare a game folder with your own Serpent Isle files under game/serpentisle/static. Use lowercase for every file and folder name, then copy the complete game folder into the app with Finder or iTunes file sharing. Keep the app’s Documents folder, including its settings, saves and autosaves, before changing the app. The iOS guide is at https://exult.info/docs.html#iOS-Guide.
