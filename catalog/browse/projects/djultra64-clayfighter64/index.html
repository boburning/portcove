Setup

  1. Supply both exact owned games

    This combines ClayFighter63⅓ gameplay with Sculptor's Cut donor characters; it does not recreate all of Sculptor's Cut. Supply your own ClayFighter63⅓ USA and ClayFighter:Sculptor's Cut USA ROMs. After normalization to big-endian z64, their SHA256 values must be 357f26c6cd72559c5c05e8c2df46369624630dbcb1c02b3b6f3338f6ac79af07 and 9ccebc317b7ee892be3bdc0d1c8ae46687995908ed51ebd58d6855e5e25abd7f, respectively. Keep both originals separately. Other regions, revisions and modified ROMs are unsupported. Upstream preparation handles supported byte orders or a single-ROM ZIP.

  2. Complete upstream asset installation

    Use a complete v2.1.1 Windows x86-64 copy you already have. The GPL licence for authored port code does not cover packaged branding, depicted original characters or the title announcement, whose source is unknown. On Windows 10/11 x64 with an SSSE3/SSE4.1 CPU and current Vulkan drivers, run Install Assets.vbs outside Portcove and finish asset installation. The included Python runtime checks both inputs and creates local imported files. Keep all supplied DLLs, configuration, notices and assets together.

  3. Select the prepared native player

    After successful installation, select clayfighter64.exe in the complete portable package root, set that root as working directory and use literal arguments --rom probe-output/base.z64 --sc-assets local/sc_roster/asset-image-roster.z64. These are the same native arguments used by the upstream Play wrapper. Do not select VBS/CMD/Python installers or unfinished data. The native player owns the game window and normal game loop. Saving launch details and requesting Play require separate consent.

  4. Keep portable custom profiles inside the game

    Display, native game options, P1/P2 controls and training settings live in local/settings/ by default; graphics caches live under local/cache/. The executable locates its installation from its own directory/config and changes CWD to it. Optional --data-dir or --user-data selects a profile only inside that installation; outside paths and escaping symlinks are rejected. --controls imports a profile but subsequent edits save inside the installation. Preserve every selected in-root profile, temporary/recovery copies and any custom source controls before maintenance.

Limitations and evidence

  • Portcove downloads are paused because the title announcement audio is of unknown origin. You need your own original game files.
  • You can add a prepared complete copy you already have; extraction, updates and recovery remain upstream-owned.
  • Before first prepared startup, moves or updates, close the game and keep a separate complete recovery copy of local/, probe-output/, config and all original ROMs.
