Setup

  1. Check the required game files

    Use your own PlayStation 4 CUSA14876 v01.00 game files. v01.21 is required for the optional 60 FPS and Pit Stop features. The README gives abbreviated eboot SHA-256 prefixes; this guide does not include the complete accepted hashes.

  2. Follow upstream setup

    Follow the project’s CTRNativePorted-version-win64 ZIP instructions with the launcher, player and matching HLE DLLs, or its separate bootstrap.ps1 source-build route. Select your own base-game and update directories. No other game assets are supplied; Portcove has not inspected a release file.
