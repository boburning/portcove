Setup

  1. Check the required game files

    Use your own Xbox 360 Rock Band Blitz package or complete extracted contents. A local build requires game/default.xex. This guide does not establish the exact supported region, revision or executable hash. The Ultimate mod is optional. PS3 assets are only for an optional button scheme that is not implemented.

  2. Follow upstream setup

    Windows local source build: LLVM/Clang, CMake3.25+, Ninja, VisualStudioBuildTools/WindowsSDK, own game/default.xex; upstream repair/SDK patch steps then two build passes, outputs rb_blitz.exe.
