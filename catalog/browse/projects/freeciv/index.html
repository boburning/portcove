Setup

  1. Open the GTK4 client

    On Windows 10 or later, choose the x64 GTK4 installer. On Linux x86-64, allow the GTK4 AppImage to run as a program and open it. On Apple Silicon Mac, install freeciv with Homebrew and run freeciv-gtk4.

  2. Start or restore a local game

    Choose Start New Game and then Start to play locally against the computer. Use Game → Save Game As to name and save your game. From the title screen, choose Load Saved Game, select your save, then choose Start in the lobby.

Setup notes
Find saves and settings
The default profile is %APPDATA%/.freeciv on Windows and ~/.freeciv on Linux and Mac. Look in its saves folder for saved games. Keep the full profile for settings and custom data, and copy any other save location you configured.
Check other desktop builds
Homebrew publishes a Linux ARM64 package. For Intel Mac, see the upstream source build instructions and check your package manager’s current availability.

Limitations and evidence

  • Back up your save files, settings and custom rulesets before updating or moving the game. Use the current release when opening saves or scenarios from other players.
