Setup

  1. Choose your original cartridge dump on first Play

    Choose Play, then select your own North American Mario Kart 64 cartridge dump in the player. The player checks the file and keeps its own copy in its profile, so keep your original separately. Another edition is not accepted.

  2. Keep the complete player package

    For a copy you manage yourself, extract the whole Windows package and run MarioKart64Recompiled.exe with its assets and the supplied SDL2 and DXC libraries beside it.

Setup notes
Keep your actual profile when updating
Preserve the player's profile before replacing a copy you manage yourself: normally %LOCALAPPDATA%\MarioKart64Recompiled. It holds the copied original, saves, settings and mods. A copy you run with portable.txt keeps them in its own folder instead. Keep a working copy before replacing the player.

Limitations and evidence

  • The package includes Chiaro fonts by Fontworks that the project license does not cover. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • The reviewed v0.9.2 release currently supports single-player modes.
