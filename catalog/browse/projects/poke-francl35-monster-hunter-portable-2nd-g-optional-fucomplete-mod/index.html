Setup

  1. Check the required game files

    Use your own Japanese Monster Hunter Portable 2nd G disc and decrypted EBOOT.ELF. European and USA Freedom Unite are unsupported. This guide does not specify the exact Japanese serial number, revision, hash or FUComplete mod version; check the project’s profile before setup.

  2. Follow upstream setup

    Generate the main C++ code from your own decrypted EBOOT.ELF and build locally with CMake, SDL3 and Vulkan. Overlay libraries are separate. These instructions do not establish a precompiled player release.

Limitations and evidence

  • This is a work in progress rather than a general release. The project reports village, quest, combat and zone tests, with remaining edge cases and interpreter fallback for some code. Standalone overlay generation is not yet a confirmed documented procedure, and macOS hydration is incomplete.
