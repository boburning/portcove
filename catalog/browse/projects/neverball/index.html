Setup

  1. Run the stable Windows player

    Download and extract the complete neverball-1.6.0.zip from Neverball’s Downloads page. Keep data and the included DLLs beside neverball.exe in the neverball-1.6.0 folder. Start neverball.exe on Windows with support for 32-bit applications and a working OpenGL graphics driver. For Portcove registration, choose neverball.exe and its containing working directory. Add --data and the full path to that package’s data folder as two separate arguments. Review the selection, then choose Play.

  2. Install the Linux game through your package manager

    Install neverball from Debian or Ubuntu and let your package manager install the common files, levels and runtime libraries. Start Neverball with a working OpenGL driver.

  3. Keep your runs and settings

    Close the desktop game and copy the full Neverball folder in Documents/My Games on Windows or ~/.neverball on Linux. It contains your settings, records and replays. Keep custom levels you added to the installation separately before replacing the package.
