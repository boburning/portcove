Setup

  1. Prepare a separate game copy

    Use the original developers' Little Fighter 2 v2.0a installer. Extract it with the upstream tagged helper into a new writable folder, or copy a complete already-extracted v2.0a tree. Keep the original installer and any original extracted tree separately.

  2. Set up the Linux x64 AppImage

    Make LF2-Port-x86_64.AppImage executable. Put the working tree in a folder named game beside it, or open the upstream picker and choose lf2.exe from the complete working tree. To import a complete ZIP, choose ZIP archive in the file-type menu if the picker starts with the executable filter.

  3. Add the working Linux player

    Once the AppImage works on your system, select it in Portcove and keep its containing folder as the start folder. Save the launch details, then choose Play. Removing the registration leaves the working tree in place.

Limitations and evidence

  • This upstream player includes translated original game code. The original game and its data remain under the original developers' terms.
  • Use a separate writable working tree. The game can write files inside it as well as in the port profile. Back up both locations before replacing the player. A successful new ZIP import replaces the previous imported tree, so preserve its recordings and changes first.
