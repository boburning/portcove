Setup

  1. Start the Windows or Linux player

    On Windows x64, extract the full Win32 ZIP and open EmptyEpsilon.exe from its own folder. On Debian-compatible Linux x64, install the publisher’s .deb with your system package manager and open EmptyEpsilon. The Linux package depends on SDL2 and FreeType.

  2. Use the upstream Android or Mac setup

    Choose the publisher’s ARM64 or ARM32 Android APK for your device. For Intel or Apple Silicon Mac, follow the community source-build instructions. The release includes the standalone game and its scenarios.

  3. Match the crew’s release

    Use the same EmptyEpsilon version on the host and every device. If you build from source, set the version to match the host using the upstream build guide. Use Tutorials to try the local controls.

Setup notes
Keep your settings and custom scenarios
Keep options.ini and keybindings.json in the directory set by EE_CONF_DIR, or in the .emptyepsilon folder in your home directory by default. If the game uses its start folder for settings, preserve them there. Keep custom scripts, resources and packs in the locations where you added them.
