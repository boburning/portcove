Upstream availability claim
packages

Published TRX packages bundle the Tomb Raider II Golden Mask expansion levels, converted game images and music, and data injections built from the original games. The engine licence does not cover that game content and Portcove has no permission for it, so Portcove does not download these packages. Use an existing copy you are permitted to use. Reconsider with a program-only package or attributable permission for the included content.

A release may contain research reports rather than a playable package.

Setup

  1. Windows installer setup

    Run the upstream Windows Installer EXE. Choose a separate TRX folder and the packs you want. Point it to your supported Steam, GOG or disc installation for each game. In Portcove, select the installed TRX.exe and use its containing folder as the start folder.

  2. Windows portable ZIP setup

    For manual setup, open the upstream release page and choose the combined Windows ZIP. Extract it into a new writable folder. Follow the upstream file map to copy your own original files into the correct games/<game-id>/ folders. Select TRX.exe and its containing folder. Keep the complete extracted package with the player.

  3. Linux x86-64 setup

    Extract the complete Linux x64 ZIP into a new writable folder. Follow the same upstream file map for your own originals. Select the TRX executable in the extracted folder and use that folder as the start folder.

  4. Intel and Apple Silicon Mac setup

    The universal TRX 1.12 Mac package requires macOS 14 or later on Intel and Apple Silicon. Mount the DMG, copy TRX.app to Applications, and open the installed app once as described by upstream. Use the upstream manual setup guide to place the original game files under the corresponding Contents/Resources/games/<game-id>/ folders. Open TRX.app from Applications to play.

Setup notes
Preserve the TRX game data and profiles
Keep a backup of your original game files, cfg, saves, screenshots and any custom profile directories before replacing the runtime. On Mac, preserve any original game files or player data stored inside the bundle before replacing TRX.app. The upstream guide explains migration from the older combined layout.
Try the bundled Tomb Raider I PC Demo
The TRX 1.12 Linux ZIP and universal Mac DMG include the PC Demo. Choose Tomb Raider I PC Demo in the game selector, or launch the Linux player with --mod tr1-demo-pc. The full game still needs files from your own copy.
Keep a working copy before updating
Extract each new ZIP into a separate folder. Follow the upstream file map for the originals you supply and keep the build-provided files with their version. Preserve saves, screenshots, configuration and any paths selected through TRX_DIR or the documented TRX path overrides before switching your registration.

Limitations and evidence

  • The three games keep their corresponding original-data requirements. Installing the engine does not supply ownership of commercial game data.
  • Keep game files, cfg, saves, screenshots and any custom profile folders backed up when applying upstream updates.
