Setup

  1. Check the required game files

    Use your own complete extracted retail Xbox 360 Crash of the Titans folder, including default.xex, default.rcf, english.rcf, sound1.rcf, sound2.rcf and shaders. The installer checks one known XEX SHA-256; this guide does not include the full accepted hash.

  2. Follow upstream setup

    Use the version-matched instructions for the published CrashRecomp-v1.04.zip (155742930 bytes), CrashSetup.exe and your own supported game folder. Its tools recompile and build locally. Newer README instructions describe an offline CrashSetup-v1.05.exe, CrashLauncher.exe, CrashOTTDE.exe and userdata, but the v1.05 tag was unavailable when checked on 2026-10-25 at 07:06:52.013 UTC. This guide does not establish that installer as available. Source-clone dist/CrashRecomp.exe and older ZIP instructions are version-specific. Optional HD, subtitle and other derived assets have separate requirements.
