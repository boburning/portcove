The Legend of Zelda: Breath of the Wild — Switch edition (SavageWindRecomp)

An alpha Breath of the Wild Switch-edition port generating LAS-derived static code locally for Windows/Linux Vulkan. The project reports only shrines and the Great Plateau, with nobody beyond it; distant-map rendering, controllers and gyro remain incomplete. Alpha 3 ZIP/AppImage launchers check and copy your data, build an image and recompile locally. Windows x64 and Linux x64 need SSE4.2/Vulkan 1.3, with optional faster AVX2/FMA. The Linux aarch64 file is highly experimental and untested on real ARM hardware. Supply your own extracted 1.9.0 ExeFS, including main/main.npdm/rtld/sdk/subsdk0, and complete merged RomFS. It never decrypts or supplies keys, firmware or dump tools. DLC is unsupported; 1.8.2 may run but is explicitly unsupported. Portcove offers no setup or launch integration and has not tested gameplay.
