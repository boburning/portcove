Setup

  1. Finish setup in the upstream Android app

    Install this fork’s Android ARM64 APK, open it and choose your own supported Mystical Ninja Starring Goemon ROM through its file picker. The app verifies and copies the ROM into app-scoped storage; no manual folder placement or legacy storage permission is needed. Then choose Start. Upstream requires Android 9+ and Vulkan; a physical controller is useful but current releases also have touch controls.

  2. Keep your data when changing versions

    Saves and settings share the app-scoped profile. Before starting a game, Settings > Saves can import a checked compatible save and keeps the previous file alongside as .pre-import.bak. That is an upstream import safeguard, not a complete backup or compatibility promise for arbitrary emulator saves. Preserve app data using the upstream Android methods before uninstalling or clearing storage. For an affected Adreno launch crash, the guide offers disabling Framebuffer Effects before selecting an optional custom driver. Portcove does not install drivers, update the APK or back up its profile.
