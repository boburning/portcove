Setup

  1. Install FreeDink

    On Debian or Ubuntu, install the freedink package and its dependencies, then open FreeDink from the launcher or run freedink. On Intel or Apple Silicon Mac, run brew install freedink and then freedink. Homebrew also packages FreeDink for Linux ARM64. These packages include or install the game data.

  2. Start and save the adventure

    Choose Start from the title screen. Use the arrow keys to walk and Space to talk or examine. Talk to a Save Machine to keep your progress. Choose Continue from the title screen to load your saved game.

Setup notes
Find the base game saves
Look for save files in the game data’s dink directory or in ~/.dink/dink. Ubuntu's base game data directory is /usr/share/games/dink/dink. For a Homebrew install, check share/dink/dink inside the folder reported by brew --prefix freedink before you upgrade or remove the package.

Limitations and evidence

  • Close FreeDink before backing up your saves. Keep save files from the active game or D-Mod directory and its matching subfolder under ~/.dink.
