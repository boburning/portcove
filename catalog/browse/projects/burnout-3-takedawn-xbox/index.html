    Use only an existing Takedawn installation and components you are permitted to use. Takedawn is the original Xbox Burnout 3: Takedown native implementation, separate from the PS2 port and other Burnout games. Windows uses its upstream setup installer, not a portable ZIP. Finish installation and supported GUI preparation separately from Portcove, using your own North American NTSC-U retail Xbox disc as XISO, full disc image or full extracted folder.     Select Takedawn.exe in the actual installed program folder, use that containing folder as working directory and no arguments. Attach the completed game entry, not the setup installer or takedawn-setup.exe. The inspected source runs the title through the host window in the selected process; this guide makes no successor-process supervision claim for upstream Restart game or setup relaunches. Complete those upstream operations outside the attached session, then start a new reviewed Play session.

    Review and consent to the exact selected executable, working directory and empty argument list, then choose Play separately. You and upstream own installation, update checks, deliberate runtime replacement and recovery. Takedawn documents manual updates through its own installer; Portcove does not operate that updater. Removing the registration preserves all external files. Portcove supplies no external update, backup, rollback, conversion, migration, uninstall or data deletion.
