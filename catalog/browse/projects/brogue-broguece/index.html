Setup

  1. Choose your desktop package

    Get the Brogue Community Edition 1.15.1 archive for your system. Extract the whole archive to a folder you can write to. The release includes the game and tiles.

  2. Start Brogue Community Edition

    On Windows x64, start brogue.exe in its extracted folder. On Linux x86-64, install SDL2 and SDL2_image through your distribution, then run ./brogue from the extracted folder. Use a Linux folder path without spaces for the supplied script. On macOS 15 or later, choose the Apple Silicon or Intel archive and open the included Brogue CE app. If macOS blocks the unsigned app on first launch, follow the publisher’s Mac instructions.

Setup notes
Keep your saves and recordings
Use Save Game before leaving a run. Back up your .broguesave and .broguerec files before replacing the package. Look beside brogue.exe on Windows, in the extracted bin folder on Linux, and in ~/Library/Application Support/Brogue/Brogue CE on Mac.
Find the separate Android port
The desktop project links to https://github.com/bilgincoskun/brogue-android-port/releases for Android. Its latest published build is v0.12.5.2. Keep its saves separate from the desktop 1.15.1 release.

Limitations and evidence

  • Opening a save and continuing can consume that play copy. Keep a separate backup before restoring.
