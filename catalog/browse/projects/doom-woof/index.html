Setup

  1. Choose your game data

    Use the IWAD from your own Doom installation or the freely available Freedoom IWAD. Pass -iwad followed by the path to that file. Keep the supplied woof.pk3 beside the extracted player or in its packaged location. It contains engine resources and does not replace the IWAD.

  2. Start Woof! on Windows

    Extract the complete x64 ZIP and start woof.exe from its directory. Use woof-setup.exe there to configure controls or video. The publisher also provides a separate 32-bit Windows ZIP.

  3. Start Woof! on Linux

    Make the x86-64 AppImage executable and run it with your IWAD. The inspected 16.0.0 player needs glibc 2.38 or later. If FUSE is unavailable, extract the AppImage with --appimage-extract and run AppRun from the complete extracted folder. Homebrew also offers the woof-doom formula for Linux, including ARM64.

  4. Start Woof! on a Mac

    Extract the publisher's universal ZIP, keep woof, woof-setup, woof.pk3 and soundfonts together and run ./woof with your IWAD from Terminal. Both the Intel and Apple Silicon slices in 16.0.0 require macOS 26 or later.

Setup notes
Keep saves with the game that created them
On Linux, preserve $XDG_DATA_HOME/woof, normally ~/.local/share/woof. This holds woof.cfg and savegames grouped by IWAD filename. Keep your actual profile and matching runtime before changing ports or versions.

Limitations and evidence

  • The publisher player can register a Discord link handler when launched. The game, its profile and updates stay under your control or the package manager's.
  • The packaged notices omit credits for some bundled engine assets. See the publisher's Legalese section for those credits.
