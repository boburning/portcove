Setup

  1. Check the required game files

    Use your own exact USA SLUS-01411 disc and CUE, plus your own SCPH1001 BIOS. Compare both with the full hashes in the upstream README.

  2. Follow upstream setup

    Follow the MSYS2 instructions to check, extract and regenerate code from your own inputs, then build ForbiddenMemories.exe locally. Upstream documents RUN_FM_APV2_BYPASS.cmd for startup. Portcove does not install or prepare this source project automatically.
