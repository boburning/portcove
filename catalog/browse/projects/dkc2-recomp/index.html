Setup

  1. Prepare the exact runtime

    Extract the complete official v0.0.2 Windows x64 ZIP into a writable folder outside your Portcove library. Omit assets/img/boxart.tga and leave every other file unchanged.

  2. Choose compatible folders

    Use short paths with basic Latin characters for both the runtime folder and your original game file.

  3. Select your original game file

    Choose and check your own stock headerless USA .sfc original in Portcove, then choose the prepared runtime folder below for review.

Limitations and evidence

  • Portcove selects the GDI compatibility renderer and bypasses the artwork launcher. You manage updates, settings, diagnostics and saves in this external folder; removal unregisters only.
  • Known upstream alpha rendering and level-dispatch limitations remain. Startup checks do not establish completed gameplay or populated save/load.
