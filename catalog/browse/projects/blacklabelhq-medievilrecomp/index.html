Setup

  1. Choose your original disc in the game

    Choose Play, then use MediEvil’s disc picker to select your own supported North American MediEvil CUE/BIN or CHD. The game validates the disc and remembers its path, so keep the disc in a folder outside the game folder. Portcove does not supply original game files.

  2. Run a copy you manage yourself

    Extract the official package for your system (Windows x64 ZIP, Linux x64 TAR.GZ, or macOS Apple Silicon or Intel ZIP) into a separate folder and start medievil.exe (medievil on Linux and macOS) from that folder. The player needs the .NET 10 runtime and OpenAL; follow upstream's prerequisite instructions if either is missing. To add that copy to Portcove, select the player and its folder.

Limitations and evidence

  • The project publishes no licence, and the package bundles the recompiled game code and third-party libraries without their licence notices. Portcove downloads it only from the project’s own releases. You need your own original game files.
  • In a copy you manage yourself, the in-game updater replaces the game's program files. Keep a copy of your working folder, including settings.json, interface.ini, the memory-card files and mods, before updating.
