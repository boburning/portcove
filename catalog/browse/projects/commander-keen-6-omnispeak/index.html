Setup

  1. Match the episode and EGA revision

    Use your own Keen 6 v1.4 or v1.5 EGA GAMEMAPS.CK6, EGAGRAPH.CK6 and AUDIO.CK6 with the matching Omnispeak episode support files. Keen 4 shareware does not supply this episode. CGA, v1.0 and other unsupported revisions are not interchangeable. Keep original files and their version intact.

  2. Choose the ordinary upstream game package

    Use the official stable Windows 64-bit v1.1 package rather than the separate modding preview. Extract its full wrapper, including its data directory and support files. Register omnispeak.exe inside that wrapper with the same working directory. Use a separate player copy for Keen 6. Copy the contents of data/keen6e14 for v1.4 EGA or data/keen6e15 for v1.5 EGA beside omnispeak.exe, along with your matching GAMEMAPS.CK6, EGAGRAPH.CK6 and AUDIO.CK6; the wrapper initially contains Keen 4 files, not a ready Keen 5/6 layout. Keep your originals elsewhere unchanged. Then use two argument lines, /EPISODE and 6v14 for v1.4 EGA or 6v15 for v1.5 EGA, in Change launch details. /GAMEPATH plus the real original-data folder and /USERPATH plus a separate writable save/config folder can keep episode data and profiles apart. Each option and value is a separate literal argument. Registration does not execute the player; choose Play separately.

  3. Use the official Linux v1.1 launcher

    Extract omnispeak-linux-1.1.tar.gz into a separate working folder for Keen 6 v1.4 or v1.5 EGA. This archive is for x86-64 or 32-bit x86. Keep the architecture-specific SDL2 folders and use the publisher’s omnispeak launcher from the prepared folder. Copy your matching GAMEMAPS.CK6, EGAGRAPH.CK6 and AUDIO.CK6 into that working folder along with the episode support files from data/keen6e14 or data/keen6e15 for the selected revision. Use /EPISODE 6v14 or /EPISODE 6v15, as appropriate and keep the actual config and save directory. This shell launcher splits argument values at spaces, so use a path without spaces for an explicit /USERPATH. The archive’s bundled Keen 4 shareware data does not supply this episode.

  4. Keep upstream update ownership

    You manage this external game, its original files and its profile using the project’s tools. Add it to Portcove, choose Play separately and remove its registration when you no longer want it listed. Portcove does not take over its files or offer updates, backups, rollback or deletion for this copy. Keep a working copy and back up its data before updating. Other platforms need their own supported package and application instructions. These Windows instructions do not establish that the game runs on any platform.

Setup notes
Keep saves and support files with their chosen profile
Preserve your original-data folder, matching episode support files, complete working player and actual writable profile before changing versions. /USERPATH explicitly selects the save/config directory; otherwise the upstream build can use its default directory or an SDL user-path fallback. Keep separate episode profiles and all custom paths backed up with players closed. Upstream claims DOS-save compatibility; Portcove has not exercised your saves and does not promise automatic conversion, managed backup or rollback.

Limitations and evidence
