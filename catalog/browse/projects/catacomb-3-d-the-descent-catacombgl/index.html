Setup

  1. Keep the correct original game folder

    Use your own Catacomb 3-D: The Descent data from the Catacombs Pack. Abyss shareware does not supply this game. Keep the complete original folder and its companion files. CatacombGL can find a GOG Windows installation; otherwise use its own folder picker. Original data is separate from the player and remains yours.

  2. Set up the Windows x86-64 player

    Choose Preview for the official Windows 64-bit beta ZIP, extract it and keep CatacombGL.exe and SDL2.dll together. Register CatacombGL.exe with that folder as its working directory. Leave arguments empty for the game picker, or use the single documented argument --descent after the original folder is recognized. Registration does not start it; choose Play deliberately.

  3. Set up the Linux x86-64 player

    Choose Preview and download the official Linux tar.xz. Use Portcove Download to extract it into a new setup folder, or unpack it yourself. The current package needs SDL2, OpenGL, glibc 2.38 and libstdc++ with GLIBCXX_3.4.32. Open the CatacombGL executable, then use its folder picker to recognize your original game. Register that executable and its containing folder. Leave arguments empty for the picker, or use --descent after the original folder is recognized.

  4. Keep upstream update ownership

    You manage this external game, its original files and its profile using the project’s tools. Add it to Portcove, choose Play separately and remove its registration when you no longer want it listed. Portcove does not take over its files or offer updates, backups, rollback or deletion for this copy. Keep a working copy and back up its data before updating. Native setup and gameplay remain unobserved in Portcove.

Setup notes
Preserve this engine’s profile
Windows normally keeps CatacombGL.ini and game-specific data under the actual Roaming AppData/CatacombGL folder. Linux uses ~/.config/CatacombGL, with this game’s saves under Cat3D/. A custom --ini or --log location stays external. All four games share the profile and control settings. Close other CatacombGL copies before starting another. Back up the whole profile, saves and original data before updating. Upstream v0.5.7 documents no controller support and no save compatibility with the original DOS games. ReflectionHLE is a separate implementation; do not move saves between them on the basis of a shared game title.

Limitations and evidence

  • The reviewed CatacombGL release is beta. Original DOS save compatibility and controller support are not offered by this version.
  • All four games share the profile and control settings. Close other CatacombGL copies before starting another. Back up the whole profile, saves and original data before updating.
  • ReflectionHLE is a separate implementation; do not move saves between them on the basis of a shared game title.
