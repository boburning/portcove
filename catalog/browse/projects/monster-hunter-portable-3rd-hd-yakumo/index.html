Setup

  1. Prepare the game on first Play

    On first Play, choose the uncompressed PSP UMD ISO from your own Monster Hunter Portable 3rd HD Ver. PS3 release (NPJB-40001) and let Yakumo prepare the game. If Yakumo copies the image, the copy is kept and backed up with the managed data. If you use the image where it is, keep it at a stable location outside the managed runtime and back it up yourself.

  2. Complete the exact owned-input preparation upstream

    Yakumo needs the PSP UMD image from your own Monster Hunter Portable 3rd HD Ver. PS3 release (NPJB-40001) as an uncompressed ISO. The ordinary PSP edition, a whole PS3 disc image and compressed CSO files are different inputs. For a Windows copy you prepared yourself, let Yakumo prepare the game there and keep Yakumo.exe in its complete creating folder with its overlay libraries, FFmpeg DLLs and other files. If that working copy already starts with supported literal --data-dir or game-folder arguments, enter the same arguments when you select it instead of leaving them empty; do not silently change the creating data or save roots.

  3. Set up Yakumo on Linux, Steam Deck, Mac or Android

    On x64 Linux or Steam Deck, open the Flatpak through your desktop or Steam; it uses the Freedesktop Platform 25.08 runtime. If you unpack the x64 tarball instead, start it with ./yakumo from the unpacked folder so the launcher sets the stack size; it needs glibc 2.29 or later, a Vulkan driver and the Vulkan loader. On an Apple Silicon Mac with macOS 13 or later, open the ARM64 disk image and copy the whole Yakumo.app to Applications, then open it directly. The publisher uses ad hoc signing; follow its macOS guide for the first-open prompt. On Android 10 or later with Vulkan 1.1, install the ARM64 APK and choose your ISO in the Android file picker. The app copies it into its own storage, so allow about 1.3 GB for the image in addition to the app, and use Yakumo to back up your saves before replacing or removing the app. Use Yakumo for setup and play on these systems.

  4. Select the prepared Windows player

    Select Yakumo.exe and use its containing folder as the working directory. Leave arguments empty. Keep the complete independently permitted runtime and finish the title-specific preparation before Play.

Limitations and evidence

  • MIT covers the project’s own original code; third-party IP remains independently owned. Preserve the applicable packaged FFmpeg LGPL and font/dependency notices; this is not a whole-game rights certificate.
  • Upstream documents untranslated/blank save-dialog screens, curved-surface issues and unsupported code mods; reported rendering, multiplayer, controller and save compatibility are publisher claims, not Portcove observations. No game, original, helper, installer or native session was run.
  • For a copy you prepared yourself, the Windows installed profile normally uses %APPDATA%/Yakumo/MHP3rd and the upstream ZIP with portable.txt uses data/ beside the executable. Existing portable.txt, a data/ folder, --portable, --data-dir and MHP3RD_DATA_DIR/MHP3RD_PORTABLE choices affect selection; retain the actual established mode and do not add/remove markers or trigger profile-copy prompts as registration work. A non-writable data directory fails instead of silently falling back.
  • In a copy you prepared yourself, upstream Set Up Game Data Again and Restart Now after save import can end the selected process and start a successor. Perform those actions outside the attached session; Core does not adopt that successor or offer upstream save import/export, texture installation, backup or network configuration. Retain the old working runtime and all data before replacement.
  • Yakumo keeps the managed copy's settings, saves, save backups and prepared game in its data folder. Leave MHP3RD_DATA_DIR, MHP3RD_GAME_DIR, MHP3RD_MODS_DIR and MHP3RD_PORTABLE unset, and add no --data-dir or game-folder argument. Otherwise Yakumo can play from or save to a folder Portcove does not keep.
  • Restart Now after a save import and Set Up Game Data Again restart Yakumo. On Windows, Portcove keeps the session open until the restarted Yakumo closes.
  • If you already use Yakumo, the first Play of the managed copy can offer to copy your data from %APPDATA%\Yakumo\MHP3rd. The original files stay where they are.
