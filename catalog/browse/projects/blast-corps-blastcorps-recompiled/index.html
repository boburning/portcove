Setup

  1. Select your own supported original

    On first Play, choose your own North American revision 1.1 Blast Corps ROM in the player. The player keeps its own copy, bc.n64.us.z64, in its profile. Keep your original separately.

  2. Keep the complete Windows player

    For a copy you manage yourself, keep the BlastCorps Recompiled 1.1.1 Windows package files together: BlastCorpsRecompiled.exe, assets, the DLLs and recompcontrollerdb.txt. The published player needs no game compiler or separate installer. To add that copy to Portcove, select BlastCorpsRecompiled.exe and its package folder; removing it from Portcove leaves every file in place.

Setup notes
Preserve the actual profile before maintenance
The normal Windows profile is %LOCALAPPDATA%\BlastCorpsRecompiled. A portable.txt file in the working folder makes that folder the profile, and if Windows cannot report the local app data folder the player also uses the working folder. Preserve the folder actually used, including the copied bc.n64.us.z64 original, saves, settings, mods and mod settings. Close the player before replacing a copy you manage yourself.

Limitations and evidence

  • The package includes the Suplexmentary Comic NC font, which the project license does not cover, plus the CutOutsFLF font and a fan-made splash image. Portcove downloads the package only from the project’s own releases. You need your own original game files.
  • Portcove has not observed native setup, gameplay or saves. Changing versions does not rewind saves or check mods; keep a separate backup of the profile.
