Setup

  1. Select your disc on first Play

    No installer or BIOS is required. Choose Play, then select your own Brave Fencer Musashi USA SLUS-00726 CUE with every referenced BIN track when the upstream picker appears. A 2048-byte ISO is not equivalent. An existing remembered disc can be reused. If Linux has no zenity/kdialog picker, keep the CUE and tracks in disc beside launch.sh, or in ~/Games/brave-fencer-musashi/disc.

  2. Keep your upstream profile

    Windows uses %APPDATA%\bfm-port; Linux uses the bfm-port folders under XDG state/config/cache (normally ~/.local/state, ~/.config and ~/.cache), with screenshots under Pictures. The standard card is bfm_card0.mcd. A managed runtime continues using that upstream profile; quit other copies before playing. Keep an existing customized copy and its OS launcher if you need its environment choices. Portcove does not register launch.sh or launch.cmd as an external native executable.

Limitations and evidence

  • These are experimental previews with known unfinished game paths. Windows r48 was tested upstream under Wine, not qualified by Portcove on native Windows. Stable r38 is a separate Linux alternative; current preview selection does not establish whole-game completion.
  • Linux requires glibc 2.38 or newer plus system OpenGL, X11 or Wayland, and ALSA or PulseAudio/PipeWire libraries. Custom native mods may need disabling or rebuilding when changing runtimes; preserving their files does not establish compatibility.
