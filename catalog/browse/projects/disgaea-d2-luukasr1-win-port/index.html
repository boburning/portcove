Setup

  1. Prepare the US game

    Open the launcher from the complete portable ZIP. Supply your own compatible US ISO and the BLUS31313 version 1.40 update. First setup downloads tools and compiles the player locally. It requires an internet connection and a DirectX 12 graphics driver.

  2. Return to the prepared player

    Open the launcher again and choose Play after preparation. Keep its prepared game files. Use the upstream launcher for settings and follow its release notes when replacing it.

Setup notes
Keep the current Windows profile
Saves and settings live in %LOCALAPPDATA%/DisgaeaD2Recomp-Graphics-Preview. Back up that folder before switching versions. The stable v1.0.2 launcher retains a build prepared with v1.0.0 according to the publisher.
Use a separate European profile
The v1.0.32 European preview has separate setup for BLES01939. It accepts an owned European PS3_GAME folder or ISO and keeps US and European profiles separate. Check its prerelease instructions before deciding to use it.

Limitations and evidence

  • Use each supported original with its own profile. Portcove does not build or update this game or back up its profile.
