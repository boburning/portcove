Setup

  1. Choose your player on Windows

    The Windows download for this entry is the Chocolate Doom x86-64 ZIP. The publisher release offers separate chocolate-heretic, chocolate-hexen and chocolate-strife ZIPs. Keep the matching player, setup utility and DLLs together. Run the setup utility to configure controls and audio, then use the game executable to play.

  2. Select the IWAD for the game you want to play

    Point the matching player at your IWAD with -iwad followed by the file path. Chocolate Doom accepts Doom IWADs or the freely available Freedoom data. Chocolate Heretic accepts the original Heretic IWAD or heretic1.wad from the v1.2 shareware release. Use hexen.wad or the original four-level demo IWAD with Chocolate Hexen, and strife1.wad with Chocolate Strife. Keep accompanying Strife voice data with the IWAD. The engine packages contain no original game data.

Limitations and evidence

  • Keep your actual IWADs, settings, saved games, autoload files and the creating runtime before changing versions or switching engine variants.
  • If a final text screen appears after you choose Quit, press a key to close the player.
