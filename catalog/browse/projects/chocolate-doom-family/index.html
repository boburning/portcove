Setup

  1. Set up Doom on Windows

    Choose the matching original Doom IWAD or one of the listed demo editions. Portcove keeps your original file and prepares a separate copy for Play. Saved games are separate for each exact IWAD. Keep the same original with its saves; select a separate setup to change editions.

Setup notes
Heretic and Strife on Windows
The official release also offers separate chocolate-heretic and chocolate-strife Windows ZIPs. Keep each player, setup utility and DLLs together in an installation you maintain. Supply the matching Heretic IWAD, or the Strife IWAD and its accompanying voice data. These upstream alternatives retain their own setup, updates and data ownership; this managed Doom entry does not convert them into managed routes.
Install a distribution package on Linux or Mac
Use your Linux distribution’s chocolate-doom package for all four players. Debian packages are available on x86-64 and ARM64. On Intel or Apple Silicon Mac, use brew install chocolate-doom on a supported Homebrew host. Run the matching chocolate-doom, chocolate-heretic, chocolate-hexen or chocolate-strife command. Your package manager owns updates.
Register an existing Chocolate Doom player on Linux
Use portcove external select-preview for chocolate-doom-family with the absolute chocolate-doom executable path, --working-directory for its folder, --arg=-iwad and a separate --arg with the absolute path to your Doom or Freedoom IWAD. Repeat those details with portcove external select and pass the preview SHA-256 to --expected-preview. Start the game with portcove exec chocolate-doom-family. Removing the registration keeps the player, IWAD and profile.
Find settings and saves
For a portable Windows copy, start the player in its own folder and keep the configuration and saves it writes there. On Linux the default profile is $XDG_DATA_HOME/chocolate-doom, normally ~/.local/share/chocolate-doom. On Mac it is normally ~/Library/Application Support/chocolate-doom. Preserve the actual paths if you use -config, -extraconfig or -savedir. The default per-game save folders can differ by IWAD.
Use a short save directory for Chocolate Hexen 3.1.1
Chocolate Hexen 3.1.1 can fail to save when the path is long. Create a writable folder with a short absolute path and start Chocolate Hexen with -savedir followed by that path. Use a different folder for the demo and full game. Before moving either, close the game and copy its whole save folder so each slot stays with its map files.

Limitations and evidence

  • Keep saves with their creating game and runtime. Changing engines or game editions does not convert saved games.
  • A profile that points outside its local autoload or music-pack folders must be preserved and corrected before Play. Portcove does not rewrite existing settings.
