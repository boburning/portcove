Setup

  1. Check your original game files

    Use your own 1.0.0 NSP for title 010051F0207B2000 and prod.keys. Keep the locally prepared v0 modules, RomFS and shaders. Other versions and regions are unconfirmed.

  2. Follow the project’s setup

    Build the Mac app with build_mac_app.py. Optional embedding places your game data in Application Support. The keep-data rebuild preserves RomFS. The iOS build requires local signing and separate game content.

Setup notes
Version and platform notes
The project reports sound and Mii creation on Mac, with input problems in later scenes. An iPad Air M2 running iPadOS 27 has limited startup evidence. The iPhone build has no play report. There is no release package.
