Setup

  1. Choose your original game folder

    Choose the folder containing base and d3xp from your own classic Doom 3 and Resurrection of Evil installation patched to 1.3.1. Portcove checks and prepares the base and expansion PK4 files, then you can select Play. BFG Edition is a different product. Keep your original installation separately. On Windows, keep the managed library path short and use plain ASCII. On Linux, keep the packaged modules and install SDL2, OpenAL, libcurl and the GNU C++ and GCC runtime libraries. Keep backups of the external save and settings folders. Use a separately prepared copy for custom paths or native mods.

Limitations and evidence

  • Use a separately prepared copy for custom paths, native mods or a dedicated server. Keep backups of your external saves and settings.
