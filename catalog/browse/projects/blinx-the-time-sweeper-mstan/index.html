Setup

  1. Open the beta launcher

    On Windows, extract the complete ZIP into a writable folder and open Start Game.exe. On Linux x86-64, make the AppImage executable and open it on a host with Vulkan 1.3. The upstream Linux baseline is Ubuntu 24.04.

  2. Import your own NTSC-U original

    Skip the optional console files if you want a fresh local console identity. Choose your own supported NTSC-U ISO or XISO in the launcher. The importer shows progress and can cancel. It remembers the selected game and reuses its disc cache. If you select an extracted default.xbe instead, keep its complete original game folder. Choose your controller under Player 1 and start the game in the launcher.

Setup notes
Keep saves and console identity
Reopen the launcher to play again or change the controller and mods. On Windows keep the complete data folder beside the launcher, including its disc cache and console identity, when replacing the beta. On Linux the default is ~/.local/share/xboxllr/xbox-4d530013/data. Preserve the same XDG_DATA_HOME if you set a custom path, and back up any selected external save folder or HDD image separately. Keep any companion .xboxllr profile.

Limitations and evidence

  • Back up your existing console identity and saves before changing the game's profile. Portcove does not update this beta or back up its profile.
