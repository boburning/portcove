Setup

  1. Choose your game data

    Use an IWAD from your own Doom installation or a freely available Freedoom IWAD. Keep the supplied odamex.wad with the upstream client. It contains engine resources and the client still needs your IWAD.

  2. Start Odamex on Windows

    Extract the complete x64 ZIP. Open odamex.exe for the client or odalaunch.exe for the launcher. The publisher also offers a 32-bit ZIP. Put your own IWAD where the launcher can select it, or pass -iwad followed by the quoted path to the client.

  3. Start Odamex on Linux

    Install net.odamex.Odamex from Flathub for x86-64 or ARM64. Use the desktop launcher or run flatpak run net.odamex.Odamex client -iwad followed by the path to your IWAD. The publisher also provides separate Flatpak bundles for both architectures.

  4. Start Odamex on a Mac

    Open the publisher’s universal disk image and keep the complete app folder together. Choose Odamex.app for the client or odalaunch.app for the launcher. Both Intel and Apple Silicon client slices in 12.3.0 require macOS 11 or later.

Setup notes
Preserve the client profile
The inspected Linux publisher Flatpak uses ~/.odamex for settings, logs and saved games. Preserve the actual profile and its matching IWAD before changing engines or packages.

Limitations and evidence

  • Package replacement and preservation stay with the package manager or your external installation. Online play requires compatible game data and server settings.
