Super Smash Bros. Ultimate (ssbu-arena)

SSBU Arena is an independent Windows fork for competitive one-on-one Super Smash Bros. Ultimate. The v0.2.52 release provides SSBU-Arena.exe to prepare and update the game from your own supported files. Upstream reported testing rollback with two windows on one PC. Portcove has yet to verify setup, matchmaking or gameplay.

Setup

  1. Supply your own game files

    Follow the instructions for your own Super Smash Bros. Ultimate dump, matching update, and any keys required for the selected build. The project documents 13.0.4 and 13.0.5.

  2. Start the upstream launcher

    On Windows x64, choose SSBU-Arena.exe. Let the launcher install or update its companion files. The separate runtime archive and release manifest are for the launcher.

Limitations and evidence

  • The publisher requires compatible versions for online play. Linux and macOS availability and gameplay have not been verified by Portcove.
