Setup

  1. Choose the upstream desktop player

    On Linux, choose the x64 or ARM64 archive matching your computer. On Mac, choose Intel, Apple Silicon, or the universal archive. Extract it and open openprivateer with its bundled SDL3 library alongside it. See the upstream manual for Mac first launch. The publisher lists a separate Windows x64 package.

  2. Point OpenPrivateer at your original game files

    In Game Data, use Add Folder to use your own PRIV.TRE and INITCFG.PAK in place. Righteous Fire uses RF.TRE and INITRF.PAK. For the GOG or Steam edition, use Extract from GOG/Steam and choose GAME.GOG or GAME.bin. The launcher copies the needed files and leaves the original installation intact.

  3. Keep the active user-data folder

    Use Files and Diagnostics to find and back up the active data folder, including openprivateer.ini, savegame and any custom content. Portable mode keeps those files beside the player. Keep your backup separate before replacing the program folder or using the launcher’s removal options.

Limitations and evidence

  • These are upstream alpha builds. Linux and Windows require Vulkan. Mac requires Metal. Open the client named openprivateer for play. The separate openprivateer_server hosts multiplayer.
