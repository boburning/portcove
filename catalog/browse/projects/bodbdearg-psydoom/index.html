Setup

  1. Keep the Windows player together

    Extract the complete Windows x64 ZIP into a separate folder. If the player requires it, follow upstream’s Windows Visual C++ runtime prerequisite.

  2. Choose your PlayStation game disc

    Finish setup with PsyDoom.exe and its folder. On Play, use the launcher to select a supported PS1 Doom or Final Doom .cue file, keeping all referenced track files with it. A PC Doom WAD does not replace that disc image.

  3. Register your prepared player

    Complete the upstream setup in your permitted working copy first. Select the actual PsyDoom.exe and its containing folder as the working directory; keep all companions. Normally leave arguments empty. Enter separate literal arguments only when deliberately following documented options. Confirm the selected player, folder and arguments; registration does not start a game. Choose Play separately when ready.

Setup notes
Preserve your working copy
Updates remain with you and upstream. Keep original disc files and mods backed up. Windows settings, saves and demos normally use AppData/Roaming/com.codelobster/PsyDoom; also preserve a local launcher.ini or custom files if your copy uses them.
Keep your runtime and data recoverable
You and upstream own runtime replacement, originals, saves, settings and profiles. Close all actual players and preserve the working copy and every actual data location before upstream changes. Removing the registration leaves all external files untouched. Managed Install, Update, Backup, Rollback, migration, original authentication and external deletion are unavailable for this route.
