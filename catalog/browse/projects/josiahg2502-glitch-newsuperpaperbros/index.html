An experimental Super Paper Mario port with project-reported gameplay and enhancements. Windows 10/11 x64 uses Direct3D 12/Vulkan; new Linux 64-bit support needs glibc 2.35+ and Vulkan. Screenshot names do not establish macOS support. Use your own supported Wii disc and follow the project’s setup. Its source packager expects an HQ-music mod locally; that optional content is separate from engine requirements. You and the project manage installation and version changes. Setup

  1. Keep the complete prepared Windows package

    Use your independently permitted prepared New Super Paper Bros. Windows copy. The reviewed v1.0.8 route uses your own Super Paper Mario Wii USA R8PE01 revision 0 or Europe R8PP01 disc, as ISO, CISO or WBFS, through upstream setup. Finish extraction and any preparation outside Portcove. Keep the complete release, engine modules, launcher companions and Disc/DATA. The source packager’s local HQ-music and HD-texture inputs are separate from the player’s own original-disc requirement; do not treat those extra assets as an original-data license grant.

  2. Select the normal launcher and keep it open

    Select New Super Paper Bros.exe, use the complete release folder as working directory and leave arguments empty. In its Game page set When the game closes to Close the launcher too ([launcher] close_with_game=true), and leave the launcher open while its child game runs. The normal launcher starts the packaged engine and closes on the child’s exit with this setting. Portcove supervises only the selected launcher; it does not acquire independent child-process control. Do not use the --play test switch, which starts the child and returns immediately.

  3. Review registration before the separate Play step

    Portcove records your selected native executable, working folder and literal arguments. Upstream and you own original preparation, settings, optional mods and runtime replacement. Review and relink changed launcher bytes after an upstream update. Removing the registration preserves external files. Managed installation, extraction, compilation, updates, backup, rollback, save import, migration and deletion are not offered for this copy.

Limitations and evidence

  • Use only copies, originals, music, textures and other components you are permitted to use, retaining their applicable notices. No rights to game assets follow from a framework license. Upstream screenshots and gameplay statements do not establish Portcove native, gameplay, macOS, Linux or Android acceptance.
  • Preserve old Play/UserData layouts and any upstream import backups if present; registration does not migrate, merge or certify console/Dolphin save compatibility.
