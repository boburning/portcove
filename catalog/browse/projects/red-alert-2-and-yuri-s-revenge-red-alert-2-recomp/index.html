Setup

  1. Open the installer for your system

    Use the publisher’s Windows x64 installer, Linux x86-64 archive, or Apple Silicon Mac ZIP. Extract the Linux or Mac archive before opening the installer.

  2. Select your original game folder

    Use your installed Steam or EA App copy. If the installer does not find it, choose the folder containing Red Alert 2 game.exe version 1.006 and Yuri’s Revenge gamemd.exe version 1.001. On Linux, the folder picker needs Zenity or KDialog.

  3. Build and start either game

    Choose a separate build folder and select Build my recomp. When the build finishes, use the installer’s Play actions or the matching Red Alert 2 or Yuri’s Revenge launcher it creates.

Setup notes
Keep the original and build folders
The generated launchers use the build folder, and Linux and Mac setup links to your installed original. Keep both folders available. Back up existing saves and settings before rebuilding or moving either folder.
Check the Linux and Mac prerequisites
Linux needs a 32-bit GCC toolchain plus the matching SDL2 and FFmpeg development libraries. The Apple Silicon route needs Homebrew and the Xcode command-line tools. See the publisher’s build guide for dependency details.

Limitations and evidence

  • The first build can take 30 to 60 minutes and needs about 6 GB. The installer may request permission to install build tools. The publisher documents unsigned installers, so your operating system may block them.
