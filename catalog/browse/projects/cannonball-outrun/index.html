Setup

  1. Keep your permitted working copy

    Use an already permitted Cannonball installation with the matching OutRun Revision B ROMs required by that copy. Keep its configuration and ROM folders together.

  2. Select the completed installation

    Select the native Cannonball player and its working folder. Keep your existing copy available; updates and data stay with you and upstream.

  3. Use a permitted noncommercial copy

    This route is for an already permitted noncommercial working copy. Keep the engine and third-party notices and comply with applicable modified-source conditions. You need a lawful matching OutRun original-data set; engine terms do not license the ROMs or every bundled component. Portcove does not acquire a new package for this route. The reviewed original v0.34 setup uses the documented loose Revision B ROM files in its configured ROM folder; DX ZIP support does not apply to this separate player.

  4. Confirm the player, then choose Play

    Select the actual cannonball.exe and its complete player folder as the working directory. Normally leave arguments empty; enter separate documented literal options only deliberately. Review and consent to the selected executable, folder and arguments. Registration does not start the player; choose Play separately. Keep each fork and its actual configuration and ROM data with its own working copy.

  5. Preserve the copy and every data location

    You and upstream own runtime replacement and data. Before Play with a changed copy or an upstream update, close all actual players and preserve the working folder, config.xml, ROMs, res, scores, custom music and every custom configuration or save path. Keep the previous working copy until ready. Removing the registration preserves all external files. Managed Install, Update, Backup, Rollback, migration and external deletion are unavailable.
