Setup

  1. Install the stable client

    On 64-bit Windows, run the official setup program and follow its installer prompts. The 0.5.1.2 installer filename says Win32 and contains a 64-bit client. On Mac, choose the Intel or Apple Silicon disk image and copy the complete FreeOrion app into Applications. The current package needs macOS 10.15 or newer on Intel and macOS 11 or newer on Apple Silicon.

  2. Use your Linux package manager

    Install org.freeorion.FreeOrion from Flathub, or use the FreeOrion package from your Linux distribution. Update the copy through the same package manager. The source archive in the project’s releases is for building the game.

  3. Keep your saves and settings

    Close FreeOrion before backing up. Copy the FreeOrion folder under %APPDATA% on Windows or ~/Library/Application Support on Mac. On Linux, keep the freeorion folders under ~/.config and ~/.local/share, using your configured XDG folders if they differ. For Flathub, keep ~/.var/app/org.freeorion.FreeOrion. Also keep any separate save directory you chose in the game.
