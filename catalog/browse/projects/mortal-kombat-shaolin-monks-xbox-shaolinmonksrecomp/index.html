Do not replace this check with a title-name assumption or mismatch bypass. Finish upstream game selection/validation before attachment.

  2. Keep the complete Windows package

    The inspected official 0.4.1 Windows x64 ZIP contains AMD64 OpenShao.exe and matching resources/notices. Upstream accepts ISO/XISO or complete extracted folders in place; ZIP import is a separate upstream preparation operation. Keep the selected source at its remembered location. No original, archive importer, compiler, helper or game is obtained or executed by this guide.

  3. Add the player with its saved original-file selection

    After setup, select OpenShao.exe, set the complete extracted package directory as working directory and use the documented --no-launcher argument. Review the intent and request Play separately. The host uses its remembered game-source.toml selection and the linked game; finish any missing/invalid-source prompt, update, mod installation or restart upstream before retrying. Mortal Kombat II and The Suffering demo are explicitly unsupported; this guide does not admit them.

  4. Preserve data, saves and old folder selections

    Normally keep %LOCALAPPDATA%/OpenShao for settings.toml, game-source.toml, paths.toml, logs, cache, crashes, reports and mods, and the actual Windows Saved Games/OpenShao directory for saves. Known folders may be relocated. The Files page can move data and saves independently; an existing --data-dir, --save-dir or --portable-saves changes the layout. Preserve every actual root, locator, original and older named folder before the first 0.3+ startup: upstream can move eligible legacy data/saves and rewrite their paths. This guide performs no migration, restore, backup or deletion.

  5. Check permissions before changing your copy

    Retain the GPL-2.0-or-later project notice, exact XboxXBERecomp MIT and all SDL, font, renderer, Lua and other component notices. They do not license original game recordings, discs or separate Portuguese/mod packages. The upstream launcher owns update/download/restart and optional content. Setup notes
Play and update through the v0.5.1 upstream launcher
Extract the package and open OpenShao.exe on Windows or OpenShao on Linux. Select your own supported USA or Europe Xbox game files, keep them in place and use Play from the launcher. The upstream launcher owns updates. Its Files page shows the actual data and save paths. Linux normally uses ~/.local/share/OpenShao/saves. Windows uses Saved Games/OpenShao unless relocated.
Check the v0.5.1 Linux requirements
Use glibc 2.38 or later, an x64 CPU with SSE4.2 and POPCNT, and Vulkan 1.2 with dynamic rendering and timeline semaphores. Install your system’s libcurl for mod and update downloads.
