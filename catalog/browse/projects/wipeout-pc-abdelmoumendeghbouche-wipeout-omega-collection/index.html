Setup

  1. Check the required game files

    Use your own PS4 WipEout Omega Collection dump. The README names USA CUSA07671 base 01.00 with update 01.07 as its development target; it also names European CUSA05670 without specifying a version. Merge your own base and update files or supply GOW3_PATCH_DIR as documented. GoldHEN folder dumps are also supported by the instructions. The runtime reads your eboot.bin and game files and links your libc, Fios2 and NpToolkit2. One executable serves 2048, HD and Fury. Exact supported executable and asset fingerprints are not established.

  2. Follow upstream setup

    Upstream README declares wipeout-windows.zip from Releases. Extract it, run WipEout.exe and select the owned game folder containing eboot.bin. Supply the matching owned base/update data as documented; runtime continues reading original files. Windows source build uses MSYS2 CLANG64/Python and upstream build.sh; Linux has a source-build route without a package or stated CPU matrix. No release asset was downloaded or verified. This manual discovery route is not managed acquisition or runtime qualification.
