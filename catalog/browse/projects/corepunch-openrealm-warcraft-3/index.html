Setup

  1. Add your own Warcraft III files

    Copy war3.mpq and War3Local.mpq, plus War3x.mpq and War3xLocal.mpq for The Frozen Throne, and any loose Maps folder from your own classic Warcraft III installation into one data folder for OpenRealm. Keep your original installation separately.

  2. Use a copy you manage yourself

    Extract the upstream alpha and keep its libraries and share directory. Start openwarcraft3.exe on Windows or bin/openwarcraft3 on Linux and Intel Mac with -data followed by the quoted path to your Warcraft III files, then -tft for The Frozen Throne or -roc for Reign of Chaos. Linux needs SDL2, glibc 2.38 or later and your distribution’s OpenGL, VA-API, VDPAU and OpenCL loader libraries. The Intel Mac executable needs macOS 15 or later and SDL2 compatibility libraries under /usr/local/opt/sdl2-compat.

  3. Use the publisher’s x86-64 Flatpak

    On Linux you can install the packaged OpenRealm Flatpak with the publisher’s instructions and the Freedesktop 25.08 runtime. Open it and select your Warcraft III folder through the file chooser. Choose whether to add an optional Steam shortcut when asked.

Limitations and evidence

  • This guide covers Warcraft III. The alpha package also includes development resources for other Blizzard games.
  • The Windows alpha includes SDL2, libepoxy and zlib libraries without their licence notices. The Windows and Linux alphas include the Epic Online Services SDK with the publisher’s online-service configuration for optional online play.
