Setup

  1. Supply the original iOS package

    Keep your permitted original Doom 2 RPG.ipa beside DoomIIRPG.exe, using that exact filename. This player reads the iOS package; BREW/J2ME rendering or cheat descriptions do not establish alternate game-data support.

  2. Complete the Windows prerequisites

    Extract the complete Windows ZIP into a separate working folder. Upstream requires OpenAL 1.1 on Windows; use its documented runtime installation if it is missing.

  3. Select the player and keep your saves

    Finish setup with DoomIIRPG.exe and the same folder, then choose Play.

  4. Add the game and manage your files

    Register the real Windows player with its matching working directory and separate literal arguments; do not select a converter, installer or updater as the game player. Complete any original-data or prerequisite setup deliberately through upstream instructions. Registration does not perform or authenticate that preparation, and Play is a separate explicit action.
