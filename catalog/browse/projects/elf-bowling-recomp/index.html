Setup

  1. Select the unmodified original

    Use your own 1,130,496-byte Elf Bowling.exe from the 1999 release, and keep your original separately. On first start the player asks you to choose it, checks its SHA-256 and keeps a copy in its app profile.

  2. Choose the upstream player

    On Linux x64 with glibc 2.38 or later, use the v1.1 AppImage. Set PORT_FULLSCREEN=0 to start in a window. For Windows x64, choose v1.0 in the release picker, extract the full ZIP, and run elfbowl.exe with its bundled libraries. In a copy you manage yourself, you can also put the original next to the player or point ELFBOWL_EXE to it.

  3. Use the separate Android or Mac setup

    The v1.0 release has an Android APK for ARM64 and x64. It uses Android’s file picker for the original. The upstream Mac instructions build from source with SDL2 and SDL2_ttf. The publisher supplies no Mac or Linux ARM64 package.

  4. Keep the app profile

    Preserve the NStorm/Elf Bowling profile before replacing the upstream player. It is normally under XDG_DATA_HOME or ~/.local/share on Linux, and under %APPDATA% on Windows. Android keeps its app files separately. Keep any optional locally generated artwork with the copy that uses it.

Limitations and evidence

  • The project has not published a license for its engine source. The original game is supplied separately.
