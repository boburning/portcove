Setup

  1. Set up the Windows ZIP

    Choose the Full ZIP from the official release. Extract it to a writable folder and start the bundled 32-bit srb2win.exe. Keep the PK3 files, models, and DLLs beside the game.

  2. Install on Linux

    Install org.srb2.SRB2 from Flathub on x86-64 or ARM64, then open Sonic Robo Blast 2 from your application menu.

  3. Install the Mac app

    Open the official Mac disk image and copy Sonic Robo Blast 2.app to Applications. The app includes a universal executable for Intel and Apple Silicon. Start the copy in Applications.

Setup notes
Find saves, settings, and add-ons
Windows portable copies normally write beside srb2win.exe. Preserve the actual profile if you use -home or an existing profile elsewhere. The Mac app uses ~/srb2. The Flatpak profile is ~/.var/app/org.srb2.SRB2/.srb2. Keep the srb2sav*.ssg slots, gamedata.dat, config.cfg, and your add-ons.
Check Android availability
The upstream Android port was discontinued. Older community Android releases are archived separately at SRB2-Mobile/SRB2-Android and may have different saves, controls, and compatibility from the desktop release.

Limitations and evidence

  • Close the game before copying saves, settings, or add-ons. Keep your existing profile until the replacement opens your save.
