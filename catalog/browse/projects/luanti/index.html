Setup

  1. Start the complete desktop package

    On Windows, extract the complete portable ZIP into a writable folder and start bin/luanti.exe. On Mac, choose the Intel or Apple Silicon ZIP that matches your computer and open the complete luanti.app. Check the publisher’s releases for future ZIPs.

  2. Install Luanti on Linux

    Install org.luanti.luanti from Flathub on x86-64 or ARM64, or use your distribution’s Luanti package. Run the installed launcher and update it with the same package manager.

  3. Choose a game and create a world

    Luanti supplies the engine. Install a game such as Minetest Game from ContentDB, or put a compatible game you already have in the user games folder. Select it in Start Game, choose New to create a world, then choose Play Game.

  4. Preserve the user folder you play from

    In About, choose Open User Data Directory and keep that entire folder, including worlds, games, mods, textures, mod data and minetest.conf. The Windows portable ZIP uses its top-level folder. Installed Windows typically uses %APPDATA%/Minetest. On Mac retain the application’s Contents/User folder or ~/Library/Application Support/minetest, whichever it uses. Native Linux normally uses ~/.minetest and the current Flatpak uses ~/.var/app/org.luanti.luanti/.minetest. If switching from the older Minetest Flatpak, back up ~/.var/app/net.minetest.Minetest/.minetest first. Keep any separate directory you chose through LUANTI_USER_PATH or the older MINETEST_USER_PATH.

Setup notes
Use the Android build for your device
Follow the official Android downloads or choose the APK for your device. Upstream provides ARM64, ARMv7, x86 and x86-64 builds. Android and your package source own installation and updates. Before replacing or uninstalling the app, preserve the worlds and other data under Android/data/net.minetest.minetest/files/Minetest.
