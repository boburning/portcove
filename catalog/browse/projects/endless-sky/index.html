Setup

  1. Install and play on Windows or Linux

    Portcove installs the publisher’s Windows x64 ZIP or Linux x64 AppImage. On Linux, the AppImage needs FUSE support. Select Play to use your normal Endless Sky profile.

  2. Choose a desktop package

    On Windows, extract the whole ZIP for your system and open Endless Sky.exe. On Linux x86-64, allow the publisher AppImage to run as a program and open it, or use your distribution’s package. Flathub also offers Linux x86-64 and ARM64. On Mac, open the publisher disk image and copy Endless Sky.app to Applications.

  3. Start a pilot

    Choose New Pilot, then select a starting scenario. The game saves progress while you are landed.

Limitations and evidence

  • Before updating or moving the game, close it and copy the whole player-data folder, including saves, pilots, preferences, and plugins.
