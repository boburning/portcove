Setup

  1. Keep a permitted prepared copy

    For an already obtained permitted copy, follow this fork’s on-device Import Game flow with your own complete Hollow Knight GOG/Steam v1.5.12620 Voidheart folder and its matching release patch. The folder contains Hollow Knight_Data or hollow_knight_Data. Choose the game folder and patch, then Build game data and START GAME. Do not substitute another game version or describe the published patch as containing no game content.

  2. Keep your data when changing versions

    The upstream Save Files page exports/imports slots; saves use Android/data/igawa6.dualsouls/files and imports retain the previous slot as .bak. Preserve an export before changing the app. Upstream says to update over the same signed app and never uninstall first: uninstall or Clear storage deletes saves and built data. A required data rebuild uses the matching new patch; PC save wrapping is not directly compatible.
