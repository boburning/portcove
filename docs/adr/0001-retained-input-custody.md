# Retain declared inputs without turning copies into execution authority

Retained evidence uses private staging, verified no-clobber publication and content identities in a dedicated non-cache store. This costs persistent disk space but preserves observations after checkout changes; cleanup is explicit, with no automatic eviction. Only declared non-secret inputs are captured. Historical version-2 receipts remain observations at their original time, and later retention is a new observation.

Supported standalone verification executables consume retained artifacts. Path-sensitive or unestablished layouts keep their original execution path with cooperative content verification and explicit limitations. Source helpers are checked by the trusted parent before target import, at application/driver launch boundaries and after execution; already loaded verifier sources are separately labeled observations. Neither copies nor matching metadata establish immutable execution. Original paths/bytes are never rewritten to manufacture custody.
