# Release records

Versioned release notes and dated readiness snapshots in this directory retain
the state reviewed for their original release commit. Do not rewrite them after
publication. They do not become the planning authority after generation. See
[`docs/RELEASING.md`](../RELEASING.md) and generate a new snapshot when the
release state changes.
