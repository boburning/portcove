## Intentional differences from the reference

- The approved reference supplies composition and interaction direction; production uses the existing Base UI/Tailwind/semantic-token stack. Flat tonal hero treatment follows the maintained no-component-gradient contract.
- Readiness, tested gameplay, setup statements, archive completion, prepared runtime and active installation remain different facts. Unknown/unavailable inputs are visible rather than simulated as success.
- The reviewed external-to-managed transition is atomic. There is no pretend separately prepared managed copy, switch-back or restore route without its own durable Core identity and recovery contract.
- No unlicensed third-party artwork is packaged. Genuine admitted media requires identity/edition, digest/dimensions, provenance and rights evidence; absent media reserves no gallery, and local overrides keep their ownership.
- Required original-file/BIOS choices, technical evidence, native confirmations and recovery controls remain reachable even where the reference omits them. Declaration/grouping metadata never becomes operational authority.
