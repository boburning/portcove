complete setup guides and 289 other entries. Exact shared paragraphs were reused

requires those labels to agree. Those cosmetic proposals were declined rather

are retained in the final value hashes. Recommendation information is called a
test result only where the recorded evidence kind establishes a test.

## Validation boundaries

Existing component, browser and CLI/Core contracts cover source checks, partial
scan results, external installation review, downloaded/prepared/current updates,
notice preferences, incomplete/stale backups, restore/deletion/uninstall,
cancelled versus committed-but-unrefreshed outcomes, library information export,
Steam repair and diagnostic privacy. The settings review additionally checks
named choices, boolean labels and absent saved values through real controls.
Existing narrow/enlarged and accessibility fixtures remain the rendering route.
Native confirmation text is traced to its handler; that source inspection does
not establish an observed native prompt or game session.

Initial local failures are retained under ignored `work/bt` and task logs. A
baseline settings focus failure was reproduced before using real browser input
in the fixture; focus/confirmation assertions remain. Browser fixtures require a
stable candidate: source changes while queued are refused, and editing a running
Vite input invalidates that run. Passing rendered fixtures or hosted checks does
not establish native, installed-package, gameplay, physical-control or human
comprehension acceptance. No such acceptance is added by this editorial pass.
