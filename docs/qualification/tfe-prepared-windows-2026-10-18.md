It creates a complete valid pilot, rather than an empty placeholder. It refuses to overwrite an existing file. Run it only for the selected fresh runtime; Core does not run it or seed player state.

```powershell
$runtimeRoot = 'C:\Games\TFE-1.22.420' # Your prepared runtime folder
$pilotPath = Join-Path $runtimeRoot 'DARKPILO.CFG'
$pilotBytes = [byte[]]::new(14943)
[byte[]] $header = 0x50, 0x43, 0x46, 0x12, 0x0E
[Array]::Copy($header, $pilotBytes, $header.Length)
$pilotStream = [IO.File]::Open(
    $pilotPath, [IO.FileMode]::CreateNew,
    [IO.FileAccess]::Write, [IO.FileShare]::None)
try {
    $pilotStream.Write($pilotBytes, 0, $pilotBytes.Length)
    $pilotStream.Flush($true)
} finally {
    $pilotStream.Dispose()
}
if ((Get-FileHash -LiteralPath $pilotPath -Algorithm SHA256).Hash.ToLowerInvariant() -ne
    '8166083311775ebc67d30552575c2130515f6d015253bc82ad7582dc3dd3d913') {
    throw 'Fresh pilot differs; preserve it and investigate before registration.'
}
```
