All four inspected Smash Bros. and Rayman 2 archives carry `assets/ChiaroBold.otf` (SHA-256 `47e8e89d6693882538d1943068f38b6f7334baa91126e5ba71a58cecc408be00`) and `assets/ChiaroNormal.otf` (SHA-256 `36dbd4fee533234dc9fc4c1b0bf55957a813879240804d88106290ba912a356f`). The OpenType notices identify Fontworks Japan and reserve rights. The reviewed releases and tagged package notices supply no applicable grant for those two files. This follows the [existing Portcove Chiaro disposition](gitlab-upstream-handoffs-2026-10-25.md). Wetrix's separate restriction follows its [upstream notices](https://github.com/scottjco/Wetrix_Recomp/blob/6b496f8f9f695003b0f246128eac474aa6aa85da/THIRD_PARTY_NOTICES.md).

WinBack [v0.2.1](https://github.com/RetroPulse03/WinBackRecomp/blob/v0.2.1/src/main/main.cpp) and [v0.2.2](https://github.com/RetroPulse03/WinBackRecomp/blob/v0.2.2/src/main/main.cpp) implement the same wait-for-successor path when `RECOMPLAUNCHER` is present. Their player SHA-256 values are `7303f62845083e9906b3692494db1ec297841644f191142adec15f86876775c9` and `e69d159cc3471f7ef66750e9dbd0445ebe1f2a6b701eca0429ff1748a4e9ce57` respectively. The managed declaration sets that mode and leaves the original-file picker with the game. No Core source profile is implied. The progression fixture uses controlled archives, the actual GitHub resolver and the unchanged authored contract. A fixture copy of the imported ROM represents already prepared state. The result does not supply a native WinBack launch or prove real-save compatibility.
