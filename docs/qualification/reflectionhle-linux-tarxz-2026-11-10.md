# ReflectionHLE Linux x86-64 package

[Issue #2688](https://github.com/boburning/portcove/issues/2688) and the eight sibling ReflectionHLE records (Wolfenstein 3D, Spear of Destiny, Super 3-D Noah's Ark, Keen Dreams, Catacomb 3-D, The Catacomb Abyss, Armageddon and Apocalypse, and BioMenace) gain a managed Linux x86-64 route beside their existing Windows route. One upstream package serves all nine records. The definition lets Portcove download, verify, install, launch and update the official TAR.XZ through the existing managed lifecycle; none of those steps was run with this package. The player still chooses the matching original DOS edition and folder in the upstream launcher; Portcove does not authenticate originals. The existing fixed arguments `-datadir . -cfgdir .` keep configuration and per-version data inside the managed runtime. Existing Windows routes, external profiles and original folders are unchanged and are not imported.

The inspected stable release `release-20260606` Linux asset is `reflectionhle-linux-x86_64-20260606.tar.xz`, 7,993,508 bytes, SHA-256 `90b251d827a53a9842677f4de0b06d26fa049597f47d1775e426129142506420`. The downloaded bytes matched the publisher digest. The archive holds one wrapper folder with nine entries: the `reflectionhle` executable, a GPL text, `libSDL3.so.0.4.10`, `libspeexdsp.so.1.5.2` and four symbolic links to those libraries (`libSDL3.so`, `libSDL3.so.0`, `libspeexdsp.so`, `libspeexdsp.so.1`). Core's TAR reader previously refused all links, so this route needs the shared link handling: each link becomes a regular copy of the file it names, through at most eight links in the same archive, and every other link shape still refuses. Definitions that rely on it declare `release.archive_file_links` and therefore require native capability 13. The executable has `RUNPATH $ORIGIN`, needs glibc 2.29 or newer, and links the bundled SDL3 and speexdsp by soname beside it, so the copies satisfy loading. The executable name is unique in the package. Asset selection uses the version-independent `reflectionhle-linux-x86_64-` and `.tar.xz` pieces, so an ordinary compatible release needs no catalog edit.

These are static package observations. The Linux player was not executed here, and no original DOS data was available for any of the nine games, so launcher behavior, original detection, saves and gameplay are unobserved. The Mac universal package is not offered: its executable sits inside an app bundle, where the fixed `-datadir .` arguments would write into the bundle. Android remains upstream. [Official release](https://github.com/ReflectionHLE/ReflectionHLE/releases/tag/release-20260606).
