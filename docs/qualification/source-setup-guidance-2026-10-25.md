## Offered operation and boundaries

The catalog links each project's maintained source guide and explains the exact
original inputs, preparation and launch output where established. All eighteen
complete GitHub release inventories were empty at the observation cutoff. Their
availability is therefore source-only; this is not a claim that every operation
is unsupported or that future native packages cannot fit an existing capability.

Preparation remains a deliberate upstream action. Read-only discovery does not
invoke scripts, compilers, disc tools or a game. Register only a completed native
player with its actual working directory and arguments, then choose Play
separately. A script's environment is not automatically imported. DOS binaries,
renderer prototypes and code generators are not interchangeable with a native
game. Manual registration may select a prepared output outside a download folder.

External runtime updates, original files, generated data, saves and settings stay
with the player or upstream. Keep a working copy and separate backups. Removing
registration preserves all external files. These routes do not promise managed
Update, Backup, Restore or Rollback. Exact source identity, edition and preparation
requirements remain upstream-owned. Shared Core consent, launch review and
explicit Play behavior are reused unchanged.
