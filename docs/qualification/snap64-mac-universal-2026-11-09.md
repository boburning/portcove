# Snap64 Recomp Mac universal app

[Pokémon Snap #281](https://github.com/boburning/portcove/issues/281) adds managed Intel and Apple Silicon routes to the existing Snap64 Recomp definition. Portcove downloads, verifies, installs, launches and updates the official universal ZIP. The player still supplies their own matching USA cartridge dump. Portcove replaces the runtime; the Mac app has no separate updater. The existing Windows and Linux x86-64 routes keep their own packages. Linux ARM64, the Flatpak and the Android APK remain upstream setup.

The inspected stable v1.1.6 ZIP is GitHub asset 670170561, 12,667,959 bytes, SHA-256 `58da51d88f1b2501575f182767f22f884cca2165351ddea01d3146d4877a5dd4`. The downloaded bytes matched the publisher digest. The archive has one version-named wrapper folder holding `START HERE.txt` and `Snap64Recomp.app`. The app has one file named `Snap64Recomp`, `Contents/MacOS/Snap64Recomp`, with an executable mode. It is a two-architecture Mach-O. The authored executable rule is therefore the file name only, so a successor's changed wrapper folder name needs no catalog edit. The asset rule is the version-independent `macos-universal.zip` suffix.

Upstream's [path source](https://github.com/JackandBeans/Snap64Recomp/blob/v1.1.6/src/paths.cpp) states that `SNAP_DATA_DIR` names the data directory on every platform. The existing declared variable and portable marker therefore keep the original, saves, photos, mods and settings in Portcove's persistent profile rather than `~/Library/Application Support/Snap64 Recomp`. Existing upstream-managed Mac copies are not adopted, moved or deleted.

These are static package observations. Upstream's own notes say the app was run on GitHub-hosted Apple Silicon and Rosetta but not on a physical Mac. Nothing here observes Gatekeeper behavior for a Portcove-downloaded copy, native execution, controller behavior, gameplay or a populated Mac save. Those remain separate acceptance. The app is unsigned by a developer identity, so first-launch consent stays with the player and is described in the guide.
