# Glover-R and Rocket-R Linux AppImages

The official Glover-R v1.0.1 Linux x86-64 AppImage is asset `615812657`, 18,987,512 bytes, SHA-256 `765325f48cbe2fc4646a638faf75d971c7f122980b08b6bdedb148a8513296ca`. The official Rocket-R v.1.0.1 Linux x86-64 AppImage is asset `593934675`, 21,637,624 bytes, SHA-256 `82048c0d7a8ab5555ea5f663cde7cec1563f799913ed390b12d0f6e35d9618ee`. Both downloads matched the publisher bytes and digests. [Glover-R release](https://github.com/ThatGuyMcd/Glover-R/releases/tag/v1.0.1) · [Rocket-R release](https://github.com/ThatGuyMcd/Rocket-R/releases/tag/v.1.0.1)

Both images contain a complete native player and its libraries. The bundled AppRun keeps the working directory, starts the title-specific player synchronously and returns its exit status. The exact files both completed a bounded Linux x86-64 FUSE `--help` run with isolated HOME, XDG paths and TMPDIR. Each log identifies its own bundled player and exit status zero. This observation covers startup, process lifetime and diagnostic writes. Original selection, rendering, controller behavior and gameplay remain separate.

The shared type-2 runtime creates its mount under TMPDIR and can override HOME and XDG_CONFIG_HOME through adjacent portable folders. The native player uses the selected external configuration directory for settings, saves, crash logs and mods. AppRun uses the separate state directory for `appimage-launch.log` and falls back to `/tmp/<title>-<uid>` if its primary state directory cannot be created. Core checks these coordinates and safely reserves the fallback before spawn. [Bundled AppImage runtime source](https://github.com/AppImage/type2-runtime/blob/dd6cebedcbddde9c82f89b011e8e1d40b6e43868/src/runtime/runtime.c)

Glover uses the player's own USA revision 0 8 MiB NGVE ROM, canonical SHA-1 `270be17b3c8da9b88a7b99c2a545b0bce16837f4`. Rocket uses its own US 12 MiB NSUE ROM, canonical SHA-1 `622d71a44da0b81ea68092cac9198c66154a4f4a`. Each upstream launcher validates its own original. The Windows package coordinates and distinct in-folder fallback directories retain their existing contracts. The direct Linux route uses a stable asset pattern and keeps the original and external profile with the player. Portable wrappers, Steam Deck packages and Rocket Linux ARM64 remain separate upstream setup.

Rocket's Android ARM64 APK is asset `593934373`, 10,428,559 bytes, SHA-256 `b722905b73e40238ac46d9e227a0052beec7f633374ee85c85cb86facca7af87`. ZIP integrity and the arm64-v8a payload were checked. The tagged picker copies the player's original into private app files and the player and mod UI share the app-private configuration. This is setup guidance based on the package and source. Android execution, device acceptance and update-signing compatibility remain separate.
