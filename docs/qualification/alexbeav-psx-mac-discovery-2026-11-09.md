# Alexbeav PSX Mac setup package discovery

On November 9, 2026, the latest stable GitHub releases for these 28 existing listings each published a distinct Mac Intel and Apple Silicon ZIP. The catalog now selects each archive by its existing title prefix and exact architecture suffix. The release links record the reviewed tags and published asset identities. Publisher metadata included a positive byte count and SHA-256 for every archive.

These are upstream setup kits. Keep the extracted kit together and follow its setup instructions for build tools, original discs and any required BIOS. The catalog entries describe discovery and package selection. Managed installation and native qualification have separate evidence requirements.

Both Mac archives for Apocalypse, Fighting Force, MediEvil and Parasite Eve were independently hashed and inspected. Their setup hosts are Mach-O executables for the published architecture. The bundled instructions name the tools and game inputs. Apocalypse needs the exact European BIOS, Fighting Force and MediEvil require SCPH-1001, and Parasite Eve documents its two-disc set and its OpenBIOS option. Runtime compilation, gameplay and disc switching require their own observations.
